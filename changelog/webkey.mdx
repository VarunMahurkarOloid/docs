**Oloid's WebKey** is a browser-based application that enables Multi-factor authentication(MFA) of users using physical identity factors (like Face, Badge, NFC tags, QR Code, and Pin). This application allows employees to seamlessly log into Workforce/ HRMS systems without entering a Username and Password.

## Webkey Application - Identity Providers (IDP) & Single Sign-On (SSO)

### PingOne Settings for Oloid SSO

Admin can configure required PingOne settings to enable secure single sign-on (SSO) between PingOne and Oloid applications.

This update improves integration and simplifies the SSO configuration.

[Read the full guide ›](https://oloid.help/en/articles/8727716-pingone-settings-for-oloid-sso)

### Configure PingOne SSO in Tenant Admin Portal

Admin can configure PingOne SSO directly from the Tenant Admin Portal to allow users to authenticate using PingOne credentials.

This update streamlines SSO setup and reduces configuration effort.

[Read the full guide ›](https://oloid.help/en/articles/10316179-how-to-configure-pingone-sso-in-tenant-admin-portal)

### Create IDP Profile for OIDC – Entra ID

Admin can now create an OIDC-based Entra ID identity provider profile in the Tenant Admin Portal to support passwordless authentication.

### Create IDP Profile for SAML in Tenant Admin Portal

Admin can now create a SAML-based identity provider profile in the Tenant Admin Portal to support passwordless authentication.

[Read the full guide ›](https://oloid.help/en/articles/12808717-how-to-create-idp-profile-for-security-assertion-markup-language-saml-in-the-tenant-admin-portal)

### Configure SAML IDP in Okta Admin Console

Admin can now configure Okta as a SAML identity provider by setting up required SAML parameters in the Okta Admin Console for Oloid integration.

[Read the full guide ›](https://oloid.help/en/articles/12838654-how-to-configure-security-assertion-markup-language-saml-idp-in-okta-admin-console)

### Integrate Oloid Tenant with PingOne OIDC Instance

[Read the full guide ›](https://oloid.help/en/articles/10796370-integrating-oloid-tenant-to-your-pingone-oidc-instance)

# RELEASE UPDATE - AUGUST 2025

## What's New?

## Webkey Application

- **Manual Face Capture Now Available in WebKey**  
  Tenant Admins can now enable manual capture for facial recognition in the WebKey application. Instead of the app automatically capturing the face, users can click the camera icon, or press **Enter** or **Spacebar**, to take a photo.  
  [Read the full guide ›](https://oloid.help/en/articles/10454903-webkey-platform-configuration-for-manual-capture-of-face?utm_source=chatgpt.com)

- **Video Tutorial Released for Manual Face Capture Setup**  
  To assist with enabling manual face capture, a video tutorial has been published. It walks through the same configuration process used in the Tenant Admin Portal for turning the manual capture feature on.  
  [Watch the tutorial ›](https://oloid.help/en/articles/12009765-webkey-platform-configuration-for-manual-capture-of-face-video-tutorial?utm_source=chatgpt.com)

- **Custom User-Agent Support Added to WebKey**  
  WebKey now supports configuring a custom user-agent string for logins using custom or non-default browsers. This includes options to specify the user-agent and to manage devices individually or in bulk.  
  [Read the full guide ›](https://oloid.help/en/articles/11659241-how-to-configure-custom-user-agent-in-webkey-application?utm_source=chatgpt.com)

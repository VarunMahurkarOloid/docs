## ![:loudspeaker:](/images/11583623/3a26447f2f70.png) **_New Video Tutorial Released | Add a Group to a Vault Shared Password_**

​**Content Updated**: 11 June 2026  
We've just released a **new video tutorial** that walks through how to **add a group to a Vault Shared Password** in the Tenant Admin Portal.  
This feature allows admins to grant access to a shared credential for multiple users at once. Once a group is assigned, all users within that group inherit access to the shared password based on the configured authentication workflows.  
​

![:white_check_mark:](/images/11583623/d40dcbd716ba.png) **_Prerequisites_**  
• Access to a Tenant Admin account  
• A Vault Shared Password must already be created  
​

![:bulb:](/images/11583623/f1826257146f.png)**_Good to Know_**  
• Up to **five groups** can be assigned to a single Vault Shared Password  
• Users within the assigned groups can securely access the shared credential based on the configured workflows  
​

# RELEASE UPDATE - JUNE 2026

## What's New?

## Oloid Connect

latest version - 1.23.7 (12)

### New Features:

- Offline On-Device Liveness Support – Added support for on-device liveness detection on iPads without a TrueDepth camera, enabling secure offline authentication.

- Enhanced Job Code Processing – Improved Job Code handling for greater accuracy and a smoother user experience.

- User Consent Workflow – Introduced a new consent capture flow within transactions to support compliance and user acknowledgment requirements.

- Screen Saver Feature – Added a configurable screen saver that activates when the device is idle. This helps prevent unnecessary face captures of individuals passing by the device when no user is actively performing a transaction.

- Enhanced Splash Screen Experience – Added descriptor download progress indicators during application startup, providing greater visibility into initialization status.

---

### Improvements & Enhancements:

- Health Monitoring Enhancements – Improved health monitoring capabilities for increased reliability, diagnostics, and operational visibility.

- User Synchronization Improvements – Resolved user synchronization issues to provide more consistent and reliable data updates across devices.

- Performance & Stability Optimizations – Implemented various performance improvements and stability enhancements to improve overall application responsiveness.

- General Bug Fixes – Addressed multiple issues and introduced backend enhancements to deliver a more seamless user experience.

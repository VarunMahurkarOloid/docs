**Oloid's Windows login** is a secure and user-friendly application that allows Enterprise employees to log into Windows Laptops/Desktops/Servers and Workforce/HRMS Platforms using physical identity factors (like Face, Badge, NFC tags, and PIN).

# RELEASE UPDATE - JANUARY 2026

latest version (1.0.15)

## What's New?

### Migration to .NET 8 for Windows Login

Oloid’s Windows Login app has been migrated from .NET 6 to .NET 8.

### Credential Updates and Enrollment: Allow login via local credentials.

Users can now sign in to Windows using their local Windows credentials through the Oloid Windows Login app. To enable this capability, turn on Allow Login Through Local Credentials in the Tenant Admin Portal.

[Read the full guide ›](https://oloid.help/en/articles/13615407-windows-login-how-to-configure-allow-login-through-local-credentials)

### MFA Credential - Password as Second Factor: Enable password as a second factor for Multi-Factor Authentication (MFA).

Oloid Windows Login now supports Password as a second factor for Multi-Factor Authentication (MFA). Administrators can configure password verification alongside primary credentials such as Face, PIN, Badge, or NFC, enabling an additional layer of security while maintaining a seamless Windows sign-in experience

### Face and PIN as Second Factor: Allow face enrollment followed by a PIN for MFA (toggle option).

Users can now enroll their face and then set a PIN to use PIN as a second factor after face recognition. To enable this capability, turn on Enable Face followed by PIN MFA in the Tenant Admin Portal.

[Read the full guide ›](https://oloid.help/en/articles/13644652-windows-login-how-to-enable-face-followed-by-pin-mfa)

### Windows App - Enable Windows Default Domain: Allow the use of the default Windows domain for authentication

The Oloid Windows Login app now supports the use of the default Windows domain for authentication. To enable this capability, turn on Enable Windows default domain in the Tenant Admin Portal.

[Read the full guide ›](https://oloid.help/en/articles/12266470-how-to-enable-windows-default-domain-for-windows-login-application-in-the-tenant-admin-portal)

### Offline NFC

### Enroll NFC SDK Mode

Oloid Windows Login now supports NFC SDK Mode enrollment, allowing users to register NFC credentials directly through the Windows Login app using SDK-based workflows for secure and seamless NFC credential enrollment.

[Read the full guide ›](https://oloid.help/en/articles/10002126-how-to-enroll-nfc-through-windows-login-app)

### Adaptive Pin

Admins can enable and configure Adaptive PIN for the Windows Login application from the Tenant Admin Portal, allowing PIN to be used as a secure secondary factor with supported primary authenticators. Adaptive PIN reduces repeated authentication prompts by intelligently skipping PIN verification for a configurable duration after successful sign-in.

[Read the full guide ›](https://oloid.help/en/articles/11484425-how-to-enable-and-configure-pin-credential-for-windows-login-application-in-the-tenant-admin-portal?utm_source=chatgpt.com)

### Adaptive Password

Oloid Windows Login now supports Adaptive Password, allowing administrators to enable the Password as Adaptive Multi-Factor option to skip password prompts after a successful login using Badge, QR Code, or NFC for a defined duration. Admins can configure the Adaptive Factor Duration to control how long the password prompt is suppressed after a successful authentication.

### Epic Fast switching

Oloid Windows Login now supports Epic Fast Switching, enabling users to quickly authenticate in the Epic Portal using username and Vault password, allowing faster and seamless user switching during Epic workflows.

### Epic SAML Login

Oloid Windows Login now supports Epic SAML Login, allowing users to authenticate in the Epic Portal using username and Token ID through SAML-based authentication.

**Pre-requisite**

The Supervisor app is already paired. Contact your Admin for the passcode.

For details, refer[How to create device-admin passcode for Supervisor App](/administration/device-admin-apps/windows-login-how-to-create-device-admin-passcode-for-supervisor-app).

To disable passwordless:

1. Double-click on **Supervisor** app.The app opens.
2. Do the following:Click **More Options** > **Disable Passwordless**. ![](/images/9153890/5903a4f03f61.png) The **Disable Passwordless** screen is displayed.Enter the **Device-Admin Passcode**.**Note**: The Device-Admin Passcode is created in the Oloid Portal. ![](/images/9153890/4f8f0a4c5d54.png) Click **Disable Passwordless**. ![](/images/9153890/e6a4f193fc13.png) The Passwordless is disabled successfully. ![](/images/9153890/5f5b00b5643f.png) The Supervisor app is no longer available on the Windows lock screen.

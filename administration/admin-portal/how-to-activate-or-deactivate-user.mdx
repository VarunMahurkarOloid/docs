Steps to Activate or Deactivate User:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Click user name to edit. ![Image](/images/8344346/c68110c4c870.png) The user details page is displayed. ![](/images/8344346/7cc7ae6d3fd7.png)
4. Do one of the following on **Action** dropdown:Select **Deactivate**. ![Image](/images/8344346/eb45dd715767.png) **Note**: **Deactivate** button is visible for active users in the action dropdown.The**De-activate User**pop-up box is displayed. ![](/images/8344346/c5f2cf7b1798.png) Click **Confirm De-activate**.The user status is changed from active to inactive. ![Image](/images/8344346/ecc2fe8534d7.png) Select **Activate**. ![Image](/images/8344346/26aeb5fcb6c3.png) The **Activate User**pop-up box is displayed. ![](/images/8344346/fd821f46bc3c.png) Click **Confirm Activate**.The user status is changed from inactive to active. ![Image](/images/8344346/d4e0278cd972.png)

## Introduction

This document provides instructions to map user to a group in the Tenant Admin Portal. You can add user by adding a group to a user or by adding user to a group.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- Ensure that the required user(s) and group(s) is(are) available in the Tenant Admin Portal.

## Steps to Map User to a Group

You can map user to a group using either of the following methods:

- [Add Group to a User](#h_8b919ea512)
- [Add a User(s) to a Group](#h_01d1efe451)

## Steps to Add a Group to a User

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Directory** on the left menu panel. ![](/images/8267045/e0987d0fcc97.png) The **Users**screen is displayed.
3. Click the preferred user name. ![](/images/8267045/d47587424482.png) The **User Details** page is displayed. ![](/images/8267045/c9c9537f09bc.png)
4. Click **Groups**> **+** **Add Group**. ![](/images/8267045/8cc4b670c901.png) The **Add Group** pop-up box is displayed.
5. Select the required group from the drop-down list and click **Add**.**Note:** If required, you can add a user to multiple groups. ![](/images/8267045/35aaf4192e74.png)
6. Click **Save**.The group is added and listed on the Groups tab. ![](/images/8267045/b01ba0bbbee5.png)

## Steps to Add User(s) to a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Groups** on the left panel menu. ![](/images/8267045/1f65ec6ced12.png) The **Groups** page is displayed.
3. Click the preferred group. ![](/images/8267045/9e4153afd099.png) The **Group Details** page is displayed. ![](/images/8267045/49362e6f3297.png)
4. Click **Users**> **+ Add User**. ![](/images/8267045/06ff18fc7401.png) The **Add User**pop-up box is displayed.
5. Enter the **user’s Full Name, Primary ID, OloID,** or **Employee ID**, and click **Add**.**Note:** If needed, you can add multiple users to a Group. ![](/images/8267045/8919c3cde12b.png) The user is added successfully and listed on the **Group** tab. ![](/images/8267045/c708b25c9b88.png) Note: For instructions to map users to a group in bulk, see[How to map users to Group in bulk](/administration/admin-portal/how-to-map-users-to-group-in-bulk).

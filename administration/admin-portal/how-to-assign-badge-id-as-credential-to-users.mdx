### Introduction

This document provides step-by-step instructions to assign Badge ID as a credential to users in the Tenant Admin Portal, including how to set the Wiegand format and link the Badge ID to a user’s profile.

### Steps to assign Badge:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![Image](/images/11058549/6142e01fd801.png) The **Users**page is displayed.
3. Click user name to edit. ![Image](/images/11058549/d626c453e0da.png) The **user details** page is displayed. ![](/images/11058549/83f0439c8704.png)
4. Do one of the following:Go to**Credentials**tab > **Badge**> **+** **Assign Badge**. ![Image](/images/8379462/e1d3618c6af8.png) Go to **Assign Credential**> **Assign Badge**. ![Image](/images/8379462/66fae431c3ed.png) The **Assign Badge** pop-up box is displayed. ![](/images/8379462/702141dc06b2.png)
5. Enter **Badge ID** and select **Wiegand Format**.
6. Click **Assign**.The badge ID is assigned and listed on the **Badge** tab. ![Image](/images/8379462/66a65278c328.png)

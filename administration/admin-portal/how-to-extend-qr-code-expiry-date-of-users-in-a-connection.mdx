Steps to extend QR Code expiry date for a Connection:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory**on the left menu panel. ![Image](/images/8479549/6142e01fd801.png) The **Users** page is displayed.
3. Go to **Action**> **Extend QR Code Expiry Date**. ![Image](/images/8479549/e4570d953bf9.png) The **Extend QR Code** pop-up box is displayed. ![](/images/8479549/c60bd6c40e6d.png)
4. On the pop-up box, do the following:Select a connection from the **Connection** dropdown list.Under **QR Code Validity** field adjust the date and time from the calendar icon.Under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary. (**optional**)Click **Assign**.The QR Code is successfully extended for users in the selected connection. The QR Code summary of these users is shared over email ID(s) and is available for download in the attachments.**Note**: The QR Code summary is shared with you once a day. ![](/images/8479549/8fe30d790b16.png) Video TutorialWatch the video[How to extend QR Code expiry date of Users in a Connection-Video Tutorial](/passwordless/windows/supervisor/how-to-extend-qr-code-expiry-date-of-users-in-a-connection-video-tutorial)

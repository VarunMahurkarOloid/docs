## Introduction

This document provides step-by-step instructions to log in to the Tenant Admin Portal using the Microsoft SSO login option. Microsoft Single Sign-On (SSO) allows users to securely access the Tenant Admin Portal using their Microsoft credentials without requiring a separate Oloid password.

## Prerequisites

- You should be a user in the Tenant Admin Portal with **Admin/Supervisor** role.
- The Microsoft credential (user email ID) must be added to the user details page.

## Steps to Log in using Microsoft SSO

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar > press **Enter** on your keyboard.The Oloid LOGIN page is displayed.
3. Click **Login with SSO.** ![](/images/11136469/8be0bc89f301.png) The configured Log in options are displayed.
4. Click **Continue with Microsoft** to log in to Oloid Platform with Microsoft SSO. ![](/images/8727230/b7999dab69bf.png) The **Sign in** pop-up box is displayed.
5. Enter your **Microsoft ID** > click **Next**. ​**Note:** If Microsoft SSO is configured with UPN, enter your UPN to **log in** directly. ![](/images/8727230/39102d95fb03.png) **Enter your password** pop up box is displayed.
6. Enter **Password** in the Password field > Click **Next**. ![](/images/8727230/b4da026afea6.png) You are logged in to the Tenant Admin Portal using Microsoft SSO successfully. ![](/images/8727230/4001a99b02e0.png)

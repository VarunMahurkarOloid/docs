Steps to delete QR Code for a Connection:

1. Log in to the **Tenant Admin** **Portal**.
2. On the home page of the portal, click **Directory**on the left menu panel. ![Image](/images/8488504/6142e01fd801.png) The **Users** page is displayed.
3. Select user(s) to delete QR Code.
4. Go to **Action > Delete QR Code Credential**. ![Image](/images/8488504/a197063b03e8.png) The **Delete QR Code Credential**pop-up box is displayed.
5. On the pop-up box, do the following: ![](/images/8488504/5abadd6124cb.png) Enter user email ID under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary. (**optional**)Click **Delete**.The QR Code credential is successfully deleted for the users. The QR Code summary of these users is shared over email ID(s). ![](/images/8488504/1b5d5dd22020.png)

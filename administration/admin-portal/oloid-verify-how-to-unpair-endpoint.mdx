## Introduction

This document explains how to unpair an endpoint using the **Oloid Verify**application.

## Prerequisites

- The Oloid Verify endpoint must be paired. For more, refer to [Oloid Verify - How to Pair an Endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint)
- You must have Tenant Admin or Supervisor access.

## Steps to Unpair Endpoint

1. Launch the **Oloid Verify App**.**Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [Oloid Verify - How to Pair an Endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint) ![](/images/16159090/f24f3c291c0f.png)
2. Log in to Admin mode. For more refer to [Oloid Verify - How to Log In to Admin Mode as an Admin or Supervisor](/administration/admin-portal/oloid-verify-how-to-log-in-to-admin-mode-as-an-admin-or-supervisor)The **Users** page is displayed.
3. Tap **Settings**. ![](/images/16159090/beba10f08af5.png) The **Settings** page is displayed.
4. Tap **Unpair**. ![](/images/16159090/6121b5e06523.png) The confirmation pop-up box is displayed.
5. Tap **Yes.** ![](/images/16159090/a44672cfc523.png) The Oloid Verify Endpoint is unpaired successfully. ![](/images/16159090/6aceb4128061.png) Keywords|Oloid Verify Unpair Endpoint | Unpair Oloid Verify Endpoint | Oloid Verify Endpoint|

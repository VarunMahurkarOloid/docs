Steps to assign Shared Credential:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.![](/images/12275469/b9c707f0a9b1.png)The **Users** page is displayed.
3. Select **Shared Credentials**on the left menu panel.![](/images/8423861/c2da54edb1f6.png)The **Shared Credentials** page is displayed.
4. Select credential name(s) to assign users.![](/images/8504762/df8f4397a235.png)
5. Select **+ Assign Credentials to Users**.The **Assign Users to Credentials** pop-up box is displayed.![](/images/8504762/df09fc1441da.png)
6. On the pop-up box, enter user name(s) in the **Users**dropdown list.
7. Select **Assign**.The shared password is successfully assigned among the selected users.

## Introduction

The Face credential feature in the Tenant Admin Portal allows admin to enable face recognition for the Web Key application. Once enabled, users can log in to Web Key application through face recognition.

## Prerequisites

- You must have a Tenant Admin Account.
- The **Webkey application** must be created and configured in the Tenant Admin Portal. For more, refer to[How to create and configure WebKey Application in Tenant Admin Portal](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Steps to configure face credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit. ![](/images/10800135/d5355d7e2b98.png) The application page is displayed. ![](/images/10800566/ad0013bfda59.png)
3. Go to **Authenticator tab**> Turn on**Face** toggle. ![](/images/11493834/d97a1138759c.png) The **Advanced Settings** page is displayed. ![](/images/11493834/838080b85ff2.png)
4. Enable **Take Re-consent During Transactions**toggle to to display the re-consent form to users with invalid consent during every face authentication attempt until they successfully re-sign. ![](/images/11493834/6819f6be0551.png)
5. Configure **Face Match Parameters**. ![](/images/11493834/e9ec504732c2.png) Adjust the **Face Match Threshold** slider or enter a value directly into the input box to set the face match threshold value. ![](/images/11476775/f4f631561d2f.png) **Enable Virtual Camera** toggle to to allow third-party virtual camera app to be used for face capture. If a user attempts to spoof the system using a third-party app, this feature helps detect and flag potential spoofing attempts. ![](/images/11493834/61857aeae154.png)
6. Configure**Liveness Check Parameters**.**Min Liveness Probability**: Specifies the threshold used to determine whether an image is live or spoofed.**Default value:** 0.5Images with a liveness probability of **0.5 or higher** are classified as live.**Min Liveness Quality**: Specifies the minimum quality required for an image to be suitable for a liveness check..Default: 0.1Images with a quality score of **0.1 or higher** are considered suitable for liveness verification. ![](/images/11493834/1936ecc94d9a.png)
7. **Enable Manual Capture Accessibility** toggle to allow users manually capture their face during the face recognition process.Select**Disable Auto-capture**to disable automatic face capture. When enabled, users must manually capture their face using:**Enter** or **Space bar** on desktops and laptops.**Tap anywhere** on the screen for mobile and tablet devices. ![](/images/11493834/6817ea981424.png)
8. **Enable Timed Auto-Capture**to allow the system to automatically capture the user's face if it is not captured within a set time.Set the **Time-out Duration** in seconds.After the timer ends, the system captures the face automatically, even without user action. ![](/images/11493834/57421b80210b.png)
9. **Configure Image Capture Resolution.****Select Capture Resolution**from the **Select Resolution** dropdown list.**Low: 640×480:**Lower quality image.**Medium: 1280×720:**Balanced quality.**High: 1920×1080:**High-quality image, Best clarity. ![](/images/11493834/df2b49dc487c.png)
10. Enable **Adjust Video Preview Container Spacing From Top**toggle to move the face capture preview upward for better alignment with the camera. (e.g. Chromebook )
11. Click **Save**. ![](/images/11493834/f85e3a5f31b2.png) The Face recognition for Webkey application is configured successfully. ![](/images/11493834/27ee9d0ea3af.png)

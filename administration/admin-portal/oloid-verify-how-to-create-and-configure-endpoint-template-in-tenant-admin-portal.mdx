## Introduction

The Tenant Admin Portal allows Tenant Admin to create and configure Oloid Verify Endpoint Templates to standardize the setup and deployment of Oloid Verify endpoints. These templates streamline configuration by letting administrators predefine endpoint details, settings, groups, web buttons, integrations, and health monitoring options.

## Prerequisite

You must have a Tenant Admin Account.

## Steps to create Endpoint Template

1. Log in to the **Tenant Admin Portal**.The **Application** page is displayed.
2. Select **Endpoint** from the left menu panel. ![](/images/10506225/ffabc347b873.png) The **Endpoint** page is displayed.
3. On the top right, click **Endpoint Template**. ![](/images/10345475/0ae73a42b1fc.png) The **Endpoint Template** page is displayed.
4. On the top right, click **Create Template**. ![](/images/10345475/74b771540314.png) The **Create New Template** pop-up box is displayed.
5. Do the following:Enter **Template Name**.Select **Application Type** as **Oloid Verify** from the dropdown list.Select **Endpoint Type**as**Oloid Verify** from the dropdown list.Click **Create**. ![](/images/10506225/4e797d1d4678.png) The Endpoint is created and listed successfully in Endpoint Template page. ![](/images/10506225/4c593f038216.png)

## Steps to Configure Endpoint Template

1. Click **Endpoint Template** to be configured from the listed templates. ![](/images/10506225/c236840a9d59.png)
2. Configure the following:[Details tab](#h_60d27dd031)[Configure tab](#h_727e6be56c)

## Configure Details tab

<Frame>
  <img src="/images/10506225/fa17bb1731d7.png" alt="Screenshot" />
</Frame>

1. Edit **Template Name** (If required).
2. Enter **Template Description**. (Optional)
3. Select **Endpoint Type** from the dropdown list.
4. Select **Time Zone** from the dropdown list. (Optional)**Note:** In case the Endpoint time zone is not specified, by default the endpoint inherits the time zone specified for the application.
5. Enter name in **Name Endpoint As**text field. (Optional)
6. Select **Location** from the dropdown list. Once selected, this activates the **Building** field. For more information on creating a location, refer [How to create a new location and add location details](/administration/admin-portal/how-to-create-a-new-location-and-add-location-details). (Optional)
7. Select **Building**associated with the chosen locationfrom the dropdown list. Once selected, this activates the **area** field. (Optional)
8. Select **area**within the building from the dropdown list. (Optional)
9. Click **Save**.**Note:** The **Building** and **Area** fields remain disabled until a valid **Location** is selected.​**Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes. The **Details tab** is configured successfully. ![](/images/10506225/cfa73ccf6f8e.png)

### Configure Web Button

<Frame>
  <img src="/images/10506225/7c146fbb5680.png" alt="Screenshot" />
</Frame>

1. **Enable Web Button** toggle to activate the web button on the endpoint preview screen to view transaction.Enter **URL**.**Note:** You have to enter the URL of the website where the user will review the punches. Enter **Timeout** duration.
2. Turn on **Show only on Auth**toggle to allow the web button to appear only after successful authorization.
3. Turn on **Auto Launch** toggle to automatically launch the web button and view transaction.
4. Click **Save**.​**Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.

The **Web Button**is configured successfully.

### Configure Health Setup

<Frame>
  <img src="/images/10506225/d47636ed0f3a.png" alt="Screenshot" />
</Frame>

**Enable Health Alerts**

Do the following:

1. Turn on **Enable Health Alerts**toggle to monitor the health of the paired endpoints.
2. Enter email ID(s) in **Add recipients for Endpoint Health Alerts** whom you want to share the health alert notifications.
3. Set**Email frequency**in Hours and Mins to adjust the frequency of email notifications.
4. Click **Save**to apply your changes. The Health Alert is configured for the endpoint. ![](/images/10506225/d0dd6fae83ba.png)

**Add URLs to Monitor**

Do the following:

1. Enter **Server Name**.
2. Enter URL in **Add URL that needs to be monitored** field.
3. Click **Add**.

The health check server URL is added successfully.

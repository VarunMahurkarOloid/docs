**Introduction**

An Oloid account is a User's unique ID created within the Tenant Admin Portal, enabling users to access Oloid’s Applications.

**Pre-requisite:**

- You must provide your email address or phone number to create OloID Account.
- You must turn on **Enable OloID Account**toggle button on the Connection detail page. For more information, see**[How to Enable OloID account in Connection](/administration/admin-portal/tenant-admin-portal-how-to-enable-oloid-account-for-a-connection)**.

**Steps to Create Oloid Account:**

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8347798/de5fd3ffdf6f.png) The **Users** page is displayed. ![](/images/8347798/c061480b57d2.png)
3. To create multiple user's Oloid account do the following: Select **User name(s**)> **Action**> **Create Oloid Account**.![](/images/8347798/6628867b24db.png)
4. To create single user's Oloid account do the following: Click User Name to edit.![](/images/8347798/80a09dd28dc6.png)Go to **Action** > **Create Oloid Account**. The User details page is displayed.![](/images/8347798/54351e9c9d00.png) An Oloid account is successfully created. The user can now log in to Oloid Cloudkey app using their registered email id.

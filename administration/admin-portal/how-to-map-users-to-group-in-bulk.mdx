Steps to map user to group in bulk:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Groups** on the left panel menu. ![Image](/images/8272023/d4a461cd3981.png) The **Groups** page is displayed.
3. Click **User Group Mapping** in the top right. ![Image](/images/8272023/671f07dc0c0c.png) The **User Groups Mapping** page is displayed.
4. Go to **Action > Import Users to Group**. ![Image](/images/8272023/f0a5b675c38d.png) The **Import users to group** pop-up box is displayed. ![](/images/8272023/63f6a6bfe83e.png)
5. On the pop-up box, do the following:Upload or drag and drop the CSV file with user details.**Note**: You may click **Download template** to download the CSV file template and upload the file after updating the required fields.Select **Group** from select group dropdown list.Click **Import**.
6. The user log is uploaded and listed on the **User Group Mapping** page. ![](/images/8272023/8ce830e493ab.png) You may verify the logs to see the user status.

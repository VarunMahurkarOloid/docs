## Introduction

The API Key allows admin to securely authenticate and integrate external applications with the Oloid platform. Using the Tenant Admin Portal, you can easily generate an API key for authorized system-to-system communication.

## Prerequisite

You must have **Tenant Admin Access** to generate an API key.

## Steps to Generate API Key

1. Log in to the **Tenant Admin** **Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10458687/808e1b9d1624.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![Image](/images/8232355/dd6256eec1ca.png) The **Tenant Settings** page is displayed.
4. Go to **Security** tab >**API Token** > **API Key** > click **Generate**. ![](/images/9823811/71dbd590bf23.png) The API key is generated successfully. ![](/images/9823811/e639dfef9075.png)

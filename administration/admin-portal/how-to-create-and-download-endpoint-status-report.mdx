## Introduction

Endpoint Status Report provides the status of all the endpoints of the associated applicated.

## Pre-requisite

You must have a Tenant Admin account.

## Steps to create and download Endpoint Status Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/8450433/0aee946d9a47.png) The **Ad-Hoc Reports**page is displayed. ![](/images/8450433/c340d0b652e5.png)

1. Do one of the following:Go to**Endpoint Status Report** >**+ Create Report**. ![](/images/8450433/08f22e5be53c.png) On the top right, click **Create Report**> **Endpoint Status Report**. ![](/images/8450433/9256dd02218f.png) The **Create Endpoint Status Report**pop-up box is displayed. ![](/images/8450433/a9ca896acd1c.png)
2. On the pop-up box, do the following:Select application from the **Applications**drop-down list. (Optional)Select **Last Activity Logged on Endpoint**from the calendar. (Required)Select endpoint report type from **Endpoint Report Type**drop-down list. (Optional)Select **Download**.The report is generated and saved to the local device. ![](/images/8450433/90a7a9d9f378.png) **Notes**Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.The downloaded file format for reports is XLSX.

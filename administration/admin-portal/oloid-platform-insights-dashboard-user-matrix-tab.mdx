## Introduction

The **User Matrix** page in the Insights module provides a comprehensive view of user onboarding activity, credential enrollment, and growth trends across your organization. It allows Users to download Insight reports.

## Prerequisites

- You must have a Tenant Admin account.
- Users must be added to the tenant directory for onboarding data to appear.

## Accessing the User Matrix

1. Log in to the Tenant Admin Portal.
2. From the left navigation panel, select **Insights**Icon. ![](/images/13001607/7bfe73acd168.png)
3. Select the **User Matrix** tab.The User Matrix dashboard is displayed.
4. Do the following:

[Onboarding Overview](#h_23b6b37e96)

[Onboarding Growth](#h_0dcb17ad34)

[Users Growth](#h_8fcc636e90)

## Onboarding Overview

The **Onboarding Overview** section displays a high-level summary of the total users and their onboarding status.

<Frame>
  <img src="/images/13001607/b108bc06ebc9.png" alt="Screenshot" />
</Frame>

1. The onboarding overview section displays the following details: **Total Users:**The total number of users in the tenant.**Users Onboarded with at least one credential:**The number of users who have completed onboarding by adding at least one credential.**Users without any credential** The number of users who have not added any credentials.**Onboarding Percentage Chart** A circular chart that shows the percentage of onboarded users.
2. Click **download**icon in this section to export a summary report of the onboarding data.

## Onboarding Growth

The **Onboarding Growth** section tracks how many users have been onboarded within a selected time range.

<Frame>
  <img src="/images/13001607/4a57fc0e4d95.png" alt="Screenshot" />
</Frame>

The onboarding overview section is displayed

1. Filter the onboarding growth dashboard using time filters for:TodayLast 30 DaysLast 12 Months
2. Click **download**icon to export onboarding growth data.

## Users Growth

The **Users Growth** section displays the number of users added to the system and their growth patterns over time.

<Frame>
  <img src="/images/13001607/04f2ab186e9d.png" alt="Screenshot" />
</Frame>

1. The User Growth section displays the following details:**Total Users Added:**Shows the number of users added within the tracked period.**Growth Chart:**A bar chart visualizing user growth trends.
2. Click **download**icon to export the users growth dataset.

### Introduction

This document provides step-by-step instructions to send an email invitation that allows a user to set PIN through the Oloid Platform.

### Pre-requisite:

The registered email ID must be added to the user's profile on the Oloid Platform.

### Steps to send invite to set Pin:

1. Login to the **Tenant Admin Portal**.
2. On the homepage, click **Directory**, from the left menu panel. ![](/images/14750432/e8a65014f485.png) The **Users** page is displayed.
3. Click **username** to edit. ![Image](/images/14750432/495b74c13e39.png) The **user details** page is displayed.
4. Go to **Credentials** tab > **PIN** > **Send set PIN Email**. ![](/images/9937001/ccc9351089b9.png) The **Email Invitation Preview** pop-up box is displayed.
5. Do the following: ![](/images/9937001/f6b74e5581a7.png) Enter email ID(s) and select from the dropdown to whom you want to send the mail in **Send Email to** field.Enter subject in **Email Subject** field.Enter a message in the **Email Body** field.Click **Send**.The invite to set PIN is sent to Email successfully. ![](/images/9937001/a29a35200e85.png)

The link navigates the user to the self-service portal where the user can set PIN.

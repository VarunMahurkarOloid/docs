### Steps to generate auto-pair config file:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/11513590/40c9474ee8f0.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/11513590/c45210f892b6.png) The **Tenant Settings** page is displayed.
4. Go to **Security** tab >**API Token** > **API Key**. ![](/images/10441578/f17408aa6124.png)
5. In the**Generate Temporary Access Token**section, do the following:In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.To set the start date and time, click the date picker or select **Now**.Select the **End Date/Time** field.Click the date picker, choose when the token will expire, and then click **OK**.Specify **Number of Endpoints** that can be created using the endpoint. (Optional)Click **Generate**. ![](/images/10441578/2f757f45c451.png) The auto-pair config file is generated. ![](/images/10441578/c78eb07337d7.png)
6. Click **Auto-pair config file**.The Auto-pair config file pop-up box is displayed. ![](/images/11513590/1ed4dddadb62.png)
7. Do the following:Select **Application**as**Oloid Verify**from **Application Type**dropdown list.From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.Under **Download file format**, select one of the following:**JSON** → For local device setup.**XML** → For MDM deployment.Select **Skip user confirmation for pairing**option to auto-pair endpoints without requiring user confirmation (optional but recommended).**If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.**If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.Click **Download**.The AutopairConfig file is downloaded to the local device.

## Introduction

The **Invite to Add Password** feature allows the Tenant Admin to send an email invitation to users to securely add their Windows password through the User portal.

## Prerequisites

- You must have access to a Tenant Admin account.
- The registered email ID must be added to the user's profile on the Tenant Admin Platform.

## Steps to send invite to add password

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Directory** from the left menu panel. ![](/images/8347344/e8a65014f485.png) The**Users** page is displayed.
3. Click **username** to edit. ![Image](/images/9929285/d626c453e0da.png) The **User details** page is displayed.
4. Go to**Credentials** tab > **Windows Passwords** > **Invite to Add Password**. ![](/images/9929285/e9d04648dcc0.png) The **Email Invitation Preview** pop-up box is displayed.
5. Do the following: ![](/images/9929285/7c59a32e869a.png) Enter email ID(s) and select from the dropdown to whom you want to send the mail in **Send Email to** field.Enter subject in **Email Subject** field.Enter a message in the **Email Body** field.Click **Send**.

The invite to add password is sent successfully.

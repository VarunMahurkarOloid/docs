Factor Sequence helps set up rules for *multi-factor authentication in Oloid applications. It determines the order and combination of these methods to make sure that the authentication process is effective and secure.

*Multi-Factor Authentication (MFA) is a security process that requires users to authenticate their identity using two or more verification methods.

## Steps to create Factor Sequence:

1. Log in to the **Oloid Portal**. The homepage is displayed. ![](/images/9699393/deb7364e33f9.png)
2. Click **Auth Policies** > **Factor Sequencing** from the menu panel. ![](/images/9699393/b3980aee813a.png) The **Factor Sequence for MFA Apps**page is displayed. ![](/images/9699393/8beffdca35c2.png)
3. Click **Create Factor Sequence**in the top right. ![](/images/9699393/6e9fbd58a0bc.png) The **Create Factor Sequence** pop-up box is displayed. ![](/images/9699393/877beedffd1f.png)
4. Enter **Factor Sequence Name**in the text field.
5. Click **Create**.The Factor Sequence is created and the configuration page is displayed.
6. Do the following to configure Factor Sequence:[Configure Details tab](#h_acfe4fb747)[Configure Policy Rules tab](#h_244d7b0b2c) The Factor Sequence is configured.

## Configure Details tab

1. Enter **Factor Sequence Name**.
2. Enter **Factor Sequence Description**.(Optional)
3. Click**Save**. ![](/images/9699393/214d4c6bec76.png)

## Configure Policy Rules tab

1. Go to **Policy Rules** > **Add Rule**to create a new policy rule. ![](/images/9699393/1182d60eb7e9.png) The **IF Factor 1** and **THEN Factor 2** section is displayed ![](/images/9699393/4af56c3f1025.png)
2. Select preferred credentials under **Factor 1** and **Factor 2**.
3. Click **Save**.The **Policy Rules** is saved Successfully. For detailed instructions, refer [How to add Policy Rules for Factor Sequencing](/administration/admin-portal/how-to-add-policy-rules-for-factor-sequencing)

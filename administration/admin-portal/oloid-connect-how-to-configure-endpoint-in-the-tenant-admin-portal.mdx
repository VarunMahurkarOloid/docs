## Introduction

Configuration of an endpoint in the Tenant Admin Portal allows Tenant Admins manage device settings, appearance, groups, integrations, and transaction behaviour for the Oloid Connect app.

**Note:** Once you pair an endpoint with Oloid Connect application, it gets saved and appears in the Tenant Admin Portal. After pairing, you can configure the endpoint.

## Prerequisite

You must pair Oloid Connect endpoint. To pair refer [How to pair an Oloid Connect endpoint](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint).

## Steps to configure the Endpoint

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel. ![](/images/10511068/c63f6b503e62.png) The **Endpoints** page is displayed.
3. Select the paired Oloid Connect Endpoint. ![](/images/10550185/7bae8d9b7dca.png) The **Endpoint Details**page is displayed. ![](/images/10550185/27b5dde3fabe.png)
4. Do the following:[Configure Details Tab](#h_468c479a7e)[Design Configure Tab](#h_6dd96f73df)[Configure Transactions Tab](#h_a6a25e71ec)[Configure Health Response Tab](#h_79b6afb7ff)

## Configure Details Tab

1. Edit **Endpoint Name** if required.
2. Enter**Endpoint Description**. (Optional)
3. Select **Time Zone** from the dropdown list. (Optional)**Note:** If time zone is not set for the Endpoint, it automatically uses the application's default time zone.
4. Click **Save**. ![](/images/10550185/50f1aa075de8.png) The Details tab is configured successfully. ![](/images/10550185/d869d02bae40.png)

## Design Configure Tab

Configure the following:

## Endpoint Settings

1. Turn on **Use Endpoint in Admin Mode Only**toggle to restrict the endpoint device to Admin mode.
2. Turn on **Capture Location**toggleto activate location capture on the endpoint for each transaction.**Note**: The **Location Permission** of the device must be enabled to make the feature functional.
3. Turn on **Generate Debug Logs**toggle to activate log generation for the endpoint until disabled.
4. Turn on **Landscape Mode for Preview Screen**toggle to change the user preview screen from portrait to landscape mode.
5. Click **Save**. ![](/images/10550185/8935844db625.png) The Endpoint setting is configured successfully. ![](/images/10550185/6f3d4d3662e7.png)

## Groups

1. Turn on **One Face/User (On Device FR)** toggle to ensure that only one facial image of each user is stored on the device as a reference for On-device Transaction. ![](/images/10511068/08ef35f65aa5.png)
2. Click **+ Add Group**. ![](/images/10511068/f262de33891c.png) The **Add Group** pop-up box is displayed.
3. Select group(s) in **Add Group** field.
4. Click **Save**. ![](/images/10511068/b3d3ae824d3c.png) The Group is added successfully. ![](/images/10550185/5e55e8a256fe.png)

## Web Button

1. Turn on**Web Button** toggle to display the Web Button on the endpoint preview screen. This button allows users to view transactions. In the **URL** field, enter the complete URL of the website where users will review punch data.**Note:** You have to enter the URL of the website where the user will review the punches.In the **Timeout** field, enter the delay (in minutes) before the URL launches.
2. Turn on **Show only on Auth**toggle to display the Web Button only after the user is successfully authorized. (Optional)
3. Turn on **Auto Launch** toggle to automatically launch the web button and view transaction. (Optional)
4. Click **Save**. ![](/images/10550185/af260856830e.png) The Web Button is configured successfully. ![](/images/10550185/8ffc9f507a74.png)

## Health Setup

1. Enter **Server Name**.
2. Enter URL of the server in **Add URL that needs to be monitored** field.
3. Click **Add**.The monitored URLs will appear in the list below, with columns for **Server Name** and **URL**. ​**Note:** Configure the settings only if they are applicable. Consult your Oloid representative before making any changes.

<Frame>
  <img src="/images/10550185/5126d6e9aa07.png" alt="Screenshot" />
</Frame>

The Server is added along with its URL successfully.

## Configure Transactions Tab

The Transactions tab allows you to view detailed user transactions. You can monitor transaction statuses and filter results based on success or failure.

<Frame>
  <img src="/images/10550185/ee8ca860740d.png" alt="Screenshot" />

## Configure Health Response Tab

1. Turn on **Share Endpoint Logs** toggle to share logs.
2. Turn on **Relaunch** toggle to automatically apply changes made on the Tenant Admin Portal to the Oloid Connect app without manually closing or restarting the app.
3. Click **Check Health** to initiate a health check successfully.

  <img src="/images/10550185/45d6871db5d4.png" alt="Screenshot" />
</Frame>

In this section, you can see the endpoint status, check health of the endpoint and configure health alert. For more information on health alert, see**[How to configure health alert for an endpoint](/administration/admin-portal/how-to-add-health-alerts-in-the-endpoint)**.

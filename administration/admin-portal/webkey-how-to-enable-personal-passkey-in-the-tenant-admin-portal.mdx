## Introduction

Personal Passkey enables users to authenticate to supported Webkey applications using a passkey associated with their individual account.

## Prerequisite

- You must have access to Tenant Admin account.
- Personal Passkey must be enabled in the Tenant Admin portal. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-enable-passkey-sso-in-tenant-admin-portal)
- Ensure Personal Passkey is created for the user. Refer: [How to Generate Personal Passkey in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-generate-personal-passkey)

## Steps to Enable Personal Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit. ![](/images/10800135/d5355d7e2b98.png) The application page is displayed. ![](/images/11501228/a0d46d1f6dad.png)
3. Go to **Authenticator tab.** ![](/images/15733222/49edc7b671e5.png) The Authenticator page is displayed.
4. Turn on **Personal Passkey**toggle.

Personal Passkey is successfully Enabled.

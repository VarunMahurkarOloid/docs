## Introduction

The Re-pair Endpoint feature in the Oloid Connect App allows Admins and Supervisors to restore an endpoint that requires reconfiguration. This process ensures that the endpoint reconnects properly with the assigned application and continues to operate as expected.

## Steps to re-pair an endpoint

1. Launch the **Oloid Connect**app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)The **Settings** page is displayed. ![](/images/10288447/c9a70139d5cb.png)
2. Tap **Re-pair.** ![](/images/10288447/3235bf077a70.png) **Re-pair Endpoint** pop-up is displayed. **Note:** You can only re-pair an endpoint if it is not paired. ![](/images/10288447/63d8533a14c5.png)
3. On the pop-up box, do the following:Enter**Endpoint ID**.Tap **Re-pair**.The Endpoint is re-paired successfully. ![](/images/10288447/70af46265f08.png) **Note:** Kill and relaunch the app to make the new updates function properly. ​

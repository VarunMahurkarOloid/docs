## Introduction

The **Authenticator** tab in the Oloid Vault (Chrome / Chromium) application allows admin to enable and manage authentication methods such as Face, Badge ID, and NFC/ID. Each method has different configurable parameters to enhance security and optimize authentication performance.

## Prerequisite

Chrome Vault application is created. To create refer [How to Create and Configure Chrome Vault Application in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).

## Steps to Update Authenticator Tab

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application. ![](/images/12442012/1a1c053bd1bf.png) The application detail page is displayed.
3. Go to Authenticator tab and configure the following:[Face](#h_3791424da5)[Badge ID](#h_31cebc628d)[NFC/ID](#h_e545be4337)

<Frame>
  <img src="/images/12458180/134a14dbad5f.png" alt="Screenshot" />
</Frame>

## Face

1. Select **Face**option from the left menu panel > turn on **Face**toggle.
2. Adjust the following setting for **Face Match Parameters**.**Note:**You must consult your Oloid representative before making any changes to the **Face Match Parameters** to ensure optimal authentication performance. ![](/images/11476775/fc14e8c0aa39.png) Turn on **Strict Error Handing** toggle to skip the error and perform a direct one-to-one face match. ![](/images/11476775/36a4a4154dc7.png) Turn on **Additional Face Match** toggle to perform a one-to-one face match alongside the standard face matching process. ![](/images/11476775/af505705c951.png) Adjust the **Face Match Threshold** slider or enter a value directly into the input box to set the face match threshold value. ![](/images/11476775/f4f631561d2f.png)
3. Adjust the following setting for**Liveness check parameters**.**Note:**You must consult your Oloid representative before making any changes to the **Liveness check parameters** value to ensure optimal authentication performance.**Min Liveness Probability**: Specifies the threshold used to determine whether an image is live or spoofed.Default value: 0.5Images with a liveness probability of **0.5 or higher** are classified as live.**Min Liveness Quality**: Specifies the minimum quality required for an image to be suitable for a liveness check.Default: 0.1Images with a quality score of **0.1 or higher** are considered suitable for liveness verification. ![](/images/12458180/85f514f27c2f.png)
4. Click **Save**.

<Note>
  The parameters are pre-configured. This is done by **Oloid admin**.
</Note>

### Additional Settings

1. **Configure Image Capture Resolution:** Select the preferred resolution from the **Select Resolution** dropdown list for image capture during facial authentication.
2. Click **Save**.**Note:**If the selected resolution is not available, the browser will default to the closest supported resolution. ![](/images/12458180/e1ec8d987620.png) The face credential is(are) updated successfully.

## Badge ID

1. Select **Badge ID**option from the left menu panel > turn on **Badge ID**toggle.
2. Select Badge input type from Badge type drop down list.
3. Click **Save**. **Note:** The Application will support the selected Badge input type at the linked endpoints.

## NFC/ID

1. Select **NFC/ID**option from the left menu panel.
2. Turn on **NFC/ID**toggle.

**Prerequisite:**

A shared windows password must be created in Tenant Admin Portal/Supervisor Portal.

**Steps to assign windows shared Passwords:**

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Directory** from the left menu panelThe **Users** page is displayed.
3. Select user(s) to assign Windows Shared Passwords. ![](/images/11536855/b88542fb19e7.png)
4. Go to **Action**>**+ Windows Shared Passwords**. ![](/images/11536855/de6276de49e6.png) The **Assign Windows Shared Passwords**pop-up box is displayed. ![](/images/11536855/ea89da85c358.png)
5. On the pop-up box, do the following:Select Windows Shared Password(s) from**Windows Shared Passwords**dropdown list.Click **Assign**. The Windows Shared Password is successfully assigned for the selected user(s). ![](/images/11536855/1a1159085e76.png) Related Document[How to Assign Windows Shared Passwords to Multiple Users in Supervisor Portal](/passwordless/windows/supervisor/how-to-assign-windows-shared-passwords-to-multiple-users-in-supervisor-portal)

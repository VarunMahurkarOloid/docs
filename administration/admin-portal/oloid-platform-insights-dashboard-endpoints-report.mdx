## Introduction

The **Endpoint Report** under **Insights > Reports** provides admin with a detailed view of Windows Login application endpoints in the organization.

## Prerequisite

- You must have Tenant Admin account.

## Steps to access Endpoint Report

1. Log in to the Tenant Admin Portal.
2. From the left navigation menu, click **Insights**Icon.
3. Select **Reports** > **Endpoints.** ![](/images/13256453/706491d848df.png) The **Endpoints Report**page is displayed.
4. Filter Endpoints![](/images/13256453/99b0daeec7ba.png) Use the **Add Filter** option to narrow down and view only the specific endpoints you want. This feature helps you quickly locate relevant endpoints from the list.Click **Add Filter**.Select the required filter from the dropdown.Enter the filter value to refine the endpoint results.
5. Download Endpoint Report![](/images/13256453/49418ebbd71b.png) Select the **Endpoint Name** checkbox for the required endpoint(s).Click **Download**. ![](/images/13256453/cd2fad82bb0f.png) The **Download Custom Report** pop-up is displayed. Enter the **Report Name** (required).From the **Add Table Columns** dropdown, select the columns you want to include in the report.Click **Download**.The endpoint report is downloaded successfully.

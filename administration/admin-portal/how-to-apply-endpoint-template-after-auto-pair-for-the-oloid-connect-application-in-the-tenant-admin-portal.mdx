### Introduction

This document explains how to apply an endpoint template to a paired Oloid Connect endpoint in the Tenant Admin Portal. Applying the template makes sure the preset settings are automatically applied to the endpoint.

### Prerequisites

- You must have a Tenant Admin Account.
- The Oloid Connect endpoint must be paired. To pair refer [How to pair an Oloid Connect endpoint](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint)
- An Endpoint template must be created. To create refer [How to create and configure Oloid Connect endpoint template](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-endpoint-template)

### Steps to apply Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu. ![](/images/12838474/ffabc347b873.png) The endpoint screen is displayed.
3. Select the **Endpoint**. ![](/images/12838474/b1e4699c366e.png) The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**. ![](/images/12838474/c577a37a46ab.png) The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown. ![](/images/12838474/1576abddb2e6.png) The selected template is displayed in the **Select Template** field.
6. Click **Apply**. ![](/images/12838474/faadb90c9a7b.png) The template is successfully applied to the endpoint. ![](/images/12838474/b2d3b94074ca.png)

**Steps to deactivate User:**

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8424258/5b29b0fbf2e9.png) The **Users** page is displayed.
3. Click Username to edit. ![](/images/8424258/983d9514a1f1.png) The user details page is displayed.
4. On the top-right, go to **Action** > **Deactivate**. ![](/images/8424258/1a75ab4d22db.png) The **De-activate User** pop-up box is displayed. ![](/images/8424258/dded825a5564.png)
5. Click **Confirm Deactivate**. The user is deactivated successfully. ![](/images/12569918/3e342e75e6d2.png)

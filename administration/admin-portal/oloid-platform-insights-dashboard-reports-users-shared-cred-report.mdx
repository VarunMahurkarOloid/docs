## Introduction

This report provides a list of users with Windows shared passwords.

## Prerequisite

- You must have Tenant Admin account.
- Shared credentials must be assigned to users.

## How to Access User Report

1. Log in to the Tenant Admin Portal.
2. From the left navigation menu, click **Insights** Icon.
3. Select the **Reports** tab > **Users** > **Users \<> Shared Cred** ![](/images/13256388/18ef92e2023c.png) The **User** **Shared Cred Report** page is displayed.
4. Click **Add Filters** to narrow down the report based on specific criteria. ![](/images/13256388/97420fb1ac0f.png)
5. Select filter from dropdown. ![](/images/13256388/842940811f41.png)
6. Click **Download Report** to export the User Shared Cred Report.
7. Enter **Report Name** and select the required table columns.'
8. Click **Download**. ![](/images/13256388/ca0470c9ce56.png) The Report is successfully downloaded.

---

**Notes:**

Report Generation Details

- The report runs **daily at 12:00 AM PST**.
- It displays data from the **last 30 days**.
- The **Last generated** date and time is shown at the top of the page.
- Use the pagination controls at the bottom of the page to navigate through multiple pages of users.

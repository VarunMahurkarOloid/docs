## Introduction

The Revoke Consent feature allows admins to manage users' legal consent. When activated, it resets previously obtained consent, prompting users to provide consent again if the organization updates the legal agreement document.

## Prerequisite

- You must have a Tenant Admin Account.
- User must have an active consent.

## Steps to Revoke Consent

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Directory** from the left menu panel. ![](/images/10615483/b31fc8d34d13.png) The**Users** page is displayed.
3. Select **User** from the list. ![](/images/10615483/4e9d7a616a19.png) The **Details** page is displayed.
4. Do one of the following:Click **Action** dropdown at top right > select **Revoke Consent**. ![](/images/10615483/73a6c1612acf.png) OR Go to **Consent** tab > **Active Consent >** click **Revoke Consent**. ![](/images/10615483/0668801ff0d8.png) The Confirm Revoke Consent pop-up is displayed.Click **Confirm** Revoke Consent. ![](/images/10615483/ed80eb33d974.png) The consent is revoked successfully. The Status of the consent is changed to **Consent Denied.****Note:**The user is prompted to submit consent in the User Portal during face addition. ![](/images/10615483/709590e8aba0.png)

**Note:** Once activated, the Revoke Consent button is disabled until the user submits consent again.

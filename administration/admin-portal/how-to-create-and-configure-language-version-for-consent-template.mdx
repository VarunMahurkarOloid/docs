## Introduction

The **Language Version** option allows the Tenant Admin to create localized versions of an existing consent template. Multiple language versions can be added to a single consent document.

## Prerequisite

- You must have a Tenant Admin account
- Consent Template must be created. Refer **[How to create and configure consent template](/administration/admin-portal/how-to-create-and-configure-consent-template)**
- Legal Document must be created. Refer **[How to create Legal Document](/administration/admin-portal/how-to-create-legal-document)**.

## To create a consent template

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Consent Documents** on the left menu panel. ![Image](/images/14459745/2455aadfc001.png) The **Consent Documents**page is displayed.
3. Select the required **Consent Template** for which Language version needs to created. ![](/images/14459745/c358294a3c80.png) The template detail page is displayed.
4. On the top right, click **Language Version**. ![](/images/14459745/890892dc35de.png) The **Language Version** list page is displayed.
5. On the top right, click **Create Language Version.** ![](/images/14459745/cc1ebfaea9a5.png) The Create language version pop-up box is displayed.
6. Select **Consent Language**from dropdown > click **Create Template**.

<Frame>
  <img src="/images/14459745/c85c3b8c817d.png" alt="Screenshot" />
</Frame>

The **Language Version** is successfully created.

<Frame>
  <img src="/images/14459745/0cefdc4d64de.png" alt="Screenshot" />
</Frame>

**Note:**The created language version must be in published status, language version(s) in draft status will not appear in preferred language selection dropdown.

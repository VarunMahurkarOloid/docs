## Introduction

This document provides instructions to create a Connection in the Tenant Admin Portal. A Connection is a logical group of users used to manage access within the Oloid platform. Each user belongs to one Connection. One or more Connections can be linked to one or more applications to grant user's access.

## Prerequisites

You must have an Admin access to the Tenant Admin Portal.

## Steps to Create a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left panel menu. ![](/images/8294297/177ed046ec6d.png) The **Connections** page is displayed.
3. Click **Create Connection**. ![](/images/11686694/82d58a4c843a.png) The **Create a new Connection** pop-up box is displayed.
4. Do the following.Enter **Connection Name**.**Note**: You can enable **PC/SC Badge Input** from the **Advanced Settings** section while creating a Connection for Windows Login Application. For more details refer [How to create PC/SC Badge Input enabled Connections in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-create-personal-computer-smart-card-pc-sc-badge-input-enabled-connections).Click **Create**. ![](/images/8294297/b28a616cc325.png) A connection is created successfully and listed on the **Connections** page. ![](/images/8294297/49c6b2ee3b96.png)

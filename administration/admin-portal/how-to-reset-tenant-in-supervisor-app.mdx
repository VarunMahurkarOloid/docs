To reset tenant:

1. Double-click on the **Supervisor** App.
2. Enter **Tenant Name**.![](/images/9059054/9281a2df3cf9.png)
3. Select**Next**.The **Pair Endpoint** screen is displayed.
4. On the bottom right, select **More Options** > **Reset Tenant**. ![](/images/9059054/289cb48aea83.png) The confirmation pop-up box is displayed. ![](/images/9059054/3dff66efff34.png)
5. Select **Confirm**to reset the tenant.The tenant name is reset successfully.

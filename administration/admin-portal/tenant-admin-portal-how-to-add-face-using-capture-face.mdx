## Introduction

The **Capture Face** feature in the Tenant Admin Portal allows admins to enroll or add a user’s face by capturing it directly from the Tenant Admin Portal.

## Prerequisites

- You must have access to Tenant Admin account.
- If user has Consent Denied Status then the Capture Face button will be disabled for that user.

## Steps to Capture Face if Consent is provided

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** icon > **Users**. ![](/images/13700750/cda41bdac4d1.png) The **Users**page is displayed.
3. Click user name to edit. ![](/images/13700750/fb613a4218e5.png) The User details page is displayed.
4. Click **Credentials**tab > select **Face**. ![](/images/13700750/f0a3482d74bb.png)
5. Click **Capture Face.**The camera opens.**Note:** If the user’s consent status is **Denied**, the Capture Face button is disabled. ![](/images/13700750/618634392855.png)
6. Position your face in front of the camera and click the **Capture** button to enroll your face.The Capture Face confirmation pop-up is displayed.
7. Do one of the following:Click **Yes- Submit** to submit the image.The face is submitted successfully and is displayed on the details screen.Click **No- Retake** to take the photo again.The camera turns on to retake the photo.**Note**: A maximum of five faces can be added. ![](/images/13700750/922aadff1d93.png) User Face is successfully added. ![](/images/13700750/3b482f916b40.png)

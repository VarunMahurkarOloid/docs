**Introduction**

The Badge credential feature in the Tenant Admin Portal allows admin to enable badge for the WebKey application. Once enabled, Users can authenticate to the Webkey application by scanning their badge.

**Steps to configure Badge ID credential:**

1. Log in to the **Tenant Admin Portal**. For more details, refer [How to log in to the Tenant Admin Portal](/administration/admin-portal/how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, select the Webkey application to edit. ![](/images/10800135/d5355d7e2b98.png) The application page is displayed. ![](/images/10800566/ad0013bfda59.png)
3. Go to **Authenticator**tab**.**
4. Turn on **Badge ID**toggle. ![](/images/11494069/f6cc2692f0a8.png)
5. Select a**RFID** **Badge Type** from the dropdown list.
6. Click **Save**. ![](/images/11494069/97b83c4e12bb.png) Badge authenticator for WebKey application is configured successfully. ![](/images/11494069/bbffa2e4e025.png)

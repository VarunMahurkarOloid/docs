**Introduction**

The Tenant Admin Portal allows admin to invite users to add their face as an authentication method via SMS. This feature includes a customizable SMS invite template that can be tailored to your organization's messaging standards.

**Prerequisite**

You must have a Tenant Admin account.

**Steps to customize SMS invite template:**

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/10299914/c8560f399688.png) The **user profile menu** is displayed.
3. Select **Tenant Settings.**![](/images/11967299/7a7743213fe4.png) The**Tenant Setting** page is displayed.
4. Go to **Advanced tab** > select **Face**from the left menu panel. ![](/images/11967299/5b54290b9e27.png)
5. Do the following under **Invite via SMS**:Enter SMS content in **SMS body** text field.**Note:**Ensure the SMS content is within 128-character limit.The User Portal link will be auto-attached to the SMS.To restore the default SMS message, click **Reset Template**. ![](/images/11967299/75c4afc5c3d8.png)
6. Click **Save.** ![](/images/11967299/83386353f3b5.png) The SMS invite template is updated successfully. ![](/images/11967299/b1f386f795ad.png)

## Introduction

Enabling a Custom User Agent allows the tenant admin to register new devices directly from user transactions.

## Prerequisite

- You must have a tenant admin account.
- Custom User agent must be enabled. Devices can also be added to Webkey application from Oloid portal. For further information please refer: [How to configure Custom User Agent in WebKey Application](/passwordless/web/webkey/webkey-how-to-configure-a-custom-user-agent-for-webkey)

## Steps to Add Device to Application

1. Log in to the **Tenant Admin Portal**.
2. Click **Transactions** from the left menu panel. ![](/images/13175211/f3d0cd0c3450.png) The **User Transaction Through Your Device** page is displayed.
3. Selectthe latest transactionto edit.**Note:**Device can only be added from failed transaction. ![](/images/13175211/6e95b84f5189.png)
4. On the top right, select **Action** > **Add Device to Application**. ![](/images/13175211/8f51d14638c2.png)
5. On the Confirm Device Registration pop-up box, select **Confirm**.**Note:**Registering will link the device to the application using its User Agent or Device ID ![](/images/13175211/471f64aa716a.png)

The device is successfully added to the WebKey application.

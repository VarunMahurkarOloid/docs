## Introduction

Oloid Session uses the existing Oloid authentication session to securely pass the user's credential to the next step in the workflow. When enabled, the user will be seamlessly authenticated using their active Oloid session token, without needing to re-authenticate.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure **Enable Auto Authentication of Webkey using Local Transaction**is enabled. Refer: [How to Enable Auto Authentication using Windows Oloid Session](/passwordless/web/webkey/webkey-how-to-edit-configure-tab).
- Enable Auto authentication using Local transaction for Windows Login. Refer: [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable Oloid Session

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit. ![](/images/10800135/d5355d7e2b98.png) The application page is displayed. ![](/images/11501228/a0d46d1f6dad.png)
3. Go to **Authenticator tab.** ![](/images/15420148/0092e6138588.png) The Authenticator page is displayed.
4. Do the following:Turn on **Oloid Session**toggle.Set the **Session Time-out**duration.**Session Time-out**duration specifies how long users can continue to access the device without re-authenticating after an Oloid sign-in.Click **Save.**

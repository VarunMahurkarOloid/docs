## Introduction

This document explains how to add a PIN credential to a user in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- The user must already be created in the Oloid Tenant Admin Portal.
- PIN credential settings must be enabled and configured in Tenant Admin Portal.

## Steps to create PIN

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory** on the left menu panel. ![](/images/8385780/0416a002436b.png) The **Users**page is displayed.
3. Click **user name** to edit. ![](/images/8385780/149349bfc93e.png) The user details page is displayed.
4. Do one of the following:Go to**Credentials**tab > **PIN**> **Add PIN**. ![](/images/8385780/cb63197b02c0.png) Go to **Assign Credential**> **Add PIN**. ![](/images/8385780/cee6f98ae310.png) The **Add PIN**pop-up box is displayed.
5. On the pop-up box, do the following:**Enter** **new PIN**.**Re-enter** **new PIN**.Under **Share PIN With,**select one or both available options to share the PIN with the user:In the **Email** field, enter the email address of the user with whom you want to share the PIN.In the **User Phone Number** field, enter the phone number of the user with whom you want to share the PIN.**Note:** If the **Share PIN With** option is not displayed in the **Add PIN** pop-up, an email notification will be sent to the user’s registered email address informing them of the PIN update. The new PIN will not be included in the email. For more, Contact [Oloid Support](mailto:support@oloid.ai)Click **Save**. ![](/images/8385780/f1e68a8663d6.png) The PIN credential is created and listed on the **PIN**tab. ![](/images/8385780/34f85629a4bd.png)

## Introduction

The **Web Button** feature allows users to view transaction or punch details directly from an Oloid Connect endpoint. This document explains how to quickly configure the Web Button from the Tenant Admin Portal.

## Prerequisite

You must pair Oloid Connect endpoint. To pair refer [How to pair an Oloid Connect endpoint](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint).

## Steps to configure Web Button

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel. ![](/images/10511068/c63f6b503e62.png) The **Endpoints** page is displayed.
3. Select the paired Oloid Connect Endpoint. ![](/images/8410896/0d8fe4a4b4c9.png) The **Endpoint Details**page is displayed. ![](/images/8410896/6c268f56afd3.png)​
4. Go to **Configure** Tab > Click **Web Button**. ![](/images/8410896/77c5ceb700e6.png)
5. Do the following:**Enable Web Button** toggle to display the Web Button on the endpoint preview screen. This button allows users to view transactions.In the **URL** field, enter the complete URL of the website where users will review punch data.**Note:** You have to enter the URL of the website where the user will review the punches.In the **Timeout** field, enter the delay (in minutes) before the URL launches.(Optional) Enable **Show only on Auth** to display the Web Button only after the user is successfully authorized.(Optional) Enable **Auto Launch** to automatically launch the web button and view transaction.Click **Save**. ![](/images/8410896/e7737cc2bf02.png) The Web Button tab is configured successfully. ![](/images/8410896/e205d1cc9e90.png) Keywords|Configure Web Button |Oloid Connect Web Button |Endpoint Web Button configuration|

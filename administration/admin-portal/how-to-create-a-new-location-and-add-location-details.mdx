## Create location using Transaction

Steps to create a new location through transaction:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Transactions** on the left menu panel.![](/images/8227103/2c4bea7fa2d3.png)The **User Transaction Through Your Device**page is displayed.
3. Click **Location Settings**at the bottom of the left menu panel. ![](/images/8227103/f8bbf63f99f9.png) The **Location Settings**page is displayed.
4. Click **Create Location**on the right corner of the page.![](/images/8227103/4c088e356a96.png) The **Create Location**pop-up box is displayed.![](/images/8227103/8bec0a7a8a9b.png)
5. Enter **Location Name**.
6. Click **Create**.The location is created and listed on the **Location Settings**page.![](/images/8227103/142fe189f0d8.png) **Note**: You can enable the toggle button for **Add Navigation Card.**This creates a card view on the right menu panel for that location.

## Create location using Endpoint

Steps to create a new location through endpoint:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.![](/images/8227103/63a4b7076233.png)The **Endpoints** page is displayed.
3. Select endpoint name(s) from the listed endpoints.![](/images/8227103/74805360adfe.png)
4. Go to **Action**dropdown and select **Add Location**.![](/images/8227103/0f9df1175ef7.png)The **Add Location**pop-up box is displayed.![](/images/8227103/e8f520b5ed41.png)
5. On the pop-up box do the following:Click **Select Location** field.The search result lists existing locations.![](/images/8227103/042893d3a602.png)Click **Add New**.The **Create Location**pop-up box is displayed.![](/images/8227103/ec5a594c724f.png) Enter **Location Name**.Click **Create**.The location name is created and listed on the **Location Settings**page.![](/images/8227103/ae91b8a29c9e.png)

## Adding location details

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Transactions** on the left menu panel.![](/images/8227103/2c4bea7fa2d3.png)The **User Transaction Through Your Device**page is displayed.
3. Click **Location Settings**at the bottom of the left menu panel.![](/images/8227103/f8bbf63f99f9.png)The **Location Settings**page is displayed.
4. Select location name from the listed locations.![](/images/8227103/ae91b8a29c9e.png)The Location detail page is displayed.![](/images/8227103/c8ca24ed9eed.png)
5. Enter **Address**.
6. Enter **Description**.
7. Click **+ Add Building** to enter Building Name (optional).
8. Click **Save**.The location address is updated.![](/images/8227103/f3da17853e5c.png)

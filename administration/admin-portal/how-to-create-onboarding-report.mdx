## Introduction

Onboarding Report contains the records of all the users onboarded to the Oloid Platform.

## Pre-Requisite

You must have a Tenant Admin account.

<Frame>
  <img src="/images/8450096/e8d172ccbf54.gif" alt="Screenshot" />
</Frame>

## Steps to create Onboarding Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel. ![Image](/images/8450096/7449cd2b7f6e.png) The **Scheduled Reports** page is displayed.
3. On the top right, click **Create Report**. ![Image](/images/8450096/5ef909fd35db.png) The **Create Report** pop-up box is displayed. ![](/images/8450096/c9809aff0820.png)
4. On the pop-up box, do the following:Enter **Report Name**.Select **Onboarding**report type.Click **Create**.The Onboarding report type is created and listed on the **Scheduled Reports** page. ![Image](/images/8450096/62c721ddfb7a.png)

The onboarding report can be configured to schedule the report generation frequency and send it to the customers through email . For details see, **[How to configure onboarding report](/administration/admin-portal/how-to-configure-onboarding-report).**

**Notes:**

- Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
- The downloaded file format for reports is XLSX.

## Introduction

Connection Groups in the Tenant Admin Portal allow admin to group multiple connections together. This makes it easier to apply the same settings across connections and manage them more easily.  
​**Note:** A connection can belong to only one connection group. If you select a connection that is already assigned to another connection group, the connection can't be added.

## Prerequisites

- You must create Connections. To create Connections, refer [How to create Connections in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-create-connection).

- You must create Connection Groups. To create Connection groups, refer [How to create Connection Groups in the Tenant Admin Portal](/administration/admin-portal/how-to-create-connection-groups-in-the-tenant-admin-portal).

## Steps to Configure connection groups

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/8947717/e99d2e29e38b.png) The **Connections** page is displayed.
3. Click **Connection Groups** on the top right corner of the page. ![](/images/8947717/4b806bd92f99.png) The **Connection Groups** page is displayed.
4. Select a **Connection Group**name to be configured from the list. ![](/images/8947717/8cfc06a732de.png) The **connection group** detail page is displayed.

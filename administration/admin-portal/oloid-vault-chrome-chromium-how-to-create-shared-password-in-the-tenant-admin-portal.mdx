## Introduction

The Tenant Admin Portal allows admin to create Oloid Vault (Chrome / Chromium) shared password(s) that can be securely managed and shared with multiple authorized users.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to create Vault Shared Password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The Users page is displayed. ![](/images/12275469/ea4a01aa6430.png)
3. Click **Shared Credentials**from the left menu panel **> Vault Passwords.** ![](/images/12275469/ca23ea364a6b.png) The **Vault Shared Password**page is displayed.
4. Click **Create Password**. ![](/images/12275469/9775666c60b6.png) The **Create Vault Shared Password** pop-up box is displayed.
5. On the pop-up box, do the following:Enter **Display Name**.Select **Password Type**as**Web**from the dropdown menu.Enter an existing Username or Primary ID in the **Password Owners**field > select the user from dropdown menu.**Note:** You can select multiple users in the password owner field.Click **Next**. ![](/images/12275469/db0765699364.png) Enter the **Web URL**in the text field.Enter the**Username** of your Chrome Vault account.Enter the **Password** of your Chrome Vault account.Enter **External ID**(optional)**.**Click **Create**. ![](/images/12275469/3da6b4066ff2.png) The Vault Password is created successfully and listed on the**Vault Shared Password** page. ![](/images/12275469/1e506120ee28.png)

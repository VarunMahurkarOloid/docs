## Introduction

The Tenant Admin Portal allows admin to enable OloID accounts for a Connection, providing users with a unique identity across Oloid applications.

**Note:**Enable **OloID accounts** only for Connections used with Oloid Vault, Windows Login, the Tenant Admin Portal and the Oloid User Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- A Connection must be created. To create connections, refer [Tenant Admin Portal - How to Create Connection | Oloid Help Center](/administration/admin-portal/tenant-admin-portal-how-to-create-connection)

## Steps to Enable OloID Account in a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/8488406/578f16962cec.png) The **Connections** page is displayed.
3. Select a connection name to edit. ![](/images/8488406/b1a31ec4b283.png) The **Connection detail** page is displayed.
4. Go to **Configure**tab > **Settings** > turn on **Enable** **OloID Account**toggle.
5. Click **Save**. ![](/images/8488406/c02eeca4c892.png) The OloID account is enabled successfully for all the users in the Connection. ![](/images/8488406/a9416346e685.png) **Note**: OloID account can be created for all OloID account enabled users. To create OloID account, see **[How to create OloID account](/administration/admin-portal/how-to-create-oloid-account-in-tenant-admin-portal)**.

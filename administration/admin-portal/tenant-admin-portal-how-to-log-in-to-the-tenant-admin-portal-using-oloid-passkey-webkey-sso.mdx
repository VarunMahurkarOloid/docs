## Introduction

Oloid Passkey enables secure, passwordless access to the Tenant Admin Portal using device-based authentication.

## ​Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure Passkey is enabled for the User from the Tenant Admin Portal. For more, refer: [Webkey - How to Enable Oloid (Webkey) SSO login](/resources/integrations/sso/webkey-how-to-enable-oloid-webkey-sso-login)

## Steps to log into Tenant Admin Portal using Oloid Passkey

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**.The **Oloid Login**page is displayed.
3. Click **Login with SSO**. ![](/images/13884713/9f7edd503085.png) The configured login options are displayed.
4. Click **Continue with OloID**. ![](/images/13884713/31e95a3942d7.png) The Oloid Authentication page is displayed.
5. Select the preferred credential to login. (Example face, Badge, NFC etc)**Note:**The Login options are displayed based on the authentication methods configured in the Webkey application. ![](/images/13884713/714aea6ca860.png)
6. Complete the Authentication process for the preferred credential.The user is successfully authenticated. ![](/images/13884713/e9716fb5bf9d.png)

## To configure CloudKey follow the below steps:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel.![](/images/10299914/c8560f399688.png)The user profile menu is displayed.
3. Select **Settings**.The **Tenant Settings**page is displayed.![](/images/8803628/362f22134d10.png)
4. Go to **Advanced**tab.![](/images/8803628/dfc2e0b6cc4d.png)
5. Under **Credentials** section select **CloudKey**.![](/images/8803628/2221fe00ba2c.png)
6. On the **Cloudkey Settings** page, do the following:Turn on **Enable CloudKey Proximity check** to set **GPS Refresh Frequency** and **CloudKey Distance**.Note: Cloud key Proximity check if enabled will make only those CloudKey endpoints visible which are within the proximity range. If not enabled, all the endpoints will be visible.![](/images/8803628/65fd0418b2f7.png) To set the GPS frequency, adjust the **GPS Refresh Frequency**.To adjust the distance setting, modify the **CloudKey Distance**.**Note:**Turn off the **Enable CloudKey Proximity check**to allow users to unlock doors without distance constraints.Click **Save**.The CloudKey is configured and is ready to be use.

## Introduction

Browser fingerprint allows Webkey log in to function only on registered browsers.

## Prerequisites

- You must have a Tenant Admin account.
- **Enable Browser Fingerprint** toggle must be switched on.

Browser Fingerprint can also be added to Webkey application from Oloid portal. For further information please refer: [Oloid WebKey - How to edit Configure tab](/passwordless/web/webkey/webkey-how-to-edit-configure-tab)

## Steps to configure Browser Fingerprint

1. Log in to the **Oloid Portal**.
2. Click **Transactions** from the left menu panel. ![](/images/9545445/341bb0ad45b1.png) The **User Transactions** page is displayed.
3. Selectthe latest transactionto edit.**Note:**Browser Fingerprint can only be added from failed transaction. ![](/images/9545445/da4f26598755.png)
4. On the top right, select **Action** > **Add Browser Fingerprint to Application**. ![](/images/9545445/2b7648c2a0a4.png)
5. On the **Confirm Browser Registration** pop-up box, select **Confirm**. ![](/images/9545445/533e61e4474a.png) The browser fingerprint is successfully added to the WebKey application.
6. To view the browser fingerprint details, go to **Applications** > edit **WebKey application** > **Configure** tab > **Settings**> **Browser Settings**. ![](/images/9545445/775c7e0a2791.png) **Note:** It is recommended to use Transactions menu to add browser fingerprint. In case the browser is not registered, manually add the browser details in **Application** detail page.

**Introduction**

In the Tenant Admin Portal, mapping a Connection to an Application allows the Application to use the Connection for authentication and access control. This process ensures seamless integration, enabling secure and efficient identity management. Before mapping, ensure that both the Application and Connection are created.

**Prerequisite**

- The Application must be created. To create Application, refer [How to create an application](/administration/admin-portal/tenant-admin-portal-how-to-create-an-application).
- The Connection must be created. To create Connection, refer [How to create a connection.](/administration/admin-portal/tenant-admin-portal-how-to-create-connection)

**Steps to Map Connection to Application:**

1. Log in to the **Tenant Admin Portal**.The**Applications** page is displayed.
2. Click **Application Name** to edit. ![](/images/8304594/74b912481663.png) The Application Details page is displayed.
3. Go to **Connections** tab > select **+ Add Connections.** ![](/images/8304594/5c3c98adf8e8.png) The **Add Connections** pop-up box is displayed.
4. On the pop-up box, do the following:Select Connection(s) from the **Connection** dropdown list.Click **Add**.**Note:** An application can have up to 5 connections, all of which must be either PC/SC-enabled or none—mixing connection types is not allowed. ![](/images/8304594/bc3adea22c5a.png) The Connection is mapped to Application successfully. ![](/images/8304594/42d0ce637d31.png)

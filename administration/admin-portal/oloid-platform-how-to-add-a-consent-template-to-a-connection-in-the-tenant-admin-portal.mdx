## Introduction

The Tenant Admin Portal allows admins to configure a consent template to obtain user approval before capturing and storing facial data.

## Prerequisites

- You must create a Consent template. To create refer **[How to create a Consent Template](/administration/admin-portal/how-to-create-and-configure-consent-template)**.
- You must have a Tenant Admin Account.

## Steps to add Consent

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/13407101/578f16962cec.png)The **Connections** page is displayed.
3. Select a connection name to edit. ![](/images/13407101/b1a31ec4b283.png) The Connection detail page is displayed. ![](/images/8237994/061907af2378.png)
4. Click **Configure** tab then select **Consent**tab. ![](/images/8237994/584f08015699.png)
5. Click **Enable Consent**. ![](/images/8237994/c1f20ea94402.png) Enable Consent popup-box is displayed.
6. Do the following:Select the applicable **Consent Template** from the dropdown list.**Note:**To create a consent template, refer [How to create a Consent Template](/administration/admin-portal/how-to-create-and-configure-consent-template).Click **Next**. ![](/images/8237994/7494749de491.png) Applicable User Set screen is displayed.Select **All Users** > Click **Next**. ![](/images/8237994/4fde1f3a7d0a.png) Authentication validity pop-up box is displayed.Do one of the following:**No end-date:**Select this option to allow authentication without a defined end date. Face images and biometric data for all users in the connection whether they have already provided consent or have not yet provided will remain valid, and users will continue to authenticate using face biometrics after signing the re-consent document.OR**Permit authentication until the Set Date:** Select this option and enter the preferred date.**Note**: If consent is not provided by the selected date, the face data and associated biometric information will be deleted.Click **Confirm**. ![](/images/8237994/62abddaae60b.png) **Consent Updated** popup box is displayed.Click **Okay**. ![](/images/8237994/ea8323fce375.png) Consent is enabled for the connection. ![](/images/8237994/54d8f592f999.png)

## Introduction

The **Transaction Insights** section under **Insights** provides admin with visibility into authentication across the organization.

## Prerequisite

- You must have Tenant Admin account.

## How to Access Transaction Insights

1. Log in to the **Tenant Admin Portal**.
2. From the left navigation menu, click **Insights**. ![](/images/13228776/0da87143f250.png)
3. Select the **Transaction Insights** tab.The Transaction Insights dashboard is displayed.
4. Do the Following:

## Transaction Status

This section displays the current status of transactions for the selected time period.

Available Time Filters:

- Yesterday
- Last 7 Days
- Last 30 Days

Click **Download** icon to export transaction status data.

<Frame>
  <img src="/images/13228776/5d96767325b1.png" alt="Screenshot" />
</Frame>

**Notes:** If no transactions are available for the selected time range, a _“No data to show yet”_ message is displayed.

**Transaction Status Categories**

- **Success** – Transactions completed successfully.
- **Failed** – Transactions that did not complete successfully.
- **Pending** – Transactions that are in progress.
- **Others** – Transactions that do not fall into the above categories.

## Transaction Growth

<Frame>
  <img src="/images/13228776/002072194484.png" alt="Screenshot" />
</Frame>

Users can do the following:

- Compare growth percentage with the previous period (for example, vs last week).
- Switch between:Last 7 DaysLast 30 Days

Click **Download**.

## User Activity Over Time

This section shows unique user activity based on **successful transactions** over a selected time period.

- **Last 7 Days**
- **Last 30 Days**

<Frame>
  <img src="/images/13228776/87e50bf19c06.png" alt="Screenshot" />
</Frame>

Click **Download**.

The report is successfully downloaded.

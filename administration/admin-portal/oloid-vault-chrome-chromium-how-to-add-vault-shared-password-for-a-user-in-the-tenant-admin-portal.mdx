## Introduction

The Add Vault Shared Password feature allows an admin to securely assign an existing shared password from the Vault to a specific user.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Vault Shared Password must already be created. For more information, refer [How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)

## Steps to Assign Vault Password

1. Log in to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel. ![Image](/images/13284463/bfbd42eb3ee2.png) The **Users** page is displayed.
3. Select preferred **User** from the list. ![Image](/images/13284463/495b74c13e39.png) The **User details** page is displayed. ![](/images/13284463/83f0439c8704.png)
4. Go to **Credential** tab >**Vault Passwords** > **+ Add Vault Shared Password**. ![](/images/13284463/8ab19eaa7c94.png) The Vault Shared password pop-up is displayed.
5. **Select** Vault Shared password to Assign from the dropdown.**Note:**More than one Vault shared password can be assigned for a user.
6. Click **Assign.** ![](/images/13284463/9ab708ca873e.png) Vault shared password is assigned to user. ![](/images/13284463/fc2d4460d530.png)

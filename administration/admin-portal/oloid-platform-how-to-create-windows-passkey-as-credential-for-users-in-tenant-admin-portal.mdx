## Introduction

The Windows Passkey feature in the Tenant Admin Portal allows admin to securely create and assign passkeys for users to access Windows Login application.

## Prerequisites

- You must have Tenant Admin account.
- Passkey must be enabled as a credential in the tenant settings. For further information please refer: [Oloid Platform - How to enable Passkey in Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-enable-passkey-in-tenant-admin-portal-for-windows-login)

## Steps to create Windows Passkey:

1. Log in to the Tenant Admin Portal.
2. On the home page of the portal, click **Directory** on the left menu panel. ![Image](/images/11058549/6142e01fd801.png) The **Users**page is displayed.
3. Click user name to edit. ![Image](/images/11058549/d626c453e0da.png) The **user details** page is displayed. ![](/images/11058549/83f0439c8704.png)
4. Go to**Credentials**tab > **Windows** **Passkey**> **+ Windows Passkey**.![](/images/11058549/3b4948930e2a.png) The **Create Windows Passkey** pop-up box is displayed.
5. Do the following:![](/images/11058549/1d2e143bd173.png) Enter **Display Name**. (Required)Click**Next**.Enter **Domain Name**associated with the Windows account. (Required)Enter **Windows Username**for the user account. (Required)Select Preferred Machine from the **Preferred Machine** dropdown list. (Optional)Upload the**Certificate** file or drag it into the upload area. You may also type or paste the certificate contents manually in the text box. (Required)Upload the **Private Key** file or drag it into the upload area. You may also type or paste the key contents manually in the text box.Click **Create**.

The Windows Passkey is created successfully.

Steps to delete QR Code Credential of Users in a Connection:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory**on the left menu panel. ![Image](/images/8488468/6142e01fd801.png) The **Users** page is displayed.
3. Go to **Action**> **Delete QR Code Credential**. ![Image](/images/8488468/52ddc1adbdec.png) The **Delete QR Code Credential**pop-up box is displayed. ![](/images/8488468/562bbdbf2d8e.png)
4. On the pop-up box, do the following:Select the connection from the **Connection** dropdown list.Under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary. (optional)Click **Delete**.The QR Code is successfully deleted for users in the selected connection. The QR Code summary of these users is shared over email ID(s). ![](/images/8488468/8156261abe86.png)

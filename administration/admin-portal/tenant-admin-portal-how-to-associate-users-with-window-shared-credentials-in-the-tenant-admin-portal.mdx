## Introduction

This document explains how to assign a Windows shared credential to users in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- The Shared Credential must be created in the Tenant Admin Portal. For more information, refer: [How to create shared Password for Windows login application in the Tenant Admin Portal](/passwordless/windows/passwordless/how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal)

## Steps to assign Shared Credential

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/15053580/e756874a3c8d.png) The **Users** page is displayed.
3. Select **Shared Credentials > Windows Password**on the left menu panel. ![](/images/8543917/663a015f0c8a.png) The **Windows Password** page is displayed. ![](/images/8543917/409e661d7082.png)

Do one of the following:

[Assign Shared Password.](#h_4f5ba6abf4)

[Assign Shared Password to Multiple Users](#h_646e9d7f51)

The Windows shared password is successfully assigned to the selected users.

## Assign Shared Password.

1. Select credential name to assign. ![](/images/8543917/1f62460f6f13.png) The **Windows Shared Passwords**listpage is displayed.
2. Click **+ Assign Shared Passwords to Users.** ![](/images/8543917/be6b21ac4efe.png) The **Assign Shared Passwords to Users**pop-up box is displayed.
3. On the pop-up box, enter user name(s) in the **Users**dropdown list.
4. Click **Assign**. ![](/images/8543917/a159831aca13.png) The Windows shared password is successfully assigned to the selected users. ![](/images/8543917/4c87422402e6.png) The Users assigned to the shared password will be visible under the User Assigned section in the Windows shared password. ![](/images/8543917/4bbd79280be7.png)

## Assign Multiple Shared Password to User(s)

1. Select credential name checkbox to assign.**Note:**Multiple Shared Passwords can be assigned to users. To assign multiple passwords select the checkbox next to the required shared password(s) to assign them to users.
2. Click **+ Assign Passwords to Users.** ![](/images/8543917/5a8a578dbbcb.png) The **Assign Passwords to Users**pop-up box is displayed.
3. On the pop-up box, enter user name(s) in the **Users**dropdown list.
4. Click **Assign**. ![](/images/8543917/5368601e9eed.png)

The Windows shared password is successfully assigned to the selected users.

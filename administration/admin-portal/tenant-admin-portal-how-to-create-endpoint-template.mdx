## Introduction

This document explains how to create an Endpoint Template in the Tenant Admin Portal. Endpoint Templates allow Tenant Admins to create reusable configurations that help standardize settings across multiple endpoints.

## Prerequisites

- You must have **Tenant Admin** access to the Tenant Admin Portal.
- The required application must already be created before creating an endpoint template.

## Steps to Create Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** on the left panel menu. ![](/images/8217339/02fc80e9bd26.png) The **Endpoints** page is displayed.
3. On the top right, click **Endpoint** **Templates**. ![](/images/8217339/3b1e2626f48f.png) The **Endpoints Templates** page is displayed.
4. On the top right, click **Create Template**. ![](/images/8217339/e53b292fa838.png) The **Create a New Template** pop-up box is displayed.
5. On the pop-up box, do the following:Enter **Template Name**.Select **Application Type**from **Application Type** drop-down.Select **Endpoint Type** from **Endpoint Type** dropdown.Click **Create**. ![](/images/8217339/d301492efed6.png) The Endpoint template is created and listed on the**Endpoints Template** page. ![](/images/8217339/65a3c646989b.png)

## Introduction

This document explains how to apply an endpoint template to a paired Oloid Verify endpoint in the Tenant Admin Portal. Applying the template makes sure the pre-set settings are automatically applied to the endpoint.

## Prerequisites

- You must have a Tenant Admin Account.
- The Oloid Verify endpoint must be paired. To pair refer [How to pair an Oloid Verify endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint)
- An Endpoint template must be created. To create refer [How to create and configure Oloid Verify Endpoint Template](/administration/admin-portal/oloid-verify-how-to-create-and-configure-endpoint-template-in-tenant-admin-portal)

## Steps to apply Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu. ![](/images/12838474/ffabc347b873.png) The endpoint screen is displayed.
3. Select the **Endpoint**. ![](/images/12866693/6e3d1ab91bae.png) The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**. ![](/images/12866693/b95c5e8d8132.png) The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown. ![](/images/12838474/1576abddb2e6.png) The selected template is displayed in the **Select Template** field.
6. Click **Apply**. ![](/images/12866693/d8aa76401930.png) The template is successfully applied to the endpoint. ![](/images/12866693/f464e507fb49.png)

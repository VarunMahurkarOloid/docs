## Introduction

The Network Connectivity test feature in the Oloid Verify App allows Admin and Supervisor to quickly check endpoint network status. This helps diagnose connectivity issues and ensures that the device can communicate with the configured application.

## Prerequisites

- You must have a Tenant Admin account.
- You must complete the Admin Setup. To setup refer [Oloid Verify: Admin Setup.](/administration/admin-portal/oloid-verify-admin-setup)

## Step to test network connectivity status on the endpoint

1. Launch Oloid **Verify** App. ![](/images/8612537/65448eab37c7.png) The Preview screen is displayed.
2. **Double-tap** on the Preview screen with two fingers.**Note**: You can see Preview screen after the Oloid Verify App is paired with the endpoint.
3. Tap **YES-CONTINUE** to log into **Admin Mode**. ![](/images/8612537/c9178ce671dd.png) The **Settings** screen is displayed.
4. On the **Settings** page, tap **Start** in **Health Check** section. ![](/images/8612537/fcdcea24f3dd.png) The **Please Select Health Type** pop-up box is displayed.
5. On the pop-up box, tap **Network Route Status**. ![](/images/8612537/05fb5e876755.png) The **Network Status** page is displayed. ![](/images/8612537/2d5ef6f29165.png)

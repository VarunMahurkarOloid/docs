## Introduction

The **Activate Add/Delete Users** setting allows the Tenant Admin to grant Supervisors permission to add and delete users directly from the Supervisor App. When enabled, authorized Supervisors can manage users without requiring Tenant Admin intervention.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login application is created in the Tenant Admin Portal. For more information, refer [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable the Add/Delete Users Privilege:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10458687/808e1b9d1624.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/9127132/31eacdeace01.png) The **Tenant Settings** page is displayed.
4. Go to **Advanced** > click **Supervisor Privileges**. ![](/images/9127132/69bbab15a7d2.png)
5. Enable the **Add/Delete Users** toggle.
6. Click **Save.**

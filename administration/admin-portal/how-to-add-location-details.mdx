Steps to add location details:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Transactions** on the left menu panel.![](/images/8227103/2c4bea7fa2d3.png)The **User Transaction Through Your Device**page is displayed.
3. Click **Location Settings**at the bottom of the left menu panel.The **Location Settings**page is displayed.
4. Select location name from the listed locations.![](/images/8227103/ae91b8a29c9e.png)The Location detail page is displayed.![](/images/8498715/408c92ab79bd.png)
5. Enter **Address**.
6. Enter **Description**.
7. Select **+ Add Building** to enter Building Name (Optional).
8. Click **Save**.The location address is updated.![](/images/8227103/f3da17853e5c.png)

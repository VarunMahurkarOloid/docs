## Prerequisites

- You must have access to the Tenant Admin Portal.
- The **Oloid Device Lock** application must be created and configured in the Tenant Admin Portal. For more details refer, [How to Create and Configure DeviceLock Application in the Tenant Admin Portal | Oloid Help Center](/passwordless/android/devicelock/how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal)
- Ensure that the authentication method (FR Mode) is set to **Hybrid**.
- Ensure that the user and endpoint are added to the appropriate group. For more information, refer [How to Configure Group](/administration/admin-portal/tenant-admin-portal-how-to-configure-group). ​

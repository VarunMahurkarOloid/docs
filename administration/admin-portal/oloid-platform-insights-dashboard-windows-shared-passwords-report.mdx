## Introduction

The Windows Shared Passwords report under Insights provides administrators with visibility into Windows credentials that are shared across users or endpoints.

## Prerequisite

- You must have **Tenant Admin** account.

## How to Access User Report

1. Log in to the **Tenant Admin Portal**.
2. From the left navigation menu, click **Insights**.
3. Select the **Reports** tab > **Credentials**> **Windows Shared Passwords.** ![](/images/13256535/efbdb3d4fd25.png) The Windows Shared Passwords page is displayed. ![](/images/13256535/d80a2327f09d.png)
4. Click **Download Report** to export the Windows Shared Passwords report.The Report is successfully downloaded.

Steps to send QR code link:

1. Log in to **Oloid Portal.**
2. On the homepage, click **Directory**from the left menu panel. ![Image](/images/9716724/3bb8e0636a91.png) The**Users** page is displayed. ![](/images/9716724/1f4a03b00f6b.png)
3. Do one of the followings.Select user (s) and then click **Action** > **Send Email** > **Send QR code link.** ![](/images/9716724/4ede4eee62a2.png) The QR code link is sent successfully.![](/images/9716724/e94775c43ea8.png) Click user name to edit. ![](/images/8850381/def026f51c9b.png) The User details page is displayed.Go to **Credentials**tab > **QR Code** > select **Send User Portal Link**. ![Image](/images/8850381/da75fd78849a.png) The link is send successfully. ![](/images/9716724/b3519aac8bfb.png) An email with the user portal link is sent to the registered Email ID.
4. Click the link. ![Image](/images/9716724/43d3d3d26bcd.png) The **Assigned QR Code** page is displayed to view and scan the QR code. ![](/images/9716724/11b17914dca4.png)

## Introduction

The **Endpoint Activity** section under **Insights** provides admin with a consolidated view of endpoint usage, endpoint health, and endpoint growth across the organization.

## Prerequisites

- You must have Tenant Admin account.
- Endpoints must be configured to application for endpoint data to appear.

## How to Access Endpoint Activity

1. Log in to Tenant Admin Portal.
2. From the left navigation menu, click **Insights** Icon. ![](/images/13228751/8b7dcecf8580.png)
3. Select the **Endpoint Activity** tab at the top.The Endpoint Activity dashboard is displayed.Users can download reports for the following sections.

## Active Endpoint Health

This section provides a real-time overview of the health status of active endpoints.

Health Status Categories:

- **Healthy** – Endpoints functioning normally.
- **Attention Needed** – Endpoints that require review due to warnings.
- **Critical** – Endpoints with serious issues that need immediate action.
- **Unknown** – Health status cannot be determined.
- **Health Not Enabled** – Endpoints where health monitoring is not configured.
- **Offline** – Endpoints that are currently unreachable.

<Frame>
  <img src="/images/13228751/4b4751910e78.png" alt="Screenshot" />
</Frame>

At the center of the pie chart, you can view the **Total Active Endpoints** count.

Click **Download** icon.

## Endpoint Growth

The **Endpoint Growth** section displays how the number of endpoints changes over time.

Endpoint growth can be viewed for:

- **Today**
- **Last 7 Days**
- **Last 30 Days**
- **Last 12 Months**

<Frame>
  <img src="/images/13228751/4fbb55868ef6.png" alt="Screenshot" />
</Frame>

**Notes:**

- Compare growth percentage with the previous period (for example, vs yesterday).
- If no data is available for the selected time range, a _“No data to show yet”_ message is displayed.

Click **Download** icon.

## Endpoint Status

This section shows the overall status of all endpoints in the system.

**Status Types:**

- **Active** – Endpoints currently in use and available.
- **Inactive** – Endpoints that are registered but not currently active.

The center of the chart displays the **Total Endpoints** count, combining both active and inactive endpoints.

<Frame>
  <img src="/images/13228751/1f49cda996a6.png" alt="Screenshot" />
</Frame>

Click **Download** icon.

## Introduction

Users need to provide consent to store and use their face for different applications within the workplace during face onboarding.

## Prerequisite

- You must have a Tenant Admin account
- Legal Document must be created. Refer **[How to create Legal Document](/administration/admin-portal/how-to-create-legal-document)**.

## To create a consent template

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Consent Documents** on the left menu panel. ![Image](/images/14459745/2455aadfc001.png) The **Consent Documents**page is displayed.
3. On the top right, select **Create Consent Template**. ![Image](/images/8254979/6a29746f3bc9.png) The **Create Consent Template**pop-up dialog box is displayed.
4. On the pop-up dialog box, provide the **Template Name**. ![](/images/8254979/e821a052b46b.png)
5. Click **Create Template**.The template detail page is displayed.On the template detail page, do the following:Enter **Consent Document Heading**. (Required)Edit **Version**number. (Required) Edit **Section Heading**. (Required)Edit **Consent Description**. (Required)Select template status from **Status**dropdown.**Note:**The consent document can not be added to a connection unless it is in the published status. A Consent template in draft status cannot be added to connections. Select language from **Preferred Language** dropdown. (Optional)**Note:**The selected language will appear in consent documents across all apps during face onboarding. Change **Legal Document Heading**. (optional)Select legal document(s) from **Legal Document**dropdownlist. (Required)**Note:**If unavailable, click **Create Legal Document**to upload a new legal document. Refer **[How to create Legal Document](/administration/admin-portal/how-to-create-legal-document)**.Enable **Show Scope** toggle.**Note:**Enabling this toggle displays the consent form's scope, indicating whether it applies to all applications or only the visitor application.Click **Save**. ![](/images/8254979/cb10e89a6f73.png) The Consent Template is configured successfully. ![](/images/8254979/1cf879b8b625.png) Keywords| Create consent template| Consent documents| Legal Documents| Configure Consent Template| Consent document setup|

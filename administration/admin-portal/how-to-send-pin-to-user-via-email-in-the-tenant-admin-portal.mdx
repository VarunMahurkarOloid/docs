## Introduction

This document explains how Tenant Admin can send a user’s **PIN credential** through the Tenant Admin Portal. Admins can securely share the PIN with users via email or SMS, allowing them to use it for authentication without manual setup.

## Prerequisite

- You must have access to the Tenant Admin Portal
- The registered email ID must be added to the user's profile on the Tenant Admin Portal.

## Steps to send Pin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Directory**, from the left menu panel. ![](/images/14750432/e8a65014f485.png) The **Users** page is displayed.
3. Click **username** to edit. ![Image](/images/14750432/495b74c13e39.png) The **user details** page is displayed.
4. Go to **Credentials** tab > **PIN** > **Send PIN**. ![](/images/14750432/bd948a86a228.png) ![](/images/14750432/8364924aca4b.png)
5. Do one the following:Via Email: The **Send PIN via Email**is displayed.Enter email ID(s) and select from the dropdown to whom you want to send the mail in **Send Email to** field.Click **Send**.The PIN is sent to Email successfully. ![](/images/14750432/6d405301129c.png) Via Phone Number: The **Send PIN via Phone Number**is displayed.Enter phone number of the user.Click **Send**. ![](/images/14750432/648843cce908.png) The PIN is sent to user via SMS successfully ![](/images/14750432/fbaf7170cc29.png)

The user can access the **PIN** from their Email.

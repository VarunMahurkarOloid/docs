## Introduction

This document explains how to create and assign QR Code credential for a user in the Tenant Admin Portal.

## Prerequisite

You must have Admin access to the Tenant Admin Portal.

## Steps to create QR code

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8294162/c546ab441e29.png) The **Users** page is displayed.
3. Click **username** to edit. ![](/images/8294162/aa10b2677d54.png) The **User details** page is displayed.
4. Do one of the following:Go to **Assign Credential** > **Create QR Code**. ![Image](/images/8294162/2590a1fac049.png) Go to **Credentials**tab > **QR Code** >**+Create QR Code**. ![Image](/images/8294162/240144e08155.png) The **Create QR Code**pop-up window is displayed.
5. On the pop-up box, do the following:Select **QR Code Validity**from the calendar. Enter one or more **email IDs** of the recipients(Optional).**Note:** To add multiple recipients, separate each email ID using a comma (,).Click **Assign**. ![](/images/8294162/c9422cc12730.png) The QR code is created and listed in the **QR Code**tab. The QR code is sent to the recipient's (user's) email id. ![](/images/8294162/cf2cb9689c81.png) Watch our video [How to add QR Code as credential to users - Video Tutorial](/administration/admin-portal/how-to-add-qr-code-as-credential-to-users-video-tutorial) Keywords

## Introduction

This document provides instructions to create a group in the Tenant Admin Portal. Groups help organize users and endpoints for easier management and configuration.

## Prerequisite

You must have admin access to a Tenant Admin Portal.

## Steps to Create a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Groups** on the left menu panel. ![](/images/8294358/1f65ec6ced12.png) The **Groups** page is displayed.
3. Click **Create Group** on the top right corner. ![](/images/8294358/a8a132a3ba4f.png) The **Create a new Group** pop-up box is displayed.
4. Enter **Group Name** and click **Create**. ![](/images/8294358/f97b23a9b9a1.png) The new group is created and listed on the Groups page. ![](/images/8294358/b98f7b02b35f.png) Video Tutorials**[How to create a Group in the Oloid Portal - Video Tutorial](/administration/admin-portal/how-to-create-a-group-in-the-oloid-portal-video-tutorial)**

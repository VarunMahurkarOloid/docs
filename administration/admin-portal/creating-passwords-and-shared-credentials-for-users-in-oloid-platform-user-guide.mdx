## Introduction

This document provides step-by-step instructions to create password and shared credential for users in the Oloid Portal.

## Pre-requisite

You must be a user in the Oloid Portal.  
​

## Accessing Oloid Portal

To access Oloid Portal, you should be a tenant admin. Once the tenant admin account is created, you will receive the URL and credentials (username and temporary password) for the portal on your registered email id.

## To set new Password

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar. Then, press **Enter** on your keyboard.
3. Enter your login information in the appropriate fields.![](/images/8423861/0bd5c218b1c0.png)
4. Click **LOGIN**.The **Set New Password** screen is displayed.![](/images/8423861/da0e64c931d5.png)
5. Enter New Password.**Note**: Password must contain at least one uppercase, one lowercase letter, one number, no consecutive or sequence characters The password should not contain any part of username.
6. Enter Confirm Password.
7. Click **LOGIN**.The Oloid Portal is displayed.

## To Access Oloid Portal

**Pre-requisite**: You should be a user with Oloid Portal.

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar. Then, press **Enter** on your keyboard.
3. Enter your login information in the appropriate fields.![](/images/8423861/c8525a9a83c8.png)
4. Click **LOGIN**.The Oloid Portal is displayed.**Note**: Oloid uses **SSO login** and also allows you to log in to the portal with your Google, Microsoft, Okta, or with your Email account.

## Create and Manage Credentials

Credentials allow a user to access and authenticate themselves on the Oloid Portal.

## To Create Password

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.![](/images/12275469/b9c707f0a9b1.png)The **Users** page is displayed.
3. Click **User Name** to edit.![](/images/8423861/c01c4e675212.png)The User details page is displayed.
4. Go to **Credentials** > **Passwords** tab > **CREATE PASSWORD**.![](/images/8423861/305e2b492de2.png)The **Create Password** pop-up box is displayed.![](/images/8423861/b6e14cb5f9c2.png)
5. On the pop-up box, do the following: Enter **Display Name** that displays on the Windows Login page.Select a user type from **User Type** dropdown list. Enter **Machine Name**. Enter **Username**of your Windows Login. Enter **Password**of your Windows Login. Click **Save**. The password is created and listed in the **Passwords** tab.![](/images/8423861/8e17313b76ff.png)

## To Edit Password

1. Go to the **Users** page.
2. Click **User Name**to edit.![](/images/8423861/c01c4e675212.png)The User details page is displayed.
3. Go to **Credentials** > **Passwords** tab.
4. Click **edit** icon for a particular user.![](/images/8423861/2d5c35b076f8.png)The **Edit Password** pop-up box is displayed.![](/images/8423861/a11f7f6a53d2.png)
5. Enter the new password in the **Password** field.**Note**: You should update the password only when you update the Windows password.
6. Click **Update**. The password is updated successfully.

## To Delete Password

1. Go to the **Users** page.
2. Click **Display Name** to edit. ![](/images/8423861/c01c4e675212.png)The User details page is displayed.
3. Go to **Credentials** > **Passwords** tab.
4. Click **delete** icon for a particular user.![](/images/8423861/043877734266.png)A confirmation pop-up box is displayed.![](/images/8423861/97e340a75ec7.png)
5. Select **DELETE**. The user is successfully deleted.

## Create and Manage Shared Credentials

Shared Credentials are passwords that can be used to access a local windows machine or a domain. It is shared among users to which they are assigned to.

## To Create shared Credential

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png)The **Users** page is displayed.
3. Click **Shared Credentials**on the left menu panel.![](/images/8423861/c2da54edb1f6.png)The **Shared Credentials** page is displayed.
4. On the top right, click **Create Credentials**.![](/images/8423861/ed1ab0cb0260.png)The **Create Shared Credential** pop-box is displayed.![](/images/8423861/3b7b8bf28111.png)
5. On the pop-up box do the following: Enter **Display Name** that displays on the Windows Login page.Select user type from **User Type** dropdown. Enter user name then select **Credential Owner**from the dropdown list.Select **Next**. Enter **Machine Name**.Enter**Username** of your Windows Login. Enter **Password** of your Windows Login. Click **Save**. The credential is created and listed on the**Shared Credentials** page.![](/images/8423861/12c60139946b.png)

## To Edit Shared Credential

1. Go to the **Users**page.
2. Click **Shared Credentials** on the left menu panel. ![](/images/8423861/c2da54edb1f6.png)The Shared Credentials page is displayed.
3. Click **edit** icon for a particular user.![](/images/8423861/07eddd2bd8cd.png)The **Edit Password** pop-up box is displayed.![](/images/8423861/1b2ddcd47ffb.png)
4. Enter the new password in the**Password** field. **Note**: You should update the password only when you update the Windows password.
5. Click **Update**. The password is updated successfully.

## To Delete Shared Credential

1. Go to the**Users**page.
2. Click **Shared Credentials** on the left menu panel.The **Shared Credentials** page is displayed.
3. Click **delete** icon for a particular user.![](/images/8423861/a6701f304065.png)A confirmation pop-up box is displayed.![](/images/8423861/a9b82900ad4c.png)
4. Select **DELETE**. The credential is removed from the **Shared Credentials** page.

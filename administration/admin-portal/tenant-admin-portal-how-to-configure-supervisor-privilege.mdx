## Introduction

This document provides step-by-step instructions to configure Supervisor privileges in the Tenant Admin Portal.

## Prerequisites

- You must have Tenant Admin access to the Tenant Admin Portal.
- Ensure that the applicable user is assigned the Supervisor role.

## Steps to Configure Supervisor Privileges

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10660395/cf3ebe1f2be0.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/9799715/5dbfea67c0e6.png) The **Tenant Settings** page is displayed.
4. Go to **Advanced** Tab > **Supervisor Privileges**. ![](/images/9799715/ee03085b6000.png)
5. Do the following :Enable **Add/Delete Users** toggle button to allow the supervisor to add or remove users.Enable **Endpoint Pairing** toggle button to allow the supervisor to create or pair new endpoints. ![](/images/9799715/243aae5e9514.png) The Supervisor Privileges are updated successfully. ![](/images/9799715/d498fd02f944.png)

## Introduction

This document explains how to configure PIN settings in the Tenant Admin Portal, including PIN format, lock policy, retry limits, and validation rules for user PIN credential.

## Prerequisite

You must have **Tenant Admin access** to the Tenant Admin Portal.

## Steps to Configure the PIN Credential

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/8407872/9a27ffbd000c.png) The user profile menu is displayed.
3. Select **Tenant** **Settings**. ![](/images/8407872/f05afcff224a.png) The **Tenant Settings** page is displayed.
4. Go to **Advanced** > **PIN**. ![](/images/8407872/29e25ce3916f.png) The PIN configuration page is displayed.
5. Enable **Allow Duplicates** toggle to permit identical PINs for multiple users.
6. Do the following:[Setup Configure PIN type](#h_48a70c1c05)[Configure PIN Lock Policy](#h_06934e4369)
7. Configure Maximum Pin Attempts to set the number of retries allowed.**Note:** The default value is **3 attempts,** and the maximum allowed value is **5 attempts**.
8. Enable the **Prevent Consecutive Characters in PIN** toggle to prevent users from setting PINs with consecutive numbers or characters.
9. Click **Save**. ![](/images/8407872/7f732bfcad52.png) The PIN is configured successfully.

## Setup Configure PIN Type

The Configure PIN type setting defines the format and length of the PIN that users can set as a credential.

1. Do one of the following:

**Numeric 4-Digit PIN (Default):** Allows only a 4-digit numeric PIN.

**Advanced Settings**

| **Field name** | **Description** |
|---|---|
| Block Consecutive Repeats | To prevent PINs with repeating characters (for example, aaa, 111) |
| Block Sequences | To prevent PINs with sequential characters (for example, 1234, abcd, ZYX). |

**Numeric 6-Digit PIN:** Allows only a 6-digit numeric PIN.

**Advanced Settings**

| **Field name** | **Description** |
|---|---|
| Block Consecutive Repeats | To prevent PINs with repeating characters (for example, aaa, 111) |
| Block Sequences | To prevent PINs with sequential characters (for example, 1234, abcd, ZYX). |

**Open (Alpha - Numeric PIN):** Allows a PIN of 8 to 15 characters using letters, numbers, and special characters.

**Advanced Settings**

| **Field name** | **Description** |
|---|---|
| Block Consecutive Repeats | To prevent PINs with repeating characters (for example, aaa, 111) |
| Block Sequences | To prevent PINs with sequential characters (for example, 1234, abcd, ZYX). |
| Prevent Digits | To restrict the use of numeric characters in the PIN. |
| Prevent Special Characters | To restrict the use of special characters in the PIN. |
| Prevent Letters | To restrict the use of alphabetic characters in the PIN. |
| Prevent Spaces | To prevent spaces in the PIN. |

2. Click **Save**.

<Frame>
  <img src="/images/8407872/bde6135e322c.png" alt="Screenshot" />
</Frame>

The confirmation pop-up box is displayed.

3. Enter **Confirm** and click **Apply Action**.

<Frame>
  <img src="/images/8407872/8f17a53a0415.png" alt="Screenshot" />
</Frame>

The **Configure PIN Type** is setup successfully.

## Configure PIN Lock Policy

The PIN Lock Policy tab is used to configure the settings for locking a PIN after consecutive failed authentication attempts and defining the unlock behaviour.

Do the following:

1. Turn on**Enable PIN Lock** toggle.
2. In **Consecutive failures attempts to trigger PIN Lock**, select the number of consecutive incorrect PIN attempts required to trigger the PIN lock.
3. In **Time-window for locked PIN**, specify the duration within which failed PIN attempts are evaluated.
4. Under **Auto-unlock PIN after**, select one of the following options:**After**: Specify the duration after which the locked PIN is automatically unlocked.**Never:** Keeps the PIN locked until it is reset by an admin.
5. Click **Save**. ![](/images/8407872/dbed03587d5f.png)

The **PIN Lock** is successfully configured.

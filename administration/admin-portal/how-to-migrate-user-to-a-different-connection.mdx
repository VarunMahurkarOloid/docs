Steps to Migrate User to a different Connection:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![Image](/images/8379283/6142e01fd801.png) The **Users** page is displayed.
3. Click **Username** to edit. ![Image](/images/8379283/1d6f2403541a.png) The User details page is displayed.
4. Go to **Action** > Select**Migrate User**. ![Image](/images/8379283/78f140f24140.png) The **Migrate User** pop-up box is displayed. ![](/images/8379283/d738d258f503.png)
5. Select connection to map from **Connection**dropdown.
6. Click **Save**.

The user is migrated and mapped to the new connection.

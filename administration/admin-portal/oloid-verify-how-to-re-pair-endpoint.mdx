## Introduction

The Re-pair Endpoint feature in the Oloid Verify App allows Admin and Supervisor to restore an endpoint. This process ensures that the endpoint reconnects properly with the assigned application and continues to operate as expected.

## Prerequisite

- You must have a Tenant Admin account.
- You must complete the Admin Setup. To setup refer [Oloid Verify: Admin Setup.](/administration/admin-portal/oloid-verify-admin-setup)

## Steps to re-pair an endpoint

1. Launch the **Oloid Verify** app. ![](/images/10198654/65448eab37c7.png)
2. Log in to Admin mode in Oloid Verify app. To login refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](/administration/admin-portal/oloid-verify-how-to-log-in-to-admin-mode-as-an-admin-or-supervisor)The **Home**screen is displayed. ![](/images/10198654/6e652025153e.png)
3. Go to **Settings** tab.
4. Tap **Click here to Re-pair if advised by Admin**. ![](/images/10198654/0bd16d97396f.png) The **Enter Endpoint ID** pop-up is displayed.
5. On the pop-up, do the following:Enter**Endpoint ID**.Tap **Re-pair**. ![](/images/10198654/e18a33a9b547.png) The Endpoint is re-paired successfully. ![](/images/10198654/2a0247d9ab10.png)**Note:** Kill and relaunch the app to make the new updates function properly.

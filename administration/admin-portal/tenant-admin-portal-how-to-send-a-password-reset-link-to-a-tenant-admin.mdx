## Introduction

This document provides instructions to reset the password for a Tenant Admin from the Tenant Admin Portal. When you reset the password, a password reset link is sent to the Tenant Admin's registered email address.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to reset password for Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left of the menu panel. ![](/images/8237046/ec9eff557a80.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/8237046/d7ea2e9bb3d2.png) The **Tenant Settings** page is displayed. ![](/images/8237046/17d12b67f39c.png)
4. Go to **Admin Controls** > **Tenant Admin.** ![](/images/8237046/bb0978070597.png)
5. Locate the Tenant Admin, and then select the **kebab menu** (three vertical dots) > **Reset Password**. ![](/images/8237046/c2b5312e2fad.png) The **Reset password** pop-up box is displayed.
6. Click **Confirm**. ![](/images/8237046/64dc96fdf6b8.png) The user reset password link is successfully sent to the Tenant Admin's email ID. ![](/images/8237046/87a0129f78c9.png)

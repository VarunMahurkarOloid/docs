## Introduction

The Tenant Admin Portal allows admin to create Connection Groups, which are logical groupings of multiple connections. These groups help organize and manage complex access policies across different locations, enabling shared configurations, policies, and permissions to be applied efficiently.

## Prerequisite

- You must have a Tenant Admin account.**Note**: You must have Connection Groups access to see this feature in Tenant Admin Portal. Contact Oloid Support for more information.

## Steps to Create Connection Groups:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/8304214/53248ce640c2.png) The **Connections** page is displayed.
3. Click **Connection Groups** on the top right corner of the page.**Note:** If the **Connection Groups** option is not displayed on the Connections page, contact Oloid Support. This feature must be enabled by Oloid to be available. ![](/images/8304214/cfc6488abb48.png) The **Connection Groups** page is displayed.
4. On the top right, click **Create Connection Group**. ![](/images/8304214/ab2e7aa36eee.png) The **Create a new Connection Group** pop-up box is displayed.
5. On the pop-up box, do the following:Enter a connection group name in the **Connection Group Name**text field.Click **Create**. ![](/images/8304214/52bac0e99269.png) A new connection group is created and listed on the **Connection Groups** page. ![](/images/8304214/a4cdebc076d5.png)

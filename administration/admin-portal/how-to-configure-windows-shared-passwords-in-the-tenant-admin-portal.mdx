## Introduction

The Tenant Admin Portal allows admins to manage Windows Shared Passwords and control access using users, groups, and ownership assignments. Adding groups to a Windows Shared Password enables multiple users to inherit access through group membership

## Prerequisites

- You must have a Tenant Admin account.
- Group must be created in the Tenant Admin portal. For more, refer: [How to create group](/administration/admin-portal/how-to-create-group)
- Windows shared password must be created. For more, refer: [How to create shared Password for Windows login application in the Tenant Admin Portal](/passwordless/windows/passwordless/how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal)

## Steps to Configure to Windows Shared Password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/13348724/52b1093b9ddd.png) The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password**on the left menu panel. ![](/images/13348724/53e10d0fbd01.png) The **Windows Shared Password** page is displayed. ![](/images/13348724/d4f43ed318ac.png)
4. Select Shared Password from the list.The Windows shared password details page is displayed.
5. Do the following:[Configure Users Assigned](#h_210b437e2a)[Configure Password Owners](#h_d4aa44bdab)[Configure Groups Tab](#h_94d9e5c23c)[Configure Details Tab](#h_45c7c58db7)
6. Click **Save**after configuration changes.The Windows shared password is successfully configured.

## Users Assigned

This tab displays users who are assigned to use the shared password. Multiple users can be assigned shared windows passwords. For more, refer: [How to associate users with shared credentials](/administration/admin-portal/tenant-admin-portal-how-to-associate-users-with-window-shared-credentials-in-the-tenant-admin-portal)

This tab displays users who have ownership privileges over the shared password. More password owners can be added from the tenant admin portal. ## Configure Details Tab

This tab displays configuration details of the shared password.

To configure the Details tab do the following:

1. Enter **Display Name** Name assigned to the shared password.
2. Enter **Username** Username associated with the credential.
3. Enter **Domain Name** Domain in which the credential is valid.
4. Enter **Password** Indicates whether the password is configured. ​**Note:**Use the edit option to update the password.
5. Enter **Password Source** Displays how the password was configured (for example, Manual - Supervisor).
6. Select **Password Type** Type of password (for example, Windows Domain User).
7. Select **Preferred Machine(s)**
8. Enter **External ID**(Optional)
9. Click **Save**.

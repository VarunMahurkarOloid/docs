This guide will walk you through the steps to generate a **Client ID** and **Client Secret** in the Oloid Portal. These credentials are essential for making API calls to integrate workflows and manage tenant configurations.

## Steps to generate a Client ID and Secret:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10458687/808e1b9d1624.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![Image](/images/10458687/dd6256eec1ca.png) The **Tenant Settings** page is displayed.
4. Go to**Security Tab**>**API Token**>**Admin Token**. ![](/images/10458687/68d34d827141.png) The Generate Admin Credential section is displayed.
5. Click **Generate**to generate a new **Client ID** and **Client Secret**. ![](/images/10458687/d2aaafaaf9fc.png) The Client ID and Client Secret are displayed.**Client ID**: This is a unique identifier for your tenant.**Client Secret**: This acts as a password and should be kept confidential.**Get Secret**: Click **Get Secret**to show the unmasked **Client Secret**. ![](/images/10458687/a15da346c210.png)

<Frame>
  <img src="/images/10458687/8e390024dda2.png" alt="Screenshot" />
</Frame>

The generated **Client ID** and **Client Secret** can now be used as the username and password, respectively, in API calls.

## Deleting and Regenerating Credentials

If you need to revoke the current credentials:

1. Click the **Delete** button next to the existing Client ID and Secret. ![](/images/10458687/fb3f0f5b672d.png)
2. Repeat the steps above to generate a new set of credentials.

## Security Best Practices

• Store the **Client Secret** in a secure location, such as a password manager.

• Avoid sharing these credentials publicly or with unauthorized personnel.

• If you suspect the credentials have been compromised, immediately delete them and regenerate a new set.

If you encounter any issues, please contact [Oloid Support](mailto:support@oloid.ai)

## Introduction

A Scheduled Transaction Report can be configured to schedule the report generation frequency and send it to the customers through email.

## Prerequisite

- You must have a Tenant Admin account.
- The Scheduled Transaction Report must be created. Refer: **[How to create a scheduled Transaction Report](/administration/admin-portal/how-to-create-a-scheduled-transaction-report)**

## Steps to configure Scheduled Transaction Report:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel. ![Image](/images/8455213/7449cd2b7f6e.png) The **Scheduled Reports** page is displayed.
3. Select a report name of transaction **Report Type** to edit. ![Image](/images/8455213/973b36c8bb02.png) The report type detail page is displayed. ![](/images/8455213/fcbffbb40235.png)
4. Do the following:**Settings** tab:Enter **Report Description**.Enter time unit for **Frequency**. Select a supported frequency: **Day**, **Hour**, **Minutes**.Enter **Recipient Emails**.**Endpoints**tab: Click **+ Add Endpoint**. ![Image](/images/8455213/16cac80eb8ab.png) The **Add Endpoint** pop-up box is displayedSelect **Endpoint**(s) to send transaction reports to the recipient emails.**Note:**Multiple endpoints can be added from the dropdown.Click **Add**. ![](/images/8455213/0e2fdd3dca3e.png)
5. Click **Save**.The transaction report is configured. ![](/images/8455213/de91509b371b.png)
6. On the**Scheduled Reports**page, turn on the **Status** option to send scheduled transaction reports to the specified email address(es) of recipients. ![Image](/images/8455213/ded56d1eacf5.png) **Keywords**|Transactions Report| Configure Transactions Report| Create Transactions Report| Download Transactions Report| Scheduled Report| ​

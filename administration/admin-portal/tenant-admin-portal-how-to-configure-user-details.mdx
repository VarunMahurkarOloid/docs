## Introduction

The User Details section in the Tenant Admin Portal allows administrators to create, assign, manage and update user-credentials for all users in the connection(s).

## Prerequisites

- You must have a Tenant Admin account.
- User must already exist in the Tenant Admin Portal.

## Steps to configure User Details:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** icon on the left panel menu. ![](/images/8347344/e8a65014f485.png) The **Users**page is displayed.
3. Click user name to edit. ![](/images/8347344/5199220d18a8.png) The User details page is displayed.

Configure the following:

1. [Details tab](#h_9370d6456b)
2. [Credentials tab](#h_3e38095eb2)
3. [Groups tab](#h_e595da8537)
4. [Transactions tab](#h_fc0edd8ec1)
5. [Consent](#h_4d9c957a94)

The User details are configured.

## Configure Credentials Tab

You may enable one or more credentials based on your requirements.

<Frame>
  <img src="/images/8347344/4dec858786b4.png" alt="Screenshot" />
</Frame>

### Face tab

To use face as credential, configure **Face**option. The Face tab allows you to add or invite user to add face for authentication.

**Note:**A user face cannot be onboarded if the user has not provided consent in the Oloid User Portal.

<Frame>
  <img src="/images/8347344/cad3aead315e.png" alt="Screenshot" />
</Frame>

Do the following:

- **Upload Face:**This option allows you to upload the user's face. For further information, see **[How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user)**
- **Capture Face:**This option allows you to capture the user's face. For further information, see How to capture face of a single user **[Tenant Admin Portal - How to Add face using Capture Face](/administration/admin-portal/tenant-admin-portal-how-to-add-face-using-capture-face)**
- **Invite to Add Face:**This option sends an email to the user with a link to upload their facial image. For further information, see**[How to invite to add face](/administration/admin-portal/how-to-invite-to-add-face)**

### QR Code tab

To use QR Codeas credential, configure **QR code** option. The QR Code tab allows you to manage the user's QR code credentials.

<Frame>
  <img src="/images/8347344/be4deec63528.png" alt="Screenshot" />
</Frame>

Do the following:

- **Create QR Code:**Select this option to create QR Code for the user. For further information, see **[How to create QR Code as credential for user](/administration/admin-portal/tenant-admin-portal-how-to-create-and-assign-qr-code-credential-for-a-user)**
- **Send QR Code on Email:**Select this option to send the QR code to the user's registered email ID. For further information, see **[How to send QR Code on Email](/administration/admin-portal/how-to-send-qr-code-on-email)**
- **Send User Portal Link:**Select this option to send the user the User Portal Link via email, allowing them to manage their credentials, including viewing or downloading the QR code. For further information, see**[How to send QR Code credential to user using user portal link](/administration/user-portal/how-to-send-qr-code-credential-to-user-using-user-portal-link)**

### Badge ID tab

To use badgeas credential, configure **Badge ID** option. The Badge ID tab allows you to assign or enroll a user's badge for authentication.

<Frame>
  <img src="/images/8347344/2e3c8a23aab2.png" alt="Screenshot" />
</Frame>

Do the following:

- **Assign Badge:**Select this option to manually assign a badge to the user. For further information, see **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- **Scan Badge to Enroll:** Select this option to scan or enter badge ID to enroll a new badge for the user. For further information, see **[How to enroll users using badge scan in Oloid Portal](/administration/admin-portal/how-to-enroll-users-using-badge-scan-in-oloid-portal)****Note:**Changes here create temporary badges. Use 'Replace Badge' for permanent changes.

### Windows Password tab

To use Windows Passwordas credential, configure **Windows Password** option. The **Windows Passwords** tab allows the admin to create and manage the user's Windows login credentials.

<Frame>
  <img src="/images/8347344/9288e00db524.png" alt="Screenshot" />
</Frame>

Do the following:

- **Create Password:**Select this option to generate a new Windows password for the user. For further information, see **[How to create Password for Windows Login](/passwordless/windows/passwordless/how-to-create-password-for-windows-login)**
- **Add Windows Shared Password:** Select this option to add Windows shared credentials for Windows systems, which multiple users can access.For further information, see**[How to assign Shared Credentials to user](/passwordless/windows/passwordless/how-to-assign-shared-password-for-windows-login-in-the-tenant-admin-portal)**
- **Invite to add password:**Select this option to Invite users to Add Windows password for Windows systems.For further information, see**[How to send invite to add Password to a user](/administration/admin-portal/how-to-send-invite-to-add-password-to-a-user)**

### Vault Passwords tab

To use Vault Password credential, configure **Vault Passwords** option. The Vault Passwords tab allows you to manage the user's web password credentials.

<Frame>
  <img src="/images/8347344/dd7f4dfc7479.png" alt="Screenshot" />
</Frame>

Do the following:

**Create Password:** Select this option to create password for web (Chrome Vault) application. For further information, see **[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)**.

**Add Vault Shared Password:**Select this option to assign a shared password for web (Chrome Vault) application. Please refer: **[Chrome Vault: How to Add Vault Shared Password for a User in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-add-vault-shared-password-for-a-user-in-the-tenant-admin-portal)**

### PIN tab

To use PIN credential, configure **PIN** option. The PIN tab allows you to manage the user's PIN configuration.

<Frame>
  <img src="/images/8347344/5861caaf2436.png" alt="Screenshot" />

Do the following:

- **Add PIN:**Select this option to add PIN to the user. For further information, see**[How to add PIN as credential to users](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users).**
- **Send Reset PIN Email:**Select this option to allow users to Reset PIN. To add and configure PIN. For further information, see **[How to send invite to set Pin on Email to a user](/administration/admin-portal/how-to-send-an-email-invite-to-users-to-set-their-pin)**.

## Consent tab

The **Consent** tab shows the user’s current consent status and their complete consent history.

**Note:**Consent Status are as follows:

- Provided: User has provided consent for adding face
- Denied: User has rejected consent
- Pending: User has been sent the consent and user action is pending.
- Reconsent Pending: User had previously denied consent and was re-shared the consent and user action is pending.

Click the download icon to save consent file.

</Frame>

## Introduction

The Tenant Admin Portal allows the admin to securely manage shared passwords across the organization. One of its key features is the ability to assign password owners, groups and users for Windows Shared Password.

## Prerequisites:

- You must have access to the **Tenant Admin Portal**.
- The Windows Shared Password must be created. To created Windows Shared Password refer [How to create shared Password for Windows login application in the Tenant Admin Portal](/passwordless/windows/passwordless/how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal).

## Steps to add Password Owners:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Select **Shared Credentials > Windows Password**on the left menu panel. ![](/images/8544435/500eca9ede88.png) The **Windows Shared Password** page is displayed.
4. Select the preferred display name to edit. ![](/images/8544435/5d0337a9f11b.png)
5. Go to **Password Owners**tab >**+ Add Password Owners**. ![](/images/8544435/034e92f540db.png) The **Add Password Owners**pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users**dropdown list.**Note:**Only users with Admin or Supervisor roles can be assigned as Password Owners.
7. Click **Assign**.

## Introduction

This document explains how to create and configure an **Oloid Verify**application type in the Tenant Admin Portal.

## Prerequisite

You must have a Tenant Admin Account.

## Steps to create and configure Oloid Verify Application

1. Log in to the**Tenant Admin** **Portal**.
2. On the **Applications** page, click **Create Application**. ![](/images/8300813/99ffd8a0b067.png) The **Create New Application** pop-up box is displayed. ![](/images/8300813/260d2ea2aff2.png)
3. On the pop-up box, do the following: Enter **Application Name**and select **Oloid Verify** for **Application Type**.Click **Create**.The **Oloid Verify** application is created and the configuration page is displayed.
4. Configure the following:[Details tab](#h_1819a9e861)[Authenticator tab](#h_e9f9194b90)[Design Theme tab](#h_1509b17f13)[Configure tab](#h_a2c5538f8f)[Configure Health Setup tab](#h_6e50d72a2b)[Configure Connections tab](#h_3d81b1d8a6)[Configure Integrations tab](#h_3d81b1d8a6) **Note**: These are one-time settings and all the default settings are recommended.

## Configure Details tab

1. Modify **Application name**(if required).
2. Add **Description** (Optional).
3. Set **Time-zone** (Optional).
4. Set **Idle Screen Soft Time Limit** (Optional).
5. Set **Idle Screen Hard Time Limit**(Optional).
6. Click **Save**. ![](/images/8300813/26fa427cafd9.png)

## Configure Authenticator tab

### Face

To use face as a credential, enable **Face**option.

Note: **Face** is enabled by default.

<Frame>
  <img src="/images/8300813/4c44ed26ad9b.png" alt="Screenshot" />
</Frame>

1. From the **FR Mode** drop-down, select the preferred face recognition mode:**Hybrid**: Combines cloud and on-device facial recognition.**Cloud**: Uses cloud-based facial recognition.**On Device**: Uses on-device facial recognition.
2. Enter the **On-Device Model** (e.g., ModelV) if applicable.
3. [Configure Liveness Mode](#h_2446ab73a4)
4. Click **Save**.

### Configure Liveness Mode

You can configure liveness detection for face authentication to protect against spoofing.

<Frame>
  <img src="/images/8300813/4cae3249befb.png" alt="Screenshot" />
</Frame>

1. Choose a liveness mode:Enable **Hardware Liveness** in devices with dedicated hardware sensors for higher accuracy. Enable **Software Liveness** to use software-based analysis to verify the captured face image authenticity.**Note:** Software Liveness verification may take longer to complete compared to Hardware Liveness verification. By default Hardware Liveness is enabled.
2. Adjust the following settings for Software Liveness:**Min Liveliness Probability**:Determines the probability threshold to classify an image as live.Default: `0.5` **Min Liveliness Quality**:Defines the minimum acceptable quality for images used in liveness checks.Default: `0.5`
3. Click **Save**.

<Note>
  The parameters are pre-configured. This is done by Oloid admin.
</Note>

### QR Code

To use **QR Code**credential, enable **QR Code**.

## Design Configure tab

Do the following:

1. [Configure Settings tab](#h_fdc0a54252)
2. [Customize Messages tab](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-passwordless-application-in-tenant-admin-portal)

## Configure Settings tab

- **Enable Offline Mode**: Enable this option to allow endpoint transactions to be processed even without network connectivity.
- **Use Group Authorization**: Enable this option to restrict endpoint access to users within the same group associated with the endpoint connected to the application. This ensures that only users in the specified group can authenticate online and offline.
- **Server Response Ping Timeout**: Set an appropriate time to define how long the endpoint will wait for a response from the Oloid server before switching to Offline Mode.
- **Authentication Timeout**: Set an appropriate timeout value that determines how long the application waits for the user to begin the authentication process before being redirected to the initial screen.
- **Apply Endpoint Template**: Select Endpoint template from the dropdown.
- Enable **Show on Intent/Auth Screens** to display clock on all the intent, Authentication section and identity screens. ![](/images/8300813/40a1c8d71ef4.png)

## Customize Messages tab

1. Turn on **Enable Action Status Messages** to display the action status of the user's facial transaction. You can customize the messages your user sees on the Oloid Verify App.**Action Initializing Message**: Enter Action Processing Label in the text field.**Action Success Message**: Enter Action Success Label in the text field.**Action Failure Message**: Enter Action Failure Label in the text field.Select **Auto-dismiss the error prompt after** to enter the preferred time (in seconds).
2. Edit **Authentication Failure Error Message**field (Optional). ![](/images/8300813/998ea8335eca.png)

Not applicable for Oloid Verify.

Not applicable for Oloid Verify.

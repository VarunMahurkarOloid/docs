**Steps to create and add User:**

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory**on the left menu panel. ![](/images/8185048/216cae409142.png) The **Users** page is displayed.
3. Click **Create User**. ![](/images/8185048/21b735bcdb50.png) The **Create User** pop-up box is displayed. ![](/images/8185048/96f948a8d242.png)
4. On the pop-up box, do the following:Enter **Full Name** of the user.Enter **Primary ID**.Select **Use OloID as Primary ID** to use OloID as your primary ID.Select**Connection** from the**Connection** list.Click **Create**. The new user is successfully created and added on the **Users** list. ![](/images/8185048/b1b100f9439f.png)

Watch our video [How to create a user in Tenant Admin Portal.](/administration/admin-portal/how-to-create-a-user-in-the-tenant-admin-portal-video-tutorial)

<Note>
  For ADP auto-sync enabled clients, user is automatically synchronized and there is no need to add user manually in Tenant Admin Portal. User is only required to be added in ADP which will automatically synchronized with Tenant Admin Portal.
</Note>

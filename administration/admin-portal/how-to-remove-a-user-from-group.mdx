## Introduction

This document provides instructions to remove one or more users from a group in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Remove User from Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Groups** on the left panel menu. ![](/images/8311847/1f65ec6ced12.png) The **Groups** page is displayed.
3. Click the preferred group. ![](/images/8311847/9e4153afd099.png) The **Group Details** page is displayed. ![](/images/8311847/49362e6f3297.png)
4. Click **Users**tab and do the following:Select the preferred user(s).**Note:** If needed, you can select multiple users to delete from the group.Click **Delete** icon. ![](/images/8311847/5fce626034a0.png) The**Confirm Deletion**pop-up box is displayed.Click **Delete**. ![](/images/8311847/c9f083aab1a5.png) The selected user is successfully removed from the group. ![](/images/8311847/1a7cf4e6cd08.png)

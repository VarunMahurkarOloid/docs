## Pre-requisite

Location must be created on the Location Settings page.  
​  
For more information on creating location, see **[How to create a new location and add location details](/administration/admin-portal/how-to-create-a-new-location-and-add-location-details)**.

## Steps to add location in bulk:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left panel menu. ![](/images/8227103/63a4b7076233.png)The endpoints page is displayed.
3. Select endpoints whose addresses are not updated. ![](/images/8227618/b5c71e7e5910.png)
4. Go to **Action** dropdown and select **Add Location**. ![](/images/8227618/23f341595f66.png) The**Add Location** pop-up box is displayed. ![](/images/8227618/7ab333fe3d79.png)
5. Select appropriate location from **Select Location** dropdown.
6. Click **Save**.The location is successfully updated for the selected endpoints. ![](/images/8227618/11a54e8668dd.png) **Note**: To update the address of a specific endpoint, navigate to the endpoint details page and make the necessary change.

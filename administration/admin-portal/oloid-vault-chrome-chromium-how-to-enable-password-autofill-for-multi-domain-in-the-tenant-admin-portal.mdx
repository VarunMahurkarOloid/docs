## Introduction

This document describes how to set up multi-domain password autofill for Oloid Vault (Chrome / Chromium) in the Tenant Admin Portal. When the Password Autofill feature is enabled, Oloid Vault can automatically populate saved credentials on login pages for multiple domains or related applications.  
​

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Enable Password Autofill for Multi Domain

1. Log in to the **Tenant Admin** **Portal**.
2. On the homepage, click **user profile icon**. ![](/images/9814095/8ff5cd931285.png) The **user profile menu** is displayed.
3. Click **Tenant Settings**. ![](/images/9814095/9a29195236d1.png)The **Tenant settings** page is displayed.
4. Go to **App Settings** > **Oloid Vaults**. ![](/images/9814095/a2efe5b3c9f5.png) Domain Configuration section is displayed.
5. Select**Enable Password Autofill for Multi-domain**toggle, then click **+ Add Domain Set**. ![](/images/9814095/4c46f397fe3c.png) The **Main Domain/App** and **Related Domain/Apps** sections are displayed.
6. Do the following:Enter **Main Domain/App**.Enter **Related Domain/Apps**.**Note:**You can add as many related domains/apps as needed under each main domain, and you may also create multiple domain sets if required.Click **Save**. ![](/images/9814095/be938a552161.png) The Chrome Vault domain configuration is updated successfully. ![](/images/9814095/94f81e5a36d7.png)

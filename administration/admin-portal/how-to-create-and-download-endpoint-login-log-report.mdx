## Introduction

An Endpoint Login Log provides details of all the logins made with the endpoints that are associated with the application.

## Pre-Requisite

You must have a Tenant Admin or Supervisor to create and download reports.

## Steps to create & download Endpoint Login Log:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/12807356/0aee946d9a47.png) The **Ad-Hoc Reports** page is displayed. ![](/images/12807356/c340d0b652e5.png)
3. Use one of the following methods to download the report:On the top right, click **Create Report** > **Endpoint Login** **Log** ![](/images/12807356/1f4d916b9acd.png) Select Endpoint Login Log from the left menu panel and then click **Create Report.** ![](/images/12807356/6dd1536f48b9.png) The **Create**Endpoint Login Log pop-up box is displayed. ![](/images/12807356/97b770bb5c75.png)
4. On the pop-up box, do the following:a. Select the date and time from the calendar for **From Date & Time**(Mandatory) and**To Date Time.**(optional)b. Enter **Primary ID**.(optional)c. Select Transaction Status from **Transaction Status**drop-down list (optional)d. Select Application name(s) from **Application Names**drop-down list.(optional)e. Select Endpoint name(s) from **Endpoint Names**drop-down list.(optional)f. Click **Download**

The **Endpoint Login Log** is saved to the local device and listed on the **Ad-Hoc Reports** page under the Endpoint Login Log tab.

<Frame>
  <img src="/images/12807356/2ba2475e8a72.png" alt="Screenshot" />
</Frame>

**Notes**

- Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
- The downloaded file format for reports is XLSX.
- A report can be exported for a maximum of 30 days. If the selected time duration is more than 30 days, the report will be exported with data for only the first 30 days from the selected start date.
- If optional fields are not selected, all the endpoint login details in the system are downloaded to the file.

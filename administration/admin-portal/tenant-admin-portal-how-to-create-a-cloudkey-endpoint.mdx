## Introduction

A CloudKey endpoint represents a cloud-connected access point that links a CloudKey device to an application and, optionally, a workflow.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure a CloudKey application is created. For more information, refer: [How to Create an Application](/administration/admin-portal/tenant-admin-portal-how-to-create-an-application).

## Steps to create a CloudKey endpoint:

1. Log in to the Tenant Admin Portal.
2. On the homepage of the portal, click **Endpoints** on the left menu panel. ![](/images/11196020/37e34703983c.png) The **Endpoints** page is displayed.
3. Click **Add Endpoint**on the top right corner of the page. ![](/images/8263138/802a3230ee64.png) The **Create Endpoint**pop-up box is displayed.
4. Select **CloudKey**> click **Continue**. ![](/images/8263138/6734fbbed677.png) The **CloudKey- Create a new Endpoint** pop-up box is displayed.
5. On the pop-up box, do the following:Enter **Endpoint name**. Select **Application**from the application list. Select **Workflow**from the workflow list (optional).Enter **CloudKey Url.**Enter **Door ID.**Enable **Wait for Response**(optional). Select **Location**. (Mandatory)Select **Building** (optional). Select**Area** (optional).
6. Click **Create**.

The Endpoint is created and listed on the **Endpoints** page.

## Overview

The **Insights Dashboard** provides a centralized view of key usage, and activity across the Oloid platform. It helps administrators monitor user onboarding, endpoint activity, transactions, and credential usage through visual charts and detailed reports.

## Purpose of the Insights Dashboard

The Insights Dashboard is designed to help administrators:

- Track user onboarding and adoption
- Monitor endpoint and credential activity
- Analyze authentication and transaction trends
- Identify security and usage patterns
- Generate reports.

## Key Sections in Insights Dashboard

## User Matrix

Provides visibility into:

- Total users onboarded
- Users with and without enrolled credentials
- User growth trends over time

## Endpoint Activity

Displays insights related to:

- Active and inactive endpoints
- Endpoint Growth
- Active Endpoint Health

## Transaction Insights

Shows authentication and transaction trends such as:

- Transaction Growth
- Successful and failed transactions
- Shows Unique user activity with successful transactions over time

## Credentials

Offers insight into credential usage, including:

- The Total number of Users with credentials
- Credential types (Face, PIN, Badge, etc.)

## Reports

Allows administrators to:

- View detailed tabular reports
- Apply filters to narrow results
- Download reports for Users, Endpoints and Windows Shared Passwords.

## Time-Based Insights

The dashboard supports flexible time ranges, such as:

- Today
- Last 30 days
- Last 12 months

This helps administrators analyze trends over specific periods.

## Benefits of Using Insights Dashboard

- Centralized visibility across users, endpoints, and credentials
- Easy-to-understand visual analytics
- Faster decision-making using real-time data
- Simplified reporting

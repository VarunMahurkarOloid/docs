Admin and Supervisor can log in to Admin Mode in the Oloid Verify App using following three methods:

1. [Log in using Email and Password](https://oloid.help/en/articles/8464035-how-to-log-into-the-admin-mode-of-oloid-verify-connect-app-as-a-supervisor)
2. [Log in using Face](https://oloid.help/en/articles/8464035-how-to-log-into-the-admin-mode-of-oloid-verify-connect-app-as-a-supervisor)
3. [Log in using SSO](#h_a1d339a329)

## Login using Email and Password

### Prerequisite

- You must complete the Admin Setup. For more details refer [Oloid Verify: App Installation and Admin Setup](/administration/admin-portal/oloid-verify-admin-setup).
- Password must be updated using the invite email received by the Supervisor.**Note:** In case, supervisor has not received any invite email, they should contact the Tenant Admin.

### Steps to log in with Email and Password

1. Launch the **Oloid Verify**App. ![](/images/8671139/65448eab37c7.png) **Note:** Since the endpoint is already paired, the app will launch in the preview mode. For more, refer to [Oloid Verify - How to Pair an Endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint) ![](/images/8671139/f24f3c291c0f.png)
2. Double tap with two fingers on the screen to launch the Admin Mode.
3. Tap **Yes- Continue.** ![](/images/8671139/c9178ce671dd.png) The Settings screen is displayed.
4. Tap **Login as Admin**. ![](/images/8671139/46a068a4e14c.png) The Login screen is displayed and the tenant name is pre-populated.
5. Do the following:Enter **Email ID** in the **Email** field.Enter **Password** in the **Password** field.Tap **LOGIN**. ![](/images/8671139/4d008e2895e4.png) You are logged in to the Admin Mode successfully. ​**Note:**After successfully logging in to Admin mode, the Users page is displayed. For more details, refer to the [sample screen](#h_9ea8a13fba)

## Login using Face

### Prerequisite

- Face must be onboarded for the Supervisor/Admin.
- Endpoint must be paired in the iPad. For more details refer **[How to pair an Oloid Verify endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint).**
- The connection that the supervisor belongs to, must be linked to the application the endpoint is paired with.

### Steps to log in with Face

1. Launch the **Oloid Verify** App. ![](/images/8671139/65448eab37c7.png) **Note:** Since the endpoint is already paired, the app will launch in the preview mode. ![](/images/8671139/f24f3c291c0f.png)
2. Double tap with two fingers on the screen to launch the Admin Mode.
3. Tap **Yes- Continue.** ![](/images/8671139/c9178ce671dd.png) The Settings screen is displayed.
4. Tap **Login as Admin**. ![](/images/8671139/46a068a4e14c.png) The Login screen is displayed and the tenant name is pre-populated.
5. Tap **LOG IN WITH FACE**. ![](/images/8671139/4621ea645e03.png) This will open the camera preview screen.
6. Look at the camera to confirm your identity. ![](/images/8671139/706f551b5f8f.png) You are logged in to the Admin Mode successfully. ​**Note:**After successfully logging in to Admin mode, the Users page is displayed. For more details, refer to the [sample screen](#h_9ea8a13fba)

## Log in using SSO

### Prerequisite

- Endpoint must be paired in the iPad. For more details refer **[How to pair an Oloid Verify endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint).**
- Tenant admin and Supervisor's Email ID needs to be updated in the Tenant Admin Portal.

### Steps to log in with SSO

1. Launch the **Oloid Verify**App. ![](/images/8616247/65448eab37c7.png) **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. ![](/images/8671139/f24f3c291c0f.png)
2. Double tap with two fingers on the preview screen to launch the Admin Mode.
3. Tap **Yes- Continue.** ![](/images/8671139/c9178ce671dd.png) The **Settings**screen is displayed.
4. Tap **Login as Admin**. ![](/images/8671139/46a068a4e14c.png) The Login screen is displayed.
5. On the login screen, tap **Login with SSO**. ![](/images/10255679/30bb9403dffc.png) The screen with **SSO options** is displayed. Do one of the following: Login with [Google](/resources/integrations/sso/oloid-verify-login-using-google-sso).Login with [Microsoft](/resources/integrations/sso/oloid-verify-login-using-microsoft-sso).Login with [Okta](/resources/integrations/sso/oloid-verify-login-using-okta-sso). ![](/images/8671139/6eb10904266d.png) **Note:**After successfully logging in to Admin mode, the Users page is displayed.

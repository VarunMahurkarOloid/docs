## Introduction

The **Auto-Pair Config File** feature in the **Tenant Admin Portal** allows admin to generate configuration files used for automatically pairing endpoints or devices with specific applications. This simplifies the setup process by eliminating the need for manual pairing, ensuring faster deployment and secure authentication between devices and applications.

## Prerequisite

You have **Admin access** to the **Tenant Admin Portal**.

## Steps to Generate Auto-pair Config File

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/12728542/6d5d716a7f7e.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/12728542/40f0f80efa2b.png) The **Tenant Settings** page is displayed.
4. Go to **Security** tab >**API Token `**> **API Key**. ![](/images/12728542/2732de878f64.png)
5. In the**Generate Temporary Access Token**section, do the following:Select the **Start Date/Time** field.To set the start date and time, click the date picker or select **Now**.Select the **End Date/Time** field.Click the date picker, choose when the token will expire, and then click **OK**.Specify **Number of Endpoints** that can be created using the auto-config file. (Optional)Click **Generate**. ![](/images/12728542/a06cd592ea93.png) The auto-pair config file is generated.
6. Click **Auto-pair config file**. ![](/images/10441578/c78eb07337d7.png) The Auto-pair config file pop-up box is displayed.
7. Do the following:Select **Application**as**Passwordless - DeviceLock**from **Application Type**dropdown list.From the **Select Application** dropdown list, select the application that you want the endpoints to pair with.Select **Skip user confirmation for pairing**option to auto-pair endpoints without requiring user confirmation (optional but recommended).**If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.**If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.Click **Download**. ![](/images/12728542/077c965d48dc.png) The Autopair Config file is downloaded to the local device.**Note:** To update the Auto-Pair configuration after generating the configuration file, refer to [Tenant Admin Portal - How to Update Auto-Pair Config File for Oloid DeviceLock App | Oloid Help Center](/administration/admin-portal/tenant-admin-portal-how-to-update-auto-pair-config-file-for-oloid-devicelock-app). After updating the configuration, upload the updated Auto-Pair configuration file to the endpoints manually or deploy it using your MDM solution for the changes to take effect.

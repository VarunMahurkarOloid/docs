## Introduction

In the Oloid Tenant Admin Portal, role-based Credential API tokens allow administrators to generate secure tokens that inherit permissions from predefined roles. This ensures that integrations and applications can access only the Oloid services appropriate for their intended function.

## Pre-Requisite

You must have a Tenant Admin account.

## Steps to generate Role based Credential API token:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **User Profile** icon from the bottom left. ![](/images/11659590/622566f65850.png) The **user profile menu** is displayed.
3. Click **Tenant Settings**. ![](/images/11659590/fb5a25fc9f1c.png) The **Tenant Settings** page is displayed.
4. Go to **Security**tab > select **Role Based Credential** under **API Token** dropdown menu.
5. Click **Generate**. ![](/images/11659590/a93b1127fe6f.png) The **Generate Role based Credentials**pop-up box is displayed.
6. Do the following:Enter **Token Name.**Select **Read Activity Logs** to allow users to only view the activity logSelect **Read Transaction Data** to allow users to only view the transaction data.Select **Download Consent List**to allow users to download the consent data.Click **Generate**. ![](/images/11659590/da8c2c277bc1.png) The Role Based Credential is generated successfully. **Keywords**Generate Credentials| API Tokens| Role Based Credentials| How to Generate API Token| Role Based Tokens| APIs|

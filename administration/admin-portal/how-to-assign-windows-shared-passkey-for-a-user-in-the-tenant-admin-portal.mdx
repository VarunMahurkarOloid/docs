## Introduction

The Assign Windows shared Passkey feature allows an admin to securely assign an existing shared passkey to a specific user.

## Prerequisites

- You must have a Tenant Admin account.
- Windows Passkey must already be created. For more information please refer: [Oloid Platform - How to create Windows Passkey as credential for users in Tenant Admin Portal](/administration/admin-portal/oloid-platform-how-to-create-windows-passkey-as-credential-for-users-in-tenant-admin-portal)

## Steps to Assign Windows Shared Passkey

1. Login to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel. ![Image](/images/13284463/bfbd42eb3ee2.png) The **Users** page is displayed.
3. Click**username**to edit. ![Image](/images/13284463/495b74c13e39.png) The **User details** page is displayed. ![](/images/13284463/83f0439c8704.png)
4. Go to **Credential** tab >**Windows Passkey** > **+ Windows Shared Passkey**. ![](/images/13305454/7ff8f24112e3.png) Windows Shared Passkey pop-up is displayed ![](/images/13305454/781781714829.png)
5. **Select** Windows Shared Passkey to Assign from the dropdown.
6. Click **Assign.** Windows Shared Passkey successfully added message is displayed.**Note:**More than one Windows Shared Passkey can be assigned for a user.

Windows Shared Passkey is assigned to user.

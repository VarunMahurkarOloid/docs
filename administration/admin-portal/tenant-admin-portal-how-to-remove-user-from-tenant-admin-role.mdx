## Introduction

This document provides step-by-step instructions to remove the Tenant Admin role from a user in the Tenant Admin Portal. Removing the role revokes the user's Tenant Admin access to the Tenant Admin Portal.

## Prerequisites

- You must have Tenant Admin access to the **Tenant Admin Portal**.
- The user must be an existing Tenant Admin.

## Steps to remove user from Tenant Admin role

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10660395/cf3ebe1f2be0.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/10660395/b6873b0f44b5.png) The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** tab. ![](/images/10660395/6548ca2c9aa4.png)
5. In the **Tenant Admins** tab, click **kebab menu** (three vertical dots) and select **Delete Tenant Admin**for a particular tenant admin. ![](/images/8237885/7c462077fadc.png) The **Remove Tenant Admin**pop-up box is displayed.
6. Select **Delete**. ![](/images/8237885/ada1e800c985.png) The Tenant Admin is deleted successfully. The user's Tenant Admin rights are removed, and they can no longer access the Tenant Admin Portal. ![](/images/8237885/a6f71e65333f.png)

## Introduction

The Vault Passkey feature allows administrators to view and manage secure passkey credentials associated with a user in the Tenant Admin Portal.

## Prerequisite

You must have Tenant Admin account.

## Steps to View and Edit Vault Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![Image](/images/11058549/6142e01fd801.png) The **Users**page is displayed.
3. Click user name to edit. ![Image](/images/11058549/d626c453e0da.png) The **user details** page is displayed. ![](/images/11058549/83f0439c8704.png)
4. Go to**Credentials**tab > **Vault Passkey** ![](/images/12889955/64423de433ae.png) The **Vault Passkey** is displayed.
5. Select the three-dot menu to open the options for viewing, editing, or deleting the passkey. ![](/images/12889955/c4b096c52578.png)
6. Do the following:To View: Click **Three dots icon** > select **View Details** ![](/images/12889955/cfb91ed192c2.png) To Edit: Click **Three dots icon** > select **Edit**>**Change Display Name**>**Save** ![](/images/12889955/c69df0d74abd.png) To Delete: Click **Three dots icon** > select **Delete**> **Confirm** ![](/images/12889955/b5a55d99b78e.png)

The Vault passkey is updated based on the changes made.

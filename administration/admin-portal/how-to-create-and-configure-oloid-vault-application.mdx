Steps to create and configure Oloid Vault application:

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right corner. ![](/images/10346057/e32d9f26e07e.png) The **Create New Application** pop-up box is displayed.
3. Do the following:Enter **Application Name**and select **Application Type**as **Passwordless**. ![](/images/10346057/5597b75f464e.png) Click **Next**.The **Select Passwordless Use Case**screen is displayed.Select **Oloid Vault** then click **Create**. ![](/images/10346057/ed676a46d9d9.png) The Passwordlessapplication of type **Oloid Vault** is created and the configuration page is displayed.
4. Configure the following:[Details tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Authenticator tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Configure tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Connections tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

<Note>
  These are one-time settings and all the default settings are recommended.
</Note>

## Configure Authenticator tab

You may enable one or more credential options based on your requirements.

## Face

<Frame>
  <img src="/images/10346057/310c298eec45.png" alt="Screenshot" />
</Frame>

- To use face as credential, enable **Face**option. The **Advanced Settings** page is displayed.Configure **Face Match Parameters**, and **Liveliness Check Parameters** on the Advanced Settings page.

<Note>
  The parameters are pre-configured. This is done by Oloid admin.
</Note>

**Additional Settings**

<Frame>
  <img src="/images/10346057/13d6bc6f324d.png" alt="Screenshot" />
</Frame>

- **Configure Image Capture Resolution:** Select the preferred resolution from the **Select Resolution** dropdown list for image capture during facial authentication.

- Click **Save**.**Note:**If the selected resolution is not available, the browser will default to the closest supported resolution.

## Badge ID

<Frame>
  <img src="/images/10346057/0fd968617d95.png" alt="Screenshot" />
</Frame>

Select a **Badge Type**from the dropdown list. To use Badge ID as credential, enable **Badge ID**.

## Configure Settings tab

## Vault Behavior

- **Enable Auto-Submit:**_Coming Soon_
- **Enable Copy Password:**Select this option to allow users to copy passwords from the Oloid Vault home page after logging in.
- **Enable Face Camera to open in a new Tab:**Select this option to open the face camera in a new tab for Oloid Vault users. ![](/images/10346057/fd2c905d2be1.png)

## Set Time-out durations for Re-authentication

- **Session Limit:**Set the maximum duration a user can remain signed into the Oloid Vault per session, up to a max of 55 mins.
- **Inactivity Timer:**Enable this option to protect user sessions from unauthorized access. Set the timer to automatically log off the user after a specified period of inactivity.

1.

## Introduction

A Personal Passkey allows Tenant Admin to set up secure, passwordless authentication through passkeys. Tenant Admins can generate a passkey from the user profile in the Tenant Admin Portal.

## Prerequisite

- You must have access to Tenant Admin account.
- Personal Passkey must be enabled in the Tenant Admin portal. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-enable-passkey-sso-in-tenant-admin-portal)

## Steps to Generate Personal Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click**Profile icon**on the bottom left corner of the menu panel. ![](/images/13856872/41c2bc01017a.png) The user profile menu is displayed.
3. Click **Username**. ![](/images/13856872/cf0b1d5508ee.png) The **User Profile** page is displayed.
4. Do the following: Edit **Full Name**. (Optional)Click **Save.****Note:**Click **Save**if Full Name field is changed.Click **Generate**.Enter **Phone**number. (Optional) ![](/images/13856872/b64672dde8b8.png) The Passkey registration screen is displayed. ![](/images/13856872/8263c20563eb.png) The Passkey is successfully generated. ![](/images/13856872/1d9c7cab8571.png) **Note:**The Passkey will be saved to Oloid Vault, Windows Login, Google Password manager or Windows Hello.

The Personal Passkey will be displayed on the User's profile under the Credentials tab.

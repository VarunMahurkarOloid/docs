## Introduction

The Tenant Admin Portal allows admin to configure connections for managing authentication, user onboarding, and security settings. You can customize parameters such as face quality checks, face match threshold, user termination limit, liveness check, etc. Proper configuration helps ensure secure and efficient identity management for your organization.

## Prerequisite

You must create a Connection in the Tenant Admin Portal. For more details, refer [How to create a Connection](/administration/admin-portal/tenant-admin-portal-how-to-create-connection).

## Steps to Configure a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/8305588/6df130d9ae6d.png) The **Connections** page is displayed.
3. Click connection name to be configured from the listed connections. ![](/images/8305588/b1a31ec4b283.png) The Connection Details page is displayed. ![](/images/8305588/e4a2a23f1298.png)
4. Configure the following tab:[Details Tab](#h_b59ba79671)[Configure Tab](#h_2f5941d2d6)[Application Tab](#h_38cad442ce)

## Details Tab

1. Go to **Details**tab, add a **Description**for the connection (optional). **Note**: The description should be **less than 140 characters**. ![](/images/8305588/36d2c23fe99b.png)
2. Click **Save**The description is added successfully. ![](/images/8305588/25799c89a2be.png)

## Setup Configure Tab

Go to **Configure** tab and do the following:

- [Configure Settings](#h_a7ef23e66d)
- [Configure Face Match and Liveness](#h_9fd0fc19ea)
- [Configure Consent](#h_d103919622)

### Configure Settings

1. On **Settings** section, do the following:Turn on **Enable** **OloID Account**toggle.**Note:** Enabling this toggle automatically creates Oloid Accounts for users added to this connection. Oloid Accounts are not generated for users without an email ID or phone number. Set a value in **Set User Termination Limit**field. **Note:** CSV user deletion is limited to the configured value. The default is 0 users and the maximum is 5000 users per batch.Turn on **Enable** **Email Alerts** toggle and enter the required email addresses to receive notifications.**Note:** Alerts are sent when the configured **User Termination Limit** is reached.Click **Save**. ![](/images/8305588/525da6ff3731.png) The Settings menu is configured.

### Configure Face Match and Liveness

1. On Face Match and Liveness section, do the followingTurn on **Enable** **Face Quality Check**toggle.**Note**: Enabling this toggle ensures a face quality check is performed on the captured image before it is added as a user's face credential. ![](/images/8305588/e2a6a04bb13e.png) Turn on **Face Match Threshold** toggle and adjust the slider or enter a value directly into the input box to set the face match threshold value. **(Oloid internal use)****Note**: Enabling this toggle ensures that a face recognition transaction will only be successful if the captured image meets the minimum face match threshold. ![](/images/8305588/57bf36ec2944.png) Turn on **Enable Software Liveness Check for Adding new face**toggle.Set the **Minimum Liveness Probability**value, either drag the slider or enter a value directly into the input box.**Note**: This value defines the minimum probability threshold for considering a face as "live."Set the **Minimum Liveness Quality** value, either drag the slider or enter a value directly into the input box.**Note**: This value defines the minimum quality threshold for the captured face liveness detection.Click **Save**. ![](/images/8305588/b7eda0c38be1.png) The Configure Face Match and Liveness menu is configured.

### Configure Consent

1. On Consent section, do the following:Click **Enable Consent**. ![](/images/8305588/23858fcc7ac5.png) Enable Consent popup-box is displayed.Select the applicable **Consent Template** from the dropdown list.**Note:**To create a consent template, refer [How to create a Consent Template](/administration/admin-portal/how-to-create-and-configure-consent-template).Click **Next**. ![](/images/8237994/7494749de491.png) Applicable User Set screen is displayed.Select **All Users** > Click **Next**. ![](/images/8237994/4fde1f3a7d0a.png) Authentication validity pop-up box is displayed.Do one of the following:**No end-date:**Select this option to allow authentication without a defined end date. Face images and biometric data for all users in the connection whether they have already provided consent or have not yet provided will remain valid, and users will continue to authenticate using face biometrics after signing the re-consent document.OR**Permit authentication until the Set Date:** Select this option and enter the preferred date.**Note**: If consent is not provided by the selected date, the face data and associated biometric information will be deleted.Click **Confirm**. ![](/images/8237994/62abddaae60b.png) **Consent Updated** popup box is displayed.Click **Okay**. ![](/images/8237994/ea8323fce375.png) Consent is enabled and the connection is successfully configured.

**Pre-requisite:**

The registered email ID must be added to the user's profile on the Tenant Admin Portal.

This document comprises the following:

- [Invite to Add a Face via Email](#h_7ef6540114)
- [Invite to Add a Face via SMS](#h_89043cc865)

## Steps to Send an Invite to Add a Face via Email

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8398578/e8a65014f485.png) The **Users**page is displayed.
3. Click **user name** to edit their profile. ![Image](/images/8398578/d626c453e0da.png) The **User Details** page is displayed.
4. Go to **Credentials** > **Face**> **Invite to Add Face**. ![](/images/8398578/e02033723a36.png)
5. Select **Send via Email**optionfrom the dropdown list. ![](/images/8398578/1795fa40dcbb.png) The **Email Invitation Preview** pop-up box is displayed.
6. Do the following: ![](/images/8398578/c0e0ae70abb1.png) Enter the recipient's email ID(s) in the **Send Email to** field.Edit **Email Subject** field.(Optional)Edit **Email Body** field.(Optional)Click **Send**.An email with invite link is sent to user to upload their face. ![](/images/8398578/0fa039bcf61a.png) The user receives an email with an invite link. Clicking the link directs the user to the **self-service portal** to upload their face. ![](/images/8398578/9f0b6ff6dd33.png)To upload face using the invite link, see [How to add face using the invite link](/administration/user-portal/how-to-add-a-face-using-invite-link-in-oloid-user-portal)

## Steps to Send an Invite to Add a Face via SMS

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8398578/e8a65014f485.png) The **Users**page is displayed.
3. Click **user name** to edit their profile. ![Image](/images/8398578/d626c453e0da.png) The **User Details** page is displayed.
4. Go to **Credentials** > **Face**> **Invite to Add Face**. ![](/images/8398578/e02033723a36.png)
5. Select **Send via SMS**optionfrom the dropdown list. ![](/images/8398578/2e85578ada43.png) The **SMS Invitation Preview** pop-up box is displayed.
6. Do the following: ![](/images/8398578/1f073cf59ddf.png) Enter the **User's Phone Number** in the **Enter Phone Number** field.**Note:**Select the country icon toAn change the country code prefix.Click **Save**.An SMS with invite link is sent to the user to upload their face. ![](/images/8398578/494310056d34.png) The user receives SMS with an invite link. Clicking the link directs the user to the **self-service portal** to upload their face. ![](/images/8398578/8f062785a4c1.png)

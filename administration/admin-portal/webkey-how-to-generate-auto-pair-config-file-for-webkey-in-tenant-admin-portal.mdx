## Introduction

The Auto-Pair configuration file simplifies the process of pairing endpoints with a WebKey application without requiring manual user intervention. It allows admins to securely connect endpoints using predefined configuration settings, enabling faster and more consistent deployments.

## Prerequisites

- You must have a Tenant Admin Account.
- Ensure that the Webkey application is created. For more information, refer: [How to create and configure WebKey Application in Tenant Admin Portal](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Steps to generate auto-pair config file

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/15220838/e0866adb8096.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/15220838/544c903f8218.png) The **Tenant Settings** page is displayed.
4. Go to **Security** tab >**API Token** > **API Key**. ![](/images/10441578/f17408aa6124.png)
5. In the**Generate Temporary Access Token**section, do the following:In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.To set the start date and time, click the date picker or select **Now**.Select the **End Date/Time** field.Click the date picker, choose when the token will expire, and then click **OK**.Specify **Number of Endpoints** that can be created using the endpoint. (Optional)Click **Generate**. ![](/images/10441578/2f757f45c451.png) The auto-pair config file is generated.
6. Click **Auto-pair config file**. ![](/images/10441578/c78eb07337d7.png) The Auto-pair config file pop-up box is displayed.
7. Do the following:Select **Application**as**Passwordless - Webkey**from **Application Type**dropdown list.From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.**Note:**Select **Skip user confirmation for pairing**option to auto-pair endpoints without requiring user confirmation.Click **Copy Config Text.** (optional)**Note:**This button will copy (to clipboard) the config file JSON or TEXT as a single line string.Click **Download**. ![](/images/15220838/2306c584944d.png) The Autopair Config file is downloaded to the local device.

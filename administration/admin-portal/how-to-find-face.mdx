## Pre-requisite

Face should be added to the user.

Steps to find Face:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Click User Name to edit. ![Image](/images/8355149/85582a834dc6.png)You will see a preview of the tenant.The User details page is displayed.
4. Go to **Action** > Select**Find Face**. ![Image](/images/8355149/82c6717c7bc8.png) The **Find Similar Faces** pop-up box is displayed. ![](/images/8355149/166775c31338.png)
5. On the **Find Similar Faces** pop-up box, do the following:Enter **Confidence** level.**Note**: For best results, increase confidence level above default value.Select required connection(s) from the**Connection** drop down.Click **Search**.The **Results for Similar Faces** pop-up box is displayed.The search result shows confidence level face match. **Note**: This functionality is for Oloid internal use.

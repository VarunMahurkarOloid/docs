## Introduction

This document provides instructions to add an endpoint to an existing group in the Tenant Admin Portal.  
​**Note:**Adding Endpoint to a Group can be done in two ways. You can add group to an endpoint. For detailed instructions, see [How to add group to an endpoint](/administration/admin-portal/tenant-admin-portal-how-to-add-a-group-to-an-endpoint).

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- Ensure that the endpoint is already paired.
- Ensure that the group is already created.

## Steps to add Endpoint to a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Groups** on the left menu panel. ![](/images/8315188/7e74d72c2083.png) The **Groups** page is displayed.
3. Click on a group name to edit from the listed groups. ![](/images/8315188/3d395489e548.png) The Group detail page is displayed. ![](/images/8315188/5dfeaa760543.png)
4. Go to **Endpoints** tab > Click **+ Add Endpoint**. ![](/images/8315188/76809c4f9e22.png) The **Add Endpoint** pop-up box is displayed.
5. On the **Add Endpoint** pop-up box select endpoint from the **Select** **endpoints**dropdown list.
6. Click **Add**. ![](/images/8315188/b189c4983497.png) The endpoint is added and listed on the **Endpoints** tab. ![](/images/8315188/0806e5173591.png) Keywords |Tenant Admin Portal add endpoint to group |Add endpoint to group |Assign endpoint to group |Map endpoint to group|

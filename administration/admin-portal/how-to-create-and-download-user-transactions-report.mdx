## Introduction

A User Transactions Report provides transaction details of all the endpoints of the associated applications.

## Pre-Requisite

You must have a Tenant Admin account.

## Steps to create User Transactions report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/12807325/0aee946d9a47.png) The **Ad-Hoc Reports** page is displayed. ![](/images/12807325/c340d0b652e5.png)
3. Use one of the following methods to download the report:On the top right, click **Create Report** > **User Transactions Report** ![](/images/12807325/a9c05ba361fe.png) Select User Transactions Report from the left menu panel then click **Create Report.** ![](/images/12807325/f290dfe0c802.png)
4. The **Create User Transactions Report** pop-up box is displayed. ![](/images/12807325/6369798077be.png)
5. Select the date and time from the calendar for **From Date & Time**(Mandatory) and**To Date Time.**(optional)
6. Click **Download**

The **User Transactions report**is saved to the local device and listed on the **Ad-Hoc Reports** page.

<Frame>
  <img src="/images/12807325/6822cae7612d.png" alt="Screenshot" />
</Frame>

**Notes:**

- Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
- The downloaded file format for reports is XLSX.
- If optional fields are not selected, all the User Transactions details in the system are downloaded to the file.

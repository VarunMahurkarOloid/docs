## Introduction

A scheduled **Transaction Report** contains the records of the last 24 hours of successful transactions performed across the site.

## Pre-Requisite

You must have a Tenant Admin account.

<Frame>
  <img src="/images/8446424/0700db9e5a95.gif" alt="Screenshot" />
</Frame>

## Steps to create Transaction Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel. ![Image](/images/8446424/7449cd2b7f6e.png) The **Scheduled Reports** page is displayed.
3. On the top right, click **Create Report**. ![Image](/images/8446424/5ef909fd35db.png) The **Create Report** pop-up box is displayed. ![](/images/8446424/6bd0f964a1ee.png)
4. On the pop-up box, enter **Report Name**.
5. Select **Transaction**report type.
6. Click **Create**.The Transaction report type is created and listed on the **Scheduled Reports** page. ![Image](/images/8446424/7c035b9051be.png) The Transaction report can be configured to schedule the report generation frequency and send it to the customers through email . For details see, [How to configure a scheduled transaction report](/administration/admin-portal/how-to-configure-a-scheduled-transaction-report).

**Notes**

- Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
- The downloaded file format for reports is XLSX.

## Introduction

Vault Shared Passwords allow the Tenant Admin to securely assign shared passwords to multiple users from the Tenant Admin Portal.

## Prerequisites

- You must have a Tenant Admin account.
- Vault shared password must be created. For more, refer: [Chrome Vault - How to Create Shared Password in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-shared-password-in-the-tenant-admin-portal)

## Steps to assign Vault Shared Passwords

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/15053580/e756874a3c8d.png) The **Users** page is displayed.
3. Select **Shared Credentials > Vault Passwords**on the left menu panel. ![](/images/15053580/21e69091e056.png) The **Vault Passwords** page is displayed.
4. Select credential name to edit.**Note:**Multiple Shared Passwords can be assigned to users. To assign multiple passwords select the checkbox next to the required shared password(s) to assign them to users. ![](/images/15053580/b43cce939c62.png) The **Vault Passwords** **Detail** page is displayed.
5. Click **User Assigned**> Click **+ Assign Shared Passwords to Users.** ![](/images/15053580/ad3c6812260a.png) The **Assign Passwords to Users**pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users**dropdown list.
7. Click **Assign**.

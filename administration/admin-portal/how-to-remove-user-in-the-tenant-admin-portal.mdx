## Introduction

The Tenant Admin Portal allows the admin to manage user accounts, including adding, updating, and removing users as required. Removing a user ensures that their access to applications and resources linked to the Tenant Admin Portal is permanently revoked.

## Prerequisite:

A User must be created. To create user refer [How to add Users in the Tenant Admin Portal](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal).

## Steps to remove user:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8424129/a4f34359df10.png) The **Users** page is displayed.
3. Click Username to edit. ![](/images/8424129/0da42b0c5a7b.png) The user details page is displayed.
4. On the top-right, go to **Action** > select **Delete User**. ![](/images/8424129/b5f3da353c94.png) A confirmation pop-up box is displayed.
5. Click **Delete**. ![](/images/8424129/1b7f486ef163.png) The user is permanently deleted from the Tenant Admin Portal. ![](/images/8424129/8a3b820135c4.png)

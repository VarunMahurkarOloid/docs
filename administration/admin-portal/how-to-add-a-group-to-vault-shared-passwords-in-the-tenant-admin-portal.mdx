## Introduction

Adding a **Group** to a Vault Shared Password allows the Tenant Admin to grant access to shared credentials for multiple users at once. All users within the selected group will inherit access to the shared password based on the configured authentication workflows.

## Prerequisites

- You must have access to a Tenant Admin account.
- Vault shared password must be created. For more, refer: [Chrome Vault - How to Create Shared Password in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-shared-password-in-the-tenant-admin-portal)

## Steps to Add Group to Vault Shared Password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Select **Shared Credentials > Vault Password**on the left menu panel. ![](/images/15053825/21e69091e056.png) The **Vault Shared Password** page is displayed.
4. Select the preferred Vault Shared Password name to edit. ![](/images/15053887/b43cce939c62.png) The Vault Shared Password details page is displayed.
5. Select **Groups** tab > click **+ Add Group** ![](/images/15053887/113c88948e02.png) The Add Group pop-up box is displayed. ![](/images/15053887/cb1121d8820e.png)
6. Select Group from dropdown list.
7. Click **Save**.**Note:**A maximum of five groups can be added to each vault shared password.

The Group is successfully added to the Vault Shared Password.

<Frame>
  <img src="/images/15053887/e9f34b3d51f3.png" alt="Screenshot" />
</Frame>

The group users will be able to login using the shared password.

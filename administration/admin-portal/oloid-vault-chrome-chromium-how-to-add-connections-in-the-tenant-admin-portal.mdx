## Introduction

The **Connections** tab in the Oloid Vault (Chrome / Chromium) application allows admin to link predefined connections to the application. By adding connections, you enable the application to communicate with supported endpoints for secure authentication and access.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- You must create a Oloid Vault (Chrome / Chromium) application in the Tenant Admin Portal. To create refer [How to Create and Configure Oloid Vault (Chrome / Chromium) Application in the Tenant Admin Portal | Oloid Help Center](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).
- You must create Connections. To create Connections. To more information, refer [How to create Connections in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-create-connection).

## Steps to add Connections

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application. ![](/images/12442012/1a1c053bd1bf.png) The application detail page is displayed.
3. Go to **Connections** tab > select **Add Connections**. ![](/images/12442012/ca6573087524.png) The Add Connection pop-up box is displayed.
4. Do the following:Select **Connection**(s) from Connection drop down list.Click **Add**.**Note:** An application can have up to 5 connections, and all must be either PC/SC-enabled or non-PC/SC. Combining different connection types is not allowed. ![](/images/12442012/b678d26c3cc5.png) The Connection is successfully added to the application and listed in the connections list. ![](/images/12442012/3b811329a0ff.png)

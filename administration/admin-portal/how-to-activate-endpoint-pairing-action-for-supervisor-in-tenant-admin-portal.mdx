**Introduction**

Enabling the Endpoint Pairing feature in the Tenant Admin Portal allows the Tenant Admin to grant access to Supervisors. Once enabled, supervisors can create or activate endpoints.

Steps to activate Endpoint Pairing action:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click**user profile icon**. ![](/images/10000759/9a27ffbd000c.png) The **user profile menu** is displayed.
3. Select **Tenant Settings**. ![](/images/10000759/3831c0ae8781.png) The **Tenant Settings**page is displayed.
4. Go to **Advanced** tab > **Supervisor privileges**. ![](/images/10000759/ed3aa4617ae0.png)
5. Enable **Endpoint Pairing** toggle to allow supervisors to create or pair endpoints. ![](/images/10000759/574077e4bae5.png) Now, the Supervisor can create or pair a new endpoint. ![](/images/10000759/f74978c39240.png)

## Introduction

**Read-only Mode** allows Admin to view configurations, Activity Logs, and Transactions logs. Admin can download the Transaction reports.

## Prerequisites

- You must have Tenant Admin access to the **Tenant Admin Portal**.
- The user must be an existing Tenant Admin. ​

## Steps to enable Read-only Mode for existing Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10660395/cf3ebe1f2be0.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/10660395/b6873b0f44b5.png) The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** tab. ![](/images/10660395/6548ca2c9aa4.png)
5. In the **Tenant Admins** tab, click **kebab menu** (three vertical dots) and select **Enable Read-Only Mode**for the particular Tenant Admin. ![](/images/10660395/eb8d3d5e201f.png) The **Enable Read-only Mode** confirmation pop-up box is displayed.
6. Click **Enable**. ![](/images/10660395/30c84b909445.png) The Read-only Mode is enabled for the admin successfully. ![](/images/10660395/e967a8dc37fb.png)

**Note:**Once the Read-only mode is enabled, the admin cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![](/images/10660395/4eea4d20a5b3.png)) is displayed next to the user name.

## Steps to Enable Read-only Mode while inviting Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/10660395/dfd4d50049f1.png) The **user profile menu** is displayed.
3. Click **Invite Admin**. ![](/images/10660395/b7cef0f641d0.png) The**Invite Tenant Admin**pop-up box is displayed. ![](/images/10660395/538c7a297189.png)
4. On the pop-up box, do the following: Enter **User name** or **Primary ID** of existing User in the search field.Select the accurate user name from the drop-down list. Select **Read Only Mode** to restrict the admin from performing any action in the Tenant Admin Portal.Select **Invite.** ![](/images/10660395/1622e97ec041.png) The user is successfully invited as a Tenant Admin with Read-only Mode enabled. ![](/images/10660395/b5de3b26a64a.png) **Note:**Once the Read-only mode is enabled, the admin cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![](/images/10660395/4eea4d20a5b3.png)) is displayed next to the user name.

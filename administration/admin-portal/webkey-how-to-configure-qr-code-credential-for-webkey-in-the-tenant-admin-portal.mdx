**Introduction**

The QR Code credential feature in the Tenant Admin Portal allows admin to enable QR code-based multi-factor authentication (MFA) for the WebKey application. Once enabled, Users can authenticate to the Webkey application by scanning a QR code.

### Steps to configure QR Code credential:

1. Log in to the **Tenant Admin Portal**. For more details, refer [How to log in to the Tenant Admin Portal](/administration/admin-portal/how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, select the Webkey application to edit. ![](/images/10800135/d5355d7e2b98.png) The application page is displayed. ![](/images/11494129/2bd8833f7047.png)
3. Go to **Authenticator tab.**
4. Turn on **QR Code**toggle. ![](/images/11494129/59444cd95936.png)
5. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.This option displays a camera flip button on the preview screen during QR code scanning.Under **Default camera selection**, select a camera option:**Back Camera** **Front Camera****Note:**This feature is available only for iOS devices and Android devices.
6. Click**Save.** ![](/images/11494129/9db7a656e0da.png) QR Code authenticator for Webkey application is configured successfully. ![](/images/11494129/d50bf6954201.png)

For Oloid CloudKey app to function, you need to do the following in Oloid Platform.

1. Login to the Oloid Platform using your credentials.
2. Set up Application and Connection for CloudKey. Refer [Set up Application and Connection for CloudKe](/administration/admin-portal/set-up-application-and-connection-for-cloudkey)y guide.
3. Configure CloudKey. Go to Settings> Advanced> CloudKey and configure CloudKey for the tenant. For detailed instructions, see [How to configure CloudKey](/administration/admin-portal/how-to-configure-cloudkey) guide.
4. Create a CloudKey endpoint. For detailed instructions, see [How to add a CloudKey endpoint](/administration/admin-portal/tenant-admin-portal-how-to-create-a-cloudkey-endpoint) guide.Note: Once Endpoint is created successfully , add location to the endpoint. Refer to [How to add location to the endpoint](/administration/admin-portal/how-to-add-location-to-the-endpoint) guide. For additional guides on location , refer to [Create and Manage Locations](https://oloid.help/en/collections/6445616-create-and-manage-locations)**.**This is important to ensure that the proximity settings work to display the nearest CloudKey.Also, Workflow instance needs to be deployed and running where this CloudKey endpoint is mapped and use the same door ID from workflow while creating the endpoint.
5. Onboard Users. To add users to Oloid Portal refer to the following:[How to add user](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal)[How to import users from csv file](/administration/admin-portal/tenant-admin-portal-how-to-add-users-in-bulk)
6. Assign the CloudKey to the user. For detailed instructions, see [How to add Cloudkey as credential to users](/administration/admin-portal/how-to-add-cloudkey-as-credential-to-users) guide.The CloudKey is configured and ready to use.

For more information on Platform configuration, see [Oloid Platform - Enterprise Features](https://oloid.help/en/collections/3797155-oloid-platform-enterprise-features)section.

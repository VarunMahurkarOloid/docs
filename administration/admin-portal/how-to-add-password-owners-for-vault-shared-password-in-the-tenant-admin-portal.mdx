## Introduction

Adding **Password Owners** to a Vault Shared Password allows the Tenant Admin to assign specific users with ownership privileges for managing shared credentials.

## Prerequisites:

- You must have access to a Tenant Admin account.
- The Vault Shared Password must be created. For more, refer: [Chrome Vault - How to Create Shared Password in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-shared-password-in-the-tenant-admin-portal)

## Steps to add Password Owners:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Select **Shared Credentials > Vault Password**on the left menu panel. ![](/images/15053825/21e69091e056.png) The **Vault Shared Password** page is displayed.
4. Select the preferred Vault Shared Password name to edit. ![](/images/15053825/b43cce939c62.png)
5. Go to **Password Owners**tab >**+ Add Password Owners**. ![](/images/15053825/dc169124c6ab.png) The **Add Password Owners**pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users**dropdown list.**Note:**Only users with Admin or Supervisor roles can be assigned as Password Owners.
7. Click **Assign**.

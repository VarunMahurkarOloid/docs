## Introduction

Oloid Passwordless Authenticator is a simple, seamless, secure, and scalable authentication application that provides secure, password-free access to Windows desktops and laptops, Android tablets, iPads, and workforce/HRMS platforms.

## Prerequisite

You must have admin access to Tenant Admin Portal.

## Steps to Create Passwordless Application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right corner. ![](/images/8300330/5ee1ea01dfe8.png) The **Create New Application** pop-up box is displayed. ![](/images/8300330/2eba55c61bd6.png)
3. On the pop-up box, do the following:Enter **Application Name**and select **Application Type**as **Passwordless**.Click **Next**.The **Select Passwordless Use Case** pop-up box is displayed.
4. Select the Passwordless Use Case. ![](/images/8300330/d2cbdde3a91f.png)
5. Click **Create**.The selected Passwordless application type is created and the configuration page is displayed.Depending on your application type, click the links below for detailed information on creating and configuring Passwordless Applications.

[How to create and configure Webkey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

[How to create and configure Device Lock application](/passwordless/android/devicelock/how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal)

[How to create and configure Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Introduction

Oloid WebKey SSO enables the Tenant Admin to securely access the Tenant Admin Portal using single sign-on authentication.

## ​Prerequisites

- You must have access to a Tenant Admin account.
- Credential configuration must be configured for Webkey application. For more information, refer: [How to create and configure WebKey Application in Tenant Admin Portal](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)
- Webkey SSO is **enabled for your account**. Refer: [Oloid Webkey - How to Enable Webkey SSO login](/resources/integrations/sso/webkey-how-to-enable-oloid-webkey-sso-login)

## Steps to log into Tenant Admin Portal using Webkey SSO

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**. The **Oloid Login**page is displayed.
3. Click **Login with SSO**. ![](/images/13597429/bff2da7cbde7.png) The configured login options are displayed.
4. Click **Continue with OloID**. ![](/images/13597429/0301a0e7fb53.png) The Authentication screen is displayed.
5. Select a credential to log in and complete authentication.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_108f210098). ![](/images/13597429/1b691d7608ac.png) **For Example:**If User selects **Login with Badge**the scan badge screen is displayed.
6. Tap the **Badge** on the **Reader** to scan it. ![](/images/13597429/a277175b585b.png)

The authentication successful message is displayed.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

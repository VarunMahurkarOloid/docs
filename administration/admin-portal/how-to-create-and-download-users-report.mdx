## Introduction

A Users report provides information on all the users of selected groups or connections.

## Pre-requisite

You must have a Tenant Admin account.

## Steps to create Users Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/8450674/0aee946d9a47.png) The **Ad-Hoc Reports** page is displayed. ![](/images/8450674/c340d0b652e5.png)
3. Do one of the following:Go to **Users Reports**> **+ Create Report**. ![](/images/8450674/6f195e55e36c.png) OR On the top right, click **Create Report** > **Users Report**. ![](/images/8450674/8dde96d96ad5.png) The **Create Users Report**pop-up box is displayed. ![](/images/8450674/098e084297b5.png)
4. Do the following:**Choose a report type**as Connection or Group to generate a report of users.If you select **Connection**, choose a connection from the **Connections** dropdown. (Required)If you select **Group**, select a group from the **Groups**dropdown. (Required)Click **Download** to download the user report.

The Users report is saved to the local device.

<Frame>
  <img src="/images/8450674/12e52e70403c.png" alt="Screenshot" />
</Frame>

**Notes**

- Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
- The downloaded file format for reports is XLSX.

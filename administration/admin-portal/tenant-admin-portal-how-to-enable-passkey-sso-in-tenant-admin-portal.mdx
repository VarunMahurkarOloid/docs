## Introduction

This document explains how to enable single sign-on (SSO) using passkeys in the Tenant Admin Portal. Once configured, this setting allows users to authenticate through SSO using passkeys instead of traditional login methods.

## Prerequisite

- You must have a Tenant Admin account.
- OKTA IDP must be created for the application. To create, refer [How to create IDP Profile for OIDC-Okta in the Tenant Admin Portal](/resources/integrations/sso/tenant-admin-portal-how-to-create-an-oidc-okta-idp-profile)

## Steps to configure Oloid SSO

1. Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click**Profile icon**on the bottom left corner of the menu panel. ![](/images/13597272/41c2bc01017a.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/13597272/0ed9e08eb1f7.png) The **Tenant Settings** page is displayed.
4. Click **Security** tab. ![](/images/13856829/e11cae407e57.png) On the Security tab section in the left menu panel select **Passkey.**
5. Do the following:Turn on **Enable SSO using Passkey**toggle.Click **Save**.

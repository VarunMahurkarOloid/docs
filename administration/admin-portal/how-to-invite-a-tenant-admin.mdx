**Introduction**

A Tenant Admin has complete access to Oloid platform and all the Oloid connected devices.

**Pre-requisite**

You must be a Tenant Admin to invite a new Tenant Admin.

You must be an Oloid user to be a Tenant Admin.

For adding a new user as a tenant admin, see [How to add and invite a Tenant Admin](/administration/admin-portal/how-to-add-and-invite-a-tenant-admin)

**Steps to invite a Tenant Admin**:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/8236282/dfd4d50049f1.png) The **user profile menu** is displayed.
3. Do one of the following:Go to **Tenant Settings** > **Admin Controls** tab >**Tenant admins**> **Invite Tenant Admins.** ![](/images/8236282/adcb1d8dc7fc.png) OR, go to **Tenant Settings**> **Action** >**Invite Tenant Admin.** ![](/images/8236282/cab537d9dc52.png) Click **Invite Admin**. ![](/images/8236282/bc689331a6bb.png) The**Invite Tenant Admin**pop-up box is displayed. ![](/images/8236282/538c7a297189.png)
4. On the pop-up box, do the following:Enter **User name** or **Primary ID** of existing User in the search field.Select the accurate user name from the drop-down list. ![](/images/8236282/3e46e9a1e3d5.png) Select **Read Only Mode** to restrict the Admin from performing any action in the Oloid Portal. (Optional)Select **Invite.** The Tenant Admin is listed on the **Tenant Admins** tab. An invite email is sent to the user for verification. ![](/images/8236282/c4196b609dc0.png) Video TutorialWatch the video [How to invite a Tenant Admin in Tenant Admin Portal-Video Tutorial](/administration/admin-portal/how-to-invite-a-tenant-admin-in-tenant-admin-portal-video-tutorial) ​

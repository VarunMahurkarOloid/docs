## Introduction

This document provides instructions to add a group to an endpoint in the Tenant Admin Portal.

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- Ensure that the required group is already created in the Tenant Admin Portal.

## Steps to Add a Group to an Endpoint

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Endpoints** from the left navigation panel. ![](/images/8463479/7bfe37c0e85a.png) The **Endpoints**page is displayed.
3. Select the required endpoint from the list. ![](/images/8463479/bbc7551bd7c1.png) The endpoint detail page is displayed.
4. Click **Configure**. ![](/images/8463479/79be88dd9751.png) The Configure screen is displayed.
5. Click **Groups** > **+ Add Group**. ![](/images/8463479/dcaba117101f.png) The **Add Group**pop-up box is displayed.
6. Select a group name from the **Select Group**drop-down list and then click **Save**. ![](/images/8463479/a371ea5322ed.png) The selected group is added successfully ![](/images/8463479/39fe011358e8.png)

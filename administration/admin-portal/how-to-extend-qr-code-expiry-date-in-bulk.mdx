Steps to extend QR Code for a Connection:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory**on the left menu panel. ![Image](/images/8479750/6142e01fd801.png) The **Users** page is displayed.
3. Select users.
4. Go to **Action**> **Extend QR Code Expiry Date**. ![Image](/images/8479750/6e4f88db58ee.png) The **Extend QR Code** pop-up box is displayed. ![](/images/8479750/d973efaa806c.png)
5. On the pop-up box, do the following:Under **QR Code Validity** field adjust the date and time from the calendar icon.Under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary. (**optional**)Click **Assign**.The QR Code credential is successfully extended for the selected users. The QR Code summary of these users is shared over email ID(s) and is available for download in the attachments. ![](/images/8479750/ca4aeafd5b7d.png)

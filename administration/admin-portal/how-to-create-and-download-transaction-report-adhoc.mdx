## Introduction

A Transaction Report provides transaction details of all the endpoints of the associated applications.

## Pre-requisite

You must have a Tenant Admin account.

## Steps to create Transaction Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/8450533/0aee946d9a47.png) The **Ad-Hoc Reports** page is displayed. ![](/images/8450533/c340d0b652e5.png)
3. Do one of the following:Go to **Transaction Report**> **+ Create Report**. ![](/images/8450533/526848358f2e.png) On the top right, click **Create Report** > **Transaction Report**. ![](/images/8450533/11930b69c116.png) The **Create Transaction Report** pop-up box is displayed. ![](/images/8450533/051b06bd515a.png)
4. On the pop-up box, do the following:Select the date and time from the calendar for **From Date & Time** and**To Date Time.**(optional)Select time-zone from **Time-zone** drop-down list.(optional)Select transaction status from **Transaction Status** drop-down list.(optional)Select application names from **Application Names**drop-down list.(optional)**Note:** Click the **Use Application Time** checkbox to show transactions based on the time-zone set in the application.Select endpoint names from **Endpoint Names**drop-down list.(optional)Enter **Primary ID**.(optional)Select Mode from **Mode**drop-down list.(optional)Select face match status from **Face Match Status**drop-down list.(optional)Click **Download**The **transaction report**is saved to the local device and listed on the **Ad-Hoc Reports** page. **Note:** If optional fields are not selected, all the transaction details in the system are downloaded to the file. ![](/images/8450533/9e4913416870.png)

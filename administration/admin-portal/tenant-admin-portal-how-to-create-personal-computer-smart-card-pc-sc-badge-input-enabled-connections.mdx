## Introduction

This document provides instructions to create a PC/SC-enabled connection in the Tenant Admin Portal. When creating a Connection, you can enable **PC/SC Badge Input** to allow authentication using PC/SC-compatible badge readers (for example, HID cards).

## Prerequisite

You must have an admin access to the Tenant Admin Portal.

## Steps to Create a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left panel menu. ![](/images/11686694/177ed046ec6d.png) The **Connections** page is displayed.
3. Click **Create Connection**. ![](/images/11686694/82d58a4c843a.png) The **Create a new Connection** pop-up box is displayed.
4. Do the following:Enter **Connection Name**.Click the Advanced Settings drop-down menu and select **Enable PC/SC Badge Input** to allow input from PC/SC- compatible badge readers (e.g., HID cards) for authentication.**Note**: Once a connection is tagged as PC/SC-enabled, it cannot be reverted back to non-PC/SC use cases. Click **Create**. ![](/images/11686694/854dbcd47963.png) A PC/SC enabled connection is created successfully and listed on the **Connections** page. ![](/images/11686694/00ac7da1191b.png) Keywords| Enable PC/SC Badge Input in Connection | Create PC/SC-enabled Connection |

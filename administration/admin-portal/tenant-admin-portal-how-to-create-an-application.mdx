## Introduction

This document provides instructions to create an application in the Oloid Tenant Admin Portal. Applications define the required product configurations and can be mapped to an Endpoint for use with Oloid products.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Create an application

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Create Application** in the top right corner. ![](/images/8294483/a03e60ff8588.png) The **Create New Application** pop-up box is displayed.
3. Do the following:Enter **Application Name.**Selectapplicable **Application Type.**Click **Create**. ![](/images/8294483/01ea28c722eb.png) An application is created based on the application type.
4. Add required details to configure the application and click **Save**.The application is configured and listed on the Application page. ![](/images/8294483/39c254bd93cf.png) For detailed instructions to create and configure different application types, refer to below documents. **[How to Configure Application Type – Generic](/administration/admin-portal/how-to-create-and-configure-application-type-generic)****[How to Configure Application Type - Passwordless](/administration/admin-portal/how-to-create-and-configure-application-type-passwordless)****[How to Configure Application Type - Oloid Verify](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)** Watch our video tutorial **[How to create an application in the Oloid Portal](/administration/admin-portal/how-to-create-an-application-in-the-oloid-portal-video-tutorial)**[.](/administration/admin-portal/how-to-create-an-application-in-the-oloid-portal-video-tutorial)

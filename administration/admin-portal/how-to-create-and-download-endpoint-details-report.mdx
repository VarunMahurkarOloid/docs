## Introduction

An Endpoint Details Report provides detailed information of all the endpoints associated with the application.

## Pre-requisite

You must have a Tenant Admin account.

## Steps to create Endpoint Details Report:

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc**on the left menu panel. ![](/images/8450051/0aee946d9a47.png) The **Ad-Hoc Reports**page is displayed.

<Frame>
  <img src="/images/8450051/c340d0b652e5.png" alt="Screenshot" />
</Frame>

1. Do one of the following:Go to**Endpoint Details Report** >**+ Create & Download Report**. ![](/images/8450051/0aa918c8533e.png) On the top right, click **Create Report**> **Endpoint Details Report**. ![](/images/8450051/c1a1759b3669.png) The report is created and saved to your local device. ![](/images/8450051/85ef76783f11.png) **Keywords**|Endpoint Report| Endpoint Log| Create Report| Download Report| How to Create Report| Endpoint Details

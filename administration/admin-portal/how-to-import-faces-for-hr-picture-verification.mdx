## Introduction

The HR Picture Verification upload feature allows Admins to upload High Resolution facial images of users in bulk for identity verification.

## Pre-requisite

- You must have access to a Tenant Admin account.
- Ensure that the Image name is in the given format - "primaryID_username"

## Steps to Import faces

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu.
3. Click **HR Picture Verification**. ![](/images/13524609/ee223c333054.png) The HR Picture Verification page is displayed.
4. Click **Import** **Faces**. ![](/images/13524609/198b85f810fe.png) The **Import Faces** pop-up box is displayed.
5. Upload the image file of the users. ![](/images/13524609/390015ad7ffd.png)
6. Click **Import**.The images are uploaded and listed on **Import Faces** page. **Notes:**To check the status of HR Picture Verification file upload check **Upload Logs.**Please ensure that the Image name is in the given format - "primaryID_username". Only one image per user is allowed. Images with duplicate file name will be overwritten by the latest uploaded file and name. ​**Keywords**| Import user faces| HR Picture Verification| Upload facial images in Oloid Portal| Bulk face upload for users

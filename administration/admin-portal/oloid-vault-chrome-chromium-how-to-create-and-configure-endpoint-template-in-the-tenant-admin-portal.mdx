## Introduction

The Tenant Admin Portal allows admin to create endpoint templates for the COloid Vault (Chrome / Chromium) application, enabling standardized configuration across devices.

## Prerequisites

You must have access to the Tenant Admin Portal.

## Steps to Create Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Endpoint** from the left menu panel. ![](/images/12606069/69fd1b0cb9e3.png) The **Endpoints** page is displayed.
3. Click**Endpoint Templates** from the top right. ![](/images/12606069/7178b6b03f23.png) The **Endpoint Templates** page is displayed.
4. Click **Create Template** from the top right. ![](/images/12606069/be6fc5f731b6.png) The **Create New Template** pop-up box is displayed.
5. Do the following.Enter **Template Name**.Select **Passwordless** as **Application type** from the dropdown list.Select **OloidVault**as **Endpoint Type** from the dropdown list.Select **Chrome / Chromium** as Device type.Click **Create**. ![](/images/12606069/1c084b8f4e86.png)

The Oloid Vault (Chrome / Chromium) endpoint template is created successfully and listed in Endpoint Template page.

## Steps to Configure Oloid Vault (Chrome / Chromium) Endpoint Template

1. Click the preferred Endpoint template name to configure. ![](/images/12606069/0f537ec37d5e.png) The Endpoint template details page is displayed. ![](/images/12606069/6487d870e111.png)
2. Do the following:[Configure Details tab](#h_685f83ddfc)[Edit Configure tab](#h_10c254ce93)

## Configure Details tab

1. Edit **Template Name** if required.
2. Enter **Template Description**. (Optional)
3. Enter**Name Endpoint As**. (Optional)**Note:** Once the template is selected while pairing an endpoint on the device, the name provided in the **Name Endpoint As** field will be displayed for the endpoint.
4. Select**Time Zone** from the dropdown. (Optional)
5. Click**Save**.

## Edit Configure Tab

Set up the following configurations.

[Configure Endpoint Settings](#h_beece47ce8)

[Configure Groups](#h_fa9a0bec18)

## Configure Endpoint Setting

1. Enable the **Generate Debug Logs** toggle to activate log generation for endpoint until disabled.
2. Click **Save**.

  <img src="/images/12606069/227146f13ced.png" alt="Screenshot" />

## Configure Groups

1. Select **Groups** option from left menu panel > click **Add Group**.![](/images/12606069/d588de02b7cd.png)
2. The **Add Group** pop-up box is displayed.
3. Select **Group(s)**from the dropdown list.
4. Click**Add**. ![](/images/10489271/d5453310f109.png)

The group is added successfully.

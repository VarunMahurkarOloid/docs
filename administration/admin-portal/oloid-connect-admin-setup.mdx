## Introduction

The **Oloid Connect - Admin Setup** process includes logging into the Oloid Connect app, pairing the endpoint with the Oloid Connect application.

## Prerequisites

- You must have access to Admin or Supervisor account.
- Oloid Connect Application and Connections must be configured in Tenant Admin Portal. For more information, refer to [How to Create and Configure Oloid Connect Application in Tenant Admin Portal](/administration/admin-portal/how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)

## Device Compatibility

Ensure that your device is compatible with Oloid Connect App. See, [Oloid Connect - Hardware and Software Requirements](/passwordless/ios/connect/oloid-connect-hardware-and-software-requirements)

## Internet Connection

Make sure your device is connected to the internet for the setup.

## Steps to setup the Admin Mode

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.** ![](/images/10293811/8a9b62c1a00e.png) The Welcome screen is displayed. ![](/images/10293811/5221e300bb3a.png)
3. Enter **Tenant Name**, then tap **Next**.The**Login** page is displayed.
4. Do the following:Enter **Tenant Name**.Enter your email ID in the **Email** text field.Enter your password in the **Password** text field.Tap **LOGIN**.**Note:**You may also log in using SSO options. For more, refer to[Log in Using SSO](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) ![](/images/8400084/d162bd71017a.png) The **Settings** page is displayed.
5. Pair the Endpoint. For more details, see [How to pair the endpoint in Oloid Connect app](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint) ![](/images/8400084/22efa90f57d5.png) The Endpoint is paired successfully and the Device Setup successful pop up box is displayed. ![](/images/8400084/8a8d71911c6b.png) **NOTE:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.The application prompts you to log out of Admin mode.
6. Do one of the following:Tap **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to capture live Images for facial transactions.**Note:**To go back to admin mode, **double-click with two fingers**on preview mode and tap **Yes- To Continue**.Tap **No**to stay logged in to the admin mode.

## Admin Mode Actions Without Endpoint Pairing

You can perform the following actions without pairing the endpoint:

- [View user details](/passwordless/ios/connect/oloid-connect-view-user-details)
- [Add User](/passwordless/ios/connect/oloid-connect-add-user)
- [Add Face](/passwordless/ios/connect/oloid-connect-add-face)
- [Add QR Code](/passwordless/ios/connect/oloid-connect-add-qr-code)
- [Set PIN](/passwordless/ios/connect/oloid-connect-set-pin)
- [Add NFC/ID](/passwordless/ios/connect/oloid-connect-add-nfc-id)
- [Assign Badge](/passwordless/ios/connect/oloid-connect-assign-badge)

## Common Installation Requirements

- Ensure your device meets the app's requirements.
- Check your internet connection during installation.
- Verify that you've granted the necessary permissions to the app.

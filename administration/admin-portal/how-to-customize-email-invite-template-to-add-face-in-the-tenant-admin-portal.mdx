**Introduction**

The Tenant Admin Portal allows admin to invite users to add their face as an authentication method via email. This feature includes a customizable email invite template that can be tailored to your organization's messaging standard.

**Prerequisite**

You must have a Tenant Admin account.

**Steps to customize email invite template:**

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/10299914/c8560f399688.png) The **user profile menu** is displayed.
3. Select **Tenant Settings.** ![](/images/11968617/7a7743213fe4.png) The**Tenant Setting** page is displayed.
4. Go to **Advanced tab** > select **Face**from the left menu panel. ![](/images/11968617/37196fef8ea6.png)
5. Do the following under **Invite via Email:**Enter **email subject**.Enter message content in **email body**text field. **Note:**The User Portal link will be auto-attached to the email.To restore the default email subject and email body, click **Reset Template**. ![](/images/11968617/d27ce777d8a3.png)
6. Click **Save**. ![](/images/11968617/4ec800f475f9.png) The email invite template is updated successfully. ![](/images/11968617/abc1159cf536.png)

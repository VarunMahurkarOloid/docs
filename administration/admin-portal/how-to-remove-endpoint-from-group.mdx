## Introduction

This document provides instructions to remove one or more endpoints from a group in the Tenant Admin Portal.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- Ensure that the endpoints are already added to the group.

## Steps to Remove Endpoint from Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Groups** on the left panel menu. ![](/images/8320126/1f65ec6ced12.png) The **Groups** page is displayed.
3. Click the preferred group. ![](/images/8320126/9e4153afd099.png) The **Group Details** page is displayed. ![](/images/8320126/49362e6f3297.png)
4. Click **Endpoints** tab and do the following:Select the endpoint(s) to remove from the group.**Note:** If needed, you can select multiple endpoints to delete from group.Click **Delete** icon. ![](/images/8320126/b0df5152dbe0.png) The**Confirm Deletion**pop-up box is displayed.Click **Delete**. ![](/images/8320126/a3cf20e17350.png) The selected endpoint(s) is successfully deleted from the Group. ![](/images/8320126/5e76c7c1562d.png)

## Introduction

The Active Consent feature in the Oloid Tenant Admin Portal allows administrators to quickly access and manage user consent records. It provides a clear view of the consents a user has accepted and enables admins to download or review these records for compliance, auditing, or verification purposes. This ensures that consent-related information is easily accessible and securely maintained within the platform.

## Prerequisites

1. You must have a tenant admin account
2. User must be part of the connection.
3. Consent should already be accepted by the User to view active consent.

## Steps to view and download Active Consent of a User

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Directory**from the left menu panel. ![](/images/12990356/fdfb7db91aed.png)The **Users**page is displayed.
3. Click the user name to edit. The User details page is displayed.
4. Click the **Consent Tab** > **Active Consent**. ![](/images/12990356/a503fda348f3.png) The **Consent** page is displayed.
5. Do the following:Click **download icon** to download the active consent of the user. The active consent is successfully saved to the device.Click **View**to view the active consent metadata. **Note:**Consent Status are as follows: Provided: The user has given consent to add their face data.Denied: The user has rejected the consent request.Pending: The user has received the consent request, and their action is pending.Re-consent Pending: The user had previously provided consent, but a new consent request was issued and their action is pending.

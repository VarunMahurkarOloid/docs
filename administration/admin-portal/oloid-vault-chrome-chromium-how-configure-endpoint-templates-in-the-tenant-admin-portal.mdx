## Introduction

The Endpoint Template in the Tenant Admin Portal allows Tenant Admin to configure and manage settings for endpoints used in the Oloid Vault (Chrome / Chromium) application.

## Prerequisites

You must create Endpoint Template. To create refer, [How to create Endpoint Template for Chrome Vault application in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-endpoint-template-in-the-tenant-admin-portal).

## Steps to configure Endpoint Templates

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Endpoint** from the left menu panel. ![](/images/12606069/69fd1b0cb9e3.png) The **Endpoints** page is displayed.
3. Click**Endpoint Template** from the top right. ![](/images/12606069/7178b6b03f23.png) The **Endpoint Template** page is displayed.
4. Select the preferred Endpoint Template to edit. ![](/images/12636504/d91368af2962.png) The Endpoint Template details page is displayed.
5. Do the following:Edit **Template Name**.Add **Template Description**.Select the **Time Zone** from the dropdown list.Add **Endpoint Name**.Click **Save**. ![](/images/12636504/b0bac08b7f06.png)
6. Go to Configure tab and do the following:Turn on **Generate Debug Logs** toggle to activate generation of logs for the endpoint until disabled.Click **Save**. ![](/images/12636504/833d7b11847f.png) The Endpoint Settings is configured successfully.Select **Groups** from the left menu panel > select **Add Groups**. ![](/images/12636504/555009b4c6a2.png) The **Add Group** pop-up box is displayed.Do the following on the pop-up box:Select Groups from the **Groups** dropdown list.Click **Add**. ![](/images/12636504/e2e374b6576a.png) The Endpoint Template for DeviceLock Application is configured successfully. ![](/images/12636504/2b6214ce8c42.png) Keywords| Chrome Vault Endpoint Template | Configure Endpoint Template Chrome Vault | Tenant Admin Portal Chrome Vault setup |

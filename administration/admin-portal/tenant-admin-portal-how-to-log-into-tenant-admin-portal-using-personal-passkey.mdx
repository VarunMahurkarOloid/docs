## Introduction

Personal Passkey enables secure, passwordless access to the Tenant Admin Portal using a passkey associated with an individual user account.

## ​Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Passkey is enabled for the user. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-enable-passkey-sso-in-tenant-admin-portal)
- Personal Passkey is **enabled for your account**. Refer: [How to Generate Personal Passkey in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-generate-personal-passkey)

## Steps to log into Tenant Admin Portal using Personal Passkey

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**.The **Oloid Login**page is displayed.
3. Click **Login with SSO**. ![](/images/13884713/9f7edd503085.png) The configured login options are displayed.
4. Click **Login with Passkey**. ![](/images/15531507/a375a71bc187.png) The Oloid login page is displayed.
5. Enter **Email ID**> click **Next**. ![](/images/15531507/c1a47d041a7a.png) The user is authenticated using passkey. ![](/images/15531507/f49d148c5c71.png) The User is logged into the Tenant Admin Portal. ![](/images/15531507/e5c3cba1cafa.png)

### Introduction:

The Auto Config file is created and downloaded from the Tenant Admin Portal. It includes all the necessary settings to automatically connect your iPad to the Oloid Connect application. After downloading, transfer the file to your iPad.

This process allows the endpoint to connect with the Oloid Connect application configured in the Tenant Admin Portal, without requiring manual setup.

### Prerequisites:

- You must generate the Auto-config file, transfer it to the iPad, and save it. For more, refer to [How to generate Auto-Pair config file for Oloid Connect in Tenant Admin Portal](/administration/admin-portal/how-to-generate-auto-pair-config-file-for-oloid-connect-in-tenant-admin-portal)
- In the Tenant Admin Portal, select Skip user confirmation for pairing when generating the auto-config file. The endpoints pair automatically without user confirmation (recommended). ​

### Steps to pair an Oloid Connect endpoint using Auto Config file:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.The **Welcome** screen is displayed. ![](/images/11822152/81ba504b16bd.png)
2. Tap **Auto-pair using config file.** ![](/images/11822152/b81762602875.png) The **Pair Device Using Config File**page is displayed.
3. On the **Pair Device Using Config File**, tap on **Click here to pair file**.
4. Upload the auto-config file from your iPad. ![](/images/11822152/7ca4ab6073b8.png) The auto-config file is uploaded successfully, and the selected file is displayed on the screen.
5. Tap **Upload** to initiate endpoint pairing. ![](/images/11822152/c22186eb2207.png) The Pairing Initiated screen is displayed. ![](/images/11822152/190af27f61c9.png) The Endpoint Paired Successfully. ![](/images/11822152/168417220c6d.png) After successful pairing, the preview screen is displayed. ![](/images/11822152/6bf83cd7af74.png)

### Introduction

The Tenant Admin Portal allows Admin to reset a user’s PIN for secure login. Admin can either update the PIN directly or send a reset PIN email to the user. These options enable quick PIN recovery and help maintain uninterrupted user access.

## Steps to reset PIN

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory** on the left menu panel. ![](/images/11928944/917c389dfadb.png) The **Users**page is displayed.
3. Click **user name** to edit. ![](/images/11928944/65eace4fc84a.png) The user details page is displayed.
4. Go to**Credentials**tab > select **PIN** from the left menu panel. ![](/images/11928944/9fb3874b2ce3.png)
5. Do one of the following:a. **[Edit PIN](#h_fbb2d9682e)** orb. **[Send reset PIN email](#h_c7391b56d2)** The pin is updated successfully.

## Edit PIN

1. Select **Edit**icon.![](/images/11928944/4e6ff62c7ace.png) The **Add PIN** pop-up box is displayed.
2. On the pop-up box, do the following:Enter **new PIN**.Re-enter **new PIN**.Enter the recipient's email address to share the PIN.Click **Save**. ![](/images/11928944/cc0c05667bba.png) The PIN is reset successfully. ![](/images/11928944/060c3ccba9cd.png)

## Send reset PIN email

1. Select **Send Reset PIN Email**. ![](/images/11928944/570e823be067.png) The **Email Invitation Preview**pop-up box is displayed.
2. On the pop-up box, do the following:Enter recipient email address.**Note:** The registered email ID will appear as the default.Enter **Email Subject**.Enter message in the **Email Body**.Click **Save**. **Note:** The user portal link will be auto-attached to the email. ![](/images/11928944/cd1a03965638.png)

The PIN reset email is sent successfully.

The user can follow the on-screen instructions in the email to reset the pin.

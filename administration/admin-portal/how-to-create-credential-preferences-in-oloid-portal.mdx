**Introduction**

In the Oloid Portal, Tenant Admin can set preferred and primary credentials for specific use cases. After setup, the selected credentials will appear in the specified scenarios.

To set credential preferences, follow the below steps:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10765097/4acae2255ef8.png) The user profile menu is displayed.
3. Select **Tenant** **Settings**. ![](/images/10765097/9175aea4c069.png) The **Tenant Settings** page is displayed.
4. Select **Preferences**. ![](/images/10765097/712c0bd305b8.png) The **Let's customize the portal for you** pop-up box is displayed.
5. Do the following:Select the preferred **Credentials** you want to use.Click **Next**. ![](/images/10765097/cfbdb1be3101.png) Select the **Primary** **Credentials**.Click **Save & Next**. ![](/images/10765097/08c4840e8b47.png) Select the **Use-cases** for which you intend to use the Oloid Portal.Click **Finish Setup**. ![](/images/10765097/c018049b530c.png) The selected credentials are visible in the respective use cases.

Steps to configure Endpoint:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.![](/images/8227103/63a4b7076233.png)The Endpoints page is displayed.
3. Click on an endpoint name to edit from the listed endpoints.![](/images/8227103/74805360adfe.png)The Endpoint details page is displayed.![](/images/8332796/943fcc3ade9f.png)
4. Do the following:**Transaction**tab: You can view the transaction for the endpoint. **Settings** tab:**Endpoint Settings**:Edit **Endpoint Name** (optional).Enter **Endpoint Description**(optional).Enter time-zone from **Timezone**dropdown (optional). **Note**: If Endpoint time zone is not specified, by default the endpoint takes the time zone specified for the application. Enable**Capture Location** toggle button to activate the 'Location Capture' on the endpoint for each transaction.**Note**: The Endpoint device 'Location Permission' must be enabled.Click **Save**.**Groups:**Add Group to Endpoint.**Web Button**: Turn on **Enable Web Button** toggle button to view transactions.**Integration**: Enable Integrations to perform cloud-based actions.**Configure**tab: Enter integration in the **Integration Name**field and enter URL in the**Add URLs that needs to be monitored** field. **Health Response**tab: You can check the health status of the endpoint. **Insights**:You can view number of active users and endpoint transactions.![](/images/8332796/861b3c1b1350.png) **Health:** In this section, you can see the endpoint status, check health of the endpoint and configure health alert. For more information on health alert, see**[How to configure health alert for an endpoint](/administration/admin-portal/how-to-add-health-alerts-in-the-endpoint)**. **Endpoint Location:**In this section, you can set endpoint location. For more information on adding location, see**[How to add location to the endpoint](/administration/admin-portal/how-to-add-location-to-the-endpoint)**.The endpoint is configured.

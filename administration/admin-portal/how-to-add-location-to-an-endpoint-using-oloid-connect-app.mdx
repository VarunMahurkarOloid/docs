### Pre-requisite:

- You should be a Tenant Admin and Supervisor.

### Steps to add location to an endpoint:

1. Launch the **Oloid Connect**app.The Welcome screen is displayed. ![](/images/10293864/81ba504b16bd.png)
2. Tap **Pair as Supervisor.** ![](/images/10293864/8a9b62c1a00e.png) The Welcome screen is displayed.
3. Enter **Tenant Name,**then tap **Next**. ![](/images/10293864/5221e300bb3a.png) The**Login** page is displayed. ![](/images/8601123/de8bc6acd9bb.png) The **Login** screen is displayed.
4. Do the following:Enter your email ID in the **Email** text field.Enter your password in the **Password** text field.Tap **LOGIN**. ![](/images/8601123/653f2244b4a4.png) **Note:** If your face is added to the Tenant Portal as a Tenant Admin, you can tap on **Log in with Face** to log in using your face.You can also use **Log in using SSO**to continue with [Google](/resources/integrations/sso/oloid-connect-first-time-login-using-google-sso), [Microsoft](/resources/integrations/sso/oloid-connect-first-time-login-using-microsoft-sso), and [Okta](/resources/integrations/sso/oloid-connect-first-time-login-using-okta-sso). ![](/images/8601123/0dd520ae39a9.png) The **Allow "Oloid Connect" to use your location?**pop-up box is displayed.
5. On the pop-up box, select an option:**Allow Once**: Every time you open the app, it’ll ask to use your location.**Allow While Using App:**The app can use your location only when you're using that app.**Don't Allow:** The app cannot use your location, even when you’re using the app. ![](/images/8601123/e05313bc9802.png) The **Settings**page is displayed.
6. Do the following on the **Settings** page:Add **Template** (optional).Enter **Endpoint Name**.Select Application Name from **Application Name** list.
7. Tap **Pair.** ![](/images/8601123/3eda4ea5d46e.png) The settings are saved and the Device Setup success message is displayed. ![](/images/8601123/cb2f780dbb54.png) The application prompts you to log out of Admin mode.
8. Do one of the following:Click **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to capture live Images for facial transactions.**Note:**To go back to admin mode, double-click on preview mode and tap **Yes- To Continue**.Click **No**to stay logged in to the admin mode.

<Frame>
  <img src="/images/8601123/f97b48ac5b11.png" alt="Screenshot" />
</Frame>

You can now log in to the **Tenant Admin Portal** to check the location added to the specific endpoint.

**Note:** To update the Location, see [How to update Location for Oloid Connect](/administration/admin-portal/how-to-update-location-for-oloid-connect).

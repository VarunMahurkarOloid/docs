## Introduction

To use the Oloid Connect app, you must first create and configure the application in the Tenant Admin Portal. This includes creating and managing the application, connection, and template(optional). Once configured, the app can be used to manage user authentication and access.

## Steps to create and configure Oloid Connect application

1. Log in to the**Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right. ![](/images/8655943/b7f0276ba29f.png) The **Create New Application** pop-up box is displayed.
3. On the pop-up box, do the following: Enter **Application Name**and select **Application Type**as Oloid Verify.Click **Create**. ![](/images/8655943/76250926197d.png) The **Oloid Connect for passwordless**application is created and the configuration page is displayed. ![](/images/8655943/e013c34adb99.png)
4. Configure the following:[Configure Details tab](#h_6fa3f7f997)[Authenticator tab](#h_307e5bc53a)[Design Theme tab](#h_879dec5493)[Configure tab](#h_c214dcb2c4)[Configure Health Setup tab](#h_3392ee9d98)[Configure Connections tab](#h_e4a397cd75)[Configure Integrations tab](#h_78967cab3d)[Configure Exception tab](#h_e9627bc281)
5. Click **Save**after each action to save your configuration.The application is created and configured.**Note**: These are one-time settings and all the default settings are recommended.

## Configure Details tab

1. Modify **Application name**(if required).
2. Add **Description** (Optional).
3. Set **Time-zone** (Optional).
4. Select **Factor Sequence**from dropdown list to activate Multi-Factor Authentication (Optional). For more details, refer [How to create and configure Factor Sequence](/administration/admin-portal/how-to-create-and-configure-factor-sequence).
5. Set **Idle Screen Soft Time Limit** (Optional).
6. Set **Idle Screen Hard Time Limit**(Optional). ![](/images/8655943/53da73683e28.png)

## Configure Authenticator tab

You may enable one or more credential options based on your requirements. **Face** is enabled by default.

## Face

To use face as a credential, enable **Face**option.

<Frame>
  <img src="/images/8655943/6c0bdf008b17.png" alt="Screenshot" />
</Frame>

Do the following:

1. Select**FR Mode** from the FR Mode dropdown. select the preferred face recognition mode:(if required)**Hybrid**: Combines cloud and on-device facial recognition.**Cloud**: Uses cloud-based facial recognition.**On Device**: Uses on-device facial recognition.(if required)
2. **On-Device Model**: Edit this field if required. (Optional)
3. Choose a liveness mode:Enable **Hardware Liveness** in devices with dedicated hardware sensors for higher accuracy.Enable **Software Liveness** to use software-based analysis to verify the captured face image authenticity.**Note:** Software Liveness verification may take longer to complete compared to Hardware Liveness verification. By default Hardware Liveness is enabled.
4. Adjust the following settings for Software Liveness:**Min Liveness Probability**:Determines the probability threshold to classify an image as live.Default: 0.5**Min Liveness Quality**:Defines the minimum acceptable quality for images used in liveness checks.Default: 0.1
5. Click **Save**.

<Note>
  The parameters are pre-configured. This is done by Oloid admin.
</Note>

## Configure Settings tab

1. **Enable Offline Mode**: Enable this option to allow endpoint transactions to be processed even without network connectivity.
2. **Use Group Authorization**: Enable this option to download groups so that users and endpoints of the same group are downloaded for authorization in offline mode.
3. **Authentication Timeout**: Set an appropriate timeout value to determine the duration the application waits for the user to begin the authentication process before being redirected to the initial screen.
4. **Apply Endpoint Template**: Use this option to choose a template that will be applied automatically when connecting an endpoint device.
5. **Show Clock on Intent/Auth Screens**: Turn on this toggle to show the clock on all screens Intent, Authentication selection, and Identity verification.
6. **Enable Landscape Mode for Preview Screen:**Turn on this toggle to change the user preview screen from portrait to landscape mode. ![](/images/8655943/7d22fc58a216.png)

**Introduction**

A Tenant Admin has complete access to Oloid platform and all the Oloid connected devices. You must be an Oloid user to be a Tenant Admin.

For adding an existing user as Tenant Admin, see [How to invite a Tenant Admin](/administration/admin-portal/how-to-invite-a-tenant-admin)

**Pre-requisite**

You must be a Tenant Admin to add and invite a new user as Tenant Admin.

Steps to add and invite a new user as Tenant Admin:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/10299914/c8560f399688.png) The **user profile menu** is displayed.
3. Do one of the following:Go to **Tenant Settings** > **Admin Controls** tab >**Tenant admins**> **Invite Tenant Admin.** ![](/images/8254907/c52999847883.png) OR, go to **Tenant Settings**> **Action** >**Invite Tenant Admin.** ![](/images/8254907/699ca4feee01.png) Click **Invite Admin**. ![Image](/images/8254907/99d602f0d80a.png) The**Invite Tenant Admin**pop-up box is displayed. ![](/images/8254907/9dd09fd0963c.png)
4. On the pop-up box, do the following:Enter the user name in the**Search By User or Primary ID**field.The search result lists down if there is any existing user.Click **Add user**to add a new user. ![](/images/8254907/c679f34f5f56.png) The **Create Tenant Admin** screen is displayed for the new user and username is auto populated. ![](/images/8254907/5ef47ab5492d.png) Edit **Full Name**( if required).Enter **Primary ID** or select **Use OloID as Primary ID** to use OloID as your primary ID.Select connection from the **Connection** list.Enter **Admin Email.** Select **Read Only Mode** to restrict the Admin from performing any action in the Oloid Portal. (Optional)
5. Select **Create & Invite**. The tenant admin is created and listed on the **Tenant Admins** tab. **Note**: An email is sent to the user to verify the email ID. ![](/images/8254907/41f362266637.png) Video TutorialWatch the video [How to add and invite a Tenant Admin in Tenant Admin Portal-Video Tutorial](/administration/admin-portal/how-to-add-and-invite-a-tenant-admin-in-tenant-admin-portal-video-tutorial) ​

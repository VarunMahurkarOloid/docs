## Pre-requisite:

Shared credential must be already created. To create shared credential for domain user, read [How to create shared credential for domain users.](/passwordless/windows/passwordless/how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal)

To assign shared credential to an endpoint:

1. Log in to the **Oloid Portal**.
2. On the Home page of the portal, click **Endpoints** on the left panel menu.![](/images/8717165/968a38988678.png) The Endpoints page is displayed.
3. Click on an endpoint name to edit from the listed endpoints.![](/images/8717165/2d5a561feee4.png)The Endpoint details page is displayed.![](/images/8717165/0a87ed79f85b.png)
4. Go to **Settings**tab> **Shared Credentials**>**+Assign Shared Credential**.![](/images/8717165/9a7aebdbd34f.png) The **Assign Shared Credential** pop-up box is displayed.
5. On the pop-up box, select **Domain Shared Credential(s)** from the drop-down list.![](/images/8717165/afdf9879d1c0.png)
6. Select **Assign**.The domain shared credential is successfully assigned to the endpoint.![](/images/8717165/cac3e5dc13a4.png)

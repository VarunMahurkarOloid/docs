## Introduction

The **Oloid Verify Admin Setup** process allows Tenant Admins and Supervisors to configure and prepare the Oloid Verify app for use on an iPad. This setup ensures that the endpoint is properly linked to the Oloid Verify application and ready for user authentication.

## Prerequisite

- You should be a Tenant Admin or Supervisor.
- You must create and configure Oloid Verify application in the Tenant Admin Portal. To create refer[How to create and configure Application Type - Oloid Verify](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal).
- You must download and install Oloid Verify app from the App store. To download and install refer [How to download and install Oloid Verify App](/passwordless/verify/oloid-verify-how-to-download-and-install-the-app).

## Steps to setup

1. Launch the Oloid Verify app. ![](/images/8601056/65448eab37c7.png) The Login screen is displayed.
2. Enter **Tenant Name**.
3. Enter your email id in the **Email** text field.
4. Enter your password in the **Password** text field.
5. Tap **LOGIN**.**Note:** If your face is added to the Tenant Portal as a Tenant Admin, you can tap on **LOG IN WITH FACE** to log in using your face. ![](/images/8601056/963370a0e2b8.png) The location access pop-up box is displayed
6. Do one of the following:**Allow Once:** Each time you open the app, it will request access your location.**Allow While Using App:** The app can access your location only when you are actively using it.**Don't Allow:** The app cannot access your location, even while you are using it.![](/images/8601056/a1a3e896d661.png) The **Settings** page is displayed.
7. Do one of the following on the **Settings** page. Add **Template** (optional).Enter **Endpoint Name**.Select Application Name from **Application Name** list.Tap **Pair.** ![](/images/8601056/591a4022a230.png) The settings are saved and the Device Setup success message is displayed. ![](/images/8601056/1f20c4ba77dc.png) **NOTE:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.
8. The application prompts you to log out of Admin mode.
9. Do one of the following:Tap **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to authenticate.**Note:**To go back to admin mode, **double-tap with two fingers**on preview mode and tap **Yes- to Continue**.Tap **No**to stay logged in to the admin mode. ![](/images/8601056/dd604ce67beb.png) You can perform the following actions:[View User Details](/passwordless/verify/oloid-verify-view-user-details)[Add User](/passwordless/verify/oloid-verify-add-user)[Add Faces](/passwordless/verify/oloid-verify-add-faces) SEO KeywordsOloid Verify admin setup | Oloid Verify iPad setup | set up Oloid Verify app

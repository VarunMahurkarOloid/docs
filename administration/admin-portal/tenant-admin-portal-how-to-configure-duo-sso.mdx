## Introduction

This document provides steps on how to set up Duo Single Sign-On (SSO) in the Tenant Admin Portal by enabling Duo SSO and adding the required parameters from the Duo Administrator Console.

## Prerequisite

To set up the configuration between Duo and Oloid, you must generate the parameters in Duo Administrator Console. For detailed instructions, see [Duo Settings for Oloid SSO](/resources/integrations/sso/duo-settings-for-oloid-sso).

## Steps to Configure Duo SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10660395/cf3ebe1f2be0.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/10660395/b6873b0f44b5.png) The **Tenant Settings** page is displayed.
4. On Tenant Settings page, go to **Security**tab, and click **Duo.**The Duo configuration page is displayed. ![](/images/12086393/931a6a44daaf.png)
5. Turn on **Enable Duo SSO**toggle. ![](/images/12086393/9066b043e001.png)
6. Copy both **Redirect URLs** from the Duo configuration page and add them to the **Duo Identity Administrator Console**.Use the first URL for the Tenant Admin Portal.Use the second URL for the User Portal. ![](/images/12086393/5d5b4669530f.png) **Note:** You must enter both URLs in the Duo Identity Administrator Console. They are required to complete the login configuration. For more, refer to [Duo Settings for Oloid SSO](/resources/integrations/sso/duo-settings-for-oloid-sso)
7. In the **Duo Identity Administrator Console**, go to **Application > Single Sign-On** tab, and locate the **[Metadata](/resources/integrations/sso/duo-settings-for-oloid-sso)**[link](/resources/integrations/sso/duo-settings-for-oloid-sso)section and then Copy the parameters and add the following details.**Client ID:** Add the Client ID in the Client ID field.**Auth URL:** Add the Authorization URL in the Auth URL field.**Token URL:** Add the Token URL in the Token URL field.**Client Secret:** Add the Client Secret in the Client Secret field.**User Info URL:** Add the User Info URL in the User Info URL field. ![](/images/12086393/a2578306b453.png)
8. Click **Save**. ![](/images/12086393/ebea1509d52e.png) The Duo Identity SSO is configured.

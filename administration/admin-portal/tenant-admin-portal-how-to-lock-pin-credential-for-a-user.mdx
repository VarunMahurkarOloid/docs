## Introduction

The **Lock PIN** feature allows the Tenant Admin to restrict the use of a user's PIN credential from the Tenant Admin Portal. Locking a PIN **prevents the user from authenticating with that credential** until it is unlocked or updated.

## Prerequisites

- You must have access to the **Tenant Admin Portal.**
- Ensure that the **PIN Lock** is enabled in the Tenant Settings. For further information, refer [PIN Lock Policy](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin).

## Steps to Lock PIN of a User

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Directory** in the left navigation panel. ![](/images/14014193/31eb14ea15bf.png) The **Users**page is displayed.
3. Select the **user name** to edit. ![](/images/14014193/e8b5635f6f72.png) The **User Details** page is displayed.
4. Go to**Credentials**> **PIN**. ![](/images/14014193/06da441a89ae.png) The **PIN** section is displayed.
5. Click **Lock PIN**.**Note:** The PIN Lock Policy is used to configure the settings for locking a PIN after consecutive failed authentication attempts and defining the unlock behavior. For further information, refer [PIN Lock](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin). ![](/images/14014193/3e837a890d0f.png) The **Confirm PIN Lock** pop-up box is displayed.
6. Click **Lock PIN**. ![](/images/14014193/30c92c160df8.png) The PIN credential is locked successfully. ![](/images/14014193/7784625f7ab7.png)

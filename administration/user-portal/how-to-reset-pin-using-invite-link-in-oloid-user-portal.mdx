### Introduction

This document provides step-by-step instructions to reset PIN in the Oloid User Portal using an invite link.  
Note: The admin sends an email with an invite link to reset the PIN. That link directs the user to the Oloid User Portal where user can reset the PIN.

### Steps to reset PIN using invite link:

1. Click on the invite link for reset PIN. ![](/images/9489199/fd739e1bff97.png) The Oloid User Portal opens with PIN Credential screen.
2. Select **Edit PIN**. ![](/images/9489199/309c26024ffe.png) The Reset PIN page is displayed. ![](/images/9489199/70d0b5583679.png)
3. Do the following:Enter new PIN.**Note:**Only numeric values are allowed.Re-enter new PIN.Click **Reset**.The PIN is updated successfully and a success message is displayed. ![](/images/9489199/39775551772c.png)

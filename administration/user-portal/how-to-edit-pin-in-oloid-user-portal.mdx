### Introduction

This document provides step-by-step instructions to edit PIN in the Oloid User Portal.

### Steps to edit PIN:

1. Log in to the **Oloid User Portal**.
2. On the credential home page, select **PIN**. ![](/images/9448187/bd3d550efef7.png) The **PIN Credential** page is displayed.
3. Select **Edit PIN**. ![](/images/9448187/75b1bb7c9ec6.png) The screen to reset PIN is displayed. ![](/images/9448187/e2f76246a27f.png)
4. Do the following:**Enter new PIN**.**Re-enter new PIN**.Click **Update**.The PIN is updated successfully. ![](/images/9448187/5bbc58ef549c.png) Video TutorialWatch the video [How to edit PIN using Oloid User Portal- Video Tutorial](/administration/user-portal/how-to-edit-pin-using-oloid-user-portal-video-tutorial)

## Introduction

This document explains how a user can revoke their consent using the Oloid User Portal.

## Prerequisites

- You have access to the Oloid User Portal.
- Your face credential is already onboarded and consent is previously submitted. For more, refer to [How to Add a Face Using Invite Link in Oloid User Portal](/administration/user-portal/how-to-add-a-face-using-invite-link-in-oloid-user-portal)

## Steps to Revoke Consent

1. Log in to Oloid User Portal.
2. On the Credentials page of the portal, click on the **Faces**. ![](/images/14685322/88fec361dec1.png) The **Face credential** page is displayed.
3. Click **Revoke Consent.** ![](/images/14685322/6eb76491ea52.png) The **Revoke Consent** Pop up is displayed.
4. Do one of the following:Click **Yes, Revoke Consent** to revoke your consent.Click **View Consent Form** to view or download the submitted consent.Click **Cancel** to close the pop-up without making any changes. ![](/images/14685322/e0c996708246.png) The Consent is revoked successfully, and all previously enrolled face credentials are deleted.**Note:**If consent is revoked, the Add Face Credential option is disabled and cannot be selected.

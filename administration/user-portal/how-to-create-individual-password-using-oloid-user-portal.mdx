## Introduction

Oloid User Portal allows the user to create and assign passwords to themselves.

To create individual passwords:

1. Log in to the**Oloid User Portal**.
2. On the credential home page, select **Windows** **Passwords**. ![](/images/9468372/bd0f403e88b7.png) The **Windows** **Passwords** page is displayed.
3. Select**Add**![](/images/9468372/31065b8af131.png) icon to create an individual password. ![](/images/9468372/c3e372223ae0.png) The **Windows Passwords** page is displayed to set Password.
4. Do the following:[Create password for domain user](#h_b4f2ea83a0)[Create password for local user](#h_7122bb41d2)

## Create password for Domain User

1. Select user type as **Domain User** from **Windows** **User Type**dropdown. ![](/images/9468372/60793bfbce08.png)
2. Enter **Display Name**.
3. Enter **Domain Name**.
4. Select **Preferred Machine(s)**. (Optional)**Note**: You can select multiple machine name
5. Enter **User Name**of your Windows account.
6. Enter **Password** of your Windows account (Optional).
7. Click **Create**.The password credential is created and displayed for the domain user under the **Individual Passwords**section. ![](/images/9468372/af32e0f4e01f.png)

## Create password for Local User

1. Select user type as **Local User** from **Windows User Type**dropdown. ![](/images/9468372/cfbc27591e4d.png)
2. Enter **Display Name**.
3. Select **Machine Name**.**Note**: You can select only single machine name.
4. Enter **User Name**.
5. Enter **Password**(Optional).
6. Click**Create**.The password credential is created and displayed for the local user under the **Individual Passwords**section.![](/images/9468372/37675b47df33.png)

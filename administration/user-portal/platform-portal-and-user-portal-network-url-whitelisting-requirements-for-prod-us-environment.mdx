## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform, authentication services, APIs, and supporting infrastructure**.

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Platform Portal and User Portal |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **PROD (US)** |
|---|---|
| Admin API & Platform Portal | oloid.cloud |
| Tenant platform portal | \<tenantname>.oloid.cloud |
| Admin API | api.oloid.cloud |
| System Admin API | sysadminapi.oloid.cloud |
| Tenant S3 bucket | \<tenantname>\<tenantid>.s3.us-east-1.amazonaws.com​ |
| Oloid document bucket | oloiddocument-prod.s3.us-east-1.amazonaws.com |
| Amazon Cognito IDP | cognito-idp.us-east-1.amazonaws.com |
| Amazon Cognito Identity | cognito-identity.us-east-1.amazonaws.com |
| Google Maps API | maps.googleapis.com |
| Oloid Help | oloid.help |
| GraphQL API | graphql-\<tenantname>.oloid.cloud |
| Passwordless Authentication | \<tenantname>.oloidsso.com |
| User API & Portal | api.myoloid.com |
| Tenant User Portal | \<tenantname>.myoloid.com |

---

#### Notes

- Replace **\<tenantname>** and **\<tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **\<tenantname>** and **\<tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **\<tenantname>** and **\<tenantid>** details.

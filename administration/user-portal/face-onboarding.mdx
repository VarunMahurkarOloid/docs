## Introduction

In Oloid’s Passwordless feature, adding face refers to the process of integrating a new user using facial recognition for Okta integration. You can log into Okta effortlessly and securely by simply looking at your device's camera.

The process of face onboarding in Oloid Platform involves adding faces to respective users.

## Pre-requisite

You should be a Tenant Admin in the Oloid Platform.

Face onboarding can be done in four ways:

1. [Add face to user](#h_91daef4a1b)
2. [Invite to add face to user](#h_15f2d3b7a1)
3. [Invite to add face to user in bulk](#h_1f6a904217)
4. [Import faces in bulk](#h_4eb30227ff)

## Add face to a user

To add face:

1. Log in to the **Oloid Platform**.Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu. In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Add face**" option.In the "**Users**" page select the user to whom you want to add a face. Then, follow the on-screen instructions to complete the process.

For detailed guide on adding face to a user, refer [How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user).

## Invite to add face to user

To invite to add face:

1. Log in to the **Oloid Platform**.Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu. In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Invite to Add Face**".In the "**Users**" page select the user to whom you want to add a face. Then, follow the on-screen instructions to complete the process.

The user will receive an invitation to add their face.

For detailed guide on inviting to add face to user, refer[How to invite to add face](/administration/admin-portal/how-to-invite-to-add-face).

## Invite to add face to user in bulk

To invite to add face in bulk:

1. Log in to the **Oloid Platform**.Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu. In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Invite to Add Face**".In the "**Users**" page select the user(s) to whom you want to add a face. Then, follow the on-screen instructions to complete the process.

For detailed guide on inviting to add face to user in bulk, refer [How to invite to add face in bulk](/administration/admin-portal/how-to-invite-to-add-face-in-bulk).

## Import faces in bulk

To import faces in bulk:

1. Log in to the **Oloid Platform**.Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to "**Import**". In the "**Directory**" section, select "**Import Users**".
4. Select "**Import Users**".Follow the on-screen instructions to complete the process.

For detailed guide on importing faces in bulk, refer [How to onboard faces in bulk](/administration/admin-portal/how-to-onboard-faces-in-bulk).

To edit individual passwords:

1. Log in to the **Oloid User Portal**.
2. On the Credential home page, select **Windows** **Passwords**. ![](/images/9468926/bd0f403e88b7.png) The **Windows** **Passwords**page is displayed.
3. Select password (Domain User/Local User) and click **edit** ![](/images/9468926/324b0d0b93d5.png) icon. ![](/images/9468926/5aefd891193a.png) The page is displayed to edit password. ![](/images/9468926/6a6c1edd057b.png)
4. Do the following:[View and Edit Domain User](#h_83b1137aff)[View and Edit Local User](#h_ea380296d8)

## View and Edit Domain User

<Frame>
  <img src="/images/9468926/6a6c1edd057b.png" alt="Screenshot" />
</Frame>

1. Edit **Display Name**.
2. Edit **Domain Name**.
3. Select **Preferred Machine**from the**Preferred Machine(s)** list. (Optional)
4. Edit **User Name**.
5. Enter **Password** (Optional).
6. Click **Save**.The Windows Password for domain user is updated successfully. ![](/images/9468926/801a60a77b40.png)

## View and Edit Local User

<Frame>
  <img src="/images/9468926/70917d951428.png" alt="Screenshot" />
</Frame>

1. Edit **Display Name**.
2. Select **Machine**from the**Machine** **Name**dropdown list.
3. Edit **User Name**.
4. Enter **Password**. (Optional)
5. Click **Save**.

The Windows Password for local user is updated successfully.

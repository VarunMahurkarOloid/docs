## Introduction

This document describes the steps to create a **Vault Password** in the Oloid User Portal. The process allows authorized users to securely store and manage credentials for applications or services.

## Prerequisites

- You are a registered user in the **Tenant Admin Portal**with the Admin role.
- User must have required information for the web application, including **URL/App ID**, **User Name**, and **Password**.
- The Vault Password feature must be enabled in the User Portal. To enable this feature, refer to the **Configure Setting Section** of [How to Configure Oloid User Portal in Tenant Admin Portal](/administration/user-portal/oloid-user-portal-how-to-configure-oloid-user-portal-in-tenant-admin-portal).

## Steps to Create Vault Password

1. Log in to the **Oloid User Portal**.
2. On the homepage, click **Vault Passwords**.![](/images/9880892/3e652269a4e3.png) Vault Passwords page is displayed.
3. Click**+ ADD** from the top right corner. **Note:** You cannot add Shared Credentials. ![](/images/9880892/5bf02c8a286f.png) The page to create **Vault Passwords** is displayed.
4. Do the following:Select **Web** from the **Vault Password Type** drop-down list.Enter **Display Name**. (Optional)Enter**URL/App ID**.Enter **User Name**.Enter **Password**.Click **Create**. ![](/images/9880892/ac5ead407351.png)
5. The vault password is successfully created.![](/images/9880892/468726238b17.png) The vault password is listed in the Individual Passwords section.![](/images/9880892/2d022754a9ef.png)

## Introduction

This document provides step-by-step instructions for logging in to the Oloid User Portal using Microsoft Single Sign-On (SSO). Microsoft SSO allows users to securely access the Oloid User Portal.

**Note:** To enable **Microsoft SSO Login** for Oloid User Portal, contact [Oloid Support.](mailto:Support@oloid.ai)

## Prerequisites

- You should be a user in the Tenant Admin Portal.
- The Microsoft credential (user email ID) must be added to the user details page.
- You must enable SSO options in Tenant Admin Portal. For more details, refer to [How to configure Oloid User Portal in Tenant Admin Portal](/administration/user-portal/oloid-user-portal-how-to-configure-oloid-user-portal-in-tenant-admin-portal)

## Steps to log into Oloid User Portal using Microsoft SSO Login

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar > press **Enter** on your keyboard.The Oloid User Portal page is displayed.
3. Click **Login with SSO.** ![](/images/9531151/1df4a4d26a44.png) The configured login options are displayed.
4. Click **Continue with Microsoft** to log into Oloid User Portal with Microsoft SSO. ![](/images/9531151/d42ceafe51f4.png) The Sign in pop-up box is displayed.
5. Enter your **Microsoft ID** > click **Next**. ![](/images/9531151/dbd2ded388a7.png) **Enter your password** pop up box is displayed.
6. Enter **Password** in the Password field > Click **Next**. ![](/images/8727230/b4da026afea6.png) You are logged in to the Oloid User Portal using Microsoft SSO successfully. ![](/images/9531151/1c7784deee0f.png) Keywords|Oloid User Portal Log in| Oloid User Portal |Microsoft SSO| Microsoft Single Sign-On| Login with Microsoft |Oloid User Portal Login|

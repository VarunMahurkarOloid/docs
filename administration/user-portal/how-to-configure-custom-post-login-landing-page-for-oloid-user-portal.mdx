## Introduction

The **Custom Post-Login Page** setting allows Tenant Admins to define the landing page users see after logging into the User Portal. By configuring this option in the Tenant Admin Portal, admins can control the default post-login experience and direct users to a specific page based on organizational requirements.

## Prerequisite

- You must have access to Tenant Admin account.
- Custom Post Login Landing page dropdown must be enabled by [Oloid support](https://Landing%20page%20for%20the%20user-portal.%20Displays%20all%20the%20available%20pages%20enabled%20by%20Oloid%20support).

## **Steps to configure**Custom Post-Login Landing page

1. Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click**Profile icon**on the bottom left corner of the menu panel. ![](/images/13597272/41c2bc01017a.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/13597272/0ed9e08eb1f7.png) The **Tenant Settings** page is displayed.
4. Click **App Settings**tab > select **User Portal**. ![](/images/14321285/9c6858d262a9.png)
5. On the App settings Page section in the left menu panel select **User Portal** > click **Post-Login Page.** ![](/images/14321285/aca98af56e32.png)
6. Do the following:Turn on **Custom Post-Login Landing Page**toggle.Select landing page from **Dropdown**.**Note:**Landing page for the user-portal displays all the available pages enabled by Oloid support. If you need to enable pages not listed here, please contact [Oloid support](mailto:support@oloid.ai). ![](/images/14321285/be00547bba53.png) Click **Deploy Changes**.

### Introduction

This document provides step-by-step instructions to enroll a badge in the Oloid User Portal.

### Steps to enroll badge:

1. Log in to the **Oloid User Portal**.
2. On the credential page of the Oloid User Portal, select **Badge**. ![](/images/9459048/11eeb681f9f1.png) The **Badge Credential** page is displayed.
3. Select **Enroll for Badge Login**. ![](/images/9459048/1c826e453ff3.png) The confirmation pop-up to **ensure that the Badge reader is connected to your device** is displayed
4. Click **Okay**. ![](/images/9459048/ce62d593da30.png) The **Scan your Badge**page is displayed. ![](/images/9459048/a3c0544e6a44.png)
5. Do any of the following:Enter the badge card number.Click on the**Scan or Type Data**textbox area. Tap the **Badge** on the **Badge Reader** to scan it.**Note:**If you do not click on the Scan or Type Data textbox area, you will not see the data in the text field.
6. Click **Submit**.On badge authentication, you are successfully assigned a badge credential. ![](/images/9459048/d19b2ea5707a.png) Video TutorialWatch the video [How to enroll for Badge login using Oloid User Portal](/administration/user-portal/how-to-enroll-for-badge-login-using-oloid-user-portal)

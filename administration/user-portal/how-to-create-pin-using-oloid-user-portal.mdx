### Introduction

This document provides step-by-step instructions to create a PIN using the Oloid User Portal.

### Steps to create PIN:

1. Log in to **Oloid User Portal**.
2. On the credential home page, select **PIN**. ![](/images/9423743/9338bc29bd01.png) The **PIN Credential** page is displayed.
3. Click **Add PIN**. ![](/images/9423743/ee8f30175e09.png) The screen to set PIN is displayed. ![](/images/9423743/9f75113462ae.png)
4. Do the following:**Enter new PIN**.**Re-enter new PIN**.Click **Add PIN**.The PIN is created and assigned to you. The success message is displayed. ![](/images/9423743/0bea89327356.png)
5. Close the pop-up box to view the PIN credential details. ![](/images/9423743/d62d3e27713c.png) Video TutorialWatch the video [How to create PIN using Oloid User Portal- Video Tutorial](/administration/user-portal/how-to-create-pin-using-oloid-user-portal-video-tutorial)

### Introduction

This document provides step-by-step instructions to create a PIN in the Oloid User Portal using an invite link.

**Note:** The admin sends an email with an invite link. The link directs the user to the Oloid User Portal where the PIN can be create.

### Steps to set PIN using invite link:

1. Click on the invite set PIN link. ![](/images/9459704/fd739e1bff97.png) The Oloid User Portal opens with PIN Credential page. ![](/images/9459704/c97438aeedde.png)
2. Enter new PIN.
3. Re-enter new PIN.
4. Click **Create**.The PIN is created successfully. ![](/images/9459704/8cf58a35e808.png)

## Introduction

You can configure the biometric policy (also known as the consent form) from the Connection Details page in the Tenant Admin Portal. When enabled, this feature prompts users to accept the biometric policy before they can add their face in the Oloid User Portal.

This document comprises the following:

- [To configure biometric policy in the Tenant Admin Portal](#h_b9cd9cdfe3)
- [To test biometric policy in the Oloid User Portal](#h_f2ba60fb0d)

## To configure biometric policy in the Tenant Admin Portal

Steps to configure biometric policy:

1. Log in to Tenant Admin Portal.
2. On the home page of the portal, click **Connections** on the left menu panel. ![](/images/11324573/b3e7d2e9608b.png) The **Connections** page is displayed.
3. Click connection name to be configured from the listed connections. ![](/images/11324573/a7514919527b.png)The Connection detail page is displayed. ![](/images/11324573/bf4f25bd510e.png)
4. Go to **Settings**tab.
5. Turn on **User Consent Required** toggle > Select a Template from the **User Consent Required**dropdown list. **Note**: Enabling this toggle will prompt users to provide consent to store and use their face for different applications within the workplace during face-onboarding.**Note:**To create a consent template, refer [How to create a Consent Template](/administration/admin-portal/how-to-create-and-configure-consent-template). ![](/images/11324573/6d9173dc5f2f.png)
6. Click **Save**. The connection is successfully configured.

## To test biometric policy in the Oloid User Portal

**Pre-requisite:**

- A user must be created in the Tenant Admin Portal.
- In the paired connection, enable the **User Consent Required** toggle button.

Steps to test biometric policy:

1. Log in to the **Oloid User Portal**.The Oloid User Portal login page is displayed. ![Image](/images/11324573/ca646a3ca4b2.png)
2. Select **Login with Email**.The **Login with Email** page is displayed. ![](/images/11324573/3f667b3e1bf6.png)
3. Do the following:Enter your email address in the **Email ID** field.Click **Get Verification Code**.A verification code is sent to your registered email ID.Enter the Verification code.**Note:**The One Time Verification Code expires after 60 seconds. ![](/images/11324573/efa8120662ad.png) Click **Login**.The Oloid User Portal is displayed.
4. On the homepage, click**Face**. ![Image](/images/11324573/f15168b91b68.png) The **Face Credential**page is displayed.**Note**: The user must provide their consent to proceed to the next steps if consent is enabled in the Tenant Admin Portal. ![](/images/11324573/ab515e55e573.png)
5. Select **Add Face** to complete facial enrollment. ![](/images/11324573/a9146592f49e.png)

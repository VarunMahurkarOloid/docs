To send QR Code credential to user using user portal link:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu. ![Image](/images/8850381/6142e01fd801.png) The **Users** page is displayed.
3. Click **Username**to edit. ![](/images/8850381/def026f51c9b.png) The User details page is displayed.
4. Go to **Credentials**tab > **QR Code** > select **Send User Portal Link**. ![Image](/images/8850381/da75fd78849a.png) The admin sends an email with the user portal link to view and scan the QR Code. The link navigates the user to the self-service portal where the user can perform QR Code transaction. ![](/images/8850381/08f5f1d121ce.png)

## Introduction

In Oloid's Passwordless feature, Personal Identification Number (PIN) is a simple and secure way to enhance the authentication process for your Okta account. Pin onboarding in Oloid Platform involves adding PIN to respective users.

## Pre-requisite:

- You should be a Tenant Admin in the Oloid Portal.
- User is added to Oloid Portal

## To add Pin:

1. Log in to the Oloid Platform.Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu.In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Add Pin**".On the "**Users**" page select the user to whom you want to add a Pin. Then, follow the on-screen instructions to complete the process. For detailed guide on Pin onboarding, refer **[How to add Pin as credential to users](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users).**

## Introduction

This document provides instructions to log in to the Oloid User Portal using Auth0 SSO.

## Prerequisites

- You must be a user in the Tenant Admin Portal.
- You must have valid Auth0 credentials.

## Steps to log in to Oloid User Portal using Auth0 SSO Login

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**. The **Oloid User Portal** page is displayed.
3. Click **Login with SSO**. ![](/images/11122318/763652e87727.png) The configured Login options are displayed.
4. Click **Continue with Auth0**. ![](/images/11122318/1b9aed5cc03a.png) The **Welcome** pop-up box is displayed.
5. Do the following.Enter your**Email address**.Enter your **Password**.Click **Continue**. ![](/images/11122318/a822d9b20970.png) On successful authentication, you are logged in to the Oloid User Portal using Auth0. ![](/images/11122318/af4829b8c965.png)

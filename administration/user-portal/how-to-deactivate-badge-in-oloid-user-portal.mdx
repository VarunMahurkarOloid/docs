### Introduction

This document provides step-by-step instructions to Deactivate Badge in Oloid User Portal.

### Steps to Deactivate Badge:

1. Login to the **Oloid User Portal**.
2. On the homepage, click **Badge**. ![Image](/images/9880879/7725f55b351f.png) The **Badge Credential** page is displayed.
3. Click **Deactivate Badge**. ![Image](/images/9880879/01ac80988077.png) The confirmation pop-box is displayed. ![](/images/9880879/89af51192f36.png)
4. On the pop-up box, do the following:Select reason. (Optional)Click**Deactivate**.The badge is deactivated successfully. ![](/images/9880879/8b9fe1674faa.png)

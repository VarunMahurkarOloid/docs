## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Authentication services, APIs, and supporting infrastructure**.

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Platform Portal and User Portal |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **UAT** |
|---|---|
| Admin API and Platform Portal | oloidpreview.com |
| Tenant platform portal | \<tenantname>.oloidpreview.com |
| Admin API | api.oloidpreview.com |
| System Admin API | sysadminapi.oloidpreview.com |
| Tenant S3 bucket | \<tenantname>\<tenantid>.s3.us-east-2.amazonaws.com |
| Oloid document bucket | oloiddocument-preview.s3.us-east-2.amazonaws.com |
| Amazon Cognito IDP | cognito-idp.us-east-2.amazonaws.com |
| Amazon Cognito Identity | cognito-identity.us-east-2.amazonaws.com |
| Google Maps API | maps.googleapis.com |
| Oloid Help | oloid.help |
| GraphQL API | graphql-\<tenantname>.oloidpreview.com |
| Passwordless Authentication | \<tenantname>.oloidsso.net |
| User API & Portal | api.previewoloid.net |
| Tenant User Portal | \<tenantname>.previewoloid.net |

---

#### Notes

- Replace **\<tenantname>** and **\<tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **\<tenantname>** and **\<tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **\<tenantname>** and **\<tenantid>** details.

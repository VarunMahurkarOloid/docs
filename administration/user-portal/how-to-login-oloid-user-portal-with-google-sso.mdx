To enable **Google SSO Login** on Oloid User Portal, you need to raise a ticket with [Oloid Support.](mailto:Support@oloid.ai)

**Pre-requisite**

- You should be a user in the Tenant Admin Portal.
- You must enable SSO options in Tenant Admin Portal. For more details, refer to [How to configure Oloid User Portal in Tenant Admin Portal](/administration/user-portal/oloid-user-portal-how-to-configure-oloid-user-portal-in-tenant-admin-portal) >[Configuring SSO options](/administration/user-portal/oloid-user-portal-how-to-configure-oloid-user-portal-in-tenant-admin-portal)

Steps to log in to Oloid User Portal using **Google SSO Login** option.

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar. Then, press **Enter** on your keyboard.The **Oloid User Portal** page is displayed.
3. Click **Log in with SSO**. ![](/images/11122318/763652e87727.png) The configured Login options are displayed.
4. Click **Continue with Google**. ![](/images/9514956/c8d97990ff29.png) The **Sign in** screen is displayed. ![](/images/9514956/013f6f75b34c.png)
5. On the screen, do the following.Enter**Email or phone** > click **Next**.The **Welcome** screen is displayed.Enter your **Password** > click **Next**. ![](/images/9514956/85beeaf36947.png)

You are logged in to the Oloid User Portal using Google SSO successfully.

## Introduction

The User Portal allows users to create and register an Oloid passkey for authentication.

## Prerequisite

Oloid Passkey must be enabled in the App settings for User Portal from Tenant Admin portal.

## Steps to Generate Oloid Passkey

1. Log in to the **User Portal**.
2. On the credentials page of the portal, click**Oloid Passkey.** ![](/images/13884380/68a351fb7c42.png) The **Oloid Passkey** page is displayed.
3. Click **Generate**. ![](/images/13884380/4efcd3070a66.png)
4. The Passkey registration screen is displayed. ![](/images/13884380/8263c20563eb.png) The Passkey is successfully generated. ![](/images/13884380/1ad37b6cd81b.png)

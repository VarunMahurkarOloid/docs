Steps to Logout:

1. Log in to the **Oloid User portal**.
2. On the homepage, click menu panel ![](/images/9874177/e650ea9e42a6.png) icon on the top right corner.
3. Select **Logout**. ![Image](/images/9874177/2d2ed722955c.png) The Oloid User Portal is logged out successfully.

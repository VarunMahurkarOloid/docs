## Introduction

This document describes how to configure Advanced User Sync for Workday - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for Workday -Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for Workday -Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**. ![](/images/13569620/096adf4607aa.png) The **Advanced User Sync** page is displayed.
3. Select the preferred Workday Inbound Advanced User Sync. ![](/images/13569620/d2d3c3f15e79.png) The **Advanced User Sync** detail page is displayed.
4. Do the following:[Configure Details Tab](#h_40e28daa63)[Setup Configuration Tab](#h_9439525d8b)[Configure Account Tab](#h_cf2cbcac6b)[Configure Schedule Tab](#h_95f47bd3d8)
5. Click **Activate**. ![](/images/13569620/38ed544d9ed6.png) The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**. ![](/images/13569620/cdd109f9d1eb.png) The Advanced User Sync is configured and activated successfully. ![](/images/13569620/4229dd6bbdf8.png)
7. (Optional) Go to **Action >** **User Sync**.**Note:** Selecting **Sync Now** immediately triggers a manual synchronization. ![](/images/13569620/04ed6e4eac70.png) The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**. ![](/images/13569620/012fa05e465f.png) The **Success** pop-up box is displayed. ![](/images/13569620/4b8ab6d86ec7.png) The Advanced User Sync for Workday - Inbound is configured successfully. ![](/images/13569620/0aa5eabf3c2f.png)

## Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**. ![](/images/13569620/e3e0ad046d15.png) The Details tab is configured successfully.

## Setup Configuration Tab

This tab is used to map user data from **Workday** to **Oloid** and select the Oloid connection where users are added during the inbound user sync.

Do the following:

1. Select the data mapper table from the drop-down.**Note:** Click **View Tables** to review or create a data mapper table, if required.
2. On **Add Users to Selected Connection**, do one of the following:Select the **Connection** option, and then select the required **Connection** from the drop-down list.**Note:** **(Optional)** Select **Group** from the Groups drop-down to add users only to the selected groups.ORSelect the **Data Filter Table** option, and then select the required **Data Filter Table** from the drop-down list.**Note:** Click **View Tables** to review or create a data filter table, if required.
3. On Update User, select **Sync Photos from Workday and add as Face credential**.
4. Click **Save**. ![](/images/13569620/d5554e92c61d.png) A **Confirm Update** pop-up box is displayed.
5. Click **Confirm**. ![](/images/13569620/b42aa382d7a5.png) The Configuration tab is configured successfully. ![](/images/13569620/6392101154ae.png)

## Configure Account Tab

This tab is used to add and configure the **Workday** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**. ![](/images/13569620/94c15b9750a8.png)
2. Enter **Token Endpoint**. ![](/images/13569620/7bc66ea47b21.png)
3. Enter **Workday REST API Endpoint**. ![](/images/13569620/274b9e1fb05f.png) **Note:** You can see the **Token Endpoint** and **Workday REST API Endpoint** on **View API Clients** for Integrations page in the Workday HRIS admin console. To know more, click **[here](/resources/integrations/hrms/connecting-workday-hris-with-oloid-cloud-platform)**. ![](/images/13569620/ac1d8e62df65.png)
4. Enter **WQL Query**. ![](/images/13569620/d3967d9fcc91.png) **Note:** You can see the **WQL Query** on **Convert Report to WQL** in the Workday HRIS admin console. To know more, click **[here](/resources/integrations/hrms/connecting-workday-hris-with-oloid-cloud-platform)**. ![](/images/13569620/e83ea66dbee9.png)
5. Enter **Client ID**. ![](/images/13569620/4e6651e4aa41.png)
6. Enter **Client Secret**. ![](/images/13569620/616bc00eafbe.png) **Note:** You can see the **client ID and client Secret** on Register API Client for Integrations page in the Workday HRIS admin console. To know more, click **[here](/resources/integrations/hrms/connecting-workday-hris-with-oloid-cloud-platform)**. ![](/images/13569620/86963adf4e5e.png)
7. Enter **Workday Tenant Name**. ![](/images/13569620/d0388fb49af7.png) **Note:** You can see the **Workday Tenant Name**on **View API Clients** for Integrations page in the Workday HRIS admin console. To know more, click **[here](/resources/integrations/hrms/connecting-workday-hris-with-oloid-cloud-platform)**. ![](/images/13569620/a790ecf13565.png)
8. Enter **Refresh Token**. ![](/images/13569620/d0313c8aaeb6.png) **Note:** You can see the **Refresh Token** on Delete or Regenerate Refresh Token page in the Workday HRIS admin console. To know more, click **[here](/resources/integrations/hrms/connecting-workday-hris-with-oloid-cloud-platform)**. ![](/images/13569620/eb1b23b002fb.png)
9. Click **Save**. ![](/images/13569620/34e45d9f29bc.png) The Account tab is configured successfully.
10. Click **Test**. ![](/images/13569620/fa442ba85738.png) The **Success** pop-up box is displayed. ![](/images/13569620/87802626e428.png)

The Account tab is configured successfully.

## Configure Schedule Tab

This tab is used to define when the **Workday - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#h_8d11d16647)

**OR**

[Run Once When Activated](#h_d3e16ffa20)

<Frame>
  <img src="/images/13569620/e0804a09c27b.png" alt="Screenshot" />
</Frame>

The Schedule tab is configured successfully.

### Repeat Every

The **Repeat Every**section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).**Note:** You can select multiple days (if needed).
3. Select the run time in the **Runs at** field.**Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
4. Select **Time Zone**from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.**Note:** Separate multiple email addresses with commas.
6. Click **Save**. ![](/images/13569620/824a72ed4a6d.png) The **Repeat Every** section is configured successfully. ![](/images/13569620/5890583b0a2f.png)

### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone**from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.**Note:** Separate multiple email addresses with commas.
5. Click **Save**.

The **Run Once When Activated** section is configured successfully.

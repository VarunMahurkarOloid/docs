## Introduction

The Data Mapper Table in the Tenant Admin Portal allows admins to map employee data from external systems such as Workday - Inbound to Oloid. This document provides instructions on how to create the Data Mapper table for Workday - Inbound.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Data Mapper Table

1. Log in to **Tenant Admin Portal**.
2. Go to **Agents** tab > click **Data Tables**. ![](/images/13457914/14bac2cbe71e.png) The Data Tables page is displayed.
3. Click **Create Table**. ![](/images/13457914/ed08bcea8cdd.png) The **Create Data Table** pop-up box is displayed.
4. Do the following:Enter **Table Name**.Select **Data-mapper Table** in Type of Table.Click **Next**.Select **Workday - Inbound** as a Category.Click **Create**. ![](/images/13457914/e16cb2656fa3.png) The data mapper table is created successfully. ![](/images/13457914/60ab43c4c7a0.png)

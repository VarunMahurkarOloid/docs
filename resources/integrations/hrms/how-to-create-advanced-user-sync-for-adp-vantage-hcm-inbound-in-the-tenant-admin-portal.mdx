## Introduction

The **Advanced User Sync** feature in the Tenant Admin Portal allows admin to create and manage user synchronization using supported agents such as ADP Vantage HCM - Inbound, ensuring accurate and consistent user data in the Oloid Tenant Admin Portal.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**. ![](/images/13559374/63ba2c7038a3.png) The Advanced User Sync page is displayed.
3. Click **Create User Sync**. ![](/images/13559374/07c6d6f4752d.png) The **Create User Sync** pop-up box is displayed.
4. Do the following:Enter **User Sync Name**.Select **Agent**.**Note:** Select ADP Vantage HCM - Inbound as agent.Click **Create**. ![](/images/13718491/3906913757c5.png) The advanced user sync for ADP Vantage HCM - Inbound is created successfully. ![](/images/13718491/36edbe4cb79c.png)

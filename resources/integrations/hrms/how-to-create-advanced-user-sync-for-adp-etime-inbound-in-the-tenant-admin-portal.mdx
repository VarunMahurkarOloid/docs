## Introduction

The **Advanced User Sync** feature in the Tenant Admin Portal allows admin to create and manage user synchronization using supported agents such as ADP ETime - Inbound, ensuring accurate and consistent user data in the Oloid Tenant Admin Portal.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**. ![](/images/13559374/63ba2c7038a3.png) The Advanced User Sync page is displayed.
3. Click **Create User Sync**. ![](/images/13559374/07c6d6f4752d.png) The **Create User Sync** pop-up box is displayed.
4. Do the following:Enter **User Sync Name**.Select **Agent**.**Note:** Select ADP ETime - Inbound as agent.Click **Create**. ![](/images/14468948/7df475ccdeca.png) The advanced user sync for ADP ETime - Inbound is created successfully. ![](/images/14468948/e8bc8dada8e0.png)

## Introduction

The Microsoft SSO Login feature in the Oloid Verify App allows Tenant Admin and Supervisor to access Admin Mode using Microsoft credentials.

## Prerequisite

You must have a Tenant Admin account.

## Steps to log in with Microsoft SSO

1. Launch the **Oloid Verify**App. The **Settings**screen is displayed.
2. Tap **Login as Admin**. ![](/images/10255679/46a068a4e14c.png) The Login screen is displayed.
3. On the login screen, tap **Login with SSO**. ![](/images/10255679/30bb9403dffc.png) The screen with **SSO options** are displayed.
4. Tap **Continue with Microsoft**. ![](/images/10255679/40a128542d28.png) The confirmation pop-up box is displayed.
5. Tap **Continue**. ![](/images/10255679/2c5c6bac81d2.png) The **Microsoft** **Sign in** page is displayed.
6. Enter **Email ID** > tap **Next**. ![](/images/10255679/a2692fb2ad22.png)
7. Enter**Password** > tap **Sign in**. ![](/images/10255679/5c21efba3421.png) You are logged in to Admin Mode in Oloid Verify using Microsoft SSO successfully. SEO Keywords|Oloid Verify Microsoft SSO | Oloid Verify SSO login | Microsoft SSO Admin Mode|

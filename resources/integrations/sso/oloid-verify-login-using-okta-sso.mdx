## Introduction

The Okta SSO Login feature in the Oloid Verify App allows Admin and Supervisor to securely access Admin Mode using Okta credentials.

## Prerequisite

- You must have a Tenant Admin account.

## Steps to log in with Okta SSO

1. Launch the **Oloid Verify**App.The Login screen is displayed.
2. On the login screen, tap **Login with SSO**. ![](/images/10255679/30bb9403dffc.png) The screen with **SSO options** are displayed.
3. Tap **Continue with Okta**. ![](/images/10367862/227d1715bb53.png) The confirmation pop-up box is displayed.
4. Tap on **Continue**. ![](/images/10367862/92990365313b.png) The **Okta** **Sign In** screen is displayed.
5. Enter **Username**> tap **Next**. ![](/images/10345413/b1e6e0ffa4ad.png)
6. Enter **Password** in the Password field > tap **Sign In**. ![](/images/10345413/0769ca7d69d9.png) You are logged in to Admin Mode in Oloid Verify using Okta SSO successfully.

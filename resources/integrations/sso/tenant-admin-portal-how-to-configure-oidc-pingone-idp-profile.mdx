## Introduction

This document explains how to configure an **OIDC PingOne Identity Provider (IDP) profile** in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- PingOne IDP profile must be created in Tenant Admin Portal. To create refer, [How to create IDP Profile for PingOne](/resources/integrations/sso/tenant-admin-portal-how-to-create-idp-profile-for-oidc-pingone).
- Ensure that the Webkey application is created. To create Webkey application, refer [How to create and configure WebKey Application in Tenant Admin Portal | Oloid Help Center](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal).

## Steps to Configure OIDC-PingOne IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Security** > **Identity Provider**. ![](/images/10826464/1dce6a6624c0.png) The **Identity Provider Profiles** page is displayed.
3. Click PingOne-IDP application. ![](/images/10826464/867f5923a04d.png) The application details page is displayed.
4. Do the following:[Configure Details tab](#h_1ed669b8cd)[Integrate Metadata tab](#h_bf43346286)[Configure IDP Settings tab](#h_0d13591e22)[Configure Claims tab](#h_272a7e024d)The IDP Profile is configured.

## Configure Details tab

The Details tab is used to view and manage the basic information such as IDP Name, IDP Description, etc. for the identity provider configured in the Tenant Admin Portal.

To configure the Details tab, do the following:

1. Edit the **IDP Name**. (Optional) ![](/images/10826464/30724b16547c.png)
2. Enter **Description**. (Optional) ![](/images/10826464/e9504d1e7eee.png)
3. Do one of the following:Select the required WebKey application from the **Select WebKey Application**dropdown list. ![](/images/10826464/3523813d2f8d.png) (OR)Click **Make Default**.**Note:** The **Make Default** button is enabled only when more than one IDP is added in the Tenant Admin Portal. ![](/images/10826464/8de6ed277137.png) The **Set this as Default IDP** pop-up box is displayed.Select the **Webkey Application**.Select **Set as Default**. ![](/images/10826464/f4f692ae9de3.png) The WebKey application is set as the default, and the application is linked to this IDP. ![](/images/10826464/480a5bd8d773.png)
4. Click **Save**. ![](/images/10826464/3ba1f8cc644c.png)

**Note:** If another IDP is currently set as default, it will be replaced upon confirmation.

- To make IDP as default, click **Make Default**. The confirmation pop-up box is displayed.
- Click **Set as Default**to designate the preferred IDP as default.

The Metadata tab is used to provide the required information to configure PingOne settings and enable PingOne based authentication between the identity provider and the Tenant Admin Portal.

1. Click **Oloid Metadata**.The Oloid Metadata tab is displayed. ![](/images/10826464/b629a77e43f7.png)
2. Click [Visit help page](/resources/integrations/sso/integrating-oloid-tenant-to-your-pingone-oidc-instance) for the document to configure PingOne settings for SSO login.
3. Do the following:**Download Oloid Metadata:** Download the certificate and upload it to the **IDP Signature Certificate** field.**OpenID Configuration Endpoint:** Copy the OpenID Configuration Endpoint URL and enter it in the **Discovery Endpoint URL** field in the PingOne Admin Console. ![](/images/10826464/50f047d8ff50.png) **Note:** You can find the **Discovery Endpoint URL**field in the PingOne Admin Console. For details, click **[here](/resources/integrations/sso/integrating-oloid-tenant-to-your-pingone-oidc-instance)**. ![](/images/10826464/a42ab7d5df7c.png)

## Configure Claims Tab (Optional)

The **Claims** tab is used to configure custom claims that pass user attributes from Oloid to the OIDC provider.

Do the following:

- [Custom Claims](#h_6eefcfb250)
- [Authentication Methods References (AMR) Claims](#h_18921fc1b8) ![](/images/10826464/98ab8c7a0908.png)

### Custom Claims

Custom Claims allow the admin to map Oloid user attributes to OIDC attributes.

Do the following:

1. In the **Custom Claims** tab, expand the **Custom Claims** section.The Custom Claims section is displayed. ![](/images/10826464/c3fc40cc75e4.png)
2. In the **Custom Claims** section, click **Add Field**.
3. In the **OIDC Attribute** field, enter the OIDC Attribute.
4. Select the Oloid Value from the **Oloid Value** dropdown.**Note:**Click **Add Field** to add additional claim.
5. Click **Save.** ![](/images/10826464/f8a2b2c02757.png) The Custom claims are configured successfully. ![](/images/10826464/26bf22f2f5f8.png)

### Authentication Methods References (AMR) Claims

**AMR Claims** indicate **how a user was authenticated** during the login process.

1. In the **AMR Claims** tab, expand the **AMR Claims** section.The AMR Claims section is displayed. ![](/images/10826464/450ed39699b0.png)
2. In the **AMR Claims** section enter the authentication method value. ![](/images/10826464/6bbea4cb1d9a.png) **Note:**Click **Add**to add additional AMR claim items.
3. Click **Save.** ![](/images/10826464/0c375eed5219.png) The AMR section is configured successfully. ![](/images/10826464/641cecb336af.png) The PingOne IDP is configured successfully. ![](/images/10826464/ef7780bf4cf3.png)

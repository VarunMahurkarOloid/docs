## Introduction

This document explains how to create a **SAML Identity Provider (IdP) profile** in the Oloid Portal to enable SAML-based authentication.

## Prerequisite

You must have Admin access to the Tenant Admin Portal.

## Steps to Create SAML IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security**> **Identity Provider**. ![](/images/12808717/1dce6a6624c0.png) The **Identity Provider Profiles** page is displayed.
3. Select **Create IDP**in the top right corner. ![](/images/12808717/086f0fd42723.png) **Note**: You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](/resources/integrations/sso/webkey-how-to-link-webkey-with-an-identity-provider-idp-in-tenant-admin-portal). ![](/images/10822772/689d9d6dba89.png) The **Create New IDP**pop-up box is displayed.
4. Do the following:Enter **IDP Name**.Select**SAML**asAuth Protocol.Click **Create**. ![](/images/12808717/5ffa74d3011c.png) The IDP Profile for SAML is successfully created. ![](/images/12808717/69e107c0acf7.png)

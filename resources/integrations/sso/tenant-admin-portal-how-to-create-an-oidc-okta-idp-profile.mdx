## Introduction

This document provides instructions to create an Okta IdP profile in the Oloid Portal. An IdP profile enables passwordless SSO authentication using Okta.

## Prerequisites

You must have Admin access to the Tenant Admin Portal.

## Steps to Create an Okta Idp Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page, select **Security** > **Identity Provider**. ![](/images/9214537/9e488769e2f3.png) The **Identity Provider Profiles** page is displayed.
3. Click **Create IDP**. ![](/images/9214537/321418c1eee9.png) **Note**: You cannot create a new Idp unless a default Idp is already set. Please open an existing Idp and mark it as default before proceeding. For more details refer [How to make an IDP default](/resources/integrations/sso/webkey-how-to-link-webkey-with-an-identity-provider-idp-in-tenant-admin-portal). ![](/images/10822772/689d9d6dba89.png) The **Create New IDP**pop-up box is displayed.
4. Do the following:Enter the **IDP Profile Name**.Select**OIDC**asanAuth Protocol.Click **Next**.Select **Okta**as the IDP Provider for OIDC.Click **Create**. ![](/images/9214537/73b164bbc8b7.png) The Okta IdP profile is created successfully. ![](/images/9214537/0e3c49841462.png)

## Introduction

This document explains how to enable Microsoft Entra ID Single Sign-On (SSO) in the Tenant Admin Portal. Oloid supports SSO using OIDC, enabling secure and seamless user authentication. Once configured, users can sign in to the Oloid Platform through Entra ID. Oloid currently supports only OIDC for SSO authentication.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Enable Entra ID SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10316179/a0c10011c3d1.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/14663355/2e33b366db32.png) The **Tenant Settings** page is displayed.
4. Go to **Security**tab > click **Entra ID SSO**. ![](/images/14663355/690f981dc83c.png)
5. Turn on**Enable** **Entra ID SSO** toggle.
6. Click **Save.** ![](/images/14663355/2c76eea02a7c.png) The Entra ID SSO is enabled successfully. ​**Note:** You can view the Activity Log in the Tenant Admin Portal.

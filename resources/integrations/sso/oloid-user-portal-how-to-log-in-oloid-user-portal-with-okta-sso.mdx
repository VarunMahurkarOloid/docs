## Introduction

This document provides instructions to log in to the Oloid User Portal using Okta Single Sign-On (SSO). Okta SSO enables users to access the Oloid User Portal using their existing Okta credentials.

## Prerequisite

You must have valid Okta user credentials.

## Steps to log in to Oloid User Portal using **Okta SSO**

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**. The **Oloid User Portal** page is displayed.
3. Click **Login with SSO**. ![](/images/9531562/763652e87727.png) The Configured Login options are displayed.
4. Click **Continue with Okta**. ![](/images/9531562/64aa735830ea.png) The **Sign In** pop-up box is displayed.
5. Do the following:Enter your **Okta User name**.Enter **Password**.Click **Sign In**. ![](/images/9531562/8439eed0ed58.png) You are logged in to the Oloid User portal using Okta SSO successfully. ![](/images/9531562/af4829b8c965.png)

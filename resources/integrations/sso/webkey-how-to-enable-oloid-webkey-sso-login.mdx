## Introduction

By enabling Oloid (WebKey) SSO from the Tenant Admin Portal and selecting the appropriate IDP, admins can provide users with secure single sign-on (SSO) authentication using an external Identity Provider (IDP).

## Prerequisite

- You must have a Tenant Admin account.
- OKTA IDP must be created for the application. To create, refer [How to create IDP Profile for OIDC-Okta in the Tenant Admin Portal](/resources/integrations/sso/tenant-admin-portal-how-to-create-an-oidc-okta-idp-profile)

## Steps to configure Webkey SSO

1. Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click**Profile icon**on the bottom left corner of the menu panel. ![](/images/13597272/41c2bc01017a.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/13597272/0ed9e08eb1f7.png) The **Tenant Settings** page is displayed.
4. On Tenant Settings page, go to **Security**tab, and click **Webkey SSO.** ![](/images/13597272/afd9a9a18395.png) The Webkey SSO configuration page is displayed.
5. Do the following:Turn on **Enable Oloid (WebKey) SSO**toggle.Select **IDP** from the dropdown.Click **Save**. ![](/images/13597272/3b2525f61911.png) The Oloid Webkey SSO is configured.

## Introduction

The SAML–Okta Identity Provider (IdP) Profile enables secure authentication between Okta and the Oloid Tenant Admin Portal. Configuring SAML allows users to sign in to Oloid applications using their Okta credentials.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure that the **SAML IDP** application is created. To create SAML application, refer [How to Create IDP Profile for Security Assertion Markup Language (SAML) in the Tenant Admin Portal | Oloid Help Center](/resources/integrations/sso/tenant-admin-portal-how-to-create-idp-profile-for-security-assertion-markup-language-saml).
- Ensure that the required **Okta SAML parameters** are available or can be generated from the SAML Identity Provider configuration in the Okta Admin Console. To see the parameter, refer [How to Configure Security Assertion Markup Language (SAML) IDP in OKTA Admin Console | Oloid Help Center](/resources/integrations/sso/how-to-configure-security-assertion-markup-language-saml-idp-in-okta-admin-console).
- Ensure that the Webkey application is created. To create Webkey application, refer [How to create and configure WebKey Application in Tenant Admin Portal | Oloid Help Center](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal).

## Steps to Configure SAML-Okta IDP Profile

1. Log in to the **Oloid** **Tenant Admin Portal**.
2. On the **Applications** page, click **Auth Policies** > **Identity Provider**. ![](/images/12840218/f71f621b44a7.png)The **Identity Provider Profiles** page is displayed.
3. Click preferred SAML-IDP application. ![](/images/12840218/42de48092cf0.png) The IDP details page is displayed. ![](/images/12840218/53e7264d74aa.png)
4. Do the following:[Configure Details tab](/resources/integrations/sso/how-to-configure-oidc-okta-idp-profile-in-the-tenant-admin-portal)[Integrate Metadata tab for Okta Settings](/resources/integrations/sso/how-to-configure-oidc-okta-idp-profile-in-the-tenant-admin-portal)[Configure IDP Settings tab](/resources/integrations/sso/how-to-configure-oidc-okta-idp-profile-in-the-tenant-admin-portal)[Configure Claims tab](#h_ecb80a1178)The IDP Profile is configured successfully.

Do the following:**Download Certificate:** Download the certificate and upload it to the **IdP Signature Certificate** field.**Sign-On URL:** Copy the Sign-on URL and enter it in the **IdP Issuer URL** field.**Entity ID:** Copy the Entity ID and enter it in the **Sign-on URL** field. ![](/images/12840218/4312beb7cb94.png) **Note:** You can find the **IdP Signature Certificate, IdP Issuer URL** and **Sign-on URL**fields on the SAML protocol section on SAML in OKTA Admin Console. ## Configure Claims Tab (Optional)

The **Claims** tab is used to configure custom claims that pass user attributes from Oloid to the OIDC provider.

Do the following:

- [Additional Claims](#h_ad38192031)
- [Group Claims](#h_a562946c89) ![](/images/12840218/ff4d336b05ca.png)

### Add Additional Claims

Custom Claims allow the admin to map Oloid user attributes to OIDC attributes.

Do the following:

1. In the **Additional Claims** section, click **Add Field**. ![](/images/12840218/3bb9446e08ac.png)
2. In the**SAML Claim**field, enter the claim name to be sent to the service provider.
3. Selectone of the following types.**Basic:** Standard claim format.**Unspecified:** No specific format defined.**URI Reference:** Claim uses a URI-based format.
4. In the **Oloid Value** dropdown, select the corresponding Oloid attribute (for example, Oloid ID).**Note:**Click **Add Field** to add additional claim items.
5. Click **Save.** ![](/images/12840218/8daad6246d55.png) The Custom claims tab is configured.

### Group Claims

The **Group Claims** section allows you to pass user group-related attributes from Oloid to the Service Provider during authentication.

1. In the **Group** **Claims** tab, expand the **Group Claims** section.The Group Claims section is displayed.
2. Click **Add Field**. ![](/images/12840218/132fd3ac63b5.png)
3. Enter the following details:**Attribute Name**: Enter the group attribute name to be sent to the Service Provider.**Type**: Select the claim format:**Basic****Unspecified****URI Reference****Oloid Value**: Enter or select the group-related value.**Condition**: Select one of the following:**Contains****Equal****Starts With**
4. Click **Save**. ![](/images/12840218/236ec3bee860.png) The **Group Claims** section is configured successfully. ![](/images/12840218/c94dce08a8e5.png) The **SAML IDP** is successfully configured. ![](/images/12840218/dfae0bdab0ad.png)

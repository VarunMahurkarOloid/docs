## Introduction

Each WebKey application must be mapped to a single IDP profile. The Tenant admin can configure multiple IDP profiles, but only one can be set as the default. When an IDP profile is marked as the default, users are redirected to the HRMS platform associated with the linked WebKey application during login.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure Webkey application is already created. For more information, refer: [How to create and configure WebKey Application in Tenant Admin Portal](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)
- Ensure IDP is already created. For more information, refer: [How to create IDP Profile for OIDC-PingOne in Tenant Admin Portal](/resources/integrations/sso/tenant-admin-portal-how-to-create-idp-profile-for-oidc-pingone)

This document comprises the following:

- [Assign WebKey application to IDP](#h_03e266120b)
- [Make an IDP as default](#h_ba61702807) If you setup IDP as default, it will automatically update redirect URLs and replace the previously assigned default IDP.
- [Re-assign WebKey application from IDP](#h_2279d8a876)

## Steps to Assign WebKey application to IDP

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Auth Policies** > **Identity Provider**. ![](/images/11401191/9a507702453d.png) The **Identity Provider Profiles** page is displayed.
3. Select an IDP Profile Name to edit. ![](/images/11401191/7dc99af1ed56.png) The details page is displayed.
4. Select the required WebKey application from the **Select WebKey Application**dropdown list.
5. Click **Save**.The IDP profile is assigned successfully to the Webkey application. ![](/images/11401191/c08955756828.png)

## Steps to make an IDP as default:

1. Follow this section to [Assign WebKey Application to IDP](#h_03e266120b).
2. Click **Make Default** to set this IDP as the default. (Optional)**Note:** If another IDP is currently set as default, it will be replaced upon confirmation. ![](/images/11401191/74c83ec299ff.png) The confirmation box is displayed.
3. Click **Set as Default**to designate the preferred IDP as default. ![](/images/11401191/a32b5f43122d.png)

## Steps to re-assign WebKey application from IDP:

1. Follow this section to [Assign WebKey Application to IDP](#h_03e266120b)
2. Select a different WebKey application to reassign.

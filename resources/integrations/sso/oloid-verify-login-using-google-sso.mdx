## Introduction

The Google SSO Login feature in the Oloid Verify App allows Tenant Admin and Supervisor to securely access Admin Mode using Google SSO credentials.

## Prerequisites

You must have a Tenant Admin account.

## Steps to login with Google SSO

1. Launch the **Oloid Verify**App.The Login screen is displayed.
2. On the login screen, tap **Login with SSO**. ![](/images/10247971/30bb9403dffc.png) The screen with **SSO options** are displayed.
3. Tap **Continue with Google**. ![](/images/10247971/8ef5047b76b0.png) The confirmation pop-up box is displayed.
4. Tap **Continue**. ![](/images/10247971/578636b14eaf.png) The **Sign in** page is displayed.
5. Enter **Email ID** > tap **Next**. ![](/images/10247971/e81db6048b47.png)
6. Enter**Password** > tap **Next**. ![](/images/10247971/f6673e3bef9b.png) You are logged in to Admin Mode in Oloid Verify using Google SSO successfully.

## Introduction

This document explains how to register and configure an application in **Microsoft Entra ID** and enable **FIDO2 (Passkey)** authentication for integration with the Tenant Admin Portal.

## Prerequisite

You must have Tenant Admin Access for Microsoft Entra ID.

## Steps to Configure Microsoft Entra ID for Advanced User Sync

1. [Register an Application](#h_b6f6d7e4d4)
2. [Configure the Application](#h_98bc76e322)
3. [Create Client Secret](#h_d15cf6534d)
4. [Enable FIDO2 Authentication](#h_7f409bd1e4)

Microsoft Entra ID is configured Successfully.

## Register an Application

1. Log in to Azure Portal and select **Microsoft Entra ID** on the home page. ![](/images/13607433/c59e9f199b4f.png) The Microsoft Entra ID page is displayed.
2. Go to **Overview >** **Manage** **> App registrations > New registration**. ![](/images/13607433/428b5534ff8f.png) The Register an application page is displayed.
3. Do the following. Enter **Name**.Select Supported account types.**Note:** Select Accounts in this organizational directory only.Click **Register**. ![](/images/13607433/5be4ea94bcc4.png) The application is registered successfully.

## Configure the Application

1. Navigate to the **newly registered app >** **API Permissions >** **Add a permission > Microsoft Graph.** ![](/images/13607433/df5fb3f03372.png) The **Request API Permissions** pop-up box is displayed.
2. Select **Application permissions**. ![](/images/13607433/1a32b679a439.png) The **List of API** permissions is displayed.
3. Do the following:On **User** drop-down, select the following:User.Read.AllUser.Read Basic.All (Optional). ![](/images/13607433/44a2c541c039.png) On **GroupMember** drop-down, select the **GroupMember.Read.All** ![](/images/13607433/5da5cd0b5d4d.png) On **UserAuthenticationMethod** drop-down, select the **UsersAuthenticationMethod.ReadWrite.All** ![](/images/13607433/87e90c2b8c0f.png) On **Policy** drop-down, select the following:Policy.Read.AuthenticationMethod.Policy.ReadWrite.AuthenticationFlows. ![](/images/13607433/855880da8c96.png) Click **Add Permissions.**The Permissions are listed on the API. Click **Grant admin consent for Oloid inc.** ![](/images/13607433/a41691914f4c.png) The **API Permissions** are successfully created. ![](/images/13607433/00252f582cf5.png)

## Create Client Secret

1. Go to **Certificates & secrets** > **Client Secrets > + New client secret**. ![](/images/13607433/8910233e19de.png) The **Add a client secret** screen is displayed.
2. Do the following:Enter **Description**.Select the **Expires** duration from the drop-down list.**Note:** Select 365 days (12 months).Click **Add**. ![](/images/13607433/c49632b43923.png) The **Client Secret** is added successfully and listed on **Client Secret** tab.**Note:** Click on the **Copy to Clipboard**icon next to the value field to copy the secret. This option is available only at the time of creation. ![](/images/13607433/35dc47baba60.png)
3. Go to **Overview**and copy the values of **Client ID** and **Directory** (**Tenant) ID**. ![](/images/13607433/b3ae151aac4a.png) The application is configured successfully.

## Enable FIDO2 Authentication in Azure Portal

1. Go to **Tenant** **Overview > Manage > Security**in the vertical navigation menu. ![](/images/13607433/34459d86d45c.png)
2. Go to **Security > Manage > Authentication Methods**. ![](/images/13607433/c892077c4fc1.png) The Authentication page is displayed.
3. Go to**Manage > Policies**, select **Passkey (FIDO2)** in **Authentication method policies** table. ![](/images/13607433/7727fe84af69.png) The Passkey (FIDO2) setting page is displayed.
4. Click **Enable and Target** tab and do the following:Enable the toggle.Select **All User** as Target.**Note**: If you want all users to use FIDO2 authentication.Click **Save**. ![](/images/13607433/30531fdb698a.png) The **Enable and Target** tab is configured successfully.
5. Click **Configure**tab and do the following:Select Allow Self-Service set up **Yes**.Select Enforce Attestation **No**.Select Enforce key restrictions **No**.Select Restrict specific key **Allow**.Click **Save**. ![](/images/13607433/feea6f9ec6ea.png) The Configure tab is configured successfully. FIDO2 is successfully configured.

## Introduction

The PingOne SSO Login feature in the Oloid Connect App allows Tenant Admin and Supervisor to securely access Admin Mode using PingOne SSO credentials.

## Prerequisite

You must download the Oloid Connect app from App Store. For more details, refer [How to download Oloid Connect app](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-in-ipad).

## Steps to log in with Ping One SSO

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.The **Welcome**screen is displayed.
2. Tap **Pair as Supervisor.** ![](/images/10293811/8a9b62c1a00e.png) The **Welcome** page is displayed.
3. Enter **Tenant Name.**
4. Tap **Next**. ![](/images/10345413/ad89cb4d5d7a.png) The**Login** page is displayed.
5. Tap **Login with SSO**. ![](/images/10345413/3ea7c41ad72d.png) The screen with **SSO options** is displayed.
6. Select **Continue with Ping**. ![](/images/13866936/70bbe2bcbfdd.png) The Sign on screen is displayed.
7. Do the following:Enter **Username.**Enter**Password.**
8. Tap **Sign On**. ![](/images/13866936/1e4dc9b1880e.png) You are logged in to Admin Mode successfully. ![](/images/13866936/9dd0d4269acd.png)

Follow these steps to add **Client Application** For **Oloid Applications:**

1. In the Admin Console, go to **Applications > Applications > Create App Integration.** ![](/images/8159402/a709c9a1c1bd.png)
2. Select**OIDC - OpenID** Connect as the **Sign-in method** and **Native Application** as **Application type.**![](/images/8159402/643baccce720.png)
3. Do the following the next screen( General Settings) to configure the application:Enter a name for the application in the **App integration name** field..Select **Authorzation Code** as **Grant type**.Add the following as **Sign-in redirect URIs:** com.oloid.oloidapp:/callback com.oloid.OloID:/callback Select Allow everyone in your organization to access under **Assignments.**![](/images/8159402/43704d566f6c.png)
4. Click **Save.**
5. Share the **ClientID** and **Okta root domain** of the new app with Oloid.![](/images/8159402/0c2fe329c41b.png)

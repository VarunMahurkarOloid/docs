## Introduction

The **Advanced User Sync** feature allows admin to create and manage user synchronization using supported agents such as **OKTA – Inbound**, ensuring accurate and consistent user data in the Tenant Admin Portal.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**. ![](/images/13559374/63ba2c7038a3.png) The Advanced User Sync page is displayed.
3. Click **Create User Sync**. ![](/images/13559374/07c6d6f4752d.png) The **Create User Sync** pop-up box is displayed.
4. Do the following:Enter **User Sync Name**.Select **Okta - Inbound**as Agent.Click **Create**. ![](/images/13700439/d8f2061fa5e2.png) The advanced user sync for Okta - Inbound is created successfully. ![](/images/13700439/1dda722da553.png)

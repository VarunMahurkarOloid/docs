## Introduction

Identity providers (IDP) help the system store and verify the user identity. Oloid acts as IDP for Passwordless SSO use cases.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create PingOne IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**. ![](/images/10822772/1dce6a6624c0.png) The **Identity Provider Profiles** page is displayed.
3. Select **Create IDP**in the top right corner. ![](/images/10822772/00fd9dc6db08.png) **Note**: You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](/resources/integrations/sso/webkey-how-to-link-webkey-with-an-identity-provider-idp-in-tenant-admin-portal). ![](/images/10822772/689d9d6dba89.png) The **Create New IDP**pop-up box is displayed.
4. Do the following:Enter **IDP Profile Name**.Select**OIDC**asAuth Protocol.Select**Next**.Select **PingOne**as IDP Provider for OIDC.Click **Create**. ![](/images/10822772/c90f1eb6a499.png) The IDP Profile for OIDC-PingOne is successfully created.

Steps to assign Shared Credential:

1. Log in to the **Supervisor Portal.**The Users page is displayed. ![](/images/9680203/6ffcf34ed62b.png)
2. Click **Shared Credentials**>**Windows Passwords**on the left menu panel. ![Image](/images/9680203/8b451d0b0d1d.png) The Windows Passwords page is displayed. ![](/images/9684906/b39329d58f67.png)
3. Select credential name to edit. ![Image](/images/9684906/d8acacd34e6b.png) The credential details page is displayed. ![Image](/images/9684906/96101d153f3c.png)
4. Select **User Assigned**tab **>** **+ Assign Shared Password to Users**. ![Image](/images/9684906/10eed3b00087.png) The **Assign Shared Password to Users**pop-up box is displayed. ![](/images/9684906/48adf8bed54a.png)
5. On the pop-up box, enter user name(s) in the **Users**dropdown list.
6. Select **Assign**. The shared password is successfully assigned and listed on the credential details page. ![](/images/9684906/d9ff6704ef0e.png) ![Image](/images/9684906/ee3ef79d0a36.png)

## Introduction

Identity Providers (IDPs) are used to manage and verify user identities for authentication. This document explains how to create an **Entra ID Identity Provider (IDP) profile** in the Tenant Admin Portal using **OIDC authentication**.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Entra ID IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**. ![](/images/13349621/1dce6a6624c0.png) The **Identity Provider Profiles** page is displayed.
3. Click **Create IDP**in the top right corner. ![](/images/13349621/00fd9dc6db08.png) **Note**: You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](/resources/integrations/sso/webkey-how-to-link-webkey-with-an-identity-provider-idp-in-tenant-admin-portal). ![](/images/10822772/689d9d6dba89.png) The **Create New IDP Profile** pop-up box is displayed.
4. Do the following:Enter **IDP Name**.Select**OIDC**asAuth Protocol.Click **Next**.Select **Entra ID**as IDP Provider for OIDC.Click **Create**. ![](/images/13349621/8b83ad84c37c.png) The IDP Profile for OIDC Entra ID is created successfully. ![](/images/13349621/36aff37a9a2d.png)

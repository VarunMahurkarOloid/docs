## Introduction

This document provides instructions on how to create an Advanced User Sync using the **Entra ID - Inbound** agent in the Tenant Admin Portal.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**. ![](/images/13559374/63ba2c7038a3.png) The **Advanced User Sync** page is displayed.
3. Click **Create User Sync**. ![](/images/13559374/07c6d6f4752d.png) The **Create User Sync** pop-up box is displayed.
4. Do the following:Enter **User Sync Name**.Select **Agent**.**Note:** Select **Entra ID - Inbound** as agent.Click **Create**. ![](/images/13598284/7f918ca100d4.png) The advanced user sync for Entra ID - Inbound is created successfully. ![](/images/13598284/f13909bc2c07.png)

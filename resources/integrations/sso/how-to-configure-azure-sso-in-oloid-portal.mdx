**To configure Azure SSO:**

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel.![](/images/11129577/22a7f38f999c.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/11129577/56502e051bdc.png)The **Tenant Settings** page is displayed.
4. Go to **Security**tab > click **Azure**. ![](/images/11129577/267ad1af0fae.png)
5. Turn on **Enable Azure SSO**toggle > click **Save**. ![](/images/11129577/217c9e79e5cb.png) The Azure SSO is successfully configured. ![](/images/11129577/efb20ef32ba7.png)

Steps to Delete Weigand Access:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, select **Weigand Access** on the left panel menu. ![](/images/8492278/422b02b87c1a.png) The **Weigand Access** page is displayed.
3. Select the Weigand Name to delete. ![](/images/8492278/799e238d6cbf.png) The **Weigand details**page is displayed.
4. Go to **Action** dropdown and select **Delete**. ![](/images/8492278/cfa07b7e5690.png) The confirmation pop-up box is displayed. ![](/images/8492278/5ad777060599.png)
5. Do the following:Enter Wiegand name in **Type the name of the Wiegand**.Enter the reason under **Please type the reason you are deleting the Wiegand**.Click **Delete**.The Weigand Access is permanently deleted. ![](/images/8492278/235a0755ec86.png)

Wiegand details are provided by customer for their access control system.

Steps to Create Weigand:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Weigand Access** on the left panel menu. ![](/images/8492248/422b02b87c1a.png) The **Weigand Access** page is displayed.
3. On the top right, select **Create Weigand**. ![](/images/8492248/7622f0c90a6b.png) The **Create Wiegand** pop-up box is displayed. ![](/images/8492248/68041f31c08a.png)
4. On the pop-up box, enter **Wiegand Name** and select **Format**from the dropdown list.
5. Click **Create**.

The Weigand Access is created and Wiegand details page is displayed.

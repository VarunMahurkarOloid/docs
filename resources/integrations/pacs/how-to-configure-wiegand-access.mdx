Steps to configure Weigand Access:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, select **Weigand Access** on the left menu panel. ![](/images/8492442/422b02b87c1a.png) The **Weigand Access** page is displayed.
3. Select the Weigand Name to edit. ![](/images/8492442/067bb412f4c5.png) The **Weigand details**page is displayed. ![](/images/8492442/861fb5067e3b.png)
4. Do the following:**Description**: Provide a description of the Wiegand Format(Optional).You can describe the specific arrangement of your binary card data.**Length**: Enter length of Wiegand Format.Length = number of bits in a badge binary.**Facility Code**: Enter the Facility Code of the card format.This is a number that represents the facility or building that the card will be used in.**Facility Code Start**: Enter the start number of the Facility Code. This is used to identify or represent each cardholder.**Facility Code Length**: Enter the facility code length.Facility Code Length is the length (number of bits) available for storing facility code.**Encoded # Start**: Enter encoding start position.Encoded Start represents the starting bit position from where card number will be stored.**Encoded # Length**: Enter encoded length.Encoded length represents number of bits available to store the card number. ​**Note**: These details are provided by customer for their access control system.Select **+ Add Parity Bit Definitions** to enter values.**Note**: A parity bit is used as a very simple quality check for the accuracy of the transmitted binary data.![](/images/8492442/0c669dd40982.png) Click **Save**.The Wiegand format is configured and listed on the **Wiegand Access** page. ![](/images/8492442/547b6d9c64b5.png)

**Introduction**

This document provides step-by-step instructions for configuring the Card Reader using the RF IDEAS Configuration Utility for Oloid Connect, WebKey, Chrome Vault, and DeviceLock applications.

**Pre-requisite:**

- You must configure the badge card. For further details, refer [How to configure rf IDEAS readers for badge card](/passwordless/windows/passwordless/windows-login-how-to-configure-rf-ideas-readers-for-badge-card)
- You must identify the card type and card format. For further details, refer [How to find the Card Type and Card Format using the RF IDeas Configurator Tool](/resources/guides/how-to-find-the-card-type-and-card-format-using-the-rf-ideas-configurator-tool)

To configure rfIDEAS for Keystroke Type Reader:

1. Launch the **rf IDEAS Configuration Utility** app. ![](/images/11079712/1d8374afcfa1.png) The app opens. ![](/images/11079712/60b92e57eb67.png)
2. Connect the card reader to the system.
3. Click**Connect**from the top left menu bar. ![](/images/11079712/a747658453e5.png)The DEVICE LIST is configured and displayed. ![](/images/11079712/b84c61236178.png)
4. In the left menu panel, select **SDK**. ![](/images/11079712/fdc2d8eca3c8.png)**Note:** It is not always necessary for the card reader to support both SDK and keyboard types. Some readers may support only one of the modes. Turn off the **Disable Keystrokes for SDK** toggle button to enable keystrokes for the Keystroke-type readers. ![](/images/11079712/6ab3e30a82bf.png)**Note**: If this option is turned on, keystrokes will be disabled. This option applies only to SDK-type readers. Click **Write**, and then click **Connect** to apply the configuration.**Note**: Make sure the **Disable Keystrokes for SDK** setting remains as configured (enabled or disabled) after applying the action. This ensures that the card reader works correctly based on your intended use case, whether supporting SDK, keystrokes, or both. ![](/images/11079712/314ba5c188ed.png) In the **Card ID** section, click **GetID** to retrieve the card ID.**Note:**You need toscan the badge card using the card reader for the card ID to get displayed. ![](/images/11079712/58263b59e08a.png)Select the **Test Area**to scan your badge card with the card reader.The badge number is displayed in the Test Area.**Note:**Make sure the badge number matches the card number. To calculate the card number, see [Facility Code Calculation](https://oloid.help/en/articles/10229274-how-to-use-data-from-configurator-tool-to-create-wiegand-format-definition-in-oloid).
5. In the left menu panel, select **Format**.
6. In the **Data Format** tab, do the following:Set **Strip leading bit count** and **Strip trailing bit count** to **0**.Disable both **Send FAC** and **Send ID** options. ![](/images/11079712/53b859e3a92a.png)
7. Go to **Delimiters**tab, and do the following:In the **Pre-data delimiters (ABC)** section, select **Insert Keystroke 1**. ![](/images/11079712/87725ef4d58c.png) The **Virtual keyboard - select keycode and modifier(s)**is displayed.Select **\<NONE>** and press **Enter**on your keyboard. ![](/images/11079712/6ab7d295798e.png)
8. Click **Write** to apply the changes. ​ ​

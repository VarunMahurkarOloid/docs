To update badge reader:

1. On the **Admin Home** screen, select **Settings**. ![](/images/9069684/3dd33c8ddf1a.png)
2. Select **rf IDEAS Reader Update**. ![](/images/9069684/ebd052637480.png)
3. Do one of the following:Upload ManuallySelect uploaded file The file is uploaded and the badge reader is updated.

## Upload Manually

1. Select **Upload Manually** on the screen.**Note:**The badge reader must be connected to the system. ![](/images/9069684/fa6cdfd0db69.png)
2. Click **Program Reader**.
3. Click or drag and drop to upload the .hwg file. ![](/images/9069684/f43262160b81.png)
4. Click **Upload File**.

**Note:**You can download the .hwg file from Oloid Portal. For more details, refer [How to download HWG file in Oloid Portal](/administration/admin-portal/windows-login-how-to-upload-download-hwg-file-in-tenant-admin-portal).

The badge reader is updated with the latest configuration.

<Frame>
  <img src="/images/9069684/3b4b565e30d6.png" alt="Screenshot" />
</Frame>

## Select uploaded file

1. Select the uploaded .hwg file.**Note:**The badge reader must be connected to the system. ![](/images/9069684/23b2f3408db0.png)
2. Click **Program Reader**.The badge reader is updated with the latest configuration. ![](/images/9069684/3b4b565e30d6.png)

User onboarding refers to adding users to the Oloid Portal and adding their credentials.

To add users to Oloid Portal refer to the following:

1. [How to add user](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal)
2. [How to import users from csv file](/administration/admin-portal/tenant-admin-portal-how-to-add-users-in-bulk)

To add credentials to users, refer to the following

1. [Face Onboarding](/administration/user-portal/face-onboarding)
2. [Badge Onboarding](/administration/user-portal/badge-onboarding)
3. [Pin Onboarding](/administration/user-portal/pin-onboarding)
4. [QR Onboarding](/administration/user-portal/qr-onboarding)
5. NFC[How to assign NFC/ID as a credential to the user](/administration/admin-portal/how-to-assign-nfc-id-as-a-credential-to-the-user)
6. Windows Password[How to create Password for Windows Login](/passwordless/windows/passwordless/how-to-create-password-for-windows-login)
7. Vault Password[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)
8. CloudKey[How to add CloudKey as credential to users](/administration/admin-portal/how-to-add-cloudkey-as-credential-to-users)

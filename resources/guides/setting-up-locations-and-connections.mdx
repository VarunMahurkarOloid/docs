## Setting up Location

In order to effectively manage your devices and users within the Oloid Platform, it's crucial to set up locations. Locations allow you to track your endpoints and the users associated with them. To do this, you need to map locations and connections, and it's important to pair endpoints with the application of the location.

Here's how to set up locations:

1. **Create Locations:** Start by creating locations within the Oloid Platform. Locations can represent physical places, departments, or any relevant organizational structure.
2. **Map Endpoints:** Pair each endpoint (device) with the respective location. This mapping associates each device with a specific physical or logical location.
3. **Location Permissions:** Ensure that you grant location permissions when your app prompts for it. This permission is essential for tracking endpoints and users accurately.

For step by step instructions on creating locations and adding location details in endpoints, see below documents.

- **[How to add location to the endpoint](/administration/admin-portal/how-to-add-location-to-the-endpoint)**
- **[How to create a new location and add location details](/administration/admin-portal/how-to-create-a-new-location-and-add-location-details)**
- **[How to add location to endpoints in bulk](/administration/admin-portal/how-to-add-location-to-endpoints-in-bulk)**

For step-by step instruction on pairing endpoint, see **[Pairing Supervisor tablets to Passwordless Application](/passwordless/ios/connect/oloid-connect-pairing-supervisor-ipad-to-passwordless-application)**

## Setting Up Connections

Setting up connections is essential to ensure that users within those connections can access the functionalities provided by the associated endpoints within the designated application. **It's recommended to create a unique connection for each endpoint location to maintain clarity and organization.**

Here's how to set up connections:

- **Create Connections:** Establish connections within the Oloid Platform. Each connection should represent a group of users who will be using the application within a specific location. For detailed instructions, see**[How to create Connections.](/administration/admin-portal/tenant-admin-portal-how-to-create-connection)**
- **Assign Users:** Assign users to the appropriate connections based on their roles and responsibilities. This ensures that users within each connection have access to the functionalities they need. For detailed instructions, see**[How to add users in bulk](/administration/admin-portal/tenant-admin-portal-how-to-add-users-in-bulk)****[How to add user](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal)****[How to add user from endpoint](/passwordless/ios/connect/oloid-connect-add-user)**
- **Connection and Endpoint Naming:** Maintain consistency by giving each location, connection, and endpoint the same name based on the application. This naming convention helps keep everything organized and easy to manage.

By following these steps to set up locations and connections for your Passwordless App within the Oloid Platform, you can effectively track your devices, manage user access, and maintain a structured and organized authentication and access management system. This approach ensures that users have the right level of access based on their location and role, enhancing both security and user experience.

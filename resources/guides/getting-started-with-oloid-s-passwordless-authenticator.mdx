## What is Oloid's Passwordless Authenticator?

Oloid Passwordless Authenticator is a simple, seamless, secure and scalable Authentication application that enables username(-less) and password-less authentication for devices ( Windows Desktop/ Laptop, Android Tablets and iPads) and Workforce/HRMS Platforms (OKTA, VMWare WorkspaceOne, Workday, Salesforce etc).

Oloid Passwordless does not require an Enterprise employee to use Username and Password to log into devices or Workforce/HRMS Platforms. With Oloid Passwordless employees can use physical identity factors (like Face, Badge , NFC tags and Pin) to log into devices and Workforce/HRMS Platforms using secure Multi-factor Authentication (MFA).

Oloid’s Passwordless Application combines virtual identity with physical identity of employees.

Oloid’s Passwordless application is especially suitable for deskless and frontline workers who have difficulty in remembering or using Username and Password to access devices or Workforce/HRMS Platforms.

Oloid's Passwordless Authenticator is available in four variants :

- [WebKey](#h_f117f6b7b5)
- [Oloid Connect App](#h_76ce22911a)
- [Windows Device Login](#h_9a112194a9)
- [Oloid DeviceLock](#h_a17b75a1a4)

## WebKey

This browser-based application enables Multi-factor authentication(MFA) of users using physical identity factors (like Face, Badge , NFC tags and Pin) .This application allows employees to seamlessly log into Workforce/ HRMS systems without entering Username and Password.

## Oloid Connect App

Oloid Connect is a contactless authentication application which can be installed on your iPad. You can log into Workforce Identity platforms through this application using Face, Badge or Pin depending on your device configuration.

To know more about **Oloid Connect app for Passwordless** feature , see **Oloid Guides** on **[Oloid Connect App for Passwordless](https://oloid.help/en/collections/7945968-oloid-connect-for-passwordless)**

## Windows Device Login

Oloid's Windows login is a secure and user-friendly authentication method that allows you to access your devices, apps, online services, and networks using various authentication options, including your face, badge, PIN, or MFA (Multi-Factor Authentication).

To know more about Oloid's **Windows Login, see Oloid Guides** on **[Windows Login](https://oloid.help/en/collections/7487490-windows-login) .**

## Oloid DeviceLock

It is an Android-based application to log into your Workforce Identity platforms using Multi-factor authentication. ( badge and pin).

To know more about **Oloid's Devicelock**, see **Oloid Guides** on **[Oloid DeviceLock](https://oloid.help/en/collections/7487488-oloid-devicelock).**

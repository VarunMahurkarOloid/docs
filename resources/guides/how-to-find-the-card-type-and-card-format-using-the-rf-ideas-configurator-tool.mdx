**Overview**

This article explains how to identify the card type and card format using the RF IDeas Configurator Tool, which is essential for accurate card configuration and integration.

**Introduction**

RF IDeas Configurator Tool allows access cards to be used as digital identifier throughout the workplace.

**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [RF IDEAS website](https://www.rfideas.com/support/tools/downloads).

To find the card type and card format:

1. Launch the rf IDEAS Configuration Utility app. ![](/images/9720607/1d8374afcfa1.png) The app opens. ![](/images/9720607/60b92e57eb67.png)
2. Make sure the card reader is connected to the system.
3. Select **Connect** from the left menu panel. ![](/images/9720607/92ff083f0124.png) The DEVICE LIST is configured and displayed. ![](/images/9398720/b84c61236178.png)
4. Select **Tools**from the left menu panel.![](/images/9720607/048f5dfc1f76.png)
5. Go to **Card Analyzer** tab, and click **Start**. ![](/images/9720607/d44c6285b25e.png) The Welcome screen is displayed.
6. Select **Learn Card**. ![](/images/9720607/ce0b528b2e2c.png)
7. Place the card on the reader and leave it there, then click **Start Scan**. ![](/images/9720607/e33ff35d398b.png) As the scan runs, the Card Type and Supporting Readers are displayed. If it identifies a card type, it will beep and display the Card Type in the top box. ![](/images/9720607/06e2d6512161.png)
8. Once the status scan is complete, if you want to configure the reader, then click **Auto Config**. ![](/images/9720607/6f34341b03c6.png) The Auto Config screen is displayed.
9. To identify the card, view the card type and the card format information. ![](/images/9720607/6a0923e7da94.png)
10. Click **Exit**. ![](/images/9720607/d71ca2882a86.png)

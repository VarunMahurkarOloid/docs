## Introduction

The **Current User Editable** reauthentication workflow allows the currently logged-in user to reauthenticate while also enabling a different authorized user to authenticate if required.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](/administration/admin-portal/how-to-create-and-configure-application-type-passwordless)

## Steps to Enable Current User Editable

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**. ![](/images/13713982/7dacbe1e90eb.png) The application details page is displayed. ![](/images/13713982/b89e4448e051.png)
3. Click **Configure**tab> **Epic EHR**. ![](/images/13713982/09fe4e8dbdcc.png) The Epic EHR page is displayed.
4. Do the following:Turn on **Enable Reauthentication Workflow**toggle button.Click **Save.** ![](/images/15099661/c91471db011e.png) Current User Editable; Reauthenticates the currently logged-in user but allows the authentication device to submit a different user if required.**Note:**The default factor for this authentication is set to application factor and cannot be changed. ![](/images/15102516/9667b9104fc4.png)

Current User editable is enabled for Epic EHR.

## Introduction

The **Reauthenticate Current User** workflow allows the logged-in user to verify their identity again during an active session in Epic workflows. Admins can configure this workflow in the Tenant Tenant Admin Portal.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](/administration/admin-portal/how-to-create-and-configure-application-type-passwordless)

## Steps to Configure Reauthenticate Current User

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**. ![](/images/13713982/7dacbe1e90eb.png) The application details page is displayed. ![](/images/13713982/b89e4448e051.png)
3. Click **Configure**tab> **Epic EHR**. ![](/images/13713982/09fe4e8dbdcc.png) The Epic EHR page is displayed.
4. Do the following:Turn on **Enable Reauthentication Workflow**toggle button. ![](/images/15100167/c91471db011e.png) Turn on **Enable Reauthentication Workflow**toggle button.Select **Reauthenticate Current User**. From the Application Factor dropdown, choose the authentication factor.Click **Save**. ![](/images/14650126/3819558bc32d.png) Reauthenticate current user is configured.

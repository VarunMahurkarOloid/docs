## Introduction

This method requires the logged-in user to verify their identity again using a factors selected under the reauthentication workflow configuration.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user. Refer: **[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin)**

## Steps to Reauthenticate current user in Epic Hyperspace

1. Log in to **Epic Hyperspace** application on your Windows Machine. refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](/passwordless/windows/passwordless/windows-login-healthcare-how-to-log-in-to-epic-hyperspace-using-badge-id-pin-when-epic-sso-is-not-enabled)**The **Epic Hyperspace** home page is displayed. ![](/images/13903549/e2f7272b7fa5.png)
2. On the top menu panel of the homepage, click **Reauthentication Test View**. ![](/images/13903549/b69ec7db1b2a.png) The Reauthentication Test view page is displayed.
3. Click **Reauthenticate Current User - Second Factor.** ![](/images/14753012/b2c806ce69da.png) The **Enter PIN**screen is displayed.**Note:**Authentication is based on the factor selected in Reauthenticate Current User (Second Factor) under the reauthentication workflow. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
4. The current user must enter the **PIN** > click **Submit.****Note**: The current user (the user already logged into Epic Hyperspace) must authenticate. ![](/images/14753012/584f93c1a150.png) The **Oloid Re-authentication** screen is displayed.
5. The current user must tap the **Badge** on the **Badge Reader** to scan it. ![](/images/14753012/8a6f5319ad35.png) The **Enter PIN**screen is displayed.
6. The current user must enter the **PIN** > click **Submit.****Note:**Authentication mode is based on Application factors configured for you. ![](/images/14753012/584f93c1a150.png)
7. Hyperspace pop-up box is displayed. Click **Ok**The current user is successfully reauthenticated.

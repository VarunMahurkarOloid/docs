## Introduction

Guided Access Mode keeps the iPad limited to one app or a few apps, so users are unable to access other features or apps. This setup is useful for check-ins, time tracking, or using the iPad as a display screen. For more, refer to [Use Guided Access with iPhone and iPad](https://support.apple.com/en-in/111795)

### The following topics are covered in this document.

- [How to set up Guided Access in iPad](#h_027b514d84)
- [How to enable Guided Access Mode in iPad](#h_238f11d43b)
- [How to disable Guided Access Mode in iPad](#h_40f2409831)

## Setting up Guided Access

1. Open your iPad.
2. Go to **Settings > General > Accessibility** ![](/images/8655926/42d650a17dec.png)
3. Scroll down the list to the bottom and tap **Guided Access.**
4. Tap the toggle to switch on Guided Access. ![](/images/8655926/f1e7fb1188b3.png)
5. Tap **Passcode Settings**. Tap **Set Guided Access Passcode.** ![](/images/8655926/e71969198d87.png)
6. Tap **Set Guided Access Passcode.** ![](/images/8655926/0de7cf06eb4d.png)
7. Enter a passcode, then re-enter it to confirm. ![](/images/8655926/5c0566b95929.png)

## Enable Guided Access Mode

1. Open the Oloid Connect application, then triple-press the **Home/Power**button.
2. Click **Start**.

<Frame>
  <img src="/images/8655926/6d66fe07ce18.png" alt="Screenshot" />
</Frame>

## Disable Guided Access Mode

1. To end a Guided Access session, triple-press the **Home/Power** button.
2. Enter your **passcode** when prompted.
3. Click **End**. ![](/images/8655926/8241aebce6f3.png)

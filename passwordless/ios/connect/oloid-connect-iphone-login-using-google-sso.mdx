## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **Google Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](/administration/admin-portal/how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-on-iphone)

## Steps to Log in with Google SSO

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app. ![](/images/13595968/59f3ef29d1af.png) The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.** ![](/images/13595968/798bdb49d5e0.png) The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**. ![](/images/13595983/e6455e2ee873.png) TheLogin page is displayed.
4. Tap **Login with SSO**. ![](/images/13595983/b05deb860548.png) The screen with **SSO options** is displayed.
5. Tap **Continue with Google**. ![](/images/13595983/2e166088f11f.png) The confirmation pop-up is displayed.
6. Tap **Continue**. ![](/images/13595983/4227f47116ac.png) The **Sign in** screen is displayed.
7. Do the following:Enter **Email ID**.Tap **Next**. ![](/images/13595983/4c4d3fb33dbb.png) The **Welcome** screen is displayed.
8. Do the following:Enter **Password**.Tap **Next**. ![](/images/13595983/cad314ac20f6.png) You are successfully logged in to Oloid Connect Admin Mode.

**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to assign a QR code to user.

### Steps to add QR Code:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) The **Settings** page is displayed. ![](/images/8601079/9dd0d4269acd.png)
2. Tap **Users**on the menu at the bottom of the screen. ![](/images/10307929/9901946f0d12.png) The **Users**page with list of users is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top. ![](/images/8764539/1b7260adf861.png) The user's**Details** screen is displayed.
4. Tap **QR Code**tab>Tap **Add**. ![](/images/8764539/ecf9ead00c4c.png) The **Create QR Code** pop-up box is displayed.
5. Do the following:Select **QR code Validity** from the calendar.Enter **Email ID(s)**to whom you want to S**hare QR Code With**. (Optional)Tap **Save**. ![](/images/8764539/2a96645195c7.png) The QR code is assigned to the user. ![](/images/8764539/4cb46b2834ae.png)

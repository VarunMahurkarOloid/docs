## Introduction

This feature of the **Oloid Connect app** allow Tenant Admin and Supervisor to set up  iPhone in Admin mode. Once set up, you can manage settings, pair endpoints, and use the app for authentication.

## Pre-requisite:

- You should be a Tenant Admin or Supervisor.
- Application, Connections, and template (optional) must be configured in Tenant Admin Portal.

## Device Compatibility

Ensure that your device is compatible with Oloid Connect App. See, [Hardware requirement for Oloid Connect installation](/passwordless/ios/connect/oloid-connect-hardware-and-software-requirements)

## Internet Connection

Make sure your device is connected to the internet for the setup.

## Steps to setup the Admin Mode:

1. Launch the **Oloid Connect** app.The **Welcome** screen is displayed. ![](/images/12554774/59f3ef29d1af.png)
2. Tap **Pair as Supervisor.** ![](/images/12554774/798bdb49d5e0.png) The Welcome screen is displayed. ![](/images/12554774/624394da4e94.png)
3. Enter **Tenant Name**, then tap **Next**.The**Login** page is displayed.
4. Do the following:Enter your email ID in the **Email** text field.Enter your password in the **Password** text field.Tap **LOGIN**.**Note:**You may also log in using SSO options. ![](/images/12554774/ea9184ff1810.png) The **Settings** page is displayed.
5. Pair the endpoint. For more, refer to[How to pair an Oloid Connect endpoint on iPhone](/passwordless/ios/connect/how-to-pair-oloid-connect-endpoint-on-iphone) ![](/images/12554774/762f5d018aef.png) The settings are saved and the Device Setup success message is displayed. ![](/images/12554774/9c3a448a57b6.png) **NOTE:** Once the iPhone is successfully paired, other settings can be configured in the Tenant Admin Portal.The application prompts you to log out of Admin mode.
6. Do one of the following:Tap **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to capture live Images for facial transactions.**Note:**To go back to admin mode, **double-click with two fingers**on preview mode and tap **Yes- To Continue**.Tap **No**to stay logged in to the admin mode.

## Introduction

This document explains how to pair an endpoint using the **Oloid Connect**application. Pairing connects the endpoint to the Oloid Connect application in the Tenant Admin Portal and prepares the endpoint for authentication and transaction activities.

## Prerequisite

- You must have Admin or Supervisor access.
- You must install Oloid Connect and complete the Admin setup before pairing an endpoint. For more, refer to [How to Download and Install the Oloid Connect App](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-in-ipad)

## Steps to Pair an Endpoint

1. Log in to**Oloid** **Connect**![](/images/10288412/f7c4703dd471.png) app.The **Welcome** screen is displayed. ![](/images/8616268/81ba504b16bd.png) **Note**: You must Complete the Admin setup**.**For more information, refer to[Oloid Connect - Admin Setup](/administration/admin-portal/oloid-connect-admin-setup)The Settings page is displayed on a successful login.
2. Do the following:Add **Template**(optional).**Note**: Templates allow Admins to configure Endpoints at scale. A template has to be created in Tenant Admin Portal. For more, refer to [How to create and configure Oloid Connect endpoint template](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-endpoint-template)Enter **Endpoint Name**.Select **Application Name**from **Application Name** dropdown list.Click **Pair**. ![](/images/8616268/3eda4ea5d46e.png) The settings are saved and endpoint is successfully paired. ![](/images/8616268/cb2f780dbb54.png) The application prompts you to log out of Admin mode.
3. Do one of the following:Click **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to do the transactions.Click **No**to stay logged in to the admin mode. ![](/images/8616268/f97b48ac5b11.png)

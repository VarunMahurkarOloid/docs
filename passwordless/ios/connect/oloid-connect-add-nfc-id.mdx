**Introduction:**

This feature of the Oloid Connect app allows Tenant Admins and Supervisors to assign NFC to users.

**Pre-requisite:**

User should be added to the connection paired with the application.

### Steps to add NFC/ID:

1. Launch the **Oloid Connect** app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) The **Settings** page is displayed. ![](/images/10304065/c9a70139d5cb.png)
2. Tap **Users**on the menu at the bottom of the screen. ![](/images/10304065/9901946f0d12.png) The **Users**page with list of users is displayed.
3. Tap on the selected user to view details. ![](/images/10304065/1b7260adf861.png) The details screen is displayed.
4. Go to**NFC/ID**tab. The **Add NFC/ID** screen is displayed. ![](/images/10304065/2b4e4c5ce467.png) **Note:**The card reader must be connected to the iPad.
5. Scan the **NFC token** on the **NFC** **reader**.The**NFC/ID** is successfully assigned to the user.

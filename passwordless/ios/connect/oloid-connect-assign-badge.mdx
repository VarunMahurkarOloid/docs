## Introduction

This document explains how to assign a badge to a user using the Oloid Connect iPad app. Admin can scan a physical badge using a connected badge reader to enroll it for a user.

## Prerequisites

- User should be added to the connection paired with the application.
- The badge reader must be connected to the iPad.

## Steps to assign Badge

1. Launch the **Oloid Connect**app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)The **Settings** page is displayed. ![](/images/10304065/c9a70139d5cb.png)
2. Tap **Users**on the menu at the bottom of the screen. ![](/images/10304065/9901946f0d12.png) The **Users**page is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top to assign the badge. ![](/images/10304065/1b7260adf861.png) The user **details** screen is displayed.
4. Go to **BadgeID**. ![](/images/13395774/c7c037be066c.png) The **BadgeID**screen is displayed.
5. Tap **Scan Badge.** ![](/images/13395774/182fbde759ce.png) The **Scan Badge**pop up is displayed.
6. Scan the **Badge**on the **Badge** **reader**.**Note:**The badge reader must be connected to the iPad. ![](/images/13395774/0dd4bc848996.png) The Badge is scanned Successfully.
7. Tap **Create.** ![](/images/13395774/a2b676e06b0b.png) The **Badge** is assigned successfully to the user. ![](/images/13395774/e481d75c129f.png) The assigned badge ID details are displayed on the **BadgeID** screen. ![](/images/13395774/d6f2215a5adf.png) Keywords|Assign badge in Oloid Connect |Badge enrollment using iPad |Oloid Connect badge assignment|

## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Oloid Connect |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **UAT** | **Description** |
|---|---|---|
| Admin API | api.oloidpreview.com | The Admin API is used for Authentication. |
| Tenant User API | api.previewoloid.net | The Tenant User API is used for user authentication credential. |
| Face Authentication | fr.oloidpreview.com | The Face Authentication API is used to authenticate users through facial recognition. |

---

## Google and Amazon Services

| **Service** | **UAT** |
|---|---|
| Firebase Authentication | firebase.google.com |
| Google APIs | googleapis.com |
| Cloud Firestore | firestore.googleapis.com |
| Firebase Storage | firebasestorage.googleapis.com |
| Google Cloud Storage | storage.googleapis.com |
| Amazon Web Services (AWS) | *.amazonaws.com |

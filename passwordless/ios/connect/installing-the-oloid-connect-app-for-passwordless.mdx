## Introduction

This document explains how to install the **Oloid Connect app** for passwordless authentication.

## Prerequisites

- You should be a Tenant Admin and Supervisor.
- Application, Connections, and template (optional) must be configured in Tenant Admin Portal.

## Device Compatibility

Ensure that your device is compatible with the Oloid Connect App. See, [Oloid Connect Passwordless - Hardware and Software Requirements](/passwordless/ios/connect/oloid-connect-passwordless-hardware-and-software-requirements)

## Internet Connection

Ensure that the device is connected to the internet using Wi-Fi or mobile data, for the app installation and setup.

## Steps to install and setup the Admin Mode

1. Go to **App Store** and download **Oloid Connect App**.For detailed information see, **[How to download Oloid Connect application](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-in-ipad).**
2. Install the application and launch it after the installation is complete.The **Welcome** screen is displayed. ![](/images/8400084/81ba504b16bd.png)
3. Tap **Pair as Supervisor.** ![](/images/10293811/8a9b62c1a00e.png) The Welcome screen is displayed.
4. Enter **Tenant Name** > tap **Next**. ![](/images/10293811/5221e300bb3a.png) The**Login** page is displayed.
5. Do the following:Enter your email ID in the **Email** text field.Enter your password in the **Password** text field.Tap **LOGIN**.**Note:**You may also log in using SSO options. For more, refer to[Log in Using SSO](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) ![](/images/8400084/d162bd71017a.png) The **Settings** page is displayed.
6. Pair the endpoint. For more information, refer to [How to pair the endpoint in Oloid Connect app](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint) ![](/images/8400084/22efa90f57d5.png) The settings are saved and the Device Setup success message is displayed. ![](/images/8400084/8a8d71911c6b.png) **NOTE:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.The application prompts you to log out of Admin mode.
7. Do one of the following:Tap **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to capture live Images for facial transactions.**Note:**To go back to admin mode, **double-click with two fingers**on preview mode and tap **Yes- To Continue**.Tap **No**to stay logged in to the admin mode.

### Admin Mode Actions Without Endpoint Pairing

You can perform the following actions without pairing the endpoint:

- [View user details](/passwordless/ios/connect/oloid-connect-view-user-details)
- [Add User](/passwordless/ios/connect/oloid-connect-add-user)
- [Add Face](/passwordless/ios/connect/oloid-connect-add-face)
- [Add QR Code](/passwordless/ios/connect/oloid-connect-add-qr-code)
- [Set PIN](/passwordless/ios/connect/oloid-connect-set-pin)
- [Add NFC/ID](/passwordless/ios/connect/oloid-connect-add-nfc-id)

### Common Installation Issues

Ensure your device meets the app's requirements.

- Check your internet connection during installation.
- Verify that you've granted the necessary permissions to the app.

### Support Contact

If you encounter any specific issues or have questions, reach out to **[Oloid support](mailto:support@oloid.ai)** for personalized assistance.

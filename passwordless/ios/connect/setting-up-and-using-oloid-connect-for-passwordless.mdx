**Oloid Connect for Passwordless** enables secure login to Workforce or HRMS platforms without using passwords. It allows users to authenticate using **Face, Badge, PIN, QR Code, or NFC**, providing a simple and secure login experience.

## Prerequisites

1. iPad for installing the Oloid Connect app.
2. You must have admin access to Tenant Admin Portal.
3. Supervisor privileges must be configured within the Oloid Platform to manage users and endpoints.

## **Installation and Config**uration

- Download and Install the Oloid Connect App
- Configure the Oloid Connect App

The Oloid Connect app is installed and configured on the iPad.

For more details, see [How to download Oloid Connect app](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-in-ipad)

For more details, see [Installing the Oloid Connect App](/passwordless/ios/connect/installing-the-oloid-connect-app-for-passwordless)

## Configuration

## Platform

For an end-user to use the Oloid Connect for Passwordless app, the Tenant admin must perform the following configuration in the Oloid Platform.

- Set up Application and Connection**Note:**Configure Passwordless tab under application must be configured for the Passwordless feature to work in Oloid ConnectFor more details, see [How to create and configure Oloid Connect for Passwordless application](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-passwordless-application-in-tenant-admin-portal)
- Create User and assign to Connection For creating user assigning them to Connection, see [How to add user](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal) guide
- Assign Credentials to usersFor assigning credential to users, see [User Onboarding](/resources/guides/user-onboarding-for-oloid-portal) guide
- Create and Configure Endpoint Template For more details, see [How to create and configure Oloid Connect endpoint template](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-endpoint-template)
- Configure Oloid Connect Endpoint **Note:** Oloid Connect Endpoint is created in the Oloid Connect app.For more details, see [How to configure Oloid Connect Endpoint](/administration/admin-portal/oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal)
- Grant Supervisor privileges to perform the assigned activitiesGrant Supervisor permission to add or delete users in the Oloid Connect app For more details, [How to Activate Add User Action on the App for Supervisor](/administration/admin-portal/windows-login-how-to-enable-add-delete-users-in-tenant-admin-portal-for-supervisors)Grant Supervisor permission to pair the endpoint in Oloid Connect appFor more details, [How to activate Endpoint Pairing action in Oloid Portal](/administration/admin-portal/how-to-activate-endpoint-pairing-action-for-supervisor-in-tenant-admin-portal) ​

## Oloid Connect App

## Admin Home

After installing the Oloid Connect app, the Tenant Admin and Supervisor can log in to admin mode to manage users and credentials. (before pairing the endpoint if desired)

## Settings Screen

On the Settings screen, the tenant admin/supervisor can pair the Endpoint in Oloid Connect, which generates an endpoint ID with endpoint details in the Tenant Admin Portal.

1. Once the endpoint is paired successfully, you can log in using Face RecognitionFor details, see [How to log into the admin mode of Oloid Connect App as a Supervisor/Admin](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)
2. The Tenant Admin or Supervisor can access the settings section of the Oloid Connect app to pair, repair, and unpair endpoints.

For details, refer to the following guides:

[How to pair an Oloid Connect endpoint](/passwordless/ios/connect/oloid-connect-how-to-pair-an-endpoint)

[How to repair an endpoint in Oloid Connect App](/administration/admin-portal/how-to-re-pair-an-endpoint-in-oloid-connect-app)

[How to add location to an endpoint using the Oloid Connect App](/administration/admin-portal/how-to-add-location-to-an-endpoint-using-oloid-connect-app)

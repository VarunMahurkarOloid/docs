## Introduction

The Users screen in the Oloid Connect app provides access to a list of all registered users. From this screen, you can view detailed information about any individual user.

## Steps to view User details:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app and login with the provided options.**Note:** For more information about how to log in to the Oloid Connect, refer to[How to log in to the Admin mode in Oloid Connect App](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)**.** ![](/images/10293811/81ba504b16bd.png) The **Settings** page is displayed. ![](/images/10307929/c9a70139d5cb.png)
2. Tap **Users**on the menu at the bottom of the screen. ![](/images/10307929/9901946f0d12.png) The **Users**page with list of users is displayed.
3. Tap on the selected user to view details, or search for a user using the search bar at the top.

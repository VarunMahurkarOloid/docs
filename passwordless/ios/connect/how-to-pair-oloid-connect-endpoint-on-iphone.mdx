## Introduction

This feature of the **Oloid Connect app** allows Tenant Admins and Supervisors to pair an endpoint on iPhone. Pairing an endpoint enables the app to connect with the configured application and perform transactions.

## Prerequisite

- You must download and the install the Oloid Connect app. To download and install refer to [How to Download and Install the Oloid Connect App on iPhone](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-on-iphone).
- You must complete the Admin setup before pairing an endpoint. To complete the Admin setup refer to [Oloid Connect - Admin Setup on iPhone](/passwordless/ios/connect/oloid-connect-admin-setup-on-iphone).

## Steps to pair an endpoint

1. Launch the Oloid Connect app. ![](/images/12577230/d82e31ed444c.png)
2. Log in to**Oloid** **Connect** app.The Settings page is displayed on a successful login.
3. Do the following:Add **Template**(optional).**Note**: Templates allow Admins to configure Endpoints at scale. A template has to be created in Oloid Portal. See [How to create and configure Oloid Connect endpoint template](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-endpoint-template)Enter **Endpoint Name**.Select **Application Name**from **Application Name** dropdown list.Click **Pair**. ![](/images/12577230/762f5d018aef.png) The settings are saved and endpoint is successfully paired. ![](/images/12577230/9c3a448a57b6.png) The application prompts you to log out of Admin mode.
4. Do one of the following:Click **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to do the transactions.Click **No**to stay logged in to the admin mode. ![](/images/12577230/86c9ce040830.png) The app remains in Admin mode. ![](/images/12577230/63fd842234af.png) The endpoint is successfully paired with your iPhone.

**Introduction**

This feature of Oloid Connect app allows Tenant Admin and Supervisors to set the PIN for a user.

### Steps to Set PIN:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)The **Settings** page is displayed. ![](/images/10288447/c9a70139d5cb.png)
2. Tap **Users**on the menu at the bottom of the screen. ![](/images/11735953/9901946f0d12.png) The **Users**page with list of users is displayed.
3. Tap on the selected user to view details, or search for a user using the search bar at the top. ![](/images/8536726/1b7260adf861.png) The Details screen is displayed.
4. Select a user from the list. ![](/images/8768778/1b7260adf861.png) The user's details screen is displayed.
5. Go to the **PIN** tab >Tap **Add** to set PIN. ![](/images/8768778/e4bdc71da7fc.png) The **Create PIN** pop-up box is displayed.
6. Do the following:**Enter your new PIN**.**Re-enter new PIN**.Enter **Email ID(s)** you want to **Share PIN With**. (Optional)Tap **Save**. ![](/images/8768778/175b36275bdf.png) The PIN credential is successfully created for the user. ![](/images/8768778/a35e74bc7ccd.png)

## Introduction

This document provides step-by-step instructions for logging in with QR Code and PIN to Workforce / HRMS platform.

## Pre-requisite

- User must have an Okta account.
- In the Oloid Portal, admin must do the following:Okta credential (user email ID) must be added to the user details page in Oloid Portal.Assign QR Code to the user. For more details, refer [How to create QR code as credential for User.](/administration/admin-portal/tenant-admin-portal-how-to-create-and-assign-qr-code-credential-for-a-user)Add PIN for the user. For more details, refer [How to add PIN as credential to users.](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users)Enable QR Code and PIN options under the Oloid Verify Application. For more details, refer [How to create and configure Connect for Passwordless application.](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-passwordless-application-in-tenant-admin-portal)

## Using the QR Code

1. Launch the Oloid Connect app in your iPad.
2. On the home page of the app, select **QR Auth**. ![](/images/9842058/14b2c891f622.png) This opens the camera on your iPad.
3. Show your QR Code for automatic capture. ![](/images/9842058/e6af2dfc8fdb.png)
4. On QR code authentication, the **Enter PIN to Login**screen is displayed. ![](/images/9790290/033a0541686a.png)
5. Enter the **PIN**.On PIN authentication, you are signed in to the **Workforce /HRMS** platform. ![](/images/9790290/e1d30618319e.png)

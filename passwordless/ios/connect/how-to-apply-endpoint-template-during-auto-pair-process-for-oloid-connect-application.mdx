## Introduction

This document explains how to apply an Endpoint Template during the auto-pair configuration process for the Oloid Connect application. Applying the Endpoint Template ensures that predefined settings are automatically assigned to endpoint as part of the pairing process.

## Prerequisites

1. You have **Tenant Admin** access to the **Tenant Admin Portal**.
2. An **Endpoint Template** has been created. To create refer[How to create and configure Oloid Connect endpoint template](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-endpoint-template)

## Steps at a Glance

1. Create the Oloid Connect application in the Tenant Admin Portal and select the desired endpoint template in the**“Apply Endpoint Template”**field.
2. Generate and download the auto-pair config file; ensure it is mapped to the application with the predefined template.
3. Pair the Oloid Connect endpoint using the auto-pair option. The endpoint template is applied automatically.

## Steps to Apply Endpoint Template During Auto-Pair Process

## Step 1: Create and Configure the Oloid Connect Application

1. Log in to the **Tenant Admin Portal**.
2. Create the **Oloid Connect** application. Refer[How to create and configure Oloid Connect Application in Tenant Admin Portal](/administration/admin-portal/how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)**Note:** If Oloid Connect application is already created then select the desired application from the application list.
3. In the **Settings section**, select the applicable template from [Apply Endpoint Template](/administration/admin-portal/how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal) dropdown.**Note:** Endpoint template must be added to apply template when using auto-pair option to pair the endpoint. ![](/images/12750269/902ac3050434.png) The endpoint template is selected.
4. Select **Save**. ![](/images/12750269/11a341753832.png)

The Endpoint Template is successfully applied to the selected Oloid Connect Application.

## Step 2: Generate and Download the Auto-config File

1. Generate and download the auto-pair config file. Refer [How to generate Auto-Pair config file for Oloid Connect in Tenant Admin Portal](/administration/admin-portal/how-to-generate-auto-pair-config-file-for-oloid-connect-in-tenant-admin-portal)**Note:** Ensure that the **Application Mapping** includes the application where the **Endpoint Template** is specified. This mapping ensures that auto-pair applies the correct endpoint configuration. ![](/images/12586251/97a72e3e3bbe.png)

## Step 3: Pair Oloid Connect endpoint with Auto-config File

1. On the target iPad, launch the **Oloid Connect App.**
2. Pair the endpoint using auto-pair option. To auto-pair refer [How to pair Oloid Connect App using Auto config file](/administration/admin-portal/how-to-pair-oloid-connect-app-using-auto-config-file)**Note:** Once the auto-pair process completes, the **Endpoint Template** settings is automatically applied to the paired endpoint.

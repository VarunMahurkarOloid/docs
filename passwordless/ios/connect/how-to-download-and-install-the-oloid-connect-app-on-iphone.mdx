The **Oloid Connect app** allows users to authenticate securely using their iPhone for Oloid’s passwordless access solutions. This guide provides step-by-step instructions to download and install the app on an iPhone.

### Prerequisite:

- Make sure you have a stable internet connection and an Apple ID.
- Your iPhone runs on **iOS 15 or later**.
- You have access to the **Apple App Store**.

### Steps to download and install Oloid Connect App on iPhone:

1. Locate the **App Store** on your home screen and tap on it to launch the application. ![](/images/12554658/44a45b60ab4b.png)
2. In the search bar, type **“Oloid Connect.”**. ![](/images/12554658/9ec238a99946.png)
3. Select **Oloid Connect** app. ![](/images/12554658/8c38226dba8d.png)
4. Review the app's details, ratings, and user reviews to make sure it's the correct app you want to download. ![](/images/12554658/18e122ca27dc.png)
5. Tap the **Get**button located next to the **Oloid Connect** app icon. ![](/images/12554658/cf13ac238e7c.png) **Note**: If prompted, enter your Apple ID password or use Touch ID/Face ID to confirm the download.Wait for the app to finish downloading. ![](/images/12554658/55936bad718c.png)
6. Once installation is complete, tap **Open** to launch the **Oloid Connect** app.The welcome screen is displayed. ![](/images/12554658/59f3ef29d1af.png) The Oloid Connect app is successfully installed.

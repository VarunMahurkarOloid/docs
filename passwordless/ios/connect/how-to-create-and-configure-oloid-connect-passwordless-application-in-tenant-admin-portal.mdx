## Introduction

This document explains how to **create and configure an Oloid Connect application for passwordless login** in the Tenant Admin Portal.

## Prerequisite

You must have admin access to **Tenant Admin Portal.**

## Steps to create and configure Connect for Passwordless application

1. Log in to the**Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right. ![](/images/8655943/b7f0276ba29f.png) The **Create New Application** pop-up box is displayed.
3. On the pop-up box, do the following: Enter **Application Name**and select **Application Type**as Oloid Verify.Click **Create**. ![](/images/8655943/76250926197d.png) The **Oloid Connect for passwordless**application is created and the configuration page is displayed. ![](/images/8655943/e013c34adb99.png)
4. Configure the following:[Configure Details tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Authenticator tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Configure tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Design Theme tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Configure Health Setup tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Configure Connections tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Configure Integrations tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)[Configure Exception tab](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal)
5. Click **Save**after each action to save your configuration.The application is created and configured.**Note**: These are one-time settings and all the default settings are recommended.

## Configure Details tab

1. Modify **Application name**(if required).
2. Add **Description** (Optional).
3. Set **Time-zone** (Optional).
4. Select **Factor Sequence**from dropdown list to activate Multi-Factor Authentication (Optional). For more details, refer [How to create and configure Factor Sequence](/administration/admin-portal/how-to-create-and-configure-factor-sequence).
5. Set **Idle Screen Soft Time Limit** (Optional).
6. Set **Idle Screen Hard Time Limit**(Optional). ![](/images/8655943/53da73683e28.png)

## Configure Authenticator tab

You may enable one or more credential options based on your requirements. **Face** is enabled by default.

### Face

To use face as a credential, enable Face toggle.

<Frame>
  <img src="/images/9896977/bac1d9f04230.png" alt="Screenshot" />
</Frame>

Do the following:

1. Select**FR Mode** from the FR Mode dropdown. select the preferred face recognition mode:(if required)**Hybrid**: Combines cloud and on-device facial recognition.**Cloud**: Uses cloud-based facial recognition.**On Device**: Uses on-device facial recognition.(if required)
2. **On-Device Model**: Edit this field if required. (Optional)
3. Choose a liveness mode:Enable **Hardware Liveness** in devices with dedicated hardware sensors for higher accuracy.Enable **Software Liveness** to use software-based analysis to verify the captured face image authenticity.**Note:** Software Liveness verification may take longer to complete compared to Hardware Liveness verification. By default Hardware Liveness is enabled.
4. Adjust the following settings for Software Liveness:**Min Liveness Probability**:Determines the probability threshold to classify an image as live.Default: 0.5**Min Liveness Quality**:Defines the minimum acceptable quality for images used in liveness checks.Default: 0.1
5. Click **Save**.

<Note>
  The parameters are pre-configured. This is done by Oloid admin.
</Note>

### Badge ID

To use Badge ID as credential, enable **Badge ID**. Select **Badge Type(s)** from the dropdown and click **Save**.

### QR Code

To use QR Code credential, enable **QR Code**.

1. Enable **QR Code** option.
2. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.This option displays a camera flip button on the preview screen during QR code scanning.

- Under **Default camera selection**, select a camera option:**Front Camera** (default)**Rear Camera**

</Frame>

### PIN

**Enable PIN Selfie** to capture and save a selfie every time a user enters their PIN.

**Note:** The system will automatically take a photo (selfie) during each PIN transaction.

To create and configure Factor Sequence refer to [How to create and configure Factor Sequence](/administration/admin-portal/how-to-create-and-configure-factor-sequence).**Note:** The Factor Sequence feature is applicable only when using multi-factor authentication (MFA).
- Click **Save**.

## Configure Settings tab

1. **Enable Offline Mode**: Enable this option to allow users to perform authentication even without network connectivity.
2. **Use Group Authorization**: Enable this option to download groups so that users and endpoints of the same group are downloaded for authorization in offline mode.
3. **Authentication Timeout**: Set an appropriate timeout value to determine the duration the auth screen waits for the user to begin the authentication process before being redirected to the initial screen.
4. **Apply Endpoint Template**: Use this option to choose a template that will be applied automatically when pairing an endpoint.
5. **Show Clock on Intent/Auth Screens**: Turn on this toggle to show the clock on all screens Intent, Authentication selection, and Identity verification.
6. **Enable Landscape Mode for Preview Screen:**Turn on this toggle to change the user preview screen from portrait to landscape mode. ![](/images/9896977/ac6d29dc70bb.png)

## Customize Buttons tab

1. **Customize Authentication Button Labels**: You can customize the button label on the Connect application authentication page. ![](/images/9896977/f7a4bba37ebf.png)
2. **Configure Login Page Options:**

- **Enable Enrollment**: Select this option to customize the**Button Label** text and enter a custom URL in the **Enroll URL**field to redirect to the specified URL.**Note**: The default label is **Enroll Credential**.
- **Enable Custom Button**: Select this option to customize the**Button Label** text and enter a custom URL in the **Redirect URL**field to redirect to the specified URL.**Note**: The default label is **Login with Password**. ![](/images/8655943/3f47eeb10aae.png)

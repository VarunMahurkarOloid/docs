**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to

extend QR code expiry date and time.

### Steps to extend QR Code expiry date and time:

1. Launch the **Oloid Connect** app and login with the provided options.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) ![](/images/11735953/81ba504b16bd.png)
2. The **Settings** page is displayed. ![](/images/10288447/c9a70139d5cb.png)
3. Tap **Users**on the menu at the bottom of the screen. ![](/images/11735953/9901946f0d12.png) The **Users**page with list of users is displayed.
4. Select the user from **Users** list to extend the QR code. ![](/images/11735953/b1e0da2f3b83.png) The User details screen opens. ![](/images/11735953/ad4f0588fae6.png)
5. Tap **QR Code** tab. ![](/images/11735953/7e912ce636e3.png) The QR Code is displayed under the **QR Code** tab.
6. Tap **Edit** icon. ![](/images/11735953/d8f50134daef.png) The **Extend expiry time**pop-up box is displayed. ![](/images/11735953/70be699a3b67.png)
7. Select the QR code validity date and time from the calendar.
8. Tap**Done**.

<Frame>
  <img src="/images/11735953/ad33f25ba798.png" alt="Screenshot" />
</Frame>

The QR Code expiry time is extended.

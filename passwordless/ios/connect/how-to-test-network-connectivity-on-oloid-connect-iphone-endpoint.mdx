## Introduction

This document provides step-by-step instructions to test network connectivity on the Oloid Connect iPhone app.

## Prerequisite

The endpoint must be paired.

For more, refer to [How to pair an Oloid Connect endpoint on iPhone](/passwordless/ios/connect/how-to-pair-oloid-connect-endpoint-on-iphone)

## Steps to test Network Connectivity

1. Launch the **Oloid Connect App**.**Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App. For more, refer to [How to pair an Oloid Connect endpoint on iPhone](/passwordless/ios/connect/how-to-pair-oloid-connect-endpoint-on-iphone) ![](/images/12585316/3ea708c3c442.png)
2. Double tap with two fingers on the initial screen to launch the Admin Mode.
3. Tap **Yes- Continue.** ![](/images/12585316/9f44633e43f7.png) The **Settings**screen is displayed.
4. Tap **Start** in the **Health Check** section. ![](/images/12644692/617a53d3273a.png) The **Please Select Health Type** pop-up box is displayed.
5. On the pop-up box, tap **Network Route Status**. ![](/images/12644692/2cc5ef8741a8.png) The **Network Status** page is displayed. ![](/images/12644692/c712fcbd6711.png) Keywords|Test Network Connectivity Oloid |Oloid Connect Network Status |Network Health Check Oloid Connect|

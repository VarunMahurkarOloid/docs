**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to email QR code to users.

### Steps to send QR Code via email:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app and login with the provided options. **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app)**.** ![](/images/11735953/81ba504b16bd.png)
2. The **Settings** page is displayed. ![](/images/10288447/c9a70139d5cb.png)
3. Tap **Users**on the menu at the bottom of the screen. ![](/images/11735953/9901946f0d12.png) The **Users**page is displayed. ![](/images/8789251/0c9345bfcb3c.png)
4. Select a user from **Users** list, or search for a user using the search bar at the top to send QR code via email. ![](/images/8789251/b1e0da2f3b83.png) The User details screen opens. ![](/images/8789251/ad4f0588fae6.png)
5. Tap **QR Code** tab. ![](/images/8789251/7e912ce636e3.png) The QR Code is displayed.
6. Tap **Email** icon. ![](/images/8789251/721d260e6b21.png) The **Send QR Code on Email** pop-up box is displayed.
7. Enter the email addresses to share the QR code.
8. Tap **Save**. ![](/images/8789251/bfc6bcfe5d11.png) The QR code is sent to the user's email id.

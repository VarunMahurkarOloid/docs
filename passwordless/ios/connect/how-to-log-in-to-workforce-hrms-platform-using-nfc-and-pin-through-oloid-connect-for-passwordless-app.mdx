## Introduction

This document provides step-by-step instructions for logging in with NFC and PIN to Workforce / HRMS platform.

## Pre-requisite

- User must have an Okta account.
- In the Oloid Portal, admin must do the following:Okta credential (user email ID) must be added to the user details page in Oloid Portal.Assign NFC for the user. For more details, refer [How to assign NFC/ID as a credential to the user](/administration/admin-portal/how-to-assign-nfc-id-as-a-credential-to-the-user)Add PIN for the user. For more details, refer [How to add PIN as credential to users.](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users)Enable NFC and PIN options under the Oloid Verify Application. For more details, refer [How to create and configure Connect for Passwordless.](/passwordless/ios/connect/how-to-create-and-configure-oloid-connect-passwordless-application-in-tenant-admin-portal)

## Using the NFC

1. Launch the Oloid Connect app in your iPad.
2. On the home page of the app, select **Login with NFC/ID**. ![](/images/9790290/c8c7da56cbc3.png) The **Tap NFC Tag at the Device**screen is displayed. ![](/images/9790290/37567bf50218.png)
3. Tap the **NFC tag** on the **Reader** to scan it.**Note:**The Reader should be connected to your iPad.
4. On NFC authentication, the **Enter PIN to Login**screen is displayed. ![](/images/9790290/033a0541686a.png)
5. Enter the **PIN**.On PIN authentication, you are signed in to the **Workforce /HRMS** platform. ![](/images/9790290/e1d30618319e.png)

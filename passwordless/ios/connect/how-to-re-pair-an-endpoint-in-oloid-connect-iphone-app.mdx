## Introduction

This document provides step-by-step instructions to re-pair an endpoint using the Oloid Connect iPhone app.

## Steps to re-pair an endpoint

1. Launch the **Oloid Connect** app.**Note:** For more information about how to log in to the Oloid Connect, refer to [Oloid Connect - Admin Setup on iPhone](/passwordless/ios/connect/oloid-connect-admin-setup-on-iphone)The **Settings** page is displayed. ![](/images/12595558/10c043a40b79.png)
2. Tap **Re-pair.** ![](/images/12595558/2de66761b73d.png) **Re-pair Endpoint** pop-up is displayed.**Note:** You can only re-pair an endpoint if it is not paired. ![](/images/12595558/e4d43d07c7bc.png)
3. On the pop-up box, do the following:Enter**Endpoint ID**.Tap **Re-pair**.The Endpoint is re-paired successfully. ![](/images/12595558/a7f58c7b148f.png) **Note:** Kill and relaunch the app to make the new updates function properly.

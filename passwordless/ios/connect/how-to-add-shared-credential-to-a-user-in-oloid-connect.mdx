**Introduction**

The Shared Credential feature in the Oloid Connect app allows Tenant Admins and Supervisors to assign shared credentials to users.

### Steps to add Shared Credential:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app and login with the provided options.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log into the admin mode of Oloid Connect App as a Supervisor/Admin](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app). ![](/images/10307929/81ba504b16bd.png)
2. The **Settings** page is displayed. ![](/images/10307929/c9a70139d5cb.png)
3. Tap **Users**on the menu at the bottom of the screen. ![](/images/10307929/9901946f0d12.png) The **Users**page with list of users is displayed.
4. Tap on the selected user to view details. ![](/images/10307929/1b7260adf861.png) The user **Details**screen is displayed.
5. Go to **Password**> tap**Add Shared Credential**. ![](/images/10307929/a84be52e9e9d.png)
6. Select **Credential(s)** from the list.
7. Click **Assign**. ![](/images/10307929/a6324acc458e.png) The **Shared Credentials** are added and listed in the Password tab. ![](/images/10307929/3f09370c6eab.png)

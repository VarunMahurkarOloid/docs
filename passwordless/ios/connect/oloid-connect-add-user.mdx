**Introduction:**

This feature of the Oloid Connect app allows Tenant admins and supervisors to add new users. Endpoint pairing is not required to complete this action.

<Note>
  Supervisors privileges should be enabled to allow the supervisor to add user. For more, refer to [How to enable Add or Delete Users in Tenant Admin Portal for Supervisors](/administration/admin-portal/windows-login-how-to-enable-add-delete-users-in-tenant-admin-portal-for-supervisors)
</Note>

### Steps to add user:

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app.**Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](/administration/admin-portal/how-to-log-in-to-admin-mode-in-the-oloid-connect-app) The **Settings** page is displayed. ![](/images/8601079/9dd0d4269acd.png)
2. Tap **Actions**on the menu at the bottom of the screen. ![](/images/8601079/47587eb60b49.png) The **Actions** screen opens.
3. Tap **Add User**. ![](/images/8601079/f05d776e51cc.png) The **Add User** screen is displayed.
4. Do the following:Enter **Name**.First name and Last name should be separated by a space.Enter **Primary ID**.Only alphabets, numbers, and hyphen are accepted.Enter **Secondary ID**.Only numbers are accepted.Select connection name from**Connection Name** list.
5. Tap **Add User**. ![](/images/8601079/edaed90e1922.png) A new user is added and user details are displayed in Details screen.

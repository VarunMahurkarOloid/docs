## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **OKTA Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](/administration/admin-portal/how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](/passwordless/ios/connect/how-to-download-and-install-the-oloid-connect-app-on-iphone)

## Steps to log in with Okta SSO

1. Launch the **Oloid Connect**![](/images/10288412/f7c4703dd471.png) app. ![](/images/13595968/59f3ef29d1af.png) The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.** ![](/images/13595968/798bdb49d5e0.png) The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**. ![](/images/13595968/e6455e2ee873.png) TheLogin page is displayed.
4. Tap **Login with SSO**. ![](/images/13595968/b05deb860548.png) The screen with **SSO options** is displayed.
5. Select **Continue with Okta**. ![](/images/13595968/9c9ef8d14c61.png) The confirmation pop-up is displayed.
6. Tap **Continue**. ![](/images/13595968/8e6da9ce5357.png) The Sign In screen is displayed.
7. Do the following:Enter **Username**.Tap **Next**. ![](/images/13595968/5768403e8b3c.png)
8. Enter **Password** in the **Password** field.
9. Tap **Sign In**. ![](/images/13595968/3e65ae1a8a0f.png) You are successfully logged in to Oloid Connect Admin Mode. ![](/images/13595968/198c7f1e65fb.png)

This is based on client requirement. **Oloid's WebKey** functions with a single factor (like Face, Badge, QR Code, NFC tags, and PIN) or a combination of factors ( **Face + PIN**, **Badge +PIN** and **NFC +PIN**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](/administration/user-portal/face-onboarding) guide.
- Create Badges for users. Refer [Badge Onboarding](/administration/user-portal/badge-onboarding) guide.
- Create NFC and assign to users. Refer [NFC Onboarding](/administration/user-portal/nfc-onboarding) guide.
- Add PIN and send to users. Refer [Pin Onboarding](/administration/user-portal/pin-onboarding) guide.
- Create QR Code and send to user. Refer [QR Code Onboarding](/administration/user-portal/qr-onboarding) guide.

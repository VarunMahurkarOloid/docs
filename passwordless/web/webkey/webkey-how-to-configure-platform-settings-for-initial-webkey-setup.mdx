For Oloid's WebKey to function, it needs to be configured in the Oloid Platform.

## Initial set up

## Step 1: Set up IDP Profile

1. Create IDP Profile for OIDC-Okta. Refer to [How to create IDP Profile for OIDC-Okta](/resources/integrations/sso/tenant-admin-portal-how-to-create-an-oidc-okta-idp-profile) guide.
2. Configure OIDC-Okta IDP Profile. Refer to [How to configure OIDC - Okta IDP Profile](/resources/integrations/sso/how-to-configure-oidc-okta-idp-profile-in-the-tenant-admin-portal)

## Step 2: Set up Application and Connection

1. Create and Configure WebKey Application. Refer to [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)
2. Create Connections. Refer to [How to create Connections](/administration/admin-portal/tenant-admin-portal-how-to-create-connection)

## Step 3: Map Connections to Applications.

Once both Application and Connection are created, you need to map the Connection to the Application.

Refer to [How to Map Connection to Application](/administration/admin-portal/how-to-map-connections-to-an-application-in-the-tenant-admin-portal)

## Step 4: Create user and assign user to connection.

Create users and assign users to connections in Oloid Portal. Refer to [User Onboarding](/resources/guides/user-onboarding-for-oloid-portal) guide.

## Step 5: Enable Authenticator factors

Based on the requirement , enable authenticator factors in the tenant application. Refer to [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) > [Configure Authenticator tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

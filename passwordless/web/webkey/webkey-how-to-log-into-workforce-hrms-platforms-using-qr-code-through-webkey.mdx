## Introduction

This document provides step-by-step instructions for logging in with QR Code to Workforce /HRMS platform.

## Pre-requisite:

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the tenant Admin Portal, you must do the following:Create QR Code for the user. For more details, refer [How to create QR code as credential for User](/administration/admin-portal/tenant-admin-portal-how-to-create-and-assign-qr-code-credential-for-a-user)Enable QR Code option under the WebKey Application. For more details, refer [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)If you are using Android phones, tablets, dual-camera laptops, and laptops with external cameras, you can select camera options (front/rear). To configure camera options, refer to [Show Camera Flip button](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Using the QR Code:

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with QR Code**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_3d1c52e692). ![](/images/8855767/ad6754ccc0dd.png) By default, the front camera opens for QR code scanning.
3. Hold your mobile device or tablet with the QR code facing the preview screen. Next, scan QR Code for QR Code authentication. ![](/images/10454981/a90c754cd219.png)
4. If your device supports multiple cameras, then do the following:Tap the **Camera Flip Button** in the preview screen.Select **Front Camera** or **Back Camera** as needed.Scan the QR code.

**Note:**The Camera Flip option must be configured for WebKey application.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

## Introduction

This document provides step-by-step instructions for logging in with NFC/ID and PIN to Workforce / HRMS platforms.

## Prerequisites

- You must have an Okta account.
- In the Tenant Admin Portal, you must do the following:Assign NFC to the user. For more details, refer [How to assign NFC/ID as a credential to the user](/administration/admin-portal/how-to-assign-nfc-id-as-a-credential-to-the-user)Add a PIN for the user. For more details, refer [How to add PIN as credential to users](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users)
- In the Tenant Admin Portal, you must enable NFC/ID and PIN under the WebKey Application. For more details, refer [How to create and configure Webkey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) > [Configure Authenticator tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Login using Badge and PIN:

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with NFC/ID**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_25922b8f57). ![](/images/9245333/59f91e547ba1.png) The **Scan NFC/ID Tag**screen is displayed.
3. Tap the **NFC/ID**tag on the **Reader** to scan it.**Note:**The Reader should be connected to your system. ![](/images/9245333/8aa6ff62c84a.png) On NFC/ID authentication, the **Type or Scan PIN**screen is displayed.
4. Do any of the following:Tap the card that contains the PIN on the **Reader** to scan it.**Note:**The Reader should be connected to your system.**(OR)**Enter the **PIN**.Click **Submit**.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

## Introduction

This document provides step-by-step instructions to log in to Workforce/ HRMS using a Personal Passkey.

## Prerequisites

- Ensure Personal Passkey is created for the user. Refer: [How to Generate Personal Passkey in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-generate-personal-passkey)
- Ensure Personal Passkey is enabled for Webeky. refer: Webkey - How to Enable Personal Passkey in the Tenant Admin Portal

## Steps to Log in using Personal Passkey

1. Launch the **WebKey**Application URL in your browser.
2. On the home page of the app, select **Login with Passkey**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_fa3a755a15). ![](/images/15737154/f1728aba5aee.png) The Oloid login page is displayed.
3. Enter **Email ID**> click **Next**. ![](/images/15737154/57a837ea96d6.png) The user is authenticated using passkey. ![](/images/15737154/f3c70eff9b85.png) The User signed in to the **Workforce /HRMS** platform. ![](/images/15737154/fdf1820138c5.png)

---

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

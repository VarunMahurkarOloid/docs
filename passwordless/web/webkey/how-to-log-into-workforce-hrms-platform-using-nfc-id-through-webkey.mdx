## Introduction

This document provides step-by-step instructions for logging in with NFC/ID to Workforce /HRMS platform.

## Supported Browsers

- Chrome
- Safari

## Pre-requisite:

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the Oloid Portal, you must do the following:Assign NFC/ID to the user. For more details, refer [How to assign NFC/ID as a credential to the user](/administration/admin-portal/how-to-assign-nfc-id-as-a-credential-to-the-user)Enable NFC/ID under the WebKey Application. For more details, refer [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) >[Configure Authenticator tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Using the NFC/ID

1. Launch the **WebKey**Application URL in your browser.
2. On the home page of the app, select **Login with NFC/ID**. ![](/images/9286137/d03a9f33b416.png) The **Scan NFC/ID Tag**screen is displayed. ![](/images/9286137/db92933a36ea.png)
3. Tap the **NFC/ID**tag on the **Badge Reader** to scan it.
4. You are signed in to the **Workforce / HRMS** platform when NFC authentication is done. ![](/images/9286137/fdf1820138c5.png)

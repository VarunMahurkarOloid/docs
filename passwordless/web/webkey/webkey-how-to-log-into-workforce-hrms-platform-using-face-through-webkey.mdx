## Introduction

This document provides step-by-step instructions for logging in with face to Workforce /HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential (user email ID) must be added to the user detail page.
- In the Tenant Admin Portal, you must do the following:Add Face to the user. For more details, refer [How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user)Enable Face under the WebKey Application. For more details, refer [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)Manual face capture (as per the requirement) must be configured in Oloid Portal. You need to turn on [Enable Manual Capture Accessibility](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)toggle buttonin WebKey Configuration. For detailed instruction see, [WebKey: Platform Configuration for manual capture of face](/passwordless/web/webkey/webkey-how-to-configure-manual-face-capture-for-webkey)

## Steps to Login using Face

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with Face**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_12ebca9489). ![](/images/9259082/4ef379271f00.png) Place your face in front of the camera for facial authentication.
3. The camera auto-captures the user's face. If manual capture is enabled, press **Enter or Spacebar,**or click on the camera icon.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

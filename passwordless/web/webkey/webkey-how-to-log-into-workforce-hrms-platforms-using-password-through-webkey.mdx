## Introduction

This document provides step-by-step instructions for logging in with Password to Workforce / HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the Tenant Admin Portal, you must enable custom login option under the WebKey application. For more details, refer [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) > [Design Configure Tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) > [Configure Login Page Options](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal).

## Steps to Log in with Password:

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with Password**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_f3ebcec29c). ![](/images/8856182/a99d5811bd9c.png) The Okta Sign In page is displayed.
3. Enter your login credential.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

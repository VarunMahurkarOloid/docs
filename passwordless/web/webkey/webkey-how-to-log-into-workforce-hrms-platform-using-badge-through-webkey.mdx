## Introduction

Badge Authentication enables users to securely sign in to supported Workforce and HRMS platforms by scanning a registered badge on a connected badge reader. Once the badge is verified, Webkey authenticates the user and signs them in to the configured HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:Assign badge to the user. For more details, refer[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)Enable badge option under the Webkey Application. For more details, refer [How to create and configure Webkey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Steps to Login with Badge:

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with Badge**. **Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_d575452683). ![](/images/9259058/1b691d7608ac.png) The **Scan Badge at the Reader**screen is displayed.
3. Tap the **Badge** on the **Badge Reader** to scan it.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

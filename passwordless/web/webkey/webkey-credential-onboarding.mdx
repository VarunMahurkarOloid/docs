## Overview

**OLOID** supports multiple methods for onboarding user credentials, enabling organizations to select the enrollment workflow that best aligns with their operational and security requirements. Credentials can be enrolled directly by users, provisioned by administrators, imported in bulk, or validated against existing HR records.

This overview serves as a centralized reference for all supported WebKey credential onboarding methods and includes links to the relevant documentation.

## Introduction

This document provides step-by-step instructions for logging in with face and PIN to Workforce /HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:Add Face to the user. For more details, refer [How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user)Add PIN for the user. For more details, refer[How to add PIN as credential to users](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users)Enable Face and PIN under the WebKey Application. For more details, refer [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)Manual face capture (as per the requirement) must be configured in Tenant Admin Portal.

## Steps to Login with Face:

1. Launch the **Webkey**application URL in your browser.
2. On the home screen of the app, select **Login with Face**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_fc960b5c8b). ![](/images/8608007/4ef379271f00.png)
3. Place your face in front of the camera for facial authentication and press **Enter or Spacebar.**Note: For manual capture to function it must be configured in the Tenant Admin Portal. ![](/images/8608007/f305ad525756.png)
4. On Face authentication, the **Type or Scan PIN**screen is displayed.
5. Do any of the following:Enter **PIN**.Tap the card which contains the PIN on the **Reader** to scan it.**Note:**The Reader should be connected to your system.

Click **Submit**.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

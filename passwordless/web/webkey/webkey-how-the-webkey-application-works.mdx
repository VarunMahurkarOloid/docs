OLOID's WebKey provides a Multi-Factor Authentication solution using physical identity factors (like Face, Badge , NFC tags, QR Code, and Pin) and a custom domain for the users to seamlessly log in to their Workforce Identity Platforms.

## Step 1: Onboard Users

Onboard users in Oloid's Tenant Admin Portal with email address.

**Note:** Email address must be same as in the Workforce Identity platforms.

## Step 2: Configure Credentials (Face/Badges/NFC/Pin)

Onboard User Credentials (Face/Badges/NFC/Pin/QR Code) in the Oloid Portal.

## Step 3: Launch the URL

Launch the URL in a browser.

## Step 4: Use Authentication Method

Face : User comes in front of the screen for facial authentication

Badge : User scans badge in the Badge Reader

Pin:  User enters PIN in the Login screen

Face and PIN (for MFA): User shows the face and then enters the PIN

Badge and PIN (for MFA): User scans the badge and then enters the PIN

NFC and PIN (for MFA): User scans the nfc tag and enters the PIN

## Step 5: Log into the Workforce Identity platforms

Once Authentication is done, user is logged into the Workforce Identity platforms.

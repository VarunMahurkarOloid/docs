## Introduction

Oloid's WebKey is a browser-based application that enables Multi-factor authentication(MFA) of users using physical identity factors (like Face, Badge, NFC tags, QR Code, and PIN). This application allows employees to seamlessly log into Workforce/ HRMS systems without entering Username and Password.

## Features

- **Integration:**Fully integrable with existing single-sign-on (SSO) login systems.
- **Compatibility:**Works on all desktop, laptop, and mobile devices with standard web cameras for face login. No special hardware is required.
- **Badge Support:**Enterprises can use any standard **Badge Reader** that can be connected to the devices (Laptop/Desktop, iPad, Android Tablet).

## How WebKey Works

To understand the functionality of the WebKey application, refer to the [How WebKey Application Works](/passwordless/web/webkey/webkey-how-the-webkey-application-works) guide.

## Installation

WebKey is a browser-based application that doesn't require installation.

## Configuration

For WebKey to function, it must be configured in the Oloid Platform.

### Initial set up

- Set up IDP Profile
- Set up Application and Connection
- Create user and assign user to connection

For details see, [Platform Configuration for initial WebKey Set up](/passwordless/web/webkey/webkey-how-to-configure-platform-settings-for-initial-webkey-setup)

### Credential Set up

Oloid's WebKey supports authentication using either a single factor (Face, Badge, NFC tags, QR Code) or a multi-factor combination (Badge + PIN, NFC + PIN, Face + PIN, QR + PIN) based on the client's requirements.

For details see, [Credential Setup- WebKey](/passwordless/web/webkey/webkey-credential-setup)

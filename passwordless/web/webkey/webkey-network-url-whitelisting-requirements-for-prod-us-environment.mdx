## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Webkey |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **PROD (US)** | **Description** |
|---|---|---|
| Passwordless Authentication | \<tenantname>.oloidsso.com | Passwordless Authentication used for secure user authentication without passwords. |
| Admin API | api.oloid.cloud | The Admin API is used for Authentication. |
| Tenant User API **(Optional** **- Required only for Enrollment)** | api.myoloid.com | The User API is used for Enrollment. |
| Oloid Document Bucket **(Optional)** | oloiddocument-prod.s3.us-east-1.amazonaws.com | This URL is required when a theme is configured. |

#### Notes

- Replace **\<tenantname>** and **\<tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **\<tenantname>** and **\<tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **\<tenantname>** and **\<tenantid>** details.

Tenant Admin/Supervisor can detect spoofing attempts in WebKey application by checking if a user has logged in using a virtual camera instead of a real face scan.

**Pre-requisite:**

You must turn on**Enable Virtual Camera**in Webkey application. For more information, refer  [How to create and configure WebKey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) > [Enable Virtual Camera](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

To identify spoofing:

1. Log in to **Oloid Portal**.
2. Go to **Transactions** in the left menu panel. ![](/images/10469404/9ef195709b81.png) The User Transaction page is displayed.
3. Select the login transaction. ![](/images/10469404/a1dce8ac728e.png)
4. Go to **Details** tab, check **Virtual Camera**status. ![](/images/10469404/49d29c61718a.png) If Virtual Camera is **True**, the user has used a spoofing method to log in.

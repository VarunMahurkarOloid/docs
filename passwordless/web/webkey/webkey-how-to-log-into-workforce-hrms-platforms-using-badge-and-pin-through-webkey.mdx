## Introduction

Users must first authenticate by scanning their registered badge and then verify their identity using their PIN before being signed in to the configured Workforce or HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](/administration/admin-portal/tenant-admin-portal-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:Assign badge to the user. For more details, refer [How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)Add a PIN for the user. For more details, refer [How to add PIN as credential to users](/administration/admin-portal/how-to-add-pin-as-a-credential-for-users)Enable Badge and PIN options under the WebKey Application. For more details, refer [How to create and configure Webkey application](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

## Steps to Log in using Badge

1. Launch the **Webkey**Application URL in your browser.
2. On the home page of the app, select **Login with Badge**.**Note:**You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#h_438997cbf4). ![](/images/13597429/1b691d7608ac.png) The **Scan Badge at the Reader**screen is displayed.
3. Tap the **Badge** on the **Reader** to scan it. ![](/images/13597429/a277175b585b.png) On Badge authentication, the **Type or Scan PIN**screen is displayed.
4. Do any of the following:Enter **PIN**.Tap the card that contains the PIN on the **Reader** to scan it.**Note:**The Reader should be connected to your system.
5. Enter the **PIN**.
6. Click **Submit**.

### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

**Note:** Languages supported: English, Spanish, French, German, and Portuguese language.

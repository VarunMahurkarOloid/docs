## Introduction

The Create Vault Password feature enables an admin to securely create and store Vault password credentials for a user in the Tenant Admin Portal.

## Prerequisite

- You must have a Tenant Admin account.

## Steps to create Vault Password

1. Login to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel. ![Image](/images/13284463/bfbd42eb3ee2.png) The **Users** page is displayed.
3. Select **User** from the list. ![Image](/images/13284463/495b74c13e39.png) The **User details** page is displayed. ![](/images/13284463/83f0439c8704.png)
4. Go to **Credential** tab >**Vault Passwords** > **+ Create Passwor**d. ![](/images/9936961/b05b6606403b.png) The **Create Vault Password** pop-up screen is displayed.
5. On the screen, do the following Enter**Display Name**. (Optional)Select **Password Type** from the dropdown list.Click **Next**. ![](/images/9936961/39c7a842ab51.png) Enter**Web URL/Login UR**L.Enter **Username**.Enter **Password**.Click **Create**. ![](/images/9936961/d669671bed09.png) The Vault Password is saved successfully. ![](/images/9936961/705568e825dc.png) Keywords| Create Vault Password| Vault Password management| Vault Shared Password|

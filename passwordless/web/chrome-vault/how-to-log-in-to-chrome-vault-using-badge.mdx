## Introduction

This document explains how to log in to **Chrome Vault** using a badge.  
By scanning a registered badge on a supported card reader, users can quickly and securely authenticate without entering a password.

## Prerequisites

- You have a valid Badge assigned to you.
- Your device supports Badge and has an active Badge reader.

## Steps to log in with Badge

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9618391/2d852f873a1e.png) The Welcome screen is displayed.
2. Select **Verify Using Badge**.**Note:** You can see only the authentication ways enabled for you in the application. The button name may vary depending on the application configuration. Reach out to [support](mailto:support@oloid.ai)team if you do not see any authentication method. ![](/images/9751929/75d01f313e16.png) The **Scan Badge at the Reader** is displayed. ![](/images/9751929/30ea200776e8.png)
3. Scan the **Badge** on the**Card Reader**.On Badge authentication, you are successfully logged in to Chrome Vault. ![](/images/9751929/d93f4b446ca3.png)

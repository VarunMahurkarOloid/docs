## Introduction

This document provides instructions to install **Oloid Vault** as a browser extension. The installation steps in this document apply to **Google Chrome** browser. After installation, Oloid Vault enables users to securely manage credentials directly within supported web applications.

## Prerequisites

- The **Oloid Vault installer package** (ZIP file) is available.**Note:** Contact [Oloid Support](mailto:Support@oloid.ai) to obtain the Oloid Vault installer package
- The installer package includes:**Oloid_Vault.crx file****Registry file(s).****Note:** Restart **Chrome Browser** to apply the registry changes

## Steps to Install Oloid Vault Application

1. Download the **Oloid Vault installer ZIP file** on your system.**Note:**Ensure theinstaller file must contain **Oloid_Vault.crx** and **Registry** files.
2. Right-click the zip file and select **Extract All**.**Note:** The extracted files are saved in the same folder as the original ZIP file.
3. Install **Registry** file.**Note:** First-time users must install the required registry file before using the Oloid Vault application.
4. Open **Google Chrome**browser.
5. Go to **Extensions**> **Manage Extensions**. ![](/images/13724911/fc469ecf8a24.png) The **Extensions** page is displayed.
6. Enable **Developer Mode**toggle. ![](/images/13724911/788df43f3603.png) The **Developer mode** is enabled successfully.
7. Drag and drop the **Oloid_Vault.crx file** onto the **Chrome Extensions** page.**Note:** Ensure that **Developer mode** is enabled before dragging and dropping the Oloid_Vault.crx file.The **Add Oloid Vault** pop-up box is displayed. ![](/images/13724911/b1512af2a8e4.png)
8. Select **Add extension**. ![](/images/13724911/9768ffb53f92.png) The **Oloid Vault** is added successfully.
9. Click **Details**. ![](/images/13724911/08fb4b41fcec.png) The **Details** page is displayed.
10. Do the following:Enable **Pin to toolbar**toggle.Enable **Allow in Incognito**toggle. ![](/images/13724911/c17824e6a4c1.png) The **Oloid Vault** extension is successfully installed. You can now view **Oloid Vault** icon on the toolbar. ![](/images/13724911/3be22f0db572.png)

## Overview

Oloid supports multiple credential onboarding methods for Oloid Vault across different workflows, enabling both assisted and self-service enrollment. Depending on the use case, credentials such as Face, NFC, Badge, and QR Code can be enrolled through the User Portal, Tenant Admin Portal or provisioned by admin.

This overview provides a consolidated view of all available credential onboarding methods, along with their enrollment types and corresponding documentation.

**Oloid's Chrome Vault,**a browser extension app designed for password management improves online security. The browser extension securely stores user credentials, protecting sensitive information with encryption. It organizes passwords by website, making it easier to manage multiple accounts. With seamless autofill functionality, logging in becomes faster, reduces errors, and enhances both security and convenience.

## Download and Installation

The Chrome Vault app is installed and configured in Google Chrome browser.

- Download the Chrome Vault App installer files.For instructions to download and install the installer file, refer [How to Install Oloid Vault in Chrome Browser](/passwordless/web/chrome-vault/how-to-install-oloid-vault-in-chrome-browser)
- Install the downloaded Supervisor App installer files.For instructions to download the Supervisor app, refer[How to download Supervisor App](/passwordless/windows/supervisor/how-to-download-supervisor-app)For instructions to install the Supervisor app, refer[How to install Supervisor App](/passwordless/windows/supervisor/how-to-install-windows-authenticator-app)**Note:** If you will use the Oloid session from the Windows authentication to login to Vault, then you must install the Presence Detection version of the supervisor app.

## Configuration

### Platform

For an end-user to use the Chrome Vault app, the Tenant admin must perform the following configuration in the Oloid Platform.

- Set up Application and Connection.
- Create user and assign user to connection. For detailed instructions, refer [How to add Users in the Tenant Admin Portal | Oloid Help Center](/administration/admin-portal/how-to-add-users-in-the-tenant-admin-portal).
- Assign credentials to users. For detailed instructions, see [User Onboarding](/resources/guides/user-onboarding-for-oloid-portal) guide.

### Chrome Vault app

Chrome Vault automatically pairs the endpoint, if auto pairing fails then manually pair endpoint in admin mode.

For details, refer [Oloid Vault - How to manually pair an endpoint | Oloid Help Center](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-manually-pair-an-endpoint)

## Use

Using Chrome Vault, users can securely log into their accounts with various authentication methods, including NFC, facial recognition, and badges. Users can perform the following tasks in Chrome Vault:

- **Log in to Chrome Vault**: Choose your preferred authentication method — NFC, Face, or Badge — to securely access your stored credentials.
- **Manage passwords**: Edit, save, and update passwords for any website stored in Chrome Vault.
- **Log out**: Log out of Chrome Vault securely to ensure your credentials remain protected.

## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Oloid Vault (Chrome / Chromium) |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **PROD (US)** | **Description** |
|---|---|---|
| Admin API | api.oloid.cloud | The Admin API is used for Authentication. |
| Tenant User API | api.myoloid.com | The Tenant User API is used for credential. |
| Oloid Document Bucket **(Optional)** | oloiddocument-prod.s3.us-east-1.amazonaws.com | This URL is required when a theme is configured. |
| Geo-Decoding Service **(Optional)** | nominatim.openstreetmap.org | This URL is used to Fetch the address via Geo Location coordinates. |

## Introduction

The Oloid Vault application allows the admin to manage device pairing for secure access. If a device is no longer in use or needs to be removed from the system, you can unpair it from Chrome Vault. Unpairing ensures that the endpoint is no longer linked to your account, maintaining security and preventing unauthorized access.

## Prerequisite

You must pair your endpoint. To pair the endpoint, refer [How to pair endpoint in Chrome Vault](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-manually-pair-an-endpoint).  
​

## Steps to unpair endpoint

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9651603/33d9817a03f3.png) The **Welcome**screen is displayed.
2. Go to **More** option (![](/images/9651553/ed164f99b28a.png)) icon > **Admin Mode**. ![](/images/9651603/52bc9c7ea437.png) The **Oloid Vault** **login**screen is displayed on a new tab.
3. Do the following:Enter your **Username**or **Email ID**.Enter **Password**.Click **Login**. ![](/images/9651603/9d1a6d805798.png) Endpoint pair screen is displayed.
4. Select **Unpair Endpoint**. ![](/images/9651603/205d49c68160.png) The **Confirm Unpair** screen is displayed.
5. Select **Confirm Unpair**. ![](/images/9651603/9ee4430e980a.png) The device is unpaired successfully. ![](/images/9651603/fa24a54fbf7c.png)

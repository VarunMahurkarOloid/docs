**Pre-requisite**

You have saved credentials in the Chrome Vault application. For more information, see [How to save password in Chrome Vault](/passwordless/web/chrome-vault/how-to-save-password-in-chrome-vault)

To update password:

1. Go to a website that you need to log in.
2. Click on the password field.The Chrome Vault icon is displayed.
3. Edit the password field > **Update Password**. ![](/images/9819006/c471829ddf28.png) The Chrome Vault pop-up is displayed. ![](/images/9819006/d2ee1f26def0.png)
4. Click **Update Password**.The password is updated successfully and you can log in to the website. ![](/images/9819006/dcbf719f2329.png)

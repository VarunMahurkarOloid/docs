## Introduction

Chrome Vault allows users to log in securely using Facial authentication. When Face authentication is enabled for the application, user can sign in by showing his face on the device camera. This method eliminates the need for manual credential entry, providing a faster and more secure login experience.

## Prerequisite

Your device must have a **working camera** with permission to access the browser.

## Steps to Log in to Chrome Vault using Face

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9612252/2d852f873a1e.png) The **Welcome**screen is displayed.
2. Select **Login with Face**.**Note:**The authentication methods (Face, NFC and Badge) will be visible on the Welcome screen, only if they are enabled for the application. The button names may vary based on the application’s configuration and customization. If you do not see any authentication method available, please contact your [support](mailto:support@oloid.ai) team for assistance. ![](/images/9612252/41902ce4dde4.png) The Camera Permission pop-up box is displayed.
3. Select **Allow while visiting the site**to open the camera. ![](/images/14778605/003edd736736.png) The image capture pop-up box is displayed.
4. Do one of the following:Position yourself to face the camera for automatic capture.orPosition yourself to face the camera > click capture button. ![](/images/9612252/dafd469311ef.png) You are successfully signed in to Chrome Vault.

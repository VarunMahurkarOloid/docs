## Introduction

The Chrome Vault application securely stores and manages your website passwords in the browser. It lets you quickly access saved credentials without remembering multiple usernames and passwords. You can save passwords either while logging in through the browser or by using the add option in the Chrome Vault extension.

## Prerequisites

The Chrome Vault application must be installed. To install refer [How to install Chrome Vault application](https://oloid.help/en/articles/9610642-how-to-install-chrome-vault-application).

## Steps to save password

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9618391/2d852f873a1e.png) The welcome screen is displayed.
2. Log in to **Chrome Vault** application by selecting an authentication method. For more details refer [How to log in to Chrome Vault](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault). **Note**: You can see only the authentication ways enabled for you in the application. The button name may vary depending on the application configuration. Reach out to your [Support](Mailto:Support@oloid.ai) team if you do not see any authentication method. ![](/images/9618391/c890f9daceb6.png) You are logged in to Chrome Vault. ![](/images/9618391/bd15c8cb2675.png)
3. You can add website password using the following ways:[Using browser](#h_04780325e4)[Using the add functionality of Chrome Vault](#h_f474b215df) **Note:**You can save and use the same password for a domain and its related domains if multi-domain configuration is enabled for your Chrome Vault application.

## Using Browser

1. Go to a website that you need to log in. ![](/images/9618391/d0f645183443.png)
2. Click on any credential field .The **Chrome Vault** icon is displayed.
3. Click Chrome Vault icon (![](/images/9618391/38c82cdab7aa.png)) > **Save in Chrome Vault**. ![](/images/9618391/ab559511bf68.png) The Chrome Vault pop-up box is displayed.
4. Do the following:**Website URL:** The application auto-fills the URL field.**Username**: Enter **Username**.**Password**: Enter**Password**.Click **Save Password**. ![](/images/9618391/fb546f971504.png) The password is saved successfully ![](/images/9618391/e305f2eac7ff.png) The saved password displayed in the Chrome Vault. ![](/images/9618391/cfed7e17e4c1.png)

## Using the add functionality of Chrome Vault

- Go to a website that you need to log in. ![](/images/9618391/af61b98cdb3e.png)
- On the top right, select Chrome Vault icon from the extension space. ![](/images/9618391/6544268a2ed5.png)
- Select add ![](/images/9618391/9f56f0348dea.png) icon to enter your credential. ![](/images/9618391/9b36b1b878cd.png) The Chrome Vault screen is displayed.
- Do the following:**Website URL:** The application auto-fills the URL field.**Username**: Enter **Username**.**Password**: Enter**Password**.Click **Save Password.** ![](/images/9618391/c8b250b7e968.png) The password is saved successfully ![](/images/9618391/e305f2eac7ff.png) The saved password displayed in the Chrome Vault. ![](/images/9618391/84d4d444894d.png)

## Introduction

This document explains how to log in to Chrome Vault using NFC (Near Field Communication). NFC allows you to authenticate quickly by tapping your NFC tag on a compatible reader. This secure method streamlines access to Chrome Vault without the need to manually enter credentials.

## Prerequisites

- You have a valid NFC/ID tag assigned to you.
- Your device supports NFC and has an active NFC reader.

## Steps to Log in to Chrome Vault using NFC

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9618391/2d852f873a1e.png) The Welcome screen is displayed.
2. Select **Login With NFC/ID**.**Note**: You will only see the authentication methods (Face, Badge and NFC/ID) enabled for you. Button names may vary based on configuration. Contact [Support](Mailto:Support@oloid.ai) if no authentication method appears. ![](/images/9740334/0b5bc05e9368.png)The **Tap NFC Tag at the device**screen is displayed.
3. Tap the **NFC/ID**tag on the**Reader** to scan it. ![](/images/9740334/1b18e95c7d9f.png)After successful NFC authentication, you are logged in to Chrome Vault. ![](/images/9740334/dd6d2a6b501b.png) Related Video **[How to log in to Chrome Vault using NFC- Video Tutorial](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault-using-nfc-video-tutorial)**

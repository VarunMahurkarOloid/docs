## Introduction

This document provides the minimum hardware and software requirements needed to run the Oloid Vault (Chrome / Chromium) application. Ensure that your system meets these requirements before installing the Chrome Vault application to avoid compatibility or performance issues.

## Minimum Software Requirements

| **Components** | **Minimum Requirement** |
|---|---|
| Browser | Google Chrome |
| Operating System | Version 10 or above |

## Minimum Hardware Requirements

| **Components** | **Minimum Requirement** |
|---|---|
| RAM | 4 GB or more |
| Camera | Minimum 5 MP resolution (required for Face recognition and QR code). |
| Camera Resolution | Minimum camera resolution will be 640*480. |
| Internal Storage | 500 MB free storage space |
| Card Reader | Required Card reader for Badge/NFC authentication. |
| Badge | Required Badge for authentication. |
| NFC ID | NFC for authentication. |

**Note:** For supported card types, refer [Oloid Supported Card Types | Oloid Help Center](/resources/guides/oloid-supported-card-types)

## Incompatibility Warnings

![](/images/12569830/1c15512eb6c8.png)Oloid Vault (Chrome / Chromium) vault **may not function properly** on web browser with the following limitations:

- Operating system is below window 10.
- Devices without a functional camera or NFC module.
- Device RAM is below 4 GB.

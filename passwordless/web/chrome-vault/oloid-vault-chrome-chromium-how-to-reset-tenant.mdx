## Introduction

The **Reset Tenant** feature in Oloid Vault allows admin to remove the existing tenant configuration and restore the application to its default state. This is useful when switching to a new tenant or re-configuring the application for different organizational needs.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Reset Tenant

1. Open **Google Chrome** browser and click **Oloid Vault** icon located on the toolbar. ![](/images/9667131/33d9817a03f3.png) The **Welcome**screen is displayed.
2. Go to **More** option (![](/images/9651553/ed164f99b28a.png)) icon > **Admin Mode**. ![](/images/9651603/52bc9c7ea437.png) The Oloid Vault **login**screen is displayed on a new tab.
3. Do the following:Enter your **Username**or **Email ID**.Enter **Password**.Click **Login**. ![](/images/9667131/38c060d882ac.png) The Endpoint pair screen is displayed.
4. On the home screen, select **More** (![](/images/9667131/23098c8929fc.png)) icon > **Reset Tenant**. ![](/images/9667131/c97f850800d3.png) The **Confirm Tenant Reset** page is displayed.
5. Select **Reset Tenant**. ![](/images/9667131/6bf539f46bc9.png) The tenant has been reset successfully. ![](/images/9667131/0cc8e1c75e76.png)

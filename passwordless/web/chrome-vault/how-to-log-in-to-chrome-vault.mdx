## Introduction

The Chrome Vault application provides a secure and passwordless way for users to access their accounts using Face, Badge, or NFC/ID authentication. This ensures a faster login experience while maintaining high security standards.

## Prerequisites

Authentication method (Face, Badge, or NFC/ID) must be enabled. To enable refer [How to create and configure Chrome Vault application](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).

## Steps to login

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/12289985/2d852f873a1e.png) The Welcome screen is displayed.
2. Do one of the following:Select **Login with Face**To login with Face refer[How to log in to Chrome Vault using Face](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault-using-face). Select **Login with Badge**To login with Badge refer [How to log in to Chrome Vault using Badge](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault-using-badge). Select **Login with NFC/ID**To login with NFC/ID refer [How to log in to Chrome Vault using NFC](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault-using-nfc). ![](/images/12289985/0d5a572cb409.png)

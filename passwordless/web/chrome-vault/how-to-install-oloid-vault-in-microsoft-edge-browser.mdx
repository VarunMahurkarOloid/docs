## Introduction

This document provides instructions to install **Oloid Vault** as a browser extension. The installation steps in this document apply to **Microsoft Edge** browser. After installation, Oloid Vault enables users to securely manage credentials directly within Microsoft Edge web applications.

## Prerequisites

- The **Oloid Vault installer package** (ZIP file) is available.**Note:** Contact [Oloid Support](mailto:Support@oloid.ai) to obtain the Oloid Vault installer package
- The installer package includes:**Oloid_Vault.crx file****Registry file(s).****Note:** Restart **Microsoft Edge browser** to apply the registry changes

## Steps to Install Oloid Vault Application

1. Download the **Oloid Vault installer ZIP file** on your system.**Note:**Ensure theinstaller file must contain **Oloid_Vault.crx** and **Registry** files.
2. Right-click the zip file and select **Extract All**.**Note:** The extracted files are saved in the same folder as the original ZIP file.
3. Install **Registry** file.**Note:** First-time users must install the required registry file before using the Oloid Vault application.
4. Open **Microsoft**browser.
5. Go to **Extensions**> **Manage Extensions**. ![](/images/13741498/24a872a92018.png) The **Extensions** page is displayed.
6. Enable **Developer Mode**toggle. ![](/images/13741498/7c6f8dff15de.png) The **Developer mode** is enabled successfully
7. Drag and drop the **Oloid_Vault.crx file** onto the **Edge Extensions** page.**Note:** Ensure that **Developer mode** is enabled before dragging and dropping the Oloid_Vault.crx file.The **Add "Oloid Vault" to Microsoft Edge?** pop-up box is displayed. ![](/images/13741498/592687ebd7cf.png)
8. Select **Add extension**. ![](/images/13741498/c50d0e05b9bc.png) The **Oloid Vault** is added successfully.
9. Click **Details**. ![](/images/13741498/38485103eaa3.png) The **Details** page is displayed.
10. Select **Allow in InPrivate**. ![](/images/13741498/5498db2a6dc7.png) The **Oloid Vault** extension is successfully installed.
11. Click **Extension > Pin to Tool bar** (Optional). ![](/images/13741498/0e61a013f47b.png) The Oloid vault is added in the Microsoft Edge toolbar.You can now view **Oloid Vault** icon on the toolbar. ![](/images/13741498/4606ba2af7be.png)

## Introduction

This document explains how to manually pair an endpoint in the Oloid Vault (Chrome / Chromium) application. Manual pairing is used when automatic pairing fails or when the endpoint needs to be configured by Admin/Supervisor.

## Prerequisites

- You must have Admin or Supervisor credentials to perform endpoint pairing.
- The Chrome Vault extension must be installed and accessible from the browser toolbar.
- The application must be created and configured in the Tenant Admin Portal.

## Steps to Manually Pair Endpoint

1. Open **Google Chrome** browser and click **Chrome Vault**![](/images/9739348/0f0c3a3b0525.png) icon located on the toolbar. ![](/images/9618391/2d852f873a1e.png) The **Pairing Failed** message is displayed.
2. Click **Initiate Manual Pairing**. ![](/images/9739348/f8648d548f23.png) The Welcome screen is displayed.
3. Enter **Tenant Name** and click**Next**.**Note:** If you do not have Tenant name, contact **[Oloid support](mailto:support@oloid.ai)**. ![](/images/9739348/7e80d4b55170.png)
4. Select **Pair as Supervisor**. ![](/images/9739348/70f963ea3db8.png) The **Pair as supervisor** screen is displayed.
5. Enter your login credentials, then click **Next**. ![](/images/9739348/3b01acfd2e29.png)
6. Do the following:Enter **Endpoint Name**.Select **Application Name**.Select **Endpoint Template** (Optional).Click **Pair Device**. ![](/images/9739348/b0cea5093fa4.png) The endpoint is successfully paired, and the home page is displayed. ![](/images/9739348/8f271b934f15.png) ![](/images/9739348/eebfd5b022cc.png)

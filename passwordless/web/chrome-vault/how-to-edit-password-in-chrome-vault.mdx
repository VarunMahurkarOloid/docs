## Introduction

Chrome Vault lets you securely manage saved passwords in your browser. This document shows you how to update a saved password to keep your credentials current and avoid login issues.

## Prerequisite

The password must be saved in Chrome Vault. To save password refer [How to save password in Chrome Vault](/passwordless/web/chrome-vault/how-to-save-password-in-chrome-vault).

## Steps to edit password

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9618391/2d852f873a1e.png) The**Chrome Vault**pop-up box is displayed.
2. Click **More options menu** (![](/images/9795116/c40c7cfd1f4a.png)) on the preferred saved profile to edit it. ![](/images/9795116/5e9cf91b562a.png) The**Chrome Vault**page in edit mode is displayed.
3. Do the following:Edit the website **URL**(optional).Edit **username**(optional).Edit **password**.Click **Save Password**. ![](/images/9795116/6d58558e228e.png) The password is updated successfully. ![](/images/9795116/dfd7b06a30d5.png) **Note:**You can also edit and update your password using the Update Password option. For details, see [How to update password in Chrome Vault](/passwordless/web/chrome-vault/how-to-update-password-in-chrome-vault).

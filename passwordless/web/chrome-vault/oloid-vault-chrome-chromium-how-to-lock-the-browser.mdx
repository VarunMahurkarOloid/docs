## Introduction

This document explains how to lock the browser using the Oloid Vault (Chrome / Chromium) app. The Browser Lock feature secures all active browser tabs and requires reauthentication to unlock them.

## Prerequisites

- Ensure that the **Browser Lock** feature is enabled in the Tenant Admin Portal. For more information, refer [Lock Browser](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).
- You must login to the Chrome Vault. To log in refer [How to log in to Chrome Vault](/passwordless/web/chrome-vault/how-to-log-in-to-chrome-vault).

## Steps to Lock the Browser

1. Open **Chrome Vault**application.
2. Click **Lock Browser**. ![](/images/14075018/963ba0bae352.png) The Browser is locked successfully.**Note:** All browser tabs are locked automatically. Reauthenticate from any tab to unlock the browser. Once authentication is completed, all tabs are unlocked. ![](/images/14075018/4aff91845044.png)

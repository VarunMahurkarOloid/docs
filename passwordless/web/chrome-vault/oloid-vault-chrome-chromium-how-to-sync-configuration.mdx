## Introduction

The **Sync Configuration** feature in Oloid Vault ensures that the application is updated with the latest settings and configuration. This helps maintain consistency and keeps the application aligned with organizational requirements. You can sync configuration directly from the Oloid Vault login page or through the Admin Mode, depending on your access level.

## Prerequisite

You must set up Oloid Vault in your device. For more details refer [Setting up and using Chrome Vault](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-set-up-and-use).

## Steps to Sync Configuration

You can sync configuration in Chrome Vault using the following options:

- [Sync Config on Welcome Screen](#h_a6ebbdb1e0)
- [Sync Config in Admin Mode](#h_5b7db6b88b)

## Sync Config on Welcome Screen

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar. ![](/images/9842062/33d9817a03f3.png) The **Welcome** screen is displayed.
2. Go to **More** option (![](/images/9842062/e8cee7fd7af0.png)) icon > **Sync Config**. ![](/images/9842062/bd5e292af804.png)
3. The Syncing Configuration is initiated. ![](/images/9842062/5820a6d30cae.png) The Chrome Vault configuration is updated successfully. ![](/images/9842062/a755fc37ab68.png)

## Sync Config in Admin Mode

To use sync configuration in admin mode:

1. Log in to Admin Mode in Chrome Vault. For more details refer [How to log in to Admin Mode in Chrome Vault](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-log-in-to-admin-mode).
2. On the configuration screen of the admin mode, select **Sync Config**. ![](/images/9842062/5173cb53f233.png)
3. The Syncing Configuration is initiated.

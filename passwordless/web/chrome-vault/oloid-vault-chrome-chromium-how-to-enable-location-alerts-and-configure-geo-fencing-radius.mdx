## Introduction

This document explains how to enable the **Location Alerts** feature and configure **Geo-Fencing Radius** for the Oloid Vault (Chrome / Chromium) application.

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- You must create and configure Oloid Vault (Chrome / Chromium) application in the Tenant Admin Portal. For more, refer to [Oloid Vault (Chrome / Chromium) - How to Create and Configure Oloid Vault Application in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal)

## Steps to Enable Location Alerts

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Chrome Vault application. ![](/images/15699935/1a1c053bd1bf.png) The application **details** page is displayed. ![](/images/15699935/662e45178116.png)
3. Go to**Configure** tab > **Settings.** ![](/images/15699935/fcab5d5b4ee4.png) The settings page is displayed.
4. **Enable Location Alerts** toggle to generate an alert transaction when a user's authentication occurs outside the configured geo-fencing radius. ​**Note:** When enabled, users must grant device location access before authentication.
5. In the **Geo-fencing Radius** section, configure the allowed authentication distance:**Miles** – Enter the allowed radius in miles.​**Feet** – Enter the allowed radius in feet.**Note:** To receive a **Windows Alert** each time a location violation occurs, enable **Browser Tracking** and configure the **Push Browser-data to transaction every** interval. For more, refer to [How to Enable and Configure Browser Tracking.](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal)
6. Click **Save.** ![](/images/15699935/8a89ace4d847.png) The Location Alerts is configured successfully. ![](/images/15699935/0341a7b36b4d.png) Keywords|Geo-Fencing Radius| Chrome Vault Location Alert | Geofence Configuration|

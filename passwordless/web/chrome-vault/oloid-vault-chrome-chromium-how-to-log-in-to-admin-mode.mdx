## Introduction

Oloid Vault Admin Mode allows admin to manage settings and configure features.  
It provides access to advanced actions. Only admins can log in to Admin Mode to make changes.

## Prerequisite

You must install and setup the Oloid Vault. For more details, refer [Oloid Vault - How to Set Up and Use | Oloid Help Center](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-set-up-and-use)

## Steps to Log in to Admin Mode

1. Open **Google Chrome** browser and click **Chrome Vault** icon. ![](/images/9651553/33d9817a03f3.png)
2. (Optional) The Welcome screen with Auto-pairing process is displayed.**Note:** The auto-pairing screen appears if Oloid vault is not configured. ![](/images/9651553/00d4b6f922bd.png) The application is automatically paired successfully.
3. (Optional) In case auto-pairing fails, you can manually pair the device. For more details, refer [Oloid Vault - How to manually pair an endpoint | Oloid Help Center](/passwordless/web/chrome-vault/oloid-vault-chrome-chromium-how-to-manually-pair-an-endpoint). **Note:** Steps 2 and 3 are optional and appear only if the endpoint is not paired with the Oloid Vault. ![](/images/9651553/a97b1c62f432.png) The welcome screen is displayed.
4. Click **More** option icon (![](/images/9651553/ed164f99b28a.png)) > select **Admin Mode**. ![](/images/9651553/a9bb15597424.png) The **Login as supervisor** screen is displayed.
5. Do the following:Enter **Supervisor** **username**or **email ID**.Enter **Password**.Click **Login**. ![](/images/9651553/310d03543592.png) You are successfully logged in to the admin mode. ![](/images/9651553/deb40f974686.png)

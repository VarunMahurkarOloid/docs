## Introduction

The **Saving Passkeys** option in the Tenant Admin Portal allows the admin to enable saving of passkeys within the Oloid Vault (Chrome / Chromium) application. Once enabled, users can securely save and use passkeys for websites that support passkey logins, ensuring a faster and passwordless authentication experience.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- You must create a Chrome Vault application in the Tenant Admin Portal. To create refer, [How to Create and Configure Chrome Vault Application in the Tenant Admin Portal](/administration/admin-portal/oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).

## Steps to Enable Saving Passkeys

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application. ![](/images/12441699/1a1c053bd1bf.png) The application detail page is displayed.
3. Go to **Configure** tab and do the following:Turn on **Saving Passkeys** toggle to allow users to store passkeys in the Chrome Vault for websites that support passkey logins.Click **Save**. ![](/images/12441699/f98d1f2d7dba.png) The **Saving Passkeys** for Chrome Vault Application is successfully enabled. ![](/images/12441699/072407a087ff.png) Preview Screen The below screenshot shows a preview of the Chrome Vault application after enabling the Saving Passkeys option. ![](/images/12441699/73660bca877b.png)

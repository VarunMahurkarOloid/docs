## Introduction

The **Password** tab in the Supervisor App allows Admin and Supervisor to create Windows credentials for users. Password credentials can be created for either **Domain Users** or **Windows Local Users**, enabling users to authenticate to their assigned Windows devices.

This document comprises of the following:

- [Create credential for domain](#h_e8bfcf534a)
- [Create credential for local windows machine](#h_4b387e4539)

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](/passwordless/windows/supervisor/windows-login-how-to-add-a-user)**

## Steps to Add Password:

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**. ![](/images/9153831/b7be252b2708.png) The**Users**screen is displayed.
3. Select a user to view details. ![](/images/9153831/508a929190e0.png) The **Details** tab is displayed.
4. Select **Password**tab>**+Password**. ![](/images/9153831/d8866e4d47ac.png) The **Create Password** pop-up box is displayed. ![](/images/9153831/16e2961f78ac.png)

## Create credential for domain

1. Select **Domain User** from the **Credential Type** drop-down list.
2. Enter **Display Name**.
3. Enter **Domain Name**.
4. Select one or more **Preferred machines**. By default, the paired endpoint is selected.
5. Enter **Username**of your Windows account.
6. Enter **Password** of your Windows account.
7. Click **Save**. ![](/images/9153831/6ec9119ff8a0.png) The Password is successfully created. ![](/images/9153831/483b998a341f.png) The credential is created and displayed under the **Password** tab. ![](/images/9153831/f14c62d465ba.png)

## Create credential for local Windows machine

1. Select user type as **Local User** from **Select Credential Type**dropdown.
2. Enter **Display Name**.
3. Select **Machine Name**. (System Default paired machine name is selected)**Note**: You can select only single machine name.
4. Enter **User Name**.
5. Enter **Password**.
6. Click**Save**.

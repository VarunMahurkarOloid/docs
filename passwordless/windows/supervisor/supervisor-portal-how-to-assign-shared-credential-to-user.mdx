## Introduction

Shared Credentials are passwords that can be used to access a local windows machine or a domain. It is shared among the users to which they are assigned.

Steps to assign Shared Credential:

1. Log in to the **Supervisor Portal.**The **Users**page is displayed.
2. Click **username** to edit. ![](/images/9684618/5190fafb578a.png)
3. The user details page is displayed. ![](/images/9684618/1891e34bd82f.png)
4. Go to **Credentials** > **Windows** **Passwords** tab > **+ Add Windows Shared Credentials**. ![Image](/images/9684618/12a32169d51c.png) The **Add Shared Credentials**pop-up box is displayed. ![](/images/9684618/41d8cfbc59e1.png)
5. On the pop-up box, select shared credential(s) from **Select Shared Credentials** drop-down list.
6. Select **Assign**.The shared credential is successfully assigned to the user. ![Image](/images/9684618/45e5828384ac.png)

The Supervisor App is a Windows-based application that allows the configuration of Windows Login app. You can set up endpoints, manage users and shared credentials with multiple authentication methods such as badge, PIN, and password. Additionally, it provides network diagnostics, badge reader updates, and sync configuration. The app also works offline through the Oloid Proxy feature.

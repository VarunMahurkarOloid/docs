## Introduction

The Read-only Mode feature limits the Supervisor to viewing data in the Oloid Portal, restricting from performing any actions.

## Steps to enable Read-only Mode for existing Supervisor:

1. Log in to the **Oloid Portal**.
2. On the homepage, go to **user profile icon** from the left panel > Select **Tenant Settings**.![](/images/10650272/a23db1efc46a.png) The **Tenant Settings** page is displayed.
3. Go to **Admin Controls** > select **Supervisors**. ![](/images/10650272/41b1691fecd0.png)
4. Click **Kebab menu** (![](/images/10650272/6d896e5abdbb.png))> **Enable Read-only Mode**. ![](/images/10650272/b41259e4b6d1.png) The **Enable Read-only Mode** confirmation pop-up box is displayed.
5. Click **Enable**.![](/images/10650272/3576c3263f0d.png)

The Read-only Mode is enabled for the Supervisor.

<Frame>
  <img src="/images/10650272/6f36ed2265fa.png" alt="Screenshot" />
</Frame>

<Note>
  Once the Read-only Mode is enabled, the Supervisor cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![](/images/10650272/c9907d8b9d8c.png)) is displayed next to the user name.
</Note>

## ​Steps to enable Read-only Mode while inviting a Supervisor:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **User profile icon**on the bottom left corner of the menu panel. ![](/images/10299914/c8560f399688.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/10650272/091c088d1154.png) The **Tenant Settings** page is displayed.
4. On the **Tenant Settings** page, do one of the following:Go to **Admin Controls** > **Supervisors**tab > **Invite Supervisor**. ![](/images/10650272/706af14064bd.png) Click **Action** > **Invite Supervisor**. ![](/images/10650272/1c5aac7906ef.png) The **Invite Tenant Supervisor**pop-up box is displayed. ![](/images/10650272/cee2ef8eda90.png)
5. On the pop-up box, do the following:Enter **User name** or **Primary ID** of existing User in the search field.Select the accurate user name from the search list. ![](/images/10650272/697f635fef17.png) Select **Read Only Mode** to restrict the Supervisor from performing any action. Click **Invite**. The user is successfully invited as a Tenant Supervisor with Read-only Mode enabled. ![](/images/10650272/6f36ed2265fa.png) **Note**: Once the Read-only Mode is enabled, the Supervisor cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![](/images/10650272/c9907d8b9d8c.png)) is displayed next to the user name.

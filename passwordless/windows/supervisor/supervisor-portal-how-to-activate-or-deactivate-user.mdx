Steps to Activate or Deactivate User:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Click username to edit. ![](/images/9673602/7a171a8eb8fc.png) The user details page is displayed. ![](/images/9669597/06f74be3f37f.png)
3. Do one of the following on **Action** dropdown:Select **Deactivate**. ![](/images/9673602/889f73dd6404.png) **Note**: **Deactivate** button is visible for active users in the action dropdown.The**De-activate User**pop-up box is displayed.Click **Confirm De-activate**. ![](/images/9673602/9c5e12a45431.png) The user status is changed from active to inactive. ![](/images/9673602/d80ccdeaeaae.png) Select **Activate**. ![](/images/9673602/c5110d50b91d.png) The **Activate User**pop-up box is displayed.Click **Confirm Activate**. ![](/images/9673602/26a7c12c75ad.png) The user status is changed from inactive to active. ![](/images/9673602/9d2df8b012b8.png)

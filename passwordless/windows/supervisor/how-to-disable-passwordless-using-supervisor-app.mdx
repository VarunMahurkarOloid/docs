To disable passwordless follow the below steps:

1. Log in to **Supervisor App**.The **Admin Home** screen is displayed.
2. Select **Settings**.![](/images/9053832/020fbed619d3.png)
3. Select **Disable Passwordless**.![](/images/9053832/cbe21b139bb1.png) The **Confirm Disabling** screen is displayed.
4. Select **Disable Passwordless**.![](/images/9053832/f4c84b36d3ec.png) The Passwordless is disabled successfully.The Windows Device Login app is no longer available on the Windows lock screen.

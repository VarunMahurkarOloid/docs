Steps to create CloudKey:

1. Log in to the **Supervisor Portal**. The **Users** page is displayed.
2. Click **username**to edit. ![](/images/9673835/d3cb6459c8bb.png) The user details page is displayed. ![](/images/9673835/fba518291a49.png)
3. Do one of the following:Go to**Credentials**> **Cloud Key**> **+ Create CloudKey** ![Image](/images/9673835/d87201130767.png) Go to **Assign Credential**> **Create CloudKey**. ![Image](/images/9673835/b7b08728775c.png) The **Create CloudKey** pop-up box is displayed. ![](/images/9673835/7591b47f4d11.png)
4. Enter **Start Date / Time** and **End Date/Time.****Note**: You can click **Now**to set the current date and time. The end date is automatically set to 1 year from the current date.You can also click **10 years from Now**to set the **End Date/Time**to 10 years from the current date/time.
5. Click **Create**. The Cloudkey is created and listed on the **CloudKey** tab. ![Image](/images/9673835/a6205e5326f9.png)

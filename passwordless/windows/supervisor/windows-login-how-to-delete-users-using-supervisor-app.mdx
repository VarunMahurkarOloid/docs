## Introduction

The **Delete User** feature in the Supervisor App allows authorized Admins and Supervisors to permanently remove users from the application when they no longer require access.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Supervisors can delete users only if the required Delete User privilege is enabled for the application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)

## Steps to Delete a User:

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. Select **User Management**. ![](/images/9546517/b7be252b2708.png) The **Users** screen is displayed.
3. Select the **User** you want to delete. ![](/images/9546517/508a929190e0.png) The user details screen is displayed.
4. Click Delete on the top right corner of the screen. ![](/images/9546517/079fb06ebe4a.png) The confirmation dialog box is displayed.
5. Click **Confirm**to delete the user.

  <img src="/images/9546517/8e41200228e2.png" alt="Screenshot" />
</Frame>

The user is successfully deleted.

  <img src="/images/9546517/846dcfc046aa.png" alt="Screenshot" />

**Note:**Deleting a user permanently removes the user from the Oloid platform. This action cannot be undone. Supervisors cannot delete users who are assigned to one or more groups.

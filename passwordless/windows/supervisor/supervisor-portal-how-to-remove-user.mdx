The tenant admin must grant the supervisor permission to add or delete users.

<Frame>
  <img src="/images/9674187/afe9ee8efda2.gif" alt="Screenshot" />
</Frame>

Steps to remove user:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Click username to edit. ![](/images/9669611/7a171a8eb8fc.png) The user details page is displayed.
3. On the top-right, go to **Action** > **Delete User**. ![](/images/9674187/739f2efce641.png) A confirmation pop-up box is displayed. ![](/images/9674187/c8b0a62eb35d.png)
4. Click **Delete**.The user is permanently deleted from the Supervisor Portal.

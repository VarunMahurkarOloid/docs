The Supervisors are mapped to all endpoints associated with the assigned applications.

To assign Application to Supervisor

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel.![](/images/10299914/c8560f399688.png)The user profile menu is displayed.
3. Click **Settings.**![](/images/8442453/0fc4618a4373.png) The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**.![](/images/8442453/71dbff7fb537.png)
5. Go to more options of the selected Supervisor.![](/images/8442453/0b7ab7d256e1.png)
6. Click **Add/Delete Application.**![](/images/8442453/0a94e8c73dee.png) The **Add/Delete Application** pop-up box is displayed.![](/images/8442453/05c50636c595.png)
7. Select application from **Application**dropdown.![](/images/8442453/cb1fbcf4562d.png)
8. Click **Add**.![](/images/8442453/298f3ec5234a.png)
9. Click **Save.**

The application is assigned to the Supervisor.

## To Delete Application

1. Go to more options of the selected Supervisor.
2. Click **Add/Delete Application.**
3. The **Add/Delete Application** pop-up box is displayed.![](/images/8442453/4c71d1dd5e1c.png)
4. Delete the desired application.
5. Click **Save**.

The application is removed from Supervisor access and he can no longer view users of that location.

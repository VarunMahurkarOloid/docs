To view updates in Supervisor App :

1. Double-click on Supervisor app ![](/images/9637783/588054bd1a5a.png) icon.The app opens.
2. Select **Updates** in the bottom left. ![](/images/9637783/1627b990bc5f.png) The **About Windows Passwordless** screen opens. ![](/images/9637783/50da9c644af7.png) You can now view the latest updates of the Supervisor App.

Steps to create Oloid Account:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Select user(s) to create Oloid Account. ![](/images/9711943/13c70186e36f.png)
3. Go to **Action > Create Oloid Account**. ![](/images/9711943/60ac7366fe00.png) The Oloid account is created for the selected users. ![](/images/9711943/373219d6724c.png)

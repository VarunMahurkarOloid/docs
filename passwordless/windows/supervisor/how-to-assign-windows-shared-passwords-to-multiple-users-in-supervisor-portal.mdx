**Prerequisite:**

A shared windows password must be created in Tenant Admin Portal/Supervisor Portal.

**Steps to assign windows shared Passwords:**

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. On the Users page, select user(s) to assign Windows Shared Passwords. ![](/images/9706862/9b0ab11c90f4.png)
3. Go to **Action**>**+ Windows Shared Passwords**. ![](/images/9706862/3bc5e6886f06.png) The **Assign Windows Shared Passwords**pop-up box is displayed. ![](/images/11536855/ea89da85c358.png)
4. On the pop-up box, do the following:Select Windows Shared Password(s) from**Windows Shared Passwords**dropdown list.Click **Assign**. The Windows Shared Password is successfully assigned for the selected user(s). ![](/images/9706862/3dca4f496121.png) Related Document[How to Assign Windows Shared Passwords to Multiple Users in Tenant Admin Portal](/administration/admin-portal/how-to-assign-windows-shared-passwords-to-multiple-users-in-tenant-admin-portal)

Steps to create QR code:

1. Log in to the **Supervisor Portal.**The **Users**page is displayed.
2. Click **username** to edit. ![](/images/9669597/d3cb6459c8bb.png) The User Details page is displayed ![](/images/9669597/06f74be3f37f.png)
3. Do one of the following:Go to **Credentials**tab > **QR Code** > select **+ Create QR Code**. ![Image](/images/9669597/ec72b2c94529.png) Go to **Assign Credential** > **Create QR Code**. ![Image](/images/9669597/ab39df41a396.png) The **Create QR Code**pop-up window is displayed. ![](/images/9669597/a283b9111d24.png)
4. On the pop-up box, do the following:Select **QR Code Validity**from the calendar.Enter recipient's **email ID** to share the QR code.Click **Assign**.The QR code is created and listed in the **QR Code**tab. The QR code is sent to the recipient's (user's) email id. ![Image](/images/9669597/7ecae32a804b.png)

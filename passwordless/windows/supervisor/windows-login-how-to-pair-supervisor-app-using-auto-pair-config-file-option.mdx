## Introduction

This document explains how to pair a device as a Supervisor using the Supervisor App.

## Prerequisites

- You must have Admin or Supervisor credentials to perform endpoint pairing.

## To pair Supervisor app using auto-config file

1. Double-click on the **Supervisor App** ![](/images/9637781/588054bd1a5a.png) icon to start. The **Welcome** screen is displayed. You can see the**"Auto-pair config found!"** message.Note: The auto-pair config file is present in your installer file (Installer path\Oloid\Oloid\config). Reach out to [Oloid Support](mailto:support@oloid.ai) if you do not see auto-pair option.
2. Select **Yes, Pair my device**to auto-pair the device. ![](/images/9637781/6ee2097cc3bb.png) The device is pairing. ![](/images/9637781/3eca5c32ea3c.png) The device is paired successfully.
3. Click **Enter Supervisor Mode** to continue as Supervisor. ![](/images/9637781/3b0566e80a17.png)

**Note:**If auto-pair option fails, select **Pair using other Method** to manually pair the device.

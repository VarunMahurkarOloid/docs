To unpair endpoint:

1. Log in to **Supervisor**App.The **Admin Home** screen is displayed.
2. Select **Settings**. ![](/images/9053859/9882f7d8adfb.png)
3. Select **Unpair Endpoint**. ![](/images/9053859/181d65d1bb3a.png) The **Confirm Unpair** screen is displayed.
4. Click **Confirm Unpair**. ![](/images/9053859/d89be8b4ead1.png) The Device is unpaired successfully. **Note:**You can not unpair the device if it is associated with a group.

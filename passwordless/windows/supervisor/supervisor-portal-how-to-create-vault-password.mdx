Steps to create Vault Password:

1. Log in to the **Supervisor Portal.**The **Users**page is displayed.
2. Click the **username** to edit. ![Image](/images/10304522/d07eb41c2813.png) The user details page is displayed.
3. Go to **Credentials** >**Vault Passwords** tab > **+ Create Password**. ![](/images/10304522/d1b123d351de.png) The **Create Vault Password** pop-up box is displayed. ![](/images/10304522/2641f84d1f64.png)
4. Do the following:Enter **Display Name** that helps you identify this password. (Optional)Select**Web**type from **Password Type** dropdown list.Click**Next.** ![](/images/10304522/b34f83e1b85e.png) Enter **Web URL**.Enter **Username**.Enter **Password**.Click **Save.** The password is created and listed in the **Vault Passwords** tab. ![](/images/10304522/81a5d5b61aff.png) ​ ​

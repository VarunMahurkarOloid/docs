Steps to deactivate OloID Account of an User:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Click username to edit. ![](/images/9674152/d3cb6459c8bb.png) The user details page is displayed. ![Image](/images/9674152/a6b8820e4058.png)
3. On the top-right, go to **Action** > **Deactivate Oloid Account**. ![](/images/9674152/034348ba444b.png) A confirmation pop-up box is displayed. ![](/images/9674152/69736288f6d6.png)
4. Select **Block**.The user's Oloid account is removed successfully.**Note**: To recover your account you must create Oloid account.For more information, see **How to create OloID account.**

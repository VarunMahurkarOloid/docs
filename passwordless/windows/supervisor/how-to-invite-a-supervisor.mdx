**Introduction**

A Supervisor is a user with limited access to the Oloid Portal and all the Oloid connected devices.

**Pre-requisite**

- You must be a Tenant Admin to invite a user as Tenant Supervisor.

- You must be an Oloid user to be a Tenant Supervisor.

For adding a new user as a Tenant Supervisor, see [How to add and invite a Supervisor](/passwordless/windows/supervisor/how-to-add-and-invite-a-supervisor)

Steps to invite a Supervisor:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/8231811/dfd4d50049f1.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/10650272/091c088d1154.png) The **Tenant Settings** page is displayed.
4. On the **Tenant Settings** page, do one of the following:Go to **Admin Controls** > **Supervisors**tab > **Invite Supervisor**. ![](/images/10650272/706af14064bd.png) Click **Action** > **Invite Supervisor**. ![](/images/10650272/1c5aac7906ef.png) The **Invite Tenant Supervisor**pop-up box is displayed. ![](/images/10650272/cee2ef8eda90.png)
5. On the pop-up box, do the following:Enter **User name** or **Primary ID** of existing User in the search field.Select the accurate user name from the search list. ![](/images/8231811/d828a2bbb354.png) Select **Read Only Mode** to restrict the Supervisor from performing any action. (Optional)Click **Invite.**The tenant supervisor is listed on the **Supervisors**tab. An invite email is sent to the user for verification. ![](/images/8231811/8cdee52db4e0.png)

## Introduction

Shared Credentials are passwords that can be used to access a local Windows machine or a domain. It is shared among the users to whom they are assigned.

This document comprises the following:

- [Create Shared Credential for Domain User](#h_933b4e9ac8)
- [Create Shared Credential for Local User](#h_a1f859a58e)

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)

## Steps to Create Shared Password for Domain user

1. Log in to **Supervisor App**.The **Admin Home** screen is displayed.
2. Select **Shared Credentials**. ![](/images/9045726/b718cc04af91.png)
3. Select **Shared Password**. ![](/images/9045726/ff70ebb8a70b.png) The**Shared Password**page is displayed.
4. On the top right, click **+ Create**. ![](/images/9045726/3b4fcd8aedb3.png) The **Create Shared Password** page is displayed.
5. Do the following:Select **Credential Type**as Domain User.Enter **Display Name**.Select**Users** for **Credential Owner**. (System Default)Enter **Domain Name**. Select **Preferred Machine**from the Preferred Machine list. (System Default paired machine name is selected)Enter **Username**. Enter **Password**.Enter **External ID**. (Optional)Click **Create Password**.

## Steps to Create Shared Password for Local User

1. Log in to **Supervisor App**.The **Admin Home** screen is displayed.
2. Select **Shared Credentials**. ![](/images/9045726/b718cc04af91.png)
3. Select **Shared Password**. ![](/images/9045726/ff70ebb8a70b.png) The**Shared Password**page is displayed.
4. On the top right, click **+ Create**. ![](/images/9045726/3b4fcd8aedb3.png) The **Create Shared Password** page is displayed.
5. Do the following:Enter **Display Name**.Select user(s) for **Credential Owner**. (System Default)Select**Machine.**(System Default paired machine name is selected)Enter **User Name**.Enter **Password**.Enter **External ID**. (Optional)Click **Create Password**.

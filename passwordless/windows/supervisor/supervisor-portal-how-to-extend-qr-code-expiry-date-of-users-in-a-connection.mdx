Steps to extend QR Code expiry date for a Connection:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed. ![](/images/9673773/48d284734a3d.png)
2. Go to **Action**> **Extend QR Code Expiry Date**. ![](/images/9673773/3e5f9ff9d48a.png) The **Extend QR Code** pop-up box is displayed. ![](/images/9673773/e03423180f80.png)
3. On the pop-up box, do the following:Select a preferred connection from the **Connection** dropdown list.Under **QR Code Validity** field adjust the date and time from the calendar icon.Under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary.Click **Assign**.The QR Code is successfully extended for users in the selected connection. The QR Code summary of these users is shared over email ID(s).

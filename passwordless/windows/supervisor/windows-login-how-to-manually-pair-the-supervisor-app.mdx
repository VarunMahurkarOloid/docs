## Introduction

This document explains how to pair a device as a Supervisor using the Supervisor App.

## Prerequisites

- You must have Admin or Supervisor credentials to perform endpoint pairing.

## Steps to Pair as Supervisor

1. Double-click on the **Supervisor App** to start. ![](/images/9036798/7be9650e5076.png) The **Welcome** screen is displayed.
2. Enter **Tenant Name / Customer Code**.
3. Click **Next**. ![](/images/9059601/abc2dca713f9.png) The Select Environment screen is displayed.
4. Choose the required environment > click **Next.** ![](/images/9059601/638ee7f92e41.png) The **Pair As Supervisor** login screen is displayed.
5. Enter Supervisor **Email ID** and **Password** > Click **Login**. ![](/images/9059601/b14b198c0f1c.png) The **Pair as Supervisor** screen is displayed.
6. Do the followingSelect **Template** (Optional).Enter **Endpoint Name**. **Note:**The endpoint name field is auto-populated with the machine name by default, though it can be manually edited as required.Select **Application Name**. ![](/images/9059601/b040d82a1d6f.png)

Click **Pair Device**.

The endpoint is successfully paired and a success message is displayed.

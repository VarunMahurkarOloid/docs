## Introduction

Shared Credentials can be updated after they are created to reflect changes such as the display name, username, password, associated machine, preferred machines, or external ID.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure the shared credential is created. For more information, refer: **[How to Create Shared Credentials Using the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-create-shared-password-using-the-supervisor-app)**.

## Steps to view and edit Shared Password:

1. Log in to **Supervisor App**.The **Admin Home** screen is displayed.
2. Select **Shared Credentials**. ![](/images/9045726/b718cc04af91.png)
3. Select **Shared Password**. ![](/images/9045726/ff70ebb8a70b.png) The**Shared Password**page is displayed.
4. Select one of the following based on the type of shared credential you want to edit: [View and Edit Local Shared Credential](#h_936652798a)[View and Edit Domain Shared Credential](#h_34a2cf7044) The respective (Local / Domain) Shared Credential screen is displayed.

## View and Edit a Windows Local User Shared Credential

1. Select the required Shared Password from the list.
2. Go to **Details** tab. ![](/images/9196014/5b774e8fff72.png)
3. Edit **Display Name**.
4. Select **Machine**from the **Select Machine** list.Select a machine and then click **Assign**. ![](/images/9196014/1b93052bc7e1.png)
5. Edit **Username**.
6. Enter **Password**. (Optional)
7. Enter **External ID**. (Optional)
8. Click **Save.**

## View and Edit a Domain User Shared Credential

1. Select the required Shared Password from the list.
2. Go to **Details** tab. ![](/images/9196014/4c1e57e4a6a4.png)
3. Edit **Display Name**.
4. Edit **Domain Name**.
5. Select **Preferred Machine**from the **Select Preferred Machine** list.Select machine(s) and then click **Assign**. ![](/images/9196014/8e12a4902a68.png)
6. Edit **Username**.
7. Enter **Password**. (Optional)
8. Enter **External ID**. (Optional)
9. Click **Save.**

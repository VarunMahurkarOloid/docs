## Introduction

Credential Owners are users who are authorized to manage a shared credential. Assigning Credential Owners allows designated Admins or Supervisors to maintain ownership of shared credentials and manage them as required.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure the shared credential is created. For more information, refer: **[How to Create Shared Credentials Using the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-create-shared-password-using-the-supervisor-app)**.

## Steps to Assign Password Owners

1. Log in to **Supervisor App**.The **Admin Home** screen is displayed.
2. Select **Shared Credentials**. ![](/images/9045726/b718cc04af91.png)
3. Select **Shared Password**. ![](/images/9045726/ff70ebb8a70b.png) The**Shared Password**page is displayed.
4. Select **Credential Owners** tab > **+ Assign Owners**. ![](/images/9188537/9b267592649c.png) The **Select Credential Owner**pop-up box is displayed.
5. You can select credential owner(s) from the displayed list.**Note**: You can search the credential owner(s).
6. Click **Assign**.

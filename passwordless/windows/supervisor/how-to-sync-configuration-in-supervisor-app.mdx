To sync configuration:

1. On the admin home page, select **Settings**. ![](/images/9053832/020fbed619d3.png)
2. Select **Sync Configuration**. ![](/images/9329264/f90339c6f26f.png) The Syncing Configuration is initiated. ![](/images/9329264/5f6f7c925d30.png) The Supervisor App configuration is updated successfully. ![](/images/9329264/6aa59a225d0b.png)

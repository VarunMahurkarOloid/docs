**Introduction**

A user transaction is a record of a user's activity that captures important details such as the date and time of the action, the type of credential used (e.g., NFC, QR code, batch, pin), the name of the application accessed, and the endpoint involved. These transactions help track and analyse user interactions.

**Steps to view and download user transaction report:**

1. Log in to the **Supervisor Portal .**
2. On the home page of the portal, click **Transactions** on the left menu panel. ![](/images/11401404/72860658d479.png) The **User Transactions** page is displayed.
3. Click**Export to excel icon**. ![](/images/11401404/c8b6b7d41139.png) The **Export to Excel** pop-up box is displayed. ![](/images/11401404/0adbfec426db.png)
4. (Optional) **Customize the report** by configuring the following options:**From Date & Time**: Select the start date and time.**To Date & Time**: Select the end date and time.**Time Zone**: Select a time zone.**Use Application Time Zone**: Enable to apply the application's configured time zone.**Note:** This option only works if a time zone is set in the application. If different time zones are selected for the application and export, the application's time zone takes priority when this option is enabled.To set time zone in the preferred application, go to home page > select the Application > Details tab > Time Zone. **Transaction Status**: Select one or more statuses.**Application Names**: Select the relevant application(s).**Endpoint Names**: Select the desired endpoint(s).**User’s Primary ID**: Enter the User's **Primary ID**.**Mode**: Select the transaction mode.**Face Match Status**: Filter by face match status.
5. Click **Download** to export the report. The **user transaction report is downloaded** to your device in Excel format.

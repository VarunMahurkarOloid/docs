The preferred credential is applicable for domain user.

To mark as preferred credential:

1. On the admin home page, select **Shared Credentials**. ![](/images/9324029/277811b34948.png) The **Shared Credentials** screen is displayed.
2. Select **Mark as Preferred Credential**![](/images/9324029/be5f9fd32348.png)icon on a shared credential. ![](/images/9324029/b2676d4e999d.png)
3. Select Confirm to add your endpoint as preferred machine on the displayed pop-up box. ![](/images/9324029/d1f78a566bb2.png) The shared credential is marked as preferred machine successfully. ![](/images/9324029/d30a6ed9665b.png) **Note:** To remove shared credential as the preferred machine, you can unstar them.

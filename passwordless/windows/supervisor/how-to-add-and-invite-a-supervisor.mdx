**Introduction**

A Supervisor is a user with limited access to the Oloid Portal and all the Oloid connected devices.

For adding an existing user as Supervisor, see [How to invite a Supervisor](/passwordless/windows/supervisor/how-to-invite-a-supervisor).

**Pre-requisite**

You must be a Tenant Admin to add a new user as a Supervisor.

**Steps to add and invite a new user as Supervisor:**

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left. ![](/images/8262858/dfd4d50049f1.png) The **user profile menu** is displayed.
3. Click **Tenant** **Settings**. ![Image](/images/8262858/dd6256eec1ca.png) The **Tenant Settings** page is displayed. ![](/images/8262858/be4528d52641.png)
4. Do the following:Go to **Admin Controls** > **Supervisors**> **Invite Supervisors**. ![](/images/8262858/326a1561bb42.png) OR Click **Action** > **Invite Supervisor**. ![](/images/8262858/1c5aac7906ef.png)
5. The **Invite Tenant Supervisor** pop-up box is displayed. ![](/images/8262858/cee2ef8eda90.png)
6. On the pop-up box, do the following:Enter the user name in the**Search By User or Primary ID**field.The search result lists down if there is any existing user.Click **Add user** to add a new user. ![](/images/8262858/53321e81edd3.png) The **Create Tenant Supervisor** pop-up box is displayed for the new user. ![](/images/8262858/7751c7d49e88.png) Edit **Full Name**. (if required).Enter **Primary ID** or select **Use OloID as Primary ID** to use OloID for your primary ID. Select connection from the **Connection** list.Enter **Supervisor Email.** Select **Read Only Mode** to restrict the Supervisor from performing any action. (Optional)Click **Create & Invite**.The Tenant Supervisor is created and listed on the **Supervisors**tab. **Note**: An email is sent to the user for verification. ![Image](/images/8262858/2219d93d13e8.png) Video TutorialWatch the video [How to add and invite a supervisor in Tenant Admin Portal-Video Tutorial](/administration/admin-portal/how-to-add-and-invite-a-supervisor-in-tenant-admin-portal-video-tutorial)

Steps to generate QR Code :

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Select user(s) to generate QR Code. ![](/images/9673768/3c2718b744cc.png)
3. Go to **Action > Generate QR Code Credential**. ![](/images/9673768/f0bbc977a24a.png) The **Generate QR Code** pop-up box is displayed. ![](/images/9673768/4e3865d0a290.png)
4. Do the following:Under **QR Code Validity** field adjust the date and time from the calendar icon.Under **Share Summary With**field enter the email ID(s) with whom you would like to share the QR Code summary.Select **Send QR Code**to share QR Code with selected users (Optional).Click **Assign**.The QR Code credential is successfully assigned to the selected users. The QR Code summary of these users is shared over email ID(s).

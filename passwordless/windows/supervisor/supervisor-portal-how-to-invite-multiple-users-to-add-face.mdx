Steps to invite multiple users to add Face

1. Log in to the **Supervisor Portal**.The **Users**page is displayed.
2. Select user(s). ![](/images/9673777/4f3e03e20148.png)
3. On top right, Click **Action** > **Send email**> **Invite to add face**. ![](/images/9674132/e6d8fe105c4d.png) An email invite link is sent to the users to upload their face. ![](/images/9674132/d8b7cc322841.png)

To upload face using the invite link, see [How to add face using the invite link](/administration/user-portal/how-to-add-a-face-using-invite-link-in-oloid-user-portal).

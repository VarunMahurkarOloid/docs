Steps to download the files:

1. Log in to the **Supervisor Portal**.
2. On the homepage of the portal, click **User profile icon**on the bottom left corner of the menu panel. ![](/images/9690938/ba7229a076cd.png) The user profile menu is displayed. ![](/images/9690938/dc6b7d352fb1.png)
3. Select **File Sharing**. ![](/images/9690938/ab921c5af5ee.png) The **File Sharing**page is displayed. ![](/images/9690938/a7d1c22dc6a1.png)
4. Select the preferred file to download. ![Image](/images/9690938/97b0cc459a39.png) The file is downloaded.

Enabling Oloid Proxy allows the Supervisor app to work offline using Proxy server.

This document comprises of the following:

- [Enabling Oloid Proxy when Tenant is not configured](#h_e426a624ec)
- [Enabling Oloid Proxy when Tenant is already configured](#h_3b52919072)

## To enable Oloid Proxy when Tenant is not configured

1. Double-click on the **Supervisor Flow** app.
2. Enable**Use Proxy to connect to Oloid Cloud**. ![](/images/9053378/8a77c362350d.png)
3. Enter**OLOID Proxy URL**.**Note**: Contact [Oloid Support](mailto:support@oloid.ai) for the OLOID Proxy Url.
4. Click **Next**. ![](/images/9053378/79475e65961d.png) The **Pair Endpoint**screen is displayed.

## To enable Oloid Proxy when Tenant is configured

1. Log in to the**Supervisor Flow**app.The **Admin Home** screen is displayed. ![](/images/9053378/4a1ffa606b02.png)
2. On the bottom right, select **More Options** > **OLOID Proxy Setup**. ![](/images/9053378/70f551c53ad9.png) The **OLOID Proxy Setup**screen is displayed.
3. Enable**Use Proxy to connect to Oloid Cloud**. ![](/images/9053378/778252e53d9d.png)
4. Enter**OLOID Proxy URL**.**Note**: Contact [Oloid Support](mailto:support@oloid.ai) for the OLOID Proxy Url.
5. Click **Confirm**. ![](/images/9053378/5e3141489420.png) The Oloid Proxy Settings is successfully updated. ![](/images/9053378/edea50a07295.png)

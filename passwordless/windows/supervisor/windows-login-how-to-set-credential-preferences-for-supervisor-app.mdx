## Introduction

Credential preferences allow Tenant Admin to define the authentication methods that are available and prioritized in the Supervisor App. These preferences determine which credential types are presented during user enrollment and authentication workflows.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Set credential preferences for Supervisor App

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10441578/b90c325f9cf8.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/10441578/e184a5672785.png) The **Tenant Settings** page is displayed.
4. Click **Preferences**. ![](/images/8803434/a71b956fc06c.png) The **Let's customize the portal for you** pop-up box is displayed.
5. Do the following: Select the preferred **Credentials** you want to use.Click **Next**. ![](/images/8803434/ad7c41c0c0f4.png) Select the **Primary** **Credentials**.Click **Save & Next**. ![](/images/8803434/e9de31e57a10.png) Select the **Use-cases** for which you intend to use the Oloid Portal.Click **Finish Setup**.

  <img src="/images/8803434/d8ef31ea8719.png" alt="Screenshot" />
</Frame>

The selected credential preferences are applied successfully and are available for the configured use cases.

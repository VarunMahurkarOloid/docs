## Introduction

A user's PIN can be updated at any time to maintain security or comply with organizational policies. Admins and Supervisors can view the user's PIN details and update the PIN through the Supervisor App.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](/passwordless/windows/supervisor/windows-login-how-to-add-a-user)**

## Steps to View and Edit PIN:

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**. ![](/images/9116073/756dc404309e.png) The**Users**screen is displayed.
3. Select the user whose PIN you want to view or edit. ![](/images/9116073/508a929190e0.png) The User details screen is displayed.
4. Select **PIN**tab >click the**Edit**icon. ![](/images/9116073/318b8aeff244.png) The **Edit PIN** pop-up box is displayed.
5. Do the following:Enter your new PIN.Re-enter your new PIN.Enter one or more email addresses in the **Share PIN with** field to share the updated PIN. (Optional)Click **Update**.

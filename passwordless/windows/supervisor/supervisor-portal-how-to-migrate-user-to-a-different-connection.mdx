Steps to Migrate User to a different Connection:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Click username to edit. ![](/images/9669611/7a171a8eb8fc.png) The User details page is displayed.
3. Go to **Action** > Select**Migrate User**. ![](/images/9674164/6792a3c35fc1.png) The **Migrate User** pop-up box is displayed. ![](/images/8379283/d738d258f503.png)
4. Select connection to map from **Connection**dropdown.
5. Click **Save**.

The user is migrated and mapped to the new connection. The updated connection for the user is displayed on the Users page.

Steps to delete QR Code Credential of Users in a Connection:

1. Log in to the **Supervisor Portal**.The **Users** page is displayed. ![](/images/9674159/ab0e3496d781.png)
2. Go to **Action**> **Delete QR Code Credential**. ![](/images/9674159/030767c32e6e.png) The **Delete QR Code Credential**pop-up box is displayed. ![](/images/9674159/6f5244a48639.png)
3. On the pop-up box, do the following: Select connection from **Connection** dropdown list to delete QR Code for users in the selected connection.On **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary.Click **Delete**.The QR Code is successfully deleted for the selected users and summary details are shared with respective email IDs.

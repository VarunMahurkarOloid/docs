Steps to reset password for Supervisor:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/8232355/3aac3cc42385.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![Image](/images/8232355/dd6256eec1ca.png) The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**. ![](/images/8232355/896b75e055c7.png)
5. Click **kebab menu** (three vertical dots) and select **Reset Password**for a Supervisor. ![](/images/8232355/bec25e175377.png) The **Reset password** pop-up box is displayed. ![](/images/8232355/a7645109416f.png)
6. Click **Confirm**.The user reset password link is successfully sent to the Supervisor's email ID. ![](/images/8232355/8bc983c40637.png)

## Introduction

QR Code assignment allows the Supervisor to generate and assign QR-based credentials to users through the Supervisor App. These QR codes can be shared with users for authentication, providing a secure and contactless login option.

## Prerequisite

Ensure the Endpoint is paired.

You must have Admin or Supervisor credentials.

## Steps to Add QR Code

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**. ![](/images/15457358/4e1294f75e0c.png) The **Users**screen with list of users is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top. ![](/images/15457358/92e141f4430d.png) The user's**Details** screen is displayed
4. Select **QR Code**tab > Tap **ADD +**. ![](/images/15457358/00eaff2ff203.png) The Create QR Code pop-up box is displayed.
5. Do the following:Select the QR Code Validity date.Enter Email ID of user(s) to Share QR Code with.Tap **Create.**

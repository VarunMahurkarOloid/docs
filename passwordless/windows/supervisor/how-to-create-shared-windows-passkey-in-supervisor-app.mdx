## Introduction

The **Create Shared Passkey** feature in the Windows Supervisor App allows the authorized supervisor to generate and assign Windows shared passkeys to user(s).

## Prerequisites

- You must have access to Supervisor account.
- You must have a Windows Pro Machine.
- OpenVPN must be enabled for authenticating with passkey.
- Domain account must be created for the User.

## Steps to Create Shared Passkey in Windows Supervisor app

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Supervisor App Home** screen is displayed.
2. Click **Shared Credentials** ![](/images/14338949/8b9c61ad474d.png) The **Shared Credentials**screen is displayed
3. Select **Shared Passkey**. ![](/images/14338949/9cbb98ce80c1.png) The **Shared Passkey**details page is displayed
4. Click **Create**. ![](/images/14338949/150342b56b26.png) The Create Shared Passkey pop-up box is displayed.
5. Do the followingEnter **Display Name**Edit **Domain Name**Enter **Username**Select **Credential Owner(s)**Enter **Tags.**(Optional)Enter **External ID**(Optional)Click **Generate.**

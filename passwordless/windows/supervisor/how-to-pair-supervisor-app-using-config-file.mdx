## Pre-requisite

If endpoint is created through the Oloid Portal, you need to download the config file of the preferred endpoint from the Oloid Portal. For details, refer [How to download endpoint config file for Windows Login?](https://oloid.help/en/articles/8778331-how-to-download-endpoint-config-file-for-windows-login)

To pair an endpoint:

1. Double-click on the **Supervisor App** to start.![](/images/9036798/7be9650e5076.png) The **Pair Endpoint**screen is displayed.
2. Select**Pair Device Using Config File**.![](/images/9036798/0799d87080fe.png) The **Pair Device Using Config File** screen is displayed.
3. Select the json file you want to upload and click **Open**.![](/images/9036798/b60cbce83544.png) **Note**: Check mark to **Use the Machine Name as Endpoint Name**(Optional).
4. Click to **Upload** the endpoint JSON file.**Note**: You can choose **Reset** to upload the JSON file again.The **Pairing endpoint** screen is displayed.
5. The **Endpoint Name**is auto-populated.![](/images/9036798/3685918cb7e2.png)
6. Select **Publish**.The endpoint is paired successfully.![](/images/9036798/529483d99f9a.png) Now, you can log in to admin mode.![](/images/9036798/93e7c05c9c00.png)

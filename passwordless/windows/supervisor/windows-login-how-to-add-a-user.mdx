## Introduction

The Add User feature in the Supervisor App allows authorized Admins and Supervisors to create user accounts directly from a paired Windows endpoint.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure the required **Add User** privilege is enabled for the Supervisor. Without this privilege, Supervisors can only view users and their details.
- Ensure the **Add User** action is enabled for the application in the Tenant Admin Portal. If the **Add User** button is unavailable, contact your Tenant Admin. For more information, refer [How to Activate Add User Action on the App for Supervisor](/administration/admin-portal/windows-login-how-to-enable-add-delete-users-in-tenant-admin-portal-for-supervisors) guide.
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal.

## Steps to Add User:

1. Log in to **Supervisor App**. The **Admin Home** screen is displayed.
2. Click **User Management**. ![](/images/9041346/756dc404309e.png) The **Users** screen is displayed.
3. Select **+Add User**at the top right. ![](/images/9041346/883fb1ad2b8d.png) The **Add User** screen pop-up box is displayed.
4. Do the following:Enter **Name**.Enter **Primary ID**.Enter **Secondary ID** ( Optional)Click **Select Connection**.The Select Connection pop-up box is displayed. Do the following:Select **Connection** from the list.**Note**: You must add connection(s) to the selected application in the Tenant Admin Portal.Click **Add.** ![](/images/9041346/a1451f8f0a94.png)
5. Click **Add User**.

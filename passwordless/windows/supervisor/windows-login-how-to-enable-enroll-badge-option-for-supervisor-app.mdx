## Introduction

The Enable Badge Options setting allows Tenant Admin to control the badge enrollment options available in the Supervisor App. Depending on your authentication requirements, you can allow users to enroll using Badge only or require Badge + PIN authentication.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login application is created in the Tenant Admin Portal. For more information, refer [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable Badge Enrollment Options:

1. Log in to the Tenant Admin Portal.The Application Detail page is displayed.
2. Select the application that is configured in the Supervisor App. ![](/images/9182568/ab1f40d15779.png) The Application Details page is displayed.Go to **Configure** > click **Customize Buttons**> click **Enable Badge Options**. ![](/images/9182568/66c8c39de81d.png) The Configuration page is displayed.
3. Do one of the following:Select **Enroll Badge Only** to allow badge-only enrollment.Select **Enroll Badge + PIN** to require badge and PIN authentication.
4. Click **Save**.

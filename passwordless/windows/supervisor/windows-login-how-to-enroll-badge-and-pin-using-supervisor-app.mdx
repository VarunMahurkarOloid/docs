## Introduction

The Enroll Badge + PIN feature in the Supervisor App allows Admin and Supervisor to enroll a badge and configure a PIN for a user in a single workflow. The enrolled badge and PIN can then be used together as a multi-factor credential for Windows Login authentication.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- **Enable Badge Options** must be enabled in the Oloid Portal for the Enroll Badge option in the Supervisor App. Refer to **[How to enable badge option for Supervisor App.](/passwordless/windows/supervisor/windows-login-how-to-enable-enroll-badge-option-for-supervisor-app)**
- Ensure a supported badge reader is connected to the system.
- Ensure the user exists in the Tenant Admin Portal.

## Steps to Enroll Badge and PIN:

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. Click **Enroll Badge.** ![](/images/9046439/eae25b50b072.png)
3. Click **Enroll Badge.** ![](/images/9046439/0b9a7a9983bf.png) The **Enroll For Badge Login** screen is displayed.
4. Enter **Employee ID**.**Note**: Employee ID is the primary ID of the employee in the **Tenant Admin Portal**. Select **Make Employee ID case sensitive**checkbox to enable case sensitivity for Employee ID. (Optional)
5. Click **Continue**. ![](/images/9046439/b44f04b3aa11.png) The Scan Your Badge screen is displayed.
6. Do the following:Scan your badge in the Badge Reader. The scanned badge number is automatically populated in the Scan Badge field.Click **Submit**. ![](/images/9046439/2016653c077b.png) **Note:**If a PIN already exists for the user, the Edit PIN screen is displayed. Otherwise, the **Create PIN** screen is displayed.
7. Do one of the following:To update PIN, follow the screen instructions in the**Edit PIN** screen and click **Update**. **Note**: Click **Skip** to escape the step and the badge is enrolled successfully. ![](/images/9046439/797aaf304cb6.png) **(OR)** To add a new PIN, follow the screen instructions in the **Create PIN** screen and click **Create**. ![](/images/9046439/bdc0be6df1cc.png) Now, you have Badge and PIN enrolled successfully. ![](/images/9046439/e6ab5864d8c6.png)

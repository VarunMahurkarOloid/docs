## Introduction

Shared Credentials are passwords that can be used to access a local windows machine or a domain. It is shared among users to which they are assigned to.

This document comprises the following:

- [Create shared credential for local windows machine](#h_bad46f5497)
- [Create shared credential for domain](#h_14af33233d)

## Create shared credential for local windows machine

To create Shared Credential:

1. Log in to the **Supervisor Portal.**The Users page is displayed. ![](/images/9680203/6ffcf34ed62b.png)
2. Click **Shared Credentials**>**Windows Passwords**on the left menu panel. ![Image](/images/9680203/8b451d0b0d1d.png) The Windows Passwords page is displayed. ![Image](/images/9680203/3197962e5fd4.png)
3. On the top right, click **Create Credentials**. ![Image](/images/9680203/45913e761ab9.png) The **Create Windows Shared Password**pop-box is displayed.
4. Do the following: ![](/images/9680203/f22a86d0f4bf.png) Enter **Display Name** that displays on the Windows Login page.Select credential type as **Local User** from **Credential Type** dropdown.Select **Credential Owner List**from the dropdown list.Select **Next**. ![](/images/9680203/2a2ff77ba280.png) Enter **Machine Name**.**Note**: Enter your Windows device name.Enter**Username** of your Windows Login.Enter **Password** of your Windows Login.Click **Save**.The credential is created and listed on the**Shared Credentials** page. ![Image](/images/9680203/11bf6ce278e3.png)

## Create shared credential for domain

To create Shared Credential:

1. Log in to the **Supervisor Portal.** ![](/images/9680203/6ffcf34ed62b.png) The Users page is displayed.
2. Click **Shared Credentials**> **Windows Passwords** on the left panel. ![Image](/images/9680203/8b451d0b0d1d.png)
3. The Windows Passwords page is displayed. ![Image](/images/9680203/3197962e5fd4.png)
4. On the top right, click **Create Credentials**. ![Image](/images/9680203/45913e761ab9.png) The **Create Windows Shared Password**pop-box is displayed.
5. On the pop-up box do the following: ![](/images/9680203/f22a86d0f4bf.png) Enter **Display Name**.Select user type as **Domain User** from **User Type** dropdown.Enter user name then select **Credential Owner**from the dropdown list.Select **Next**. ![](/images/9680203/3dbae86443d5.png) Enter **Domain Name**.Select **Preferred Machine(s)**.Enter**Username** of your Windows Login.Enter **Password** of your Windows Login.Click **Save**.The credential is created and listed on the**Shared Credentials** page. ![Image](/images/9680203/f00a8b7bf760.png) **Related Document** ​[Supervisor Portal - How to assign shared credential to user](/passwordless/windows/supervisor/supervisor-portal-how-to-assign-shared-credential-to-user) Video TutorialWatch the video [How to create shared credentials for Windows login in Supervisor Portal- Video Tutorial](/passwordless/windows/supervisor/how-to-create-shared-credentials-for-windows-login-in-supervisor-portal-video-tutorial) ​ ​

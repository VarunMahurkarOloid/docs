Steps to add Credential Owners:

1. Log in to the **Supervisor Portal.**The Users page is displayed. ![](/images/9680203/6ffcf34ed62b.png)
2. Click **Shared Credentials**>**Windows Passwords**. ![Image](/images/9680203/8b451d0b0d1d.png) The Windows Passwords page is displayed.
3. Select credential name to edit. ![Image](/images/9684906/d8acacd34e6b.png)
4. Select **Credential Owners**tab >**+ Add Credential Owners**. ![Image](/images/9684955/981d8f5d48cb.png) The **Add Credential Owners**pop-up box is displayed. ![](/images/9684955/3785dc256aee.png)
5. On the pop-up box, enter user name(s) or primary ID(s) in the **Users**dropdown list.
6. Select **Assign**. The credential owners are successfully assigned. ![Image](/images/9684955/b57e42581488.png)

Steps to delete QR Code of user(s):

1. Log in to the **Supervisor Portal**.The **Users** page is displayed.
2. Select user(s) to delete QR Code. ![](/images/9674161/4f3e03e20148.png)
3. Go to **Action > Delete QR Code Credential**. ![Image](/images/9674161/376a17f81f05.png) The **Delete QR Code Credential**pop-up box is displayed. ![](/images/9674161/d1f876de923e.png)
4. On the pop-up box, do the following:Under **Share Summary With**field enter the email ID(s) with whom you want to share the QR Code summary.Click **Delete**.The QR Code credential is successfully deleted for the users. The QR Code summary of these users is shared over email ID(s).

## Pre-requisite

Face should be added to the user.

## Steps to find Face:

1. Log in to the **Supervisor Portal.**The Users page is displayed.
2. Click **username** to edit. ![](/images/9669611/7a171a8eb8fc.png) The User details page is displayed. ![](/images/9669611/e7fbecc6f46f.png)
3. Go to **Action** > Select**Find Face**. ![](/images/9669611/c6f3662bc17d.png) The **Find Similar Faces** pop-up box is displayed. ![](/images/8355149/166775c31338.png)
4. On the **Find Similar Faces** pop-up box, do the following:Enter **Confidence** **level**.**Note**: For best results, increase confidence level above default value.Select required connection(s) from the**Connection** drop-down list.Click **Search**.The **Results for Similar Faces** pop-up box is displayed.The search result shows confidence level face match.**Note**: This functionality is for Oloid internal use.

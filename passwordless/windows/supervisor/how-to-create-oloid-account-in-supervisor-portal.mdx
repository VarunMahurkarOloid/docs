**Introduction**

An Oloid account is a User's unique ID created within the Supervisor Portal, enabling users to access Oloid’s applications.

**Pre-requisite:**

- You must provide your email address or phone number to create OloID Account.
- You must turn on **Enable OloID Account**toggle button on the Connection detail page. For more information, see**[How to Enable OloID account in Connection](/administration/admin-portal/tenant-admin-portal-how-to-enable-oloid-account-for-a-connection)**.

**Steps to Create Oloid Account:**

1. Log in to the **Supervisor Portal**.
2. On the home page of the portal, click User Name to edit. ![](/images/11401882/2dd00961a96b.png)The User details page is displayed.
3. Go to **Action** > **Create Oloid Account**. ![](/images/11401882/833166f38e63.png) An Oloid account is created successfully.

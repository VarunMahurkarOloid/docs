**Prerequisite:**

Windows Passkey must be enabled in the Tenant Admin Portal.

**Steps to add Passkey:**

1. Log in to the**Supervisor App**.
2. On the Admin Home screen, select **User Management**. ![](/images/11829502/09585907661b.png) The**Home**screen is displayed.
3. Select the preferred user to view details. ![](/images/11829502/e7c3aca33a17.png)
4. Go to **Passkey**tab > select +**Passkey**. ​![](/images/11829502/bda05b55eb31.png) The **Create Passkey** pop-up box is displayed
5. On the pop-up box, do the following:Enter **Display Name**.Enter **Domain Name**.Enter **Username**.Select **Preferred Machine**.Click **Generate**. ![](/images/11829502/ec45419fdd4b.png) The Passkey is successfully assigned. ![](/images/11829502/edccda67c993.png)

You can view and download diagnostics report from Supervisor app in the following ways:

- [Using Network Diagnostics](#h_3b87719f44)
- [Using Settings Feature](#h_d55d284dce)

## Using Network Diagnostics

To view diagnostics and download report:

1. Double-click on Supervisor app ![](/images/9040866/7f2681bd2966.png) icon.The app opens.
2. Click **More Options** > **Network Diagnostics**. ![](/images/9040866/b5aa10704b9f.png) The **Diagnostics** screen opens. You can view all the active URLs.**Note:**Type **Custom URL** in the text field and press **Enter**. (Optional) ![](/images/9040866/683d63063984.png)
3. Do the following:Click **Diagnose** to refresh the URLs. ![](/images/9040866/1c750154f311.png) The URLs get refreshed with status.Click **Download Report** to download the diagnostic report. ![](/images/9040866/a287d0440bd7.png) The diagnostic report is successfully downloaded to the local device

## Using Settings Feature

1. Double-click on Supervisor app![](/images/9040866/7f2681bd2966.png) icon.The app opens.
2. Log in to **Supervisor App**.The **Admin Home** screen opens.
3. Click **Settings**.![](/images/9040866/e8b4ef8db875.png) The **Settings** screen opens.
4. Click **Diagnostics**. ![](/images/9040866/683d63063984.png)
5. The **Diagnostics** screen opens. You can view all the active URLs. ![](/images/9040866/683d63063984.png) **Note:**Type **Custom URL** in the text field and press **Enter**. (Optional)
6. Do the following:Click **Diagnose** to refresh the URLs. ![](/images/9040866/1c750154f311.png) The URLs get refreshed with status.Click **Download Report** to download the diagnostic report.

The diagnostic report is successfully downloaded to the local device.

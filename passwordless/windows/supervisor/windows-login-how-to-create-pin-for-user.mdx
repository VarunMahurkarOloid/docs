## Introduction

Admin and Supervisor can create a PIN for a user through the Supervisor App and optionally share it with the user via email.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](/passwordless/windows/supervisor/windows-login-how-to-add-a-user)**

## Steps to Create PIN:

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Admin Home** screen is displayed.
2. Select **User Management**. ![](/images/9088123/756dc404309e.png) The**Users**screen is displayed.
3. Select the user to view details. ![](/images/9088123/508a929190e0.png) The user details page is displayed.
4. Go to **PIN**tab > Click **Add**. ![](/images/9088123/504d310ebb87.png) The **Create PIN** dialog box is displayed.
5. Do the following:Enter **new PIN**.Re-enter **new PIN**.In the Share PIN with field add the email IDs of users to share this pin Via email. (Optional)Click **Create**. ![](/images/9088123/bdc0be6df1cc.png) The PIN is successfully created. ![](/images/9088123/1a95e469ea41.png)

The newly created PIN is displayed on the PIN tab.

## Introduction

The **Create Passkey** feature in the Windows Supervisor App allows authorized supervisors to generate and assign passkeys for users.

## Prerequisites

- You must have access to Supervisor account.
- Ensure you have Windows Pro Machine.
- Connect to OpenVPN.

## Steps to Create Passkey in Windows Supervisor app

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](/passwordless/windows/supervisor/how-to-log-in-to-supervisor-app)The **Supervisor App Home** screen is displayed. ![](/images/13842978/7ca9446cd3f1.png)
2. Click **User Management**The **Users** screen is displayed. ![](/images/13842978/64eb10a951e9.png)
3. Select the appropriate **User.**The **User Details** screen is displayed. ![](/images/13842978/6db0726bd55d.png)
4. Select **Passkey** > click **+ Passkey.** ![](/images/13842978/6baeb7774160.png) The Create Passkey pop-up box is displayed.
5. Do the followingEnter **Display Name** Edit **Domain Name**Enter **Username**Click **Generate.**

</Frame>

The Passkey is successfully generated.

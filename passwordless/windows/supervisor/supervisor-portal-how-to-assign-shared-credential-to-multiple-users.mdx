Steps to assign Shared Credential:

1. Log in to the **Supervisor Portal.**The Users page is displayed. ![](/images/9680203/6ffcf34ed62b.png)
2. Click **Shared Credentials > Windows Passwords**on the left menu panel. ![Image](/images/9680203/8b451d0b0d1d.png) The **Windows Password**page is displayed. ![](/images/9684697/4a18d38ca9a1.png)
3. Select credential name(s) to assign users. ![](/images/9684697/959cf70a84e2.png)
4. Select **+ Assign Credentials to Users**. ![Image](/images/9684697/2f8fcf5fdebd.png) The **Assign Credentials to Users** pop-up box is displayed. ![](/images/9684697/dd86837b3d72.png)
5. On the pop-up box, select username(s) in the **Select Users**dropdown list.
6. Select **Assign**.The shared password is successfully assigned among the selected users. ![](/images/9684697/ea89b4204fcc.png) Video TutorialWatch the video[How to assign shared credential to multiple users in the Supervisor Portal- Video Tutorial](/passwordless/windows/supervisor/how-to-assign-shared-credential-to-multiple-users-in-the-supervisor-portal-video-tutorial) ​

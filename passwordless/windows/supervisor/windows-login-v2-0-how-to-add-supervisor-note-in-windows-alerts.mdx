## Introduction

This document explains how to add a supervisor note to a Windows Alert in the Tenant Admin Portal.

## Prerequisite

- You must have access to the Tenant Admin Portal.
- Ensure that Windows Alerts are enabled and configured.

## Steps to Add Supervisor Note in Windows Alert

1. Log in to the **Tenant Admin Portal**.
2. Click **Transactions**on the left menu panel > click **Windows Alert**. ![](/images/15516986/711a3e947a68.png) The Windows Alert list page is displayed.
3. Click **All Alerts**.
4. Do one of the following:Click the **Alert Name**The **Windows Alerts**Credential page is displayed.Click **+ Add Note.** ![](/images/15516986/8bc9218e1d2c.png) Enter the **Note** in the Note field > Click **Save**. ![](/images/15516986/6d4fb4194a07.png) The Note is added. ![](/images/15516986/aed71fb6f1cd.png) (OR) Select the **Notes** icon in the **Action** column for the required Windows alert. ![](/images/15516986/113e291a3da5.png) The **Add Note**pop-up box is displayed.Enter the **Note** in the Note field > Click **Save**. ![](/images/15516986/590f2a67756d.png) Note is added for the selected alert. ![](/images/15516986/176de1f984da.png)

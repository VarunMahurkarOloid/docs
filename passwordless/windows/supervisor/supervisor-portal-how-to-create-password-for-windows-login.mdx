## Create Password for local windows machine

To create Password:

1. Log in to the **Supervisor Portal.**The Users page is displayed.
2. Click **username** to edit. ![](/images/9674358/d3cb6459c8bb.png) The User details page is displayed. ![](/images/9674358/fba518291a49.png)
3. Go to **Credentials** >**Windows** **Password** tab > **+ Create Password**. ![Image](/images/9674358/c476f80e5adb.png) The **Create Windows Password** pop-up box is displayed. ![](/images/9674358/8a29fd3e0ce2.png)
4. Do the following:Enter **Display Name** that displays on the Windows Login page.Select**Windows Local User** type from **Credential Type** dropdown list.Click**Next.** ![](/images/9674358/50ebfcac9f9e.png) Enter **Machine Name**.**Note**: Enter your Windows device name. Enter **Username**of your Windows Login.**Note:**Windows account name.Enter **Password**of your Windows Login.Click **Save**.

<Frame>
  <img src="/images/9674358/caba7e6ef4ef.png" alt="Image" />
</Frame>

The password is created and listed in the **Password** tab.

## Create Password for domain

1. Log in to the **Supervisor Portal.**The **Users** page is displayed.
2. Click **username** to edit. ![](/images/9674358/d3cb6459c8bb.png) The User details page is displayed. ![](/images/9674358/fba518291a49.png)
3. Go to **Credentials** > **Passwords** tab > **Create Password**. ![Image](/images/9674358/c476f80e5adb.png) The **Create Windows Password** pop-up box is displayed. ![](/images/9674358/8a29fd3e0ce2.png)
4. Do the following:Enter **Display Name** that displays on the Windows Login page.Select **Windows Domain User** type from **Credential Type** dropdown list.Click **Next.** ![](/images/9674358/9c7fc000fe3f.png) Enter **Domain Name**.Select **Preferred Machine**from the **Preferred Machine(s)** list.Enter **Username**of your Windows Login.**Note:** Windows account name.Enter **Password**of your Windows Login.Click **Save**. ![Image](/images/9674358/6cd6c3ac4e35.png) The password is created and listed in the **Password** tab.

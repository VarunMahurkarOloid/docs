## Introduction

The NFC/ID credential feature in the Tenant Admin Portal allows admin to enable NFC-based authentication for the Windows Login application. Once enabled, users can log in to Windows endpoints by scanning an NFC card or tag.

## Prerequisite

You must have Tenant Admin Access.

## Steps to Enable NFC/ID credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click the **Windows Login** application. ![](/images/10900687/ca340dba5264.png) The application page is displayed.
3. Go to the**Authenticato**r tab. ![](/images/11484465/83d7f75d2fd5.png) The Authenticator page is displayed.
4. Turn on the **NFC/ID**toggle. ![](/images/11484465/0bd849f04997.png) The **NFC/ID** is enabled successfully. ![](/images/11484465/d4c337788421.png)

## Configure the NFC/ID

1. Under **RFID HF/LF Settings**, do one of the following:**RfIdeas SDK:** Select this option to authenticate users using an NFC card or tag.**Note:** NFC/ID enrollment is supported only through the **Supervisor app**.**Keystroke:** Select this option to authenticate users using an NFC card or tag, or through keyboard input.**Note:** NFC/ID enrollment is supported through both the **Supervisor app** and the **Tenant Admin Portal**.
2. Click **Save**. ![](/images/11484465/4ece5c8d1e6d.png)

The NFC/ID is configured successfully.

### Sync Configuration to Apply Changes

After enabling and configuring the **NFC/ID**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

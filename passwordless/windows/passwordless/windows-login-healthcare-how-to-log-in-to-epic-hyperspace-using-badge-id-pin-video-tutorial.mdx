## Prerequisites

- The Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Ensure the Supervisor app is closed.
- **Epic Vault Password** must be created for the User. Refer: **[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin)**

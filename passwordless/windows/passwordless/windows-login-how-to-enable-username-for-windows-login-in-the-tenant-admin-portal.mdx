**Introduction**

The Enable Username feature in the Tenant Admin Portal allows admins to enable Employee ID/Primary ID and Email as credential for the Windows Login application. Once enabled, users will be prompted to enter their selected credential (Employee ID, Primary ID, or Email) before proceeding with authentication on Windows endpoints.

**Steps to enable Username:**

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the preferred Windows Login application. ![](/images/11891786/ca340dba5264.png) The application page is displayed. ![](/images/11891786/3f14ebc89502.png)
3. Go to**Authenticato**r tab.
4. Turn on **Emp ID/Primary ID** toggle. **Note:** Enabling this option will prompt the user to enter their Employee ID or Primary ID before authentication.
5. Enter a **custom label** to show instead of Emp ID/Primary ID on the login screen (optional).
6. Click **Save**. ![](/images/11891786/0e8ee776a46a.png)
7. Turn on **Email**toggle.**Note:** Enabling this option will prompt the user to enter their Email ID before authentication.
8. Select **Remember Username** option to allow the application to remember your Employee ID and Email. ![](/images/11891786/05b4b2590706.png) The Emp ID/Primary ID and Email for Windows Login application is configured successfully. ![](/images/11891786/19d70841a0ba.png)

## Introduction

Logging into **Epic Hyperspace using Badge and PIN** provides a secure and efficient authentication method for accessing Epic applications on Windows devices. Users can authenticate by scanning their assigned badge and verifying their identity with a PIN or other configured second-factor methods.

## Prerequisites

- The Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Ensure the Supervisor app is closed.
- Ensure Epic SSO is disabled.
- **Epic Vault Password** must be created for the User. Refer: **[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin)**

## Steps to log in using Badge:

1. On the Lock screen, select **Login with OLOID**. ![](/images/10616223/6b09b19664e3.png) The **Scan Badge**screen is displayed.**Note:**
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/14780782/8a6f5319ad35.png) The **Enter PIN**screen is displayed.
3. Enter the **PIN**. ![](/images/14780782/99a9dc1cf459.png) The Windows homepage is displayed. ![](/images/14780782/1614bb15ad8d.png)
4. Launch the **Epic Hyperspace** application on your Windows machine. ![](/images/14780782/130d09747b31.png) The **Scan Badge** screen is displayed.
5. Tap the **Badge** on the **Badge Reader** to scan it.**Note**: You will only see the authentication methods (Face, Badge and NFC/ID) enabled for you. Button names may vary based on configuration. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears. ![](/images/14780782/8a6f5319ad35.png) The **Enter PIN**screen is displayed.**Note:**You will only see the second factor authentication methods (PIN, Duo, PingOne etc.) enabled for you. Button names may vary based on configuration. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
6. Enter the **PIN** > click **Submit.****Note**: The current user (the user already logged into Epic Hyperspace) must authenticate. ![](/images/14780782/584f93c1a150.png)
7. The **Login confirmation** screen is displayed. Click **Continue.**

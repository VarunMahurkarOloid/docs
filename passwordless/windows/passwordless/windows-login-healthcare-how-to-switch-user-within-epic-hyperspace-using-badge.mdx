## Introduction

The **Switch User**workflow in **Epic Hyperspace** allows a second user to securely take over an active session on a shared Windows device. The current active session is closed and a new session is activated for the second user.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user. Refer: **[How to create Vault Password for a user](/passwordless/web/chrome-vault/chrome-vault-how-to-create-vault-password-for-a-user)**
- Ensure that the Supervisor app is closed.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin)**
- The badge reader must be connected to the Windows system.
- Badge Out options must be configured. Refer: [Windows Login - How to Configure Badge Out option](/passwordless/windows/passwordless/windows-login-how-to-configure-badge-out-option)

## Steps to Switch User using Badge ID

1. On the Lock screen, select **Login with OLOID**. ![](/images/10616223/6b09b19664e3.png) The **Scan Badge**screen is displayed.**Note:**
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/14780782/8a6f5319ad35.png) The **Enter PIN**screen is displayed.
3. Enter the **PIN**. ![](/images/14780782/99a9dc1cf459.png) The Windows homepage is displayed. ![](/images/14780782/1614bb15ad8d.png)
4. Log in to **Epic Hyperspace** refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](/passwordless/windows/passwordless/windows-login-healthcare-how-to-log-in-to-epic-hyperspace-using-badge-id-pin-when-epic-sso-is-not-enabled)**User is successfully logged in to **Epic Hyperspace.** ![](/images/14817588/e2f7272b7fa5.png)
5. The Second User must tap the **Badge** on the **Badge Reader** to initiate User Switch.**Note:**The User will switch from User 1 to User 2. ![](/images/14817588/2493d5ea7582.png) The **Enter PIN**screen is displayed.
6. Enter the **PIN**.**Note:**If Multi Factor Authentication (MFA) is enabled the second user must authenticate using the configured second factor, In this case PIN. ![](/images/14817588/6d6623de5a39.png)
7. The **Login confirmation** screen is displayed. Click **Continue.**

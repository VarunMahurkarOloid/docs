## Introduction

This document explains how to apply an Endpoint Template during the auto-pair configuration process for the Windows Login application. Applying the Endpoint Template ensures that predefined settings are automatically assigned to devices as part of the pairing process.

## Prerequisites

1. You have **Tenant Admin** access to the **Tenant Admin Portal**.
2. An **Endpoint Template** has been created. To create refer [How to create and configure Windows Login Endpoint Template](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-endpoint-template-in-the-tenant-admin-portal).

## Steps at a Glance

1. Create the Windows Login application in the Tenant Admin Portal and select the desired endpoint template in the**“Apply Endpoint Template”**field.
2. Generate and download the auto-pair config file; ensure it is mapped to the application with the predefined template.
3. Install the Windows Login app on the endpoint using the auto-pair option. The endpoint template is applied automatically.

## Steps to Apply Endpoint Template During Auto-Pair Process

## Step 1: Create and Configure the Windows Login Application

1. Log in to the **Tenant Admin Portal**.
2. Create the windows login application. Refer [How to create and configure Windows Login application | Oloid Help Center](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal).**Note:** If window login application is already created then select the desired application from the application list.
3. In the **Settings section**, select the applicable template from **[Apply Endpoint Template](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)** dropdown.**Note:** Endpoint template must be added to apply template when using auto-pair option to pair the endpoint.![](/images/12586251/bed967d537dd.png)The endpoint template is selected.
4. Select **Save**.![](/images/12586251/73750b26db3b.png)The Endpoint Template is successfully applied to the selected Windows Login Application.

## **Step 2:**Generate and Download the Auto-config File

1. Generate and download the auto-pair config file. Refer [How to generate Auto-Pair config file for Windows Login in Tenant Admin Portal | Oloid Help Center](/passwordless/windows/passwordless/windows-login-how-to-generate-auto-pair-config-file-for-windows-login-in-tenant-admin-portal)**Note:** Ensure that the **Application Mapping** includes the application where the **Endpoint Template** is specified. This mapping ensures that auto-pair applies the correct endpoint configuration. ![](/images/12586251/97a72e3e3bbe.png)

## Step 3: Install Windows Login Application with Auto-config File

1. On the target Windows device, launch the **Oloid Windows Login Installer**.
2. Pair the endpoint using auto-pair option. To auto-pair refer [How to pair Supervisor App using auto-config option | Oloid Help Center](/passwordless/windows/supervisor/windows-login-how-to-pair-supervisor-app-using-auto-pair-config-file-option)

Once the auto-pair process completes, the **Endpoint Template** settings is automatically applied to the paired endpoint.

**Introduction**

This document provides step-by-step instructions for logging in with QR Code to Windows device.

**Pre-requisite**

- In the Oloid Portal, you must do the following:Assign QR Code to the user. For more details, refer [How to create QR Code as credential for users](/administration/admin-portal/tenant-admin-portal-how-to-create-and-assign-qr-code-credential-for-a-user)Enable QR Code as an authenticator in the Windows application. For more details, refer [How to enable QR Code in Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)**Note**: If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png)The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens and the camera turns on.
2. Show your QR Code in front of the camera for QR Code authentication. ![](/images/10626849/d5f6b88a226b.png) On successful QR Code authentication, you are signed in to the Windows device.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully. ![](/images/10626849/4af001793749.png)Video TutorialWatch the video [How to log in to Windows device using QR Code through Windows Login app-Video Tutorial](/passwordless/windows/passwordless/how-to-log-in-to-windows-device-using-qr-code-through-windows-login-app-video-tutorial)

## Prerequisite

- In the Tenant Admin Portal, you must do the following:Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users).Enable Badge authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal).Configure password credential for Windows Login Application. For more details refer [How to configure Password credential in Windows Login Application](/passwordless/windows/passwordless/windows-login-how-to-configure-password-credential-for-windows-login). **Note**: If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).

## Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens and the **Scan Badge** pop-up box is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/11848536/ee54a0be34fc.png) After Badge authentication, the **Enter Password**pop-up box is displayed.
3. Enter the **Password** > click **Submit**. ![](/images/11848536/0f9512c27df2.png) You have logged in to Windows device using Badge and Password credential through Windows Login app successfully.

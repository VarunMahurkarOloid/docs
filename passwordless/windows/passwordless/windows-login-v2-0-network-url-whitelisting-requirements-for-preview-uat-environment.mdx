## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | Windows Authenticator App 2.0 |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **UAT** | **Description** |
|---|---|---|
| Admin API | api.oloidpreview.com | Admin API used for Authentication. |
| Tenant User API | api.previewoloid.net | The Tenant User API used for Enrollment |
| Tenant S3 bucket | \<tenantname>\<tenantid>.s3.us-east-2.amazonaws.com | Tenant S3 bucket URL used to download the Customer Logo. |
| Oloid document bucket | oloiddocument-preview.s3.us-east-2.amazonaws.com | Oloid document bucket URL is used for Consent document. |
| Oloid download service | [https://download.oloid.cloud/](https://download.oloid.cloud) | Oloid download service URL used to download oloid software. |
| Windows Login cache service | [https://oloidcache.oloidpreview.com/](https://oloidcache.oloidpreview.com) | Windows Login cache service URL used for device authentication. |
| Cloud URL | gateway.oloidpreview.com | Provides access to Oloid cloud services through path-based routing, including Admin API, User API, Downloads, Cache and Documents. |

---

#### Notes

- Replace **\<tenantname>** and **\<tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **\<tenantname>** and **\<tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **\<tenantname>** and **\<tenantid>** details.

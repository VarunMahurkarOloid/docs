The Tenant Admin / Supervisor can unblock the user's blocked screen in one of the following ways:

- [Using transaction tab](#h_ced2924017)
- [Using Windows endpoint](#h_d3822e218b)

## Using Transaction tab

1. Log in to Oloid Portal.
2. On the home page of the portal, select **Transactions**on the left menu panel. ![](/images/9790398/4526bd2f87f5.png) The User Transaction Through Your Device page is displayed. ![](/images/9790398/ddb95b3110b6.png)
3. Select **Windows Alert**. ![](/images/9790398/22aa2a32f4c0.png) The Windows Alert page is displayed.
4. Do one of the following:Go to the **Alert ID** and click **Unblock**. ![](/images/9790398/a0dda219f10f.png) OrGo to the user endpoint detail page and select **Unblock**.Note: You can also navigate to the user detail page from the Transactions (**User Transaction Through your Device)** page. ![](/images/9790398/f57d3f3fffc2.png) The user's screen is unblocked successfully. ![](/images/9790398/ac5600fd6810.png) ![](/images/9790398/94356c0b9ddd.png)

## Using Windows endpoint

1. Log in to Oloid Portal.
2. Navigate to **Endpoints**> select preferred **Endpoint Name**. ![](/images/9790398/0632fad1dcd4.png) The endpoint details page is displayed. ![](/images/9790398/a53bfe030932.png)
3. Select **Unblock**to unblock the user's screen. ![](/images/9790398/235d2eae4379.png) The endpoint is unblocked successfully and the user can continue using the system. ![](/images/9790398/5aacec290739.png)

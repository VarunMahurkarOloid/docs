**Introduction**

This document provides step-by-step instructions for logging in with NFC to Windows device.

**Pre-requisite**

In the Oloid Portal, you must do the following:

- Assign NFC ID to the user. For more details, refer [How to assign NFC/ID as credential to users](/administration/admin-portal/how-to-assign-nfc-id-as-a-credential-to-the-user)
- Enable NFC as an authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

<Note>
  If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
</Note>

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens and the Welcome screen is displayed.
2. Select **Login with NFC Tag**. ![](/images/10002126/acc78953962e.png)
3. Tap the **NFC** **Tag**on the**Reader** to scan it.**Note:**The card reader must be connected to the computer. ![](/images/12421965/56f01941c9d8.png) On NFC authentication, you are signed in to the Windows device.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully. ![](/images/9720651/4af001793749.png) **Note:**The user can also perform offline NFC authentication after completing at least one successful online NFC authentication.

**Introduction**

The QR Code credential feature in the Tenant Admin Portal allows admin to enable QR code-based single factor authentication and multi-factor authentication (MFA) for the Windows Login application. Once enabled, users can log in to Windows endpoints by scanning a QR code.

**Steps to configure QR Code credential:**

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the preferred Windows Login application. ![](/images/10900687/ca340dba5264.png) The application page is displayed. ![](/images/11484322/3f14ebc89502.png)
3. Go to**Authenticato**r tab.
4. Turn on**QR Code**toggle. ![](/images/11484322/5336d17a4c7d.png) The QR code authenticator for Windows Login application is enabled successfully. ![](/images/11484322/d0a4d38202e9.png)

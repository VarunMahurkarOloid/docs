## Introduction

This document provides instructions to enable **Face followed by PIN multi-factor authentication (MFA)** for the Windows Login application in the Tenant Admin Portal. When enabled, users must authenticate using Face as the primary factor and then enter a PIN as the secondary factor during Windows login.

## Prerequisites

- You must create and configure Windows Login application. For More, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- You Must enable Face credential in the Windows Login application. For more, refer to [How to configure Face credential for Windows Login Application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-configure-face-credential-for-windows-login-in-the-tenant-admin-portal) ​

## Steps toEnable Face Followed by PIN MFA

1. Log in to the Tenant Admin Portal.
2. Go to **Applications** > select **Windows Login** application. ![](/images/13615407/ca340dba5264.png) The **Details** page is displayed. ![](/images/13615407/1a70a9419273.png)
3. Go to **Authenticator** > enable **PIN** credential. ![](/images/13644652/45ec7c156a32.png)
4. In **PIN as Authentication Factor**, turn on **Enable Face followed by PIN MFA**.**Note:** When this option is enabled, users must authenticate using **Face as the first factor** and then enter a **PIN as the second factor (MFA)** during Windows Login.
5. Click **Save.** ![](/images/13644652/066f01b27587.png) The **Face followed by PIN MFA** is configured successfully. ![](/images/13644652/7a4929d44ac6.png)

## Sync Configuration to Apply Changes

You must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

**Introduction**

This document provides step-by-step instructions for enrolling NFC through Windows Login app.

Steps to enroll NFC through Windows Login app:

1. On the Windows lock screen, click **Login with OLOID**. ![](/images/10002126/e0bb0f5125d1.png) The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with NFC Tag**. ![](/images/10002126/acc78953962e.png)
3. Tap the **NFC Tag** on the **Card Reader** to scan it.**Note:**The card reader must be connected to the computer. ![](/images/10002126/9115e5f3bfa7.png) The NFC authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed**screen, select **Enroll Credential**. ![](/images/10002126/b8f78ab30569.png) The **Verify using Windows Credential** screen is displayed.
5. Do the following:Enter **Domain\Username**.Enter your Windows domain and username in the format `Domain\Username`.Enter **Password**.Use your Windows account password.Select **Enroll Windows credential to your account**. (Optional)Click **Continue**. ![](/images/10002126/bd6c39a089d9.png) The **Select Credential to Enroll or Update**screen is displayed.
6. Select **NFC Tag**. ![](/images/10002126/b3402fe87345.png) The **Scan your NFC Tag to Enroll**screen is displayed.
7. Scan your NFC Tag in the Card Reader. ![](/images/10002126/07f15a83e0f6.png)
8. Click **Submit**.The NFC Tag is enrolled successfully. ![](/images/10002126/f23894a859ec.png)

**Prerequisite:**

You must create a Windows Login application in the Tenant Admin Portal. For more details, refer [How to create a Windows Login Application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal).

**Steps to edit details tab:**

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the preferred Windows login application to edit. ![](/images/10749338/ca340dba5264.png) The application page is displayed. ![](/images/10749338/c69fd4cef6e4.png)
3. Do the following: Modify **Application Name**(if required).**Note**: Special characters are not allowed in Application Name.Add **Description**. (Optional)**Note**: The description should be less than **140**characters.Select your **Timezone**based on your country and region from dropdown list. (Optional)Select **Factor Sequence** from drop down list to activate Multi-Factor Authentication (MFA) for the Application's Endpoints. **Note**: These are one-time settings and all the default settings are recommended. The Details tab for Windows Login Application is edited successfully. ![](/images/10749338/92e353b2af78.png)

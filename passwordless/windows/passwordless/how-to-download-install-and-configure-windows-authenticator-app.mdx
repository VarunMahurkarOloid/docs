The Windows Authenticator App provides secure, passwordless access to your Windows machine, making it easy to log in without the need for traditional passwords. This guide provides step-by-step instructions on downloading, installing, and configuring the app using the Oloid Portal.

## Steps to download Windows Authenticator App:

1. Log in to **Oloid Portal**.
2. On the home page of the Oloid Portal, do one of the following to download the Windows Authenticator App: Using File Sharing tabNavigate to **User Profile Menu** > **Tenant Setting** > **Oloid Apps**tab > download **Windows Authenticator App**.For more details, see [Download from File Sharing](/passwordless/windows/supervisor/how-to-download-supervisor-app) Using Tenant Settings tabNavigate to **User Profile Menu**> **File Sharing**. For more details, see [Download from Tenant Setting](/passwordless/windows/supervisor/how-to-download-supervisor-app)

After the download is complete, you can proceed with installing Windows Authenticator App.

## Steps to install Windows Authenticator App:

1. Download **Windows Authenticator App**file on your system. **Note:**Select the version as advised by your Oloid Rep. ![](/images/10568115/398c2f18a125.png) The **OloidPasswordlessSupervisor.Setup.zip**file is downloaded in your system.
2. Right-click and select **Extract All** > **OloidPasswordlessSupervisor.Setup.zip**file.The extracted files will be saved in the same folder as the original zipped file.
3. Double-click on **setup.exe** file.The **Oloid Passwordless Supervisor Setup** window is displayed. ![](/images/10568115/edfacbb9a9c3.png)
4. Review the listed components and click **Install** to proceed.**Note:**If any of the files are missing, the application prompts to install the missing component.
5. On the **Oloid Passwordless Supervisor** Setup wizard, click **Next**. ![](/images/10449230/ae32b2c51922.png)
6. Use the default path to install the application and click **Next**. ![](/images/10449230/5dcdec4acd1d.png)
7. Click **Next**to confirm the installation. ![](/images/10449230/d5f6ee51e3be.png)
8. Click **Close**after the installation is complete. ![](/images/10568115/999dd18926f3.png) After successful installation, you can find the app icon ![](/images/10568115/588054bd1a5a.png) on your desktop. For first-time installation, it is recommended to restart your system.

## Steps to auto-pair the Windows Authenticator App:

1. On the Windows lock screen, do the following: Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png)The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows Login app is displayed.
2. Select **Yes, pair my device**to auto-pair the device. ![](/images/10449230/6b6d30c74a64.png) The Windows machine has been successfully paired and is now ready for use.

**OR**

After installing the Windows Authenticator app, unlock your Windows machine using a credential other than the Oloid login method.

1. On the desktop, double-click on the **Windows Authenticator App** ![](/images/10568115/588054bd1a5a.png) icon to start.The **Welcome** screen is displayed. You can see the**"Auto-pair config found!"** message.Note: The auto-pair config file is present in your installer file (Installer path\Oloid\Oloid\config). Reach out to [Oloid Support](mailto:support@oloid.ai)if you do not see auto-pair option.You can also [manually pair](/passwordless/windows/supervisor/windows-login-how-to-pair-supervisor-app-using-auto-pair-config-file-option)your Supervisor app incase auto pair fails.
2. Select **Yes, Pair my device**to auto-pair the device. ![](/images/10568115/e3ce3ccbda3a.png) The Windows machine is paired successfully.

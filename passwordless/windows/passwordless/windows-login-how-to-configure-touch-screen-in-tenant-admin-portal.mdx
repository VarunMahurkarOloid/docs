## To enable touchscreen configuration:

1. Log in to **Oloid Portal**.
2. On the homepage of the portal, click **Endpoints** on the left panel menu. ![](/images/10259846/37e34703983c.png)The Endpoints page is displayed.
3. Select the endpoint to be configured. ![](/images/10259846/cd8fdf543f2f.png)
4. Go to **Configure** tab > **Endpoint Settings**tab. ![](/images/10259846/bb7f4b953c17.png)
5. Turn on **Show on-screen keyboard** option to display an on-screen keyboard during Windows login. This option is useful for devices without a physical keyboard, such as tablets. ![](/images/10259846/38b437d1cd83.png)
6. Click **Save**.The touchscreen is configured for the endpoint.

## To use the touchscreen keyboard for the Windows login app:

1. On the Windows lock screen, tap **Login with OLOID**. ![](/images/10259846/e0bb0f5125d1.png) The Windows login app opens and the **Scan Badge** page is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/10259846/ed8b312fb70d.png) After Badge authentication, the **Enter PIN** pop-up box is displayed, and the onscreen keyboard automatically appears. ![](/images/10259846/2d81749e3264.png) **Note:**In case you are unable to view the onscreen keyboard or is accidentally closed, then tap the more ![](/images/10259846/2895e6d0553d.png) option > **On-screen Keyboard**. ![](/images/10259846/454ff69b407e.png)
3. Enter the **PIN**, then tap **Enter**.On PIN authentication, you are signed in to the Windows device.

## Introduction

This document provides step-by-step instructions for logging in with face to Windows device.

## Pre-requisite

- In the Oloid Portal, you must do the following:Add Face to the user. For more details, refer [How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user)Enable Face under the Windows application. For more details, refer [How to create and configure Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)Manual face capture (as per the requirement) must be configured in Oloid Portal. You need to turn on [Enable Manual Capture Accessibility](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)toggle buttonin Windows Configuration.**Note**: If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication. ![](/images/8637172/feddc4448eee.png) The camera auto-captures the user's face.If manual capture is enabled, press **Enter or Spacebar,**or click on the camera icon. ![](/images/8637172/93392df3c5f8.png) On successful facial authentication, you are signed in to the Windows system.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully. ![](/images/10626849/4af001793749.png)

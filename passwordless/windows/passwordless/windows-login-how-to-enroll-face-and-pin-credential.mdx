## Introduction

This document provides instructions for enrolling **Face and PIN credentials** using **Windows Login** application.

## Prerequisites

- In Tenant Admin Portal, you must enable **Allow Credential Updates and Enrollment**to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-enable-credential-updates-and-enrollment-for-windows-login)
- Ensure that either the user’s Primary ID or email ID matches the username configured in the Tenant Admin Portal.
- Face and PIN credential should be enabled in the Windows Login application.
- You must enable the **Face followed by PIN** **MFA** toggle in the Windows Login application. For more, refer to [Windows Login - How to Enable Face Followed by PIN MFA](/passwordless/windows/passwordless/windows-login-how-to-enable-face-followed-by-pin-mfa-in-tenant-admin-portal).

## Steps to Enroll Face

1. On the Windows lock screen, click **Login with OLOID**. ![](/images/10006252/e0bb0f5125d1.png) The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication. ![](/images/10006252/1697ecc2b263.png) The Face authentication fails and the Missing Credentials screen is displayed.
3. Click **Enroll Credential**. ![](/images/13666085/77bf409cddc8.png) The **Verify using Windows Credential** screen is displayed.
4. Do the following:Enter **Domain**.**Note:** The Domain name is prefilled if **Enable Windows default domain** toggle is turned on, to know more refer [How to enable Windows Default Domain for Windows Login application in the Tenant Admin Portal | Oloid Help Center](/passwordless/windows/passwordless/windows-login-how-to-enable-windows-default-domain-for-windows-login-in-the-tenant-admin-portal).Enter **Username**.Enter **Password**.**Note:** Use your Windows account password.Select **Enroll Windows credential to your account**. (Optional)Click **Continue**. ![](/images/13666085/675033a67fdf.png) The **Select Credential to Enroll or Update**screen is displayed.
5. Select **Face**. ![](/images/13666085/a44fa55bc5ec.png) The camera turns on.
6. Place your face in front of the camera for face authentication.Your face is automatically captured. ![](/images/10006252/1697ecc2b263.png) **Are you happy with picture** pop-up box is displayed.
7. Click **Yes, Submit.** ![](/images/13666085/5203fb1036ec.png) The Face credential is enrolled successfully, and **Enrollment Successful** pop-up is displayed.**Note:** You can enroll up to **5 Face credentials** for a single user.

## Enroll PIN

1. Click **Enroll Face or PIN**. ![](/images/13666085/3485f6718956.png) The **Select Credential to Enroll or Update** Pop up is displayed.
2. Select **PIN** to enroll PIN credential. ![](/images/13666085/01ce0041ee55.png) The **Add/Update PIN**screen is displayed.
3. Do the following:Enter new PIN.Re-enter new PIN.Click **Submit**.**Note:**You can configure PIN credentials in the Tenant Admin Portal. For more details, refer to [How to configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin) ![](/images/13666085/963043b5d675.png) The PIN credential is enrolled successfully. ​![](/images/13666085/b63497d0642f.png)

## Introduction

Windows Alerts enable administrators to monitor security-related events detected by the Presence Detection engine on Windows endpoints. When configured, the system can identify events such as non-Oloid logins, camera obstruction, face tracking failures, multiple face detection, unauthorized gadget usage, loss of user focus, and emotion monitoring.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure the endpoint is paired with the Windows Login application. refer: [How to pair endpoint using Pair as Supervisor in Supervisor App](/passwordless/windows/supervisor/windows-login-how-to-manually-pair-the-supervisor-app)
- Ensure that your system is unlocked
- Ensure that your system's camera is working properly

## Face Tracking Violation

If the system is unable to reliably detect or track the user's face for the configured duration, it triggers the selected action.

Do the following:

1. **Min required Face Landmark config:** Set the required percentage of face visibility for face detection.
2. **Trigger 'No Face Found' alert after:** Define the time (in seconds) after which an alert will be generated if no face is found.
3. **Action:** Select a predefined action to take when a face tracking violation occurs.**Screen Block:** The user’s screen is blocked, but they are not logged out of their session. See, [Sample screen for a blocked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**Windows Lock:**The user's screen is locked, but they are not logged out of their session. See, [Sample screen for a locked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**No Action:** No immediate response from the system, but a desktop notification may be sent if notifications are enabled in the browser settings.

## Multiple Faces Detected

**Multiple Faces** **Detected:** Turn on this button to set an alert when more than one face is detected.

Do the following:

1. **Multiple Face Detection Threshold:**Set the threshold level required to confirm the detection of multiple faces.
2. **Trigger 'Multiple Faces' alert after:** Set the number of seconds after which an alert is triggered when multiple faces are detected.
3. **Action:** Choose an action from a drop-down list in response to multiple face detection.**Screen Block:** The user’s screen is blocked, but they are not logged out of their session. See, [Sample screen for a blocked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**Windows Lock:**The user's screen is locked, but they are not logged out of their session. See, [Sample screen for a locked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**No Action:** No immediate response from the system, but a desktop notification may be sent if notifications are enabled.

## Gadget Detected

**Gadget Detected:** Turn on this button to set an alert when an unauthorized gadget is detected.

Do the following:

1. **Gadget Detection Threshold config:**Set the threshold level based on the desired detection sensitivity for detecting gadgets.
2. **Trigger 'Gadget Detected' Alert After:** Define the time (in seconds) after which an alert is generated when a gadget is detected.
3. **Action:** Select the action to perform when an unauthorized gadget is detected.**Screen Block:** The user’s screen is blocked, but they are not logged out of their session. See, [Sample screen for a blocked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**Windows Lock:**The user's screen is locked, but they are not logged out of their session. See, [Sample screen for a locked user](/passwordless/windows/passwordless/windows-login-how-to-configure-windows-alert-for-presence-detection)**No Action:** No immediate response from the system, but a desktop notification may be sent if notifications are enabled.

## Focus Monitor

Focus Monitor helps detect when a user looks away from the screen beyond a specified angle for a defined period of time.

Do the following:

1. Enable the **Focus Monitor** toggle button.
2. Enter the **Look-away angle**.The **Look-away Angle** defines the maximum angle (in Degrees) a user can turn away from the screen before focus is considered lost.
3. Enter the duration for **Focus Lost**.This defines how long the user must remain outside the allowed angle before an alert is triggered.
4. Select **Action**from drop down.
5. Click **Save.**

## Check Emotions

Check Emotions analyzes user facial expressions at configured intervals and can trigger actions based on the detected emotional state.

Do the following:

1. Enable the **Check Emotions** toggle button.
2. Configure the **Check Emotions frequency**.The **Check Emotions Frequency** to defines how often emotion analysis is performed.
3. Select **Action**from drop down.
4. Click **Save.**

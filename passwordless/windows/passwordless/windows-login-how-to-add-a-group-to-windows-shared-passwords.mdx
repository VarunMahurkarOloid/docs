## Introduction

The Add Group to Windows shared password features allows the admin to add a Group to shared windows password, this allows all users within the group to use the windows shared password.

## Prerequisites

You must have a Tenant Admin account.

## Steps to Add Group to Windows Shared Password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/13348724/52b1093b9ddd.png) The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password**on the left menu panel. ![](/images/13348724/53e10d0fbd01.png) The **Windows Shared Password** page is displayed. ![](/images/13348724/d4f43ed318ac.png)
4. Select Shared Password from the list.The Windows shared password details page is displayed. ![](/images/13348724/1afd693f7823.png)
5. Select **Groups** tab > click **+ Add Group**The Add Group pop-up box is displayed. ![](/images/13348724/9560b71eaefc.png)
6. Select Group from dropdown list.
7. Click **Save**.The Group is successfully added to the shared windows passwords

<Frame>
  <img src="/images/13348724/e9f34b3d51f3.png" alt="Screenshot" />
</Frame>

The group users will be able to login using the shared password.

## Introduction

This **document** explains how to enable the **Forgot PIN link** in Windows Login in the Tenant Admin Portal and configure the settings that allow users to recover or manage their PIN from the Windows Login screen.

## Prerequisites

- You must have **Admin access to the Tenant Admin Portal**.
- The **Windows Login application** must be created and configured. For more, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- You must enable **Allow Login Through Local Credentials**toggle in Windows Login application. For more, refer to [How to Configure Allow Login Through Local Credentials](/passwordless/windows/passwordless/windows-login-how-to-configure-allow-login-through-local-credentials)

## Steps to Enable the Forgot PIN Link

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, select the **Windows Login application**. ![](/images/14015958/ca340dba5264.png) The **Details** page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Authenticato**r tab.
4. Under **MFA Credentials**, enable the **PIN** toggle. ![](/images/11484425/e9c57d1e2182.png)
5. **Enable Forgot PIN link** toggle.
6. Select one of the following options:Select **Show Popup** to display a popup message with instructions when users click the Forgot PIN link. See, [Sample screen](#h_1f7c687912).Do the following:Enter the **Heading**.Enter the **Description**.ORSelect**Allow PIN enrollment using 'Windows credential verification'** to redirects users to the Windows credentials management page. See, [Sample screen](#h_512dd11aa8).
7. Click **Save.** ![](/images/14015958/16c0da5c511f.png) The **Forgot PIN link** is enabled successfully. ![](/images/14015958/a28e792332a5.png) Sample Application Screen Showing Popup Message![](/images/14015958/dc63095a4ac0.png) Application Screen Redirecting User to Windows Manage Credentials Page![](/images/14015958/98e304d05391.png) Sync Configuration to Apply ChangesYou must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

## Introduction

Shared passwords are passwords that can be used to access a local windows machine or domain. It is shared among users to which they are assigned to. For more details refer [How to assign shared credential with users](/passwordless/windows/passwordless/how-to-assign-shared-password-for-windows-login-in-the-tenant-admin-portal).

This document comprises the following sections:

- [Create shared password for windows domain user](#h_cd8b8fcb5e).
- [Create shared password for Windows local user](#h_f9e8dc7f1f).

## Steps to create shared password for windows domain user:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8472794/92b497a1f7a6.png) The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password**on the left menu panel. ![](/images/8472794/1567acdc6829.png) The **Windows Password** page is displayed.
4. On the top right, click **Create Password**. ![](/images/8472794/1567acdc6829.png) The **Create Windows Shared Password** pop-up box is displayed.
5. Do the following:Enter **Display Name**.Select user type as **Domain User** from **User Type** dropdown.Enter user name then select **Password Owner(s)**from the dropdown list.Select **Next**. ![](/images/8472794/545fa84f4666.png) Enter **Domain Name**.Select **Preferred Machine(s)**.Enter**Username** of your Windows Login.Enter **Password** of your Windows Login.Enter**External ID.**Click **Create.** ![](/images/8472794/970f40078715.png) The password is created and listed on the**Windows Shared Password**page. ![](/images/8472794/8cd4dd5e646d.png)

## Steps to create shared password for windows local user:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/8472794/92b497a1f7a6.png) The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password**on the left menu panel. ![](/images/13348724/53e10d0fbd01.png) The **Windows Shared Password** page is displayed.
4. On the top right, click **Create Password**. ![](/images/8472794/1567acdc6829.png) The **Create Windows Shared Password** pop-up box is displayed.
5. On the pop-up box do the following: Enter **Display Name** that displays on the Windows Login page.Select user type as **Windows Local User** from **Password Type** dropdown.Enter an existing user name, then select **Password Owner**from the dropdown list.Select **Next**. ![](/images/8472794/b50868cf06f8.png) Enter **Machine Name**.**Note**: Enter your Windows device name.Enter**Username** of your Windows Login account.Enter **Password** of your Windows Login account.Enter **External ID.**Click **Create**. ![](/images/8472794/6ad78f0f5f3f.png) The password is created and listed successfully on the**Windows Shared Password** page. ![](/images/8472794/cc466e7efb1f.png)

<Note>
  The domain shared password is also listed on the selected Endpoint details page.
</Note>

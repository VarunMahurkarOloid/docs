## Introduction

The **Reauthenticate Current User – Second Factor** workflow requires the logged-in user to verify their identity using an additional authentication factor during an active session. Tenant Admin can configure the authentication process, either as a primary or secondary authentication device, based on security requirements.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](/administration/admin-portal/how-to-create-and-configure-application-type-passwordless)

## Steps to Enable Reauthenticate Current User - Second Factor

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**. ![](/images/13713982/7dacbe1e90eb.png) The application details page is displayed. ![](/images/13713982/b89e4448e051.png)
3. Click **Configure**tab> **Epic EHR**. ![](/images/13713982/09fe4e8dbdcc.png) The Epic EHR page is displayed.
4. Do the following:Turn on **Enable Reauthentication Workflow**toggle button. ![](/images/15103078/c91471db011e.png) Select **Reauthenticate Current User - Second Factor**.From the Application Factor dropdown, choose the authentication factor assigned at the application level:OLOID is Used as Primary and Secondary Auth DeviceOLOID is Used as Primary Authentication DeviceOLOID is Used as Secondary Authentication DeviceClick **Save.** ![](/images/15103078/233b14f44238.png)

Reauthenticate Current User - Second Factor is successfully configured.

## Pre-requisite

- The badge must be assigned to the user.
- The **Enable Badge Out** option must be enabled in the Windows Login application. For details see, [Windows Login - How to enable Badge out option](/passwordless/windows/passwordless/windows-login-how-to-configure-badge-out-option)
- The badge reader must be connected to the Windows system..

## Steps to log out of Windows System using Badge:

1. On the Lock screen, select **Login with OLOID**. ![](/images/10616223/6b09b19664e3.png) The Welcome screen of the Windows Login App is displayed.
2. Enter your credentials to log in to the system..The Windows homepage is displayed. ![](/images/10616223/1614bb15ad8d.png)
3. Scan the badge on the badge reader to lock your Windows system ![](/images/10616223/2493d5ea7582.png) Your Windows system is successfully locked, and the **Lock** screen appears. ![](/images/10616223/ed4267a752e5.png) **Note:** If the Windows Login application is configured with the **Sign out of Windows** option, all open applications in the system will close, and the **Lock** screen will appear. ![](/images/10616223/caf5442be947.png) Video TutorialWatch the video [How to log out of Windows System using Badge - Video Tutorial](/passwordless/windows/passwordless/how-to-log-out-of-windows-system-using-badge-video-tutorial)

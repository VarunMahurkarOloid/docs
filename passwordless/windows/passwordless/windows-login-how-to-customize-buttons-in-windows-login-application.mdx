### Introduction

The Customize Buttons section allows Tenant admin to rename the authenticator button label displayed on the Windows Login app.

### Steps to configure Customize Buttons:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App). ![](/images/10900687/ca340dba5264.png) The application page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Configure** > **Customize Buttons** tab. ![](/images/11069364/d19ed4250a88.png)
4. In **Button Label**field, enter the text to be displayed on the Windows Login app. Example- Sign in with, Login with, Authenticate with. ![](/images/11069364/1dcd80efe073.png)
5. **Enable Badge Options** toggle to allow badge assignment through the Supervisor App. **Note**: You must enable Badge Credential in the Authenticator tab of the Windows Login application. After enabling Badge option, select one of the following modes: ​**Default:** Enroll Badge + PIN**Enroll Badge Only** Select this option to enroll badge using the Supervisor App.**Enroll Badge + PIN** Select this option to enroll badge with PIN credential using the Supervisor App.
6. Click **Save**. ![](/images/11069364/59cfd1822a08.png) The configuration is saved successfully. See, [Sample screen for customized button](#h_c464382251) ![](/images/11069364/60e247cd0ca7.png) **Note:**In **Windows Authenticator** app, you must sync the configuration to see the latest customized buttons. For more details, refer [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app)

![](/images/9398720/07f8f1eb059f.png) It is recommended to contact your Oloid Account Manager for configuration support to ensure a smooth setup.

**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [RF IDEAS website](https://www.rfideas.com/support/tools/downloads).

To configure your card reader:

1. Launch the rf IDEAS configuration utility app.Make sure the card reader is connected to the system.
2. Select **Connect** from the top menu bar. ![](/images/9398720/a747658453e5.png) The DEVICE LIST is configured and displayed. ![](/images/9398720/b84c61236178.png)
3. Select the preferred configuration from the **CONFIGURATION(s)** dropdown list. ![](/images/9398720/989d041f4e5b.png)
4. Select **Write** from the top menu bar. ![](/images/9398720/5200e5c7d3e4.png) The badge reader is updated with the new settings.
5. Select the **Test Area**to scan your badge card with the card reader. ![](/images/9398720/7413412e117c.png) The badge number is displayed in the Test Area. ![](/images/9398720/add47842254f.png) The card reader is configured for the badge card. You can click![](/images/9398720/276d7f616286.png) icon in the bottom right corner to download the .hwg file.

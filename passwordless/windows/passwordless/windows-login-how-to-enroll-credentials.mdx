## Introduction

The **Enroll Credential** process in the Windows Login app allows users to securely register authentication methods such as Face, Badge, PIN, or NFC for passwordless access.

## Prerequisites

- In Tenant Admin Portal, you must enable **Allow Credential Updates and Enrollment**to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-enable-credential-updates-and-enrollment-for-windows-login)
- Ensure the **Enable Windows default domain**toggle is turned on. For more details, refer to [How to enable Windows Default Domain for Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-enable-windows-default-domain-for-windows-login-in-the-tenant-admin-portal)
- Make sure either the user's Primary ID or email ID matches your System Account Name.

## Steps to enroll credential in Windows Login app

1. Launch the Windows Login app.
2. Select **More** ![](/images/10932990/b0e8518ca742.png) options >**Enroll Credential**. ![](/images/10932990/31a4c6956313.png) The **Verify using Windows Credential** screen is displayed.
3. Do the following: Enter **Domain Name**Enter your Windows domain name.Enter **Username**.Use your Windows account username.Enter **Password**.Use your Windows account password.Select **Enroll Windows credential to your account**. (Optional)Click **Continue**. ![](/images/10932990/522f98cff6d4.png) The **Select Credential to Enroll or Update**screen is displayed. ![](/images/10932990/bacc32c197f4.png)
4. Select any of the preferred credentials to enroll. [Enroll Face](#h_af2489d7f8)[Enroll Badge](#h_c358732157)[Enroll PIN](#h_e7735da2e1)[Enroll NFC](#h_f358fd474a)

## Enroll Face

1. Select **Face**.**Note**: If connection is enabled, user consent is requested before uploading the picture. ![](/images/10932990/1542952b8fca.png) The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication. ![](/images/10932990/1697ecc2b263.png)
3. Do one of the following:Tap **Yes- Submit** to submit the image.The face is submitted successfully and is displayed on the details screen.Tap **No- Retake** to take the photo again.The camera turns on to retake the photo.**Note**: A maximum of five faces can be added. ![](/images/10932990/ef34ffe5d58d.png) Your face is automatically captured and it is enrolled successfully.
4. Do one of the following:Click **Done**to finish enrollment.Click **Manage Credential**to enroll another credential. **Note:**Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears. ![](/images/10932990/29f47ca914ca.png)

## Enroll Badge

1. Select **Badge**. ![](/images/10932990/ba0e9babe4df.png) The **Scan your Badge to Enroll**screen is displayed.
2. Scan your badge on the Badge Reader. ![](/images/10932990/3546c50e45f8.png)
3. Click **Submit**.The badge is enrolled successfully.
4. Do one of the following:Click **Done**to finish enrollment.Click **Manage Credential**to enroll another credential.**Note:**Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears. ![](/images/10932990/29f47ca914ca.png)

## Enroll PIN

1. Select **PIN**. ![](/images/10932990/5b26bd81faf1.png) The **Add/Update PIN**screen is displayed.**Note:** You can configure PIN credentials in the Oloid Portal. For more details, refer [How to configure PIN](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin) ![](/images/10932990/efd4a7efbd64.png)
2. Do the following:Enter **PIN**.Re-enter **PIN**.The PIN is enrolled successfully.
3. Do one of the following:Click **Done**to finish enrollment.Click **Manage Credential**to enroll another credential.**Note:**Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears. ![](/images/10932990/29f47ca914ca.png)

## Enroll NFC

1. Select **NFC Tag**. ![](/images/10002126/b3402fe87345.png) The **Scan your NFC Tag to Enroll**screen is displayed.
2. Scan your NFC Tag in the Card Reader. ![](/images/10002126/07f15a83e0f6.png)
3. Click **Submit**.The NFC Tag is enrolled successfully.
4. Do one of the following:Click **Done**to finish enrollment.Click **Manage Credential**to enroll another credential.**Note:**Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.

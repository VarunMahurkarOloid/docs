**Introduction**

The NFC/ID credential feature in the Tenant Admin Portal allows the admin to enable NFC/ID credential for the Windows Login application. Once enabled, users can log in to Windows endpoints by tapping their registered NFC tag.

**Steps to enable NFC/ID credential:**

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the preferred Windows Login application. ![](/images/11891768/ca340dba5264.png) The application page is displayed. ![](/images/11891768/3f14ebc89502.png)
3. Go to**Authenticato**r tab.
4. Turn on**NFC/ID**toggle. ![](/images/11891768/4c5cce8a9f10.png) The NFC/ID authenticator for Windows Login application is enabled successfully. ![](/images/11891768/b984f3e43ab1.png)

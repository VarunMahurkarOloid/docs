## Introduction

The **Windows**Login **(Healthcare)** application enables secure and passwordless authentication for Windows-based healthcare environments. The Tenant Admin can download the installer directly from the Tenant Admin Portal and install it on supported Windows systems.

## Prerequisites

- You must have access to a Tenant Admin account.
- You have local administrator access on the Windows machine.
- Check System Requirements. For more information, refer: [Windows Login App (Healthcare) - Hardware and Software Requirements](/passwordless/windows/passwordless/windows-login-healthcare-hardware-and-software-requirements)

## Steps to download Windows Login** **App

1. Log in to **Tenant Admin Portal**.
2. On the homepage of the portal, click **User profile icon**on the bottom left corner of the menu panel.
3. The user profile menu is displayed.
4. Select **Tenant Settings**. ![](/images/13713819/c88e8e3b0807.png) The **Tenant Settings**screen is displayed. ![](/images/13713819/b41260d5cce1.png)
5. Go to **Oloid Apps**tab > **Windows**Login **(Healthcare)**. ![](/images/13713819/05aacf3be396.png)
6. Select the preferred version from the **Win-Login-Installer** dropdown list, then click the **Download** button![](/images/13713819/ad510ed335f9.png)icon. ![](/images/13713819/51719a023981.png) The installer file is downloaded to your local device.After the download is complete, you can proceed with installing Windows Login App.

## Steps to install Windows Login** **App:

1. Download **Windows**Login **Healthcare**file on your system.**Note:**Select the version as advised by your Oloid Rep. ![](/images/13713819/51719a023981.png) The **OloidPasswordlessSupervisor.Setup-H.1.1.46.zip**file is downloaded in your system.
2. Right-click and select **Extract All** > **OloidPasswordlessSupervisor.Setup.zip**file.
3. The extract folder pop-up is displayed, click **Extract.** ![](/images/13713819/1a4eced3c8cb.png) The extracted files will be saved in the same folder as the original zipped file.
4. Open the extracted folder and Double-click on **setup.exe** file. ![](/images/13713819/614f6459a863.png) The **Oloid Passwordless Supervisor Setup** window is displayed. ![](/images/10568115/edfacbb9a9c3.png)
5. Review the listed components and click **Install** to proceed.**Note:**If any of the files are missing, the application prompts to install the missing component.
6. On the **Oloid Passwordless Supervisor** Setup wizard, click **Next**. ![](/images/10449230/ae32b2c51922.png)
7. Use the default path to install the application and click **Next**. ![](/images/10449230/5dcdec4acd1d.png)
8. Click **Next**to confirm the installation. ![](/images/10449230/d5f6ee51e3be.png)
9. Click **Close**after the installation is complete. ![](/images/10568115/999dd18926f3.png) After successful installation, you can find the app icon on your desktop. For first-time installation, it is recommended to restart your system.

**Introduction:**

The self-unblock feature in Windows Login app (Presence Detection) automatically unlocks the user's screen after the specified duration, eliminating the need for Supervisor approval.

**Steps to configure self unblock:**

1. Log in to **Oloid Portal**.
2. On the homepage, select **Endpoint** from the left menu panel. ![](/images/10489306/10a75002932a.png) The **Endpoints** page is displayed.
3. Select an endpoint (Windows Login) to edit. ![](/images/10489306/eef360e478f5.png) The**Details** page is displayed.
4. Go to **Windows Alert**tab and do the followingTurn on **Enable Windows Alert**. Select **Allow Self-unblock**.Set the duration in **Self Unblock After** field after which the user can automatically unblock themselves without supervisor approval.Click **Save**. ![](/images/10489306/f5b0eb4cd0b0.png) The Self-unblock is configured for the Endpoint successfully.

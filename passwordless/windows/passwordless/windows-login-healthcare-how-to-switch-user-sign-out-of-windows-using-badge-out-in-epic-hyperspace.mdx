## Introduction

The **Switch User** workflow in Epic Hyperspace enables secure session transfer on shared Windows devices. When the **Sign out** option is enabled, all active applications are closed and the system is locked, allowing the next user to authenticate and access the system.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user.
- Ensure that Epic SSO is enabled. Refer: **[Windows Authenticator (Healthcare) - How to Enable Epic SSO in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-healthcare-how-to-enable-epic-sso-in-the-tenant-admin-portal)**
- Ensure that the Supervisor app is closed.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the User. Refer: **[Windows Login - How to Configure PIN Credential in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-configure-pin-credential-in-the-tenant-admin-portal)**
- The badge reader must be connected to the Windows system.
- Badge Out options must be configured. Refer:

## Steps to Switch User using Badge ID

1. On the Lock screen, select **Login with OLOID**. ![](/images/14836306/a883850d3968.png) The **Scan Badge**screen is displayed.**Note:**
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/14780782/8a6f5319ad35.png) The **Enter PIN**screen is displayed.
3. Enter the **PIN**. ![](/images/14780782/99a9dc1cf459.png) The Windows homepage is displayed. ![](/images/14780782/1614bb15ad8d.png)
4. Log in to **Epic Hyperspace** refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](/passwordless/windows/passwordless/windows-login-healthcare-how-to-log-in-to-epic-hyperspace-using-badge-id-pin-when-epic-sso-is-not-enabled)**User is successfully logged in to **Epic Hyperspace.** ![](/images/14817588/e2f7272b7fa5.png)
5. The Second User must tap the **Badge** on the **Badge Reader** to initiate User Switch.**Note:**The User will switch from User 1 to User 2. ![](/images/14817588/2493d5ea7582.png) All open applications in the system will close, and the **Lock** screen appears**Note:** If the Windows Login application is configured with the **Sign out of Windows** option, all open applications in the system will close, and the **Lock** screen will appear. ![](/images/14836306/a07afb7a2edb.png) The **Validating Badge** screen is displayed. ![](/images/14836306/9a802afb819e.png) The **Enter PIN**screen is displayed.
6. Enter the **PIN**.**Note:**If Multi Factor Authentication (MFA) is enabled the second user must authenticate using the configured second factor, In this case PIN. ![](/images/14836306/81433432d4ad.png) The Windows homepage is displayed. ![](/images/14836306/1614bb15ad8d.png)
7. The Second User must Launch Epic Hyperspace to Login. Refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](/passwordless/windows/passwordless/windows-login-healthcare-how-to-log-in-to-epic-hyperspace-using-badge-id-pin-when-epic-sso-is-not-enabled)**

The User is successfully switched and the second User is logged in to Epic Hyperspace.

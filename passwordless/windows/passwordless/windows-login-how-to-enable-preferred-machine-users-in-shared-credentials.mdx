This feature of Windows login app lets you add a preferred machine to a shared domain credential, enabling login to those specific Windows systems.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure the endpoint is paired with the Windows Login application.
- Create Shared Credential of credential type as Domain User. Refer here [How to create shared credentials for Windows login](/passwordless/windows/supervisor/supervisor-portal-how-to-create-shared-credentials-for-windows-login).

To enable preferred machine users:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left panel menu. ![](/images/8227103/63a4b7076233.png) The Endpoints page is displayed.
3. Select endpoint name from the listed endpoints. ![](/images/8906511/128a4f710f5b.png) The endpoint detail page is displayed.
4. Go to **Configure** > **Endpoint Settings**. ![](/images/8906511/01e517a37f26.png)
5. Turn on **Enable only Preferred Machine Login**. ![](/images/8906511/8ba2145415f7.png)
6. Click **Save**.Now, you can successfully log in to your Windows system.

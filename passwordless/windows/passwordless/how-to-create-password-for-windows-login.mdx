## Create Password for local windows machine

To create Password:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![Image](/images/8468581/6142e01fd801.png) The **Users** page is displayed.
3. Click **User Name** to edit. ![Image](/images/8468581/d626c453e0da.png) The **User details** page is displayed. ![](/images/8468581/83f0439c8704.png)
4. Go to **Credentials**tab > **Windows** **Password** > **+ Create Password**. ![Image](/images/8468581/391d08b222a7.png) The **Create Windows Password** pop-up box is displayed. ![Image](/images/8468581/9246f24ef154.png)
5. Do the following:Enter **Display Name** that displays on the Windows Login page.Select**Windows Local User** type from **Credential Type** dropdown list.Click **Next.** ![](/images/8468581/8837e2674adf.png) Enter **Machine Name**.**Note**: Enter your Windows device name.Enter **Username**of your Windows Login.Note: Username should be your Windows account name..Enter **Password**of your Windows Login.Click **Save**.The password is created and listed in the **Windows** **Passwords** tab. ![Image](/images/8468581/825813f6a398.png)

## Create Password for domain

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel. ![](/images/12275469/b9c707f0a9b1.png) The **Users** page is displayed.
3. Click **User Name** to edit. ![Image](/images/8468581/d626c453e0da.png) The User details page is displayed.
4. Go to **Credentials** tab> **Windows Passwords** > **Create Password**. ![Image](/images/8468581/c2825cfaa24b.png) The **Create Windows Password** pop-up box is displayed.
5. Do the following:Enter **Display Name** that displays on the Windows Login page.Select **Windows Domain User** type from **Credential Type** dropdown list.Click**Next.**![Image](/images/8468581/9246f24ef154.png) The next screen is displayed.![](/images/8468581/8cd5f04e0a45.png) Enter **Domain Name.**Select **Preferred Machine**from the **Preferred Machine(s)** list.Enter **Username**of your Windows Login.**Note:** Username should be your Windows account name.Enter **Password**of your Windows Login.Click **Save**.The password is created and listed in the **Windows Passwords** tab. ![Image](/images/8468581/7986c68772c6.png)

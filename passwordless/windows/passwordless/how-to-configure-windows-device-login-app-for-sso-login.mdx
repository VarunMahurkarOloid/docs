## Introduction

Oloid's Windows device login provides secure, user-friendly authentication for devices, apps, and networks, using options like facial recognition, badges, PINs, and Multi-Factor Authentication (MFA). This login mechanism enhances security and user convenience, offering a reliable alternative to traditional passwords for accessing crucial data and services.

## Configuration

To configure the Windows Device Login, perform the below steps:

1. Create "**Application**".**Note**: You must create an application of "**Passwordless**" type.
2. Create "**User**".
3. Add "**Connection**" to the "**Application**".**Note:**Add the same Connection to the Application in which the User is present.
4. Assign "**Badge**".
5. Add "**Pin**".**Note**:By default, the Pin is set to 4 Digit Numeric Pin. You can configure the Pin length. For Pin configuration, see [How to configure the Pin](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin).
6. Onboard "**Face**".
7. Create "**Password**".
8. Create and assign "**Shared Credential**".
9. Pair "**Windows Device Login endpoint**".

The Windows Device Login is now configured and ready for use.

## Introduction

Ensure that your system meets these requirements before installing the Windows Login (Healthcare) in your system to avoid compatibility or performance issues.

## Minimum Software Requirement

| **Components** | **Minimum Requirements** |
|---|---|
| Operating System | Windows 8 and above |
| Software Requirements | .Net Runtime 8.0.Net Desktop Runtime 8.0Visual C++ 14 Runtime Libraries |

## Minimum Hardware Requirement

| **Components** | **Minimum Requirements** |
|---|---|
| RAM | 4 GB or more |
| Card Reader | Required Card reader for Badge/NFC authentication. |
| Hard Disk | 256 GB or more |
| Badge | Required Badge for authentication. |
| NFC ID | Required NFC ID for authentication. |
| External WebCam (Optional, if inbuilt camera is present) | **Minimum resolution**: 720 MP (1280 x 720 pixels) or higher.**Recommended resolution**: 1080 MP (1920 x 1080 pixels). |

**Note:** For supported card types, refer [Oloid Supported Card Types | Oloid Help Center](/resources/guides/oloid-supported-card-types)

## Incompatibility Warnings

Windows Login **may not function properly** on web browser with the following limitations:

- Devices without a functional camera or NFC module.
- Device RAM is below 4 GB.

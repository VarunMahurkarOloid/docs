## Introduction

The Windows Post-login Module allows the admin to control post-login behavior on Windows devices after user authentication. Enabling this feature helps customize the user experience by triggering specific actions or workflows immediately after login.

## Prerequisite

You must have access to the Tenant Admin Portal.

## **Steps to Enable**Post Login page

1. Log in to the Tenant Admin Portal.
2. On the homepage of the portal, click **User profile icon**on the bottom left corner of the menu panel. ![](/images/15457971/24b74e59a157.png) The user profile menu is displayed.
3. Select **Tenant Settings**. ![](/images/13713819/c88e8e3b0807.png) The **Tenant Settings**screen is displayed. ![](/images/15457971/eeb6270f08ee.png)
4. Go to **App Settings**tab > **Windows App**. ![](/images/15457971/3e3cf04e0638.png) The Windows App settings page is displayed.
5. Turn on the **Enable Windows Post-login Module**toggle.
6. Click **Save.** ![](/images/15457971/f8fe4e0307f0.png) The Windows Post-login Module is enabled.

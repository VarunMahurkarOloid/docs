## Introduction

The **Auto-Pair Config File** allows the Tenant Admin to streamline the process of pairing Windows endpoints with a configured application. By generating this file from the Tenant Admin Portal, admins can automatically connect multiple endpoints.

## Prerequisites

- You must have access to a Tenant Admin Account.
- Ensure that a **Windows Login** application is already created in the Tenant Admin Portal. Refer: Windows Login - [How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to generate auto-pair config file

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/10441578/b90c325f9cf8.png) The user profile menu is displayed.
3. Click **Tenant Settings**. ![](/images/10441578/e184a5672785.png) The **Tenant Settings** page is displayed.
4. Go to **Security** tab >**API Token** > **API Key**. ![](/images/10441578/f17408aa6124.png)
5. In the**Generate Temporary Access Token**section, do the following:In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.To set the start date and time, click the date picker or select **Now**.Select the **End Date/Time** field.Click the date picker, choose when the token will expire, and then click **OK**.Specify **Number of Endpoints** that can be created using the endpoint. (Optional)Click **Generate**. ![](/images/10441578/2f757f45c451.png) The auto-pair config file is generated.
6. Click **Auto-pair config file**. ![](/images/10441578/c78eb07337d7.png) The Auto-pair config file pop-up box is displayed.
7. Do the following:Select **Application Type**as**Passwordless - Windows Login**from dropdown.From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.**Note:**Select **Skip user confirmation for pairing**option to auto-pair endpoints without requiring user confirmation.Select **TEXT**as download file format > click **Copy Config Text.** (optional)**Note:**This button will copy (to clipboard) the config file in the selected download file format.Click **Download**.

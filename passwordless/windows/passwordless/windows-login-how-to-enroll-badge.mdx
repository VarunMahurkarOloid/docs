**Introduction**

This document provides step-by-step instructions for enrolling badge through Windows Login app.

Steps to enroll badge through Windows Login app:

1. On the Windows lock screen, click **Login with OLOID**. ![](/images/10006252/e0bb0f5125d1.png) The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with Badge**. ![](/images/9991972/43cb1202b523.png)
3. Tap the **Badge** on the **Badge Reader** to scan it.**Note:**The badge reader must be connected to the computer. ![](/images/9991972/ee54a0be34fc.png) The badge authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed**screen, select **Enroll Credential**. ![](/images/9991972/b8f78ab30569.png) The **Verify using Windows Credential** screen is displayed.
5. Do the following:Enter **Domain\Username**.Enter your Windows domain and username in the format `Domain\Username`.Enter **Password**.Use your Windows account password.Select **Enroll Windows credential to your account**. (Optional)Click **Continue**. ![](/images/10002126/bd6c39a089d9.png) The **Select Credential to Enroll or Update**screen is displayed.
6. Select **Badge**.**Note:**You can also update the badge credential. ![](/images/9991972/ba0e9babe4df.png) The **Scan your Badge to Enroll**screen is displayed.
7. Scan your badge in the Badge Reader. ![](/images/9991972/3546c50e45f8.png)
8. Click **Submit**.The badge is enrolled successfully. ![](/images/9991972/c2251d55b0c7.png)

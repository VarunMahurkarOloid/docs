## Oloid's Presence Detection Feature for Windows Login Application

The Presence Detection feature in Oloid’s Windows Login Application enables the system to monitor user presence at a defined endpoint. If the camera fails to detect a user’s face, an alert is triggered. This feature can also be customized to detect additional conditions such as face tracking violations, the use of prohibited devices, detection of multiple faces, and other predefined events and actions.

When a violation is detected, the Windows screen gets blocked, disabling all interactions except for specific buttons displayed on the blocked screen. Alerts notify supervisors of the detected events, allowing them to take appropriate actions.

## How to Enable the Feature

To activate the Presence Detection feature, contact the Oloid Customer Success Team. Additionally, provide a list of events and default actions for which alerts should be triggered, as specified by the Oloid Admin. This information will be hardcoded into the endpoint configuration file for the Windows Lock setup associated with your tenant.

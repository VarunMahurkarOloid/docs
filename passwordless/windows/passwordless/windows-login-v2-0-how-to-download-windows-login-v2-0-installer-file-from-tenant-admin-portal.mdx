## Introduction

This document explains how to download the **Windows Login v2.0** installer from the Tenant Admin Portal. After downloading the installer, you can proceed with the installation and setup of the Windows Login application on your system.

## Prerequisites

- You must have access to a Tenant Admin account.
- You have local administrator access on the Windows machine.
- Check System Requirements. For more information, refer: [Windows Login Version 2 - Hardware and Software Requirements](/passwordless/windows/passwordless/windows-login-v2-0-hardware-and-software-requirements)

## Steps to download Windows Login v 2.0

1. Log in to **Tenant Admin Portal**.
2. On the homepage of the portal, click **User profile icon**on the bottom left corner of the menu panel. ![](/images/15069295/24b74e59a157.png)
3. The user profile menu is displayed.
4. Select **Tenant Settings**. ![](/images/13713819/c88e8e3b0807.png) The **Tenant Settings**screen is displayed. ![](/images/13713819/b41260d5cce1.png)
5. Go to **Oloid Apps**tab > **Windows Authenticator App V2**Login. ![](/images/15069295/739d5cfa2c52.png)
6. Select the preferred version from the **Win-Login-Installer** dropdown list, then click the **Download** button ![](/images/15069295/ad510ed335f9.png) icon. ![](/images/15069295/2417657223ce.png) The installer file is downloaded to your local device.After the download is complete, you can proceed with installing Windows Login App.

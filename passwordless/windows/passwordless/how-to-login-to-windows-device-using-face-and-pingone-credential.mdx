## Introduction

The Windows Login app allows users to securely sign in to their Windows devices using Face and PingOne Credentials. This passwordless, multi-factor login method provides a faster and more secure way to access devices.

## Prerequisites

- You must have access to a registered mobile device where the PingOne app is installed and enrolled for your user account.
- Your face must be registered.
- The Windows device has a functional camera.**Note**: If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).

## Steps to sign in to Windows Device

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The **camera** turns on.
2. Show your Face in front of the camera to capture the face. ![](/images/12421904/a8c8ecdaa6b4.png) The **Ping Authentication** pop-up box is displayed. ![](/images/13525477/26993fbc8cfb.png) The Push notification is displayed in your registered device.
3. Tap **Yes**. ![](/images/13525477/cddcb9ce746e.png)
4. The **Authentication Approved** screen is displayed. ![](/images/13525477/fb8cd0d6ee5e.png) The **Choose Your Account** pop-up box is displayed.**Note**: If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
5. Select the account to sign in. ![](/images/12421904/4af001793749.png) You are signed in to the Windows device successfully.

**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [rf IDEAS website](https://www.rfideas.com/support/tools/downloads).

To configure your card reader:

1. Launch the rf IDEAS configuration utility app.Make sure the card reader is connected to the system.
2. Select **Connect** from the top menu bar. ![](/images/9398720/a747658453e5.png) The DEVICE LIST is configured and displayed. ![](/images/9398720/b84c61236178.png)
3. Select the preferred configuration from the **CONFIGURATION(s)** dropdown list. ![](/images/9399762/016cdce3ff0f.png)
4. Select **Write** from the top menu bar. ![](/images/9399762/24d397754742.png) The card reader is updated with the new settings.
5. Place your cursor in the **Test Area**and scan your NFC tag with the card reader. ![](/images/9399762/2522136ec48f.png) The NFC tag number is displayed in the Test Area. ![](/images/9399762/add47842254f.png) The card reader is configured for the NFC tag.

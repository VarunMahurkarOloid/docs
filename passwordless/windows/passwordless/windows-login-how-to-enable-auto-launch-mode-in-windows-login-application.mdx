## Introduction

In Oloid Portal, enabling Auto Launch Mode feature in Windows Login application automatically launches the Windows Login app on the pre-login screen.

## Steps to enable Auto Launch Mode:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App). ![](/images/10852057/ca340dba5264.png) The application page is displayed. ![](/images/10852057/479f82ca733c.png)
3. Go to**Configure** > **Settings** tab. ![](/images/10852057/b8df4abc28f4.png)
4. Turn on **Enable Auto Launch** **Mode** toggle button to automatically launch the Windows Login app on the pre-login screen. ![](/images/10852057/302fb6cae958.png)
5. Click **Save**. ![](/images/10852057/71ba2ba29596.png) The configuration is saved successfully. See, [Sample screen for Auto Launch Mode](#h_e3fa7315c8)**Note:**In **Windows Authenticator App,**you must update device configuration for auto launch mode to work properly.

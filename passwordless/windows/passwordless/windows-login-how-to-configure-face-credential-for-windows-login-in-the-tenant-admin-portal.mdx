## Introduction

In the Tenant Admin Portal, enabling and configuring face credentials for the Windows Login application allows users to log in using facial recognition with advanced configuration options for enhanced security.

## Prerequisite

- You must have access to the Tenant Admin Portal.
- You must create and configure Windows Login application in the Tenant Admin portal. For more, refer to[How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Configure face credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application. ![](/images/10900687/ca340dba5264.png) The application page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Authenticator** tab > **Face** menu > Turn on**Face**toggle to use face as credential. ![](/images/11476775/2c3b33424212.png) The **Advanced Settings** page is displayed. ![](/images/11476775/4132fa59e8aa.png)​
4. Adjust the following setting for **Face Match Parameters**.**Note:**You must consult your Oloid representative before making any changes to the **Face Match Parameters** to ensure optimal authentication performance. ![](/images/11476775/fc14e8c0aa39.png) Turn on **Strict Error Handing** toggle to skip the error and perform a direct one-to-one face match. ![](/images/11476775/36a4a4154dc7.png) Turn on **Additional Face Match** toggle to perform a one-to-one face match alongside the standard face matching process. ![](/images/11476775/af505705c951.png) Adjust the **Face Match Threshold** slider or enter a value directly into the input box to set the face match threshold value. ![](/images/11476775/f4f631561d2f.png)
5. Adjust the following setting for**Liveness check parameters**.**Note:**You must consult your Oloid representative before making any changes to the **Liveness check parameters** value to ensure optimal authentication performance.**Min Liveness Probability**: Specifies the threshold used to determine whether an image is live or spoofed.Default value: 0.5Images with a liveness probability of **0.5 or higher** are classified as live.**Min Liveness Quality**: Specifies the minimum quality required for an image to be suitable for a liveness check.Default: 0.1Images with a quality score of **0.1 or higher** are considered suitable for liveness verification.
6. Click **Save**. ![](/images/11476775/6683dc0d0f64.png) The Face recognition for Windows Login application is configured successfully. ![](/images/11476775/168ee3fe99c2.png) Sync Configuration to Apply ChangesAfter enabling, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

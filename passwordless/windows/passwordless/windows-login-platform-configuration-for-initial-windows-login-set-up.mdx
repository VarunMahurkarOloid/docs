For Oloid's Windows Login to function, it needs to be configured in the Oloid Platform.

## Initial set up

## Step 1: Set up Application and Connection

1. Create and Configure Windows Login Application. Refer to [How to create and configure Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal) guide.
2. Create Connections. Refer to [How to create Connections](/administration/admin-portal/tenant-admin-portal-how-to-create-connection)

## Step 2: Map Connections to Applications.

Once both Application and Connection are created, you need to map the Connection to the Application.

Refer to [How to Map Connection to Application](/administration/admin-portal/how-to-map-connections-to-an-application-in-the-tenant-admin-portal)

## Step 3: Create user and assign user to connection.

Create users and assign users to connections in Oloid Portal. Refer to [User Onboarding](/resources/guides/user-onboarding-for-oloid-portal) guide.

## Step 4: Enable Authenticator factors

Based on the requirement , enable authenticator factors in the tenant application. Refer to [How to create and configure Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal) > [Configure Authenticator tab](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

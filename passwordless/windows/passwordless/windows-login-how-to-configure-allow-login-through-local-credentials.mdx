## Introduction

This document explains how to configure **Allow Login Through Local Credentials** for the Windows Login application in the Tenant Admin Portal. Enabling this setting allows users to sign in to Windows using their local Windows credentials.  
​

## Prerequisites

- Tenant Admin access to the **Tenant Admin Portal.**
- You must create and configure Windows Login application. For More, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal) ​

## Steps to Configure Allow Login Through Local Credentials

1. Log in to the Tenant Admin Portal.
2. Go to **Applications** > select **Windows Login** application. ![](/images/13615407/ca340dba5264.png) The **Details** page is displayed. ![](/images/13615407/1a70a9419273.png)
3. Go to **Configure** > **Settings** tab.
4. Enable **Allow Credential Updates and Enrollment** toggle to allow users to update or enroll credentials using Windows credentials.Enable **Allow Login Through Local Credentials** to allow users to log in to Windows using their local Windows credentials.
5. Click **Save**. ![](/images/13615407/df7cdfa6b6d4.png) The **Allow Login Through Local Credentials** setting is enabled successfully. ![](/images/13615407/42737d6031b2.png) Sync Configuration to Apply ChangesYou must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

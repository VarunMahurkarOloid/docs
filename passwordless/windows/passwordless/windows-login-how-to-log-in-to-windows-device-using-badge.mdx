**Introduction**

This document provides step-by-step instructions for logging in with badge to Windows device.

**Pre-requisite**

- In the Oloid Portal, you must do the following:Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](/administration/admin-portal/how-to-assign-badge-id-as-credential-to-users)Enable Badge as an authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

**Steps to sign in to Windows device:**

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens and the **Scan Badge** screen is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it. ![](/images/12421947/ee54a0be34fc.png) On Badge authentication, you are signed in to the Windows device.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully. ![](/images/10626849/4af001793749.png) **Note:**The user can also perform offline badge authentication after completing at least one successful online badge authentication.

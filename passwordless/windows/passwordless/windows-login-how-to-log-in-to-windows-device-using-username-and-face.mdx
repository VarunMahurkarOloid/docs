## Introduction

This document provides step-by-step instructions for logging in with username to Windows device.

## Pre-requisite

- You must have an Oloid account.
- You must add face to the user. For more details, refer [How to onboard face of a single user](/administration/admin-portal/how-to-onboard-face-of-a-single-user)

## Steps to sign in to Windows device

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png) The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png)The **Welcome**screen is displayed.
2. Enter your employee ID / email ID in**Enter your Employee ID / Email ID** textbox, then click **Continue**. ![](/images/8893874/7d72c0cc687c.png) The camera turns on.
3. Place your face in front of the camera for facial authentication. **Note:**Face credential must be enabled in the Oloid Portal. For more details, refer [How to create and configure Windows application](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal) ![](/images/8893874/1697ecc2b263.png)
4. On successful facial authentication, you are signed in to the Windows device.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully. ![](/images/10626849/4af001793749.png)

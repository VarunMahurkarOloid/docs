## Introduction

The Password credential feature in the Tenant Admin Portal allows admin to enable Password-based multi-factor authentication (MFA) for the Windows Login application. Once enabled, users can log in to Windows endpoints by entering a secure Password.

## Prerequisite

- A individual password must be created for the user. For more, refer to [How to create Password for Windows Login](/passwordless/windows/passwordless/how-to-create-password-for-windows-login)
- After making any updates in the Windows Login application, make sure to sync the configuration in the Supervisor App to apply the changes. For more, refer to [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app)

## Steps to configure Password credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application. ![](/images/10900687/ca340dba5264.png) The application page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Authenticato**r tab.
4. Turn on**Password**toggle. ![](/images/11507597/8f4ae9fb539d.png)
5. Turn on **Validate Using Individual Password**toggle to validate the individual password during authentication.**Note:**If no individual password is created or assigned to the user, the login will fail and an error message will be displayed.If multiple individual passwords are assigned to the same user, login will fail and an error will be displayed.Make sure each user has only one individual password created or configured. ![](/images/11507597/b35018f80214.png)
6. Turn on **Enable Password as Adaptive Multi-Factor** toggle to skip asking for password after one successful login using Badge, QR Code, or NFC within the **Adaptive Factor Duration**.
7. Set the**Adaptive Factor Duration**(in hours and minutes) to define the time interval during which the system will not prompt for a password after a successful login.
8. Click **Save**. ![](/images/11507597/b7228163b0ee.png) The Password authenticator for Windows Login application is configured successfully. ![](/images/11507597/3eb267869992.png)

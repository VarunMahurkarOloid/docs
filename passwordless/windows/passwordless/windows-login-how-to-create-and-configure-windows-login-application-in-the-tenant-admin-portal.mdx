## Introduction

This section explains how to create a Windows Login passwordless application in the Tenant Admin Portal and configure the required settings to enable secure user authentication on Windows endpoints.

## Steps to create and configure Windows Login application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right corner. ![](/images/9352266/5e05391a739f.png) The **Create New Application** pop-up box is displayed.
3. Do the following:Enter **Application Name.**Select **Application Type**as **Passwordless**.Click **Next**. ![](/images/9352266/4143d09cd7a0.png) The **Select Passwordless Use Case**page is displayed. Select **Windows Login** > click **Create**. ![](/images/9352266/0f5c1db9b27e.png) The Passwordlessapplication of type **Windows Login** is created and the configuration page is displayed.
4. Configure the following:[Details tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Authenticator tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Theme tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)[Configure tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)Health Setup tab[Connections tab](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal)

<Note>
  These are one-time settings and all the default settings are recommended.
</Note>

## Configure Details tab

1. Modify **Application Name**(if required).**Note**: Special characters are not allowed in Application Name.
2. Add **Description**. (Optional)**Note**: The description should be less than **140**characters.
3. Select your **Timezone**based on your country and region from dropdown list. (Coming Soon)
4. Select **Factor Sequence** from drop down list to activate Multi-Factor Authentication (MFA) for the Application's Endpoints. (Coming Soon)

## Configure Authenticator tab

You may enable username and one or more credential options based on your requirements.

## Enable Username

**Emp ID/Primary ID:**Enable this option to prompt the user to enter their Employee ID or Primary ID before authentication.

- (Optional) In the **Custom Label** field, enter a label that appears on the login screen instead of **Emp ID / Primary ID**.

<Frame>
  <img src="/images/9352266/57d605960ea4.png" alt="Screenshot" />
</Frame>

**Email:**Enable this option to allow users to log in using their email ID without needing further authentication.

- Select the **Remember Username** checkbox to save the user after the first login. Next time, the app skips the ID entry screen and opens the authentication screen directly.

Do the following:

1. To use face as credential, enable **Face**option. The **Advanced Settings** page is displayed.Enable the **Take Re-consent During Transactions** Toggle.Take Re-consent During transactions: When enabled, shows the re-consent form to users with invalid consent during every face authentication until they re-sign.

For more, refer to [How to configure Face credential for Windows Login Application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-configure-face-credential-for-windows-login-in-the-tenant-admin-portal) ![](/images/9352266/5b682ffe2939.png)

## Configure Settings tab

- **Enable Auto Launch Mode:**Select this option to auto-launch the Windows Login app in the login screen. **Set Time-Out for Login Screen:**Select this option to allow users to configure the maximum time the system will wait on the login screen before timing out. ![](/images/9352266/13c8b7b439de.png)
- **Use Groups for Authorization:**_Coming Soon_
- **Validate Windows Credential:**Select this option to ensure Oloid Agent checks the validity of the user’s Windows credentials before logging in. ![](/images/9352266/de1edf1ab13c.png)
- **Enable Passkey:**Turn on **Enable Passkeys**toggle button to allow users to log in using Passkey credential. ![](/images/9352266/ff7a600bc3e8.png)
- **Allow Credential Updates and Enrollment:**Select this option to allow users to self-enroll or update their credentials. Enable **Hide Option to Save Windows Credentials**toggle to hide the Save credentials option from the enrollment screen after Windows domain credentials are validated.Select **Auto-save credentials on successful validation when the Save choice is hidden**checkbox to automatically save validated Windows credentials to the user’s Oloid account when the Save credentials option is hidden. Enable **Allow Login Through Local Credentials** to allow users to log in to Windows using their local Windows credentials. For more, refer to [How to Configure Allow Login Through Local Credentials](/passwordless/windows/passwordless/windows-login-how-to-configure-allow-login-through-local-credentials) ![](/images/9352266/4b62eedbc606.png)
- **Capture Windows User Events:**Select this option to capture Windows events for user logins, logouts, locks, unlocks, and credential provider details. All captured data is stored in the transaction tab. ![](/images/9352266/2a46fe3f14e3.png)
- Enable **Auto-recover Endpoint**to automatically validate and sync the endpoint configuration during login module launch. ![](/images/9352266/e0c9d2bc2371.png)
- **Enable Manual Capture Accessibility:**Turn on this option to allow users to manually capture their face during face authentication. ![](/images/9352266/3345081d7151.png)
- **Enable Auto Authentication of Webkey using Local Transaction toggle**to auto-authenticate the user into Webkey after device login. ![](/images/9352266/f91cd4f3e592.png)
- **Enable Badge Out:**Select **Badge out using Windows Service**option to allow users to log out of their Windows system using their badge. For details, refer to [Windows Login - How to configure Enable Badge Out option](/passwordless/windows/passwordless/windows-login-how-to-configure-badge-out-option) ![](/images/9352266/98c20140832a.png)
- **Master Admin override passcode:**Follow the onscreen instruction to create master admin override passcode. For details, refer [How to create device-admin passcode for Supervisor App](/administration/device-admin-apps/windows-login-how-to-create-device-admin-passcode-for-supervisor-app) ![](/images/9352266/1669b55e8900.png)
- **Apply Endpoint Template**: Select a Windows Login endpoint template that is applied during the endpoint pairing process. ![](/images/9352266/8528a7951eb8.png)
- **Enable Proxy Configuration** to configure proxy settings for secure network communication through a proxy server.
- Do the following:Enter **Proxy URL**.Enter **Port**.Enter **Username**. Enter **Password**.
- Click **Save**.

## Introduction

The **Dev Dashboard** in the Windows System Tray application provides access to session tracking for the Windows Login environment. It allows users to view system-level details and validate logs directly from the device.

## Prerequisites

- You must have the Windows Login version 2.0 installed on your windows machine. Refer: [How to Download, Install, and Auto-Pair Windows Authenticator App (Version 2.0)](/passwordless/windows/passwordless/windows-login-v2-0-how-to-install-and-auto-pair-windows-login-v2-0-app)
- Ensure System Tray application is running in the background.

## Steps to Access Dev Dashboard

1. Log in to **Windows device** your Windows Machine. refer: [How to log in to Windows device using Badge and PIN through Windows Login app](/passwordless/windows/passwordless/windows-login-how-to-log-in-to-windows-device-using-badge-and-pin)The Windows home screen is displayed. ![](/images/14796550/ee84d4a7f283.png)
2. On the bottom Menu Bar click **Show Hidden Icons** arrow.
3. Click **Oloid System Tray**icon. ![](/images/14796550/e2e418cd4599.png) The **Oloid System Tray Application** is displayed. ![](/images/14796550/29f6d63be009.png)
4. Select **Launch Dev Dashboard** from the **Actions** dropdown. ![](/images/14796550/91370770e758.png)
5. Click **Apply Action** ![](/images/14796550/77145f807b5f.png) The Dev Dashboard is displayed.The **Dev Dashboard** in the Windows System Tray application provides system administrators with visibility into the **current active session** on the device. ![](/images/14796550/37bb371791ca.png)

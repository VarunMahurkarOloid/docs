## Introduction

This document explains how to configure login options for Oloid Apps in the Tenant Admin Portal. These settings determine how users access the Supervisor App and User Enrollment App after the Windows endpoint is paired.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure the Endpoint is paired to the Windows Login Application.

## Steps to configure the login options

1. Log in to the **Tenant Admin Portal.**Home page is displayed.
2. Select the application that is configured in the Supervisor App (Windows Login App). ![](/images/10616183/ab1f40d15779.png) The application details page is displayed. ![](/images/10616183/8ef8caf47e77.png)
3. Click **Configure**tab> **Oloid Apps**. ![](/images/15390851/2a80f3ecde8b.png) The **Oloid Apps** page is displayed.
4. Do the following: In the **Supervisor App** section:Select **User Login (Redirects to launch the User Enrollment App)** to allow users to be redirected to the User Enrollment App during login. ![](/images/15390851/cdf1e129009d.png) In the User Enrollment App section:Select **Login with Windows Credentials** to allow users to log in using their Windows credentials.Select **Login with Oloid** to allow users to log in via the Oloid user portal.**Note:**Choose one or both login options based on your authentication requirements.
5. Click **Save**. ![](/images/15390851/da33459ea476.png) The Log in options are configured. ![](/images/15390851/51df2f16bcbd.png)

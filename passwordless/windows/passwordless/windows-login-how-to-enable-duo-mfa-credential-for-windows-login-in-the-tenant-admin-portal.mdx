## Introduction

The Duo feature in the Tenant Admin Portal allows admins to enable Duo as a second factor authentication for the Windows Login application. When enabled with other primary factors, users can log in to endpoints using Duo credentials as a second factor.

**Note:**Windows Login supports Face, Badge, QR Code and NFC/ID as primary factor.

## Prerequisites

- You must have a Tenant Admin Account.
- Duo Security account credentials and details must be configured.

## Steps to Enable Duo MFA

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application. ![](/images/12412511/df73d7f81d62.png) The application page is displayed. ![](/images/12412511/ca7702338496.png)
3. Go to the**Authenticato**r tab.
4. **MFA Credential** > turn on**Duo**toggle. ![](/images/12412511/72a267506de7.png) The Duo MFA credential is enabled successfully. ![](/images/12412511/1a5387700dd4.png) Sync Configuration to Apply ChangesAfter enabling the **Duo MFA credential**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

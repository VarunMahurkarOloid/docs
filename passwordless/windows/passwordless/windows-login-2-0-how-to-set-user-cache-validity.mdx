## Introduction

User Cache Validity controls how long user data is stored locally on an endpoint after authentication. This document explains how to configure the User Cache Validity duration for an endpoint in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login Application is created. [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the Endpoint is paired with the application. Refer: [Windows Login - How to pair Supervisor App using auto-pair config file option](/passwordless/windows/supervisor/windows-login-how-to-pair-supervisor-app-using-auto-pair-config-file-option)

## Steps to Set User Cache Validity

1. Log in to the **Tenant Admin Portal**.
2. On the Left menu Panel of the Home page select **Endpoints**. ![](/images/15431849/a204bb4e8bfa.png) The **Endpoints** page is displayed.
3. Select the **Endpoint name** to edit. ![](/images/15431849/54db28d23417.png) The **Endpoints** Details page is displayed.
4. Go to **Endpoint Tab**> **Endpoint Settings**. ![](/images/15431849/b60e9684c1f4.png) The **Endpoint Settings**page is displayed.
5. Enable the **User Cache Validity** toggle.
6. Under User Cache Validity set the **Duration** as required.**Note:**User Cache validity is the duration for which the user data will be saved on the machine as cache.
7. Click **Save**. ![](/images/15431849/2619980f2b2b.png) The User Cache Validity duration is set.

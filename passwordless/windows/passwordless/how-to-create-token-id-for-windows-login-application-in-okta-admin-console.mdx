## Introduction

This document explains how to create a Token ID in the Okta Admin Console.  
The Token ID is required to securely authenticate and authorize API access for Okta integrations.

## Prerequisite

You must have **admin access** to the Okta Admin Console.

## Steps to Create Token ID

1. Log in to the **Okta Admin Account**.
2. On the left menu panel, go to **Security**>**API.** ![](/images/13175430/b913ac5f0bd0.png) The **API** screen is displayed.
3. Click **Tokens**. ![](/images/13175430/80bc2cd86eb2.png) The API Token page is displayed.
4. Click **Create token**. ![](/images/13175430/5a336a3ee01d.png) The **Create token** pop-up box is displayed.
5. Do the following:Enter **Token name**.Select the API calls from the drop-down.**Note:** Select **Any IP**.Click **Create token**. ![](/images/13175430/a03d3e73b2c4.png) The **Verify your Password** screen is displayed.
6. Enter **OKTA Password** and click **Verify**. ![](/images/13175430/fb3c8a0a7646.png) The Token ID is created successfully.

## Introduction

This document describes how to apply an endpoint template in the Tenant Admin Portal after completing auto-pair configuration on the Windows Login application. Applying an endpoint template ensures that predefined settings are consistently and automatically applied across all applicable device(s).

## Prerequisites

- You must have a Tenant Admin Account.
- The Windows Login App must be auto paired. To auto-pair refer [How to Install and Auto-Pair Windows Authenticator App through MDM](/passwordless/windows/passwordless/windows-login-how-to-install-and-auto-pair-windows-authenticator-app-through-mdm)
- An Endpoint template must be created. To create refer [How to create an endpoint template](/administration/admin-portal/tenant-admin-portal-how-to-create-endpoint-template).

## Steps to apply Endpoint Template after Auto-pair

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu.![](/images/12576484/21257a54a5dc.png) The endpoint screen is displayed.
3. Select the **Endpoint**.![](/images/12576484/9519f1a8a759.png) The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**.![](/images/12576484/ffa0b8c20cdb.png) The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown.![](/images/12576484/42175163c888.png) The selected template is displayed in the **Select Template** field.
6. Click **Apply**.![](/images/12576484/d429d4250e09.png) The template is successfully applied to the endpoint.![](/images/12576484/843a6b79211f.png)

**Introduction**

This document provides step-by-step instructions for enrolling face through Windows Login app.

Steps to enroll face through Windows Login app:

1. On the Windows lock screen, click **Login with OLOID**. ![](/images/10006252/e0bb0f5125d1.png) The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with Face**. ![](/images/10006252/14599b692e63.png) The Windows login app opens and the camera turns on.
3. Place your face in front of the camera for facial authentication. ![](/images/10006252/1697ecc2b263.png) The Face authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed**screen, select **Enroll Credential**. ![](/images/10002126/b8f78ab30569.png) The **Verify using Windows Credential** screen is displayed.
5. Do the following:Enter **Domain\Username**.Enter your Windows domain and username in the format `Domain\Username`.Enter **Password**.Use your Windows account password.Select **Enroll Windows credential to your account**. (Optional)Click **Continue**. ![](/images/10002126/bd6c39a089d9.png) The **Select Credential to Enroll or Update**screen is displayed.
6. Select **Face**.**Note**: If connection is enabled, user consent is requested before uploading the picture. ![](/images/10006252/5c207e58496b.png) The camera turns on.
7. Place your face in front of the camera for face authentication. ![](/images/10006252/1697ecc2b263.png) Your face is automatically captured and it is enrolled successfully. ![](/images/10006252/c18149c010e5.png)

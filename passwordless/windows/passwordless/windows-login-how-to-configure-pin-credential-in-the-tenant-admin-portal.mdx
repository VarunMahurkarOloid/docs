## ​Introduction

The PIN credential feature allows admins to configure PIN-based multi-factor authentication (MFA) for the Windows Login application. When enabled, users must enter a secure PIN as a secondary authentication factor after successful primary authentication.

## Prerequisites

- You must have **Tenant Admin** access to the Tenant Admin Portal.
- The **Windows Login application** must be created and configured in the Tenant Admin Portal. For More, refer to[How to create and configure Windows Login application in the Tenant Admin Portal](/passwordless/windows/passwordless/windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to configure PIN credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application. ![](/images/10900687/ca340dba5264.png) The **Details** page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Authenticato**r tab.
4. Turn on**PIN**toggle. ![](/images/11484425/e9c57d1e2182.png)
5. **Enable Face followed by PIN MFA** toggle to enable **multi-factor authentication (MFA)** by requiring a **PIN as the second authentication factor** when **Face** is used as the first factor.
6. Do the following configuration on **Adaptive Multi-Factor**which skips second factor authentication after first successful login: (Optional)Turn on**Enable PIN as Adaptive Multi Factor** toggle.Set **Adaptive Factor Duration**(in hours and minutes) to define how long the system skips prompting for second-factor authentication after a successful log in.
7. **Enable Forgot PIN link** toggle. For more, refer to [How to Enable Forgot PIN Link in Windows Login Application](/passwordless/windows/passwordless/windows-login-how-to-enable-forgot-pin-link-for-windows-login)
8. Click **Save**. ![](/images/11484425/682e51daa0ad.png) The PIN credential is configured successfully. ![](/images/11484425/c52d6a6efded.png) ​**​Note:** For setting up PIN rules, see [How to Configure PIN Settings in the Tenant Admin Portal](/administration/admin-portal/tenant-admin-portal-how-to-configure-pin). ​ ​**​Sync Configuration to Apply Changes**You must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app). Keywords

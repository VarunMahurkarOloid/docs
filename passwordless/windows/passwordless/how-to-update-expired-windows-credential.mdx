**Introduction**

This document provides step-by-step instructions to update expired Windows Credential.

**Pre-requisite**

You must enable the Validate Windows Credentials toggle button in Windows Login application in the Tenant Admin Portal. For more details, refer [How to enable Validate Windows Credential in Windows Login application](/passwordless/windows/passwordless/windows-login-how-to-enable-validate-windows-credential-for-windows-login)

**Steps to update your expired Windows Credentials:**

1. On the Windows lock screen, do the following:Click **Sign-in options**. ![](/images/10568115/b7642c7ea999.png)The Windows login app is displayed.Select **Windows login app**. ![](/images/10568115/a6e2b17283ce.png) Select **Login with OLOID**. ![](/images/10568115/f24bfc0a6fd4.png) The Windows login app opens.
2. Select your preferred authentication method.**Note:**For detailed instructions about signing in to your Windows device using different authentication methods, refer to[User Guides sections for Windows Login Device](https://oloid.help/en/collections/9564765-user-guides-windows-login) ![](/images/10954843/2bdf17bd8906.png) On successful authentication, you are signed in to the Windows device.**Note**: If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in.![](/images/10954843/4af001793749.png)
3. If your Windows password is changed or expired, the **Invalid or Missing Windows Credential** screen is displayed.
4. Select the account you want to update. ![](/images/10954843/d1093997f44f.png) The **Edit Password** screen is displayed. ![](/images/10954843/7ab4255ba7ea.png)
5. Do the following:Enter Password in the **Enter new Password** field.Enter new Password in the**Re-enter New Password** field.Click **Save**.Your password is updated, and you can log in successfully to your Windows device. ![](/images/10954843/344a3af6bd05.png) Video TutorialWatch the video [How to update expired Windows Credential- Video Tutorial](/passwordless/windows/passwordless/how-to-update-expired-windows-credential-video-tutorial)

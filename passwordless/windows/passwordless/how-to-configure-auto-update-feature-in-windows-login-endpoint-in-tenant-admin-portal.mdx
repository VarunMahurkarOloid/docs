### Introduction

You can configure the auto-update feature in Windows application endpoint from the Auto Update tab. This feature allows you to override the default auto-update configuration inherited from the application level.

Based on your requirement, you can disable auto-updates entirely for a specific endpoint or define a custom update schedule.

### Steps to Configure Auto Update:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Endpoints** on the left panel menu. ![](/images/11196020/37e34703983c.png) The **Endpoints** page is displayed.
3. Click **Endpoint Name** to edit. ![](/images/11196020/0488318552bf.png) The Endpoint detail page is displayed.
4. Go to **Configure**tab > **Auto Update** section. ![](/images/11196020/9f4928a73796.png) The **Scheduled auto-updates**section is displayed.
5. Select one of the following options:**Inherited from Application (default)**: Select this option to use the application's auto-update configuration. **Disable updates for this endpoint**: Select this option to stop automatic updates on the endpoint, even if automatic updates are enabled at the application level.**Custom Schedule**: Select this option to define a specific update schedule and select the latest or specific version. ![](/images/11196020/75fc7cced9f5.png) To configure a custom update schedule, select one of the following: Select **Latest Version** to install the latest available version.**Select Version**: Select this option to choose a specific version that differs from the custom source version.Select **Custom Source** option only if at least one custom source file is listed in the dropdown. If no file is available on the backend, the option remains disabled.Set the **Start Time** and **End Time** to define the auto update window.Configure retry settings:**Retry Frequency**: Number of retry attempts if an update fails.**Retry Interval**: Time interval between each retry attempt.**Note:**The endpoint will attempt to update only within the defined time window. If an update fails, the retry logic is applied based on the frequency and interval specified.
6. Click **Save** to apply the configuration. ![](/images/11196020/a54a36b0f638.png) The auto-update configuration is saved successfully. ![](/images/11196020/d43c6fd68d09.png) **Note:**Make sure to sync the configuration in the Supervisor App to apply the changes. For more, refer to [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app)

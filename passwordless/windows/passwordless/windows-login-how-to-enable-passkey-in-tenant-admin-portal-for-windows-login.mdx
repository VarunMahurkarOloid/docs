## Introduction

The Passkey feature enables secure, passwordless authentication for users accessing a Windows application. This article explains how an admin can enable Passkey login for a Windows application from the Tenant Admin Portal.

## Prerequisite

You must have a Tenant Admin Account.

## Steps to enable Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Windows application to edit. ![](/images/10900687/ca340dba5264.png) The application page is displayed. ![](/images/10900687/479f82ca733c.png)
3. Go to**Configure** > **Settings** tab. ![](/images/11035277/284c22ff918f.png)
4. Turn on **Enable Passkeys**toggle button to allow users to log in using Passkey credential. ![](/images/11035277/ff7a600bc3e8.png)
5.

## Introduction

The PingOne feature in the Tenant Admin Portal allows admins to enable PingOne as a second factor authentication for the Windows Login application. When enabled with other primary factors, users can log in to endpoints using PingOne credentials as a second factor.

## Prerequisite

You must have a **Tenant Admin access** in the Tenant Admin Portal.

## Steps to Enable PingOne MFA

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application. ![](/images/12412511/df73d7f81d62.png) The application page is displayed. ![](/images/12412511/ca7702338496.png)
3. Go to the**Authenticato**r tab > **MFA Credential** > turn on**PingOne**toggle. ![](/images/12888354/d974d750ed8a.png) The PingOne MFA credential is enabled successfully. **Note:** You must do the [Sync Configuration](#h_937789e31f) to apply changes. ![](/images/12888354/c08adadaaddd.png)

## Sync Configuration to Apply Changes

After enabling the **PingOne MFA credential**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](/passwordless/windows/supervisor/how-to-sync-configuration-in-supervisor-app).

## Introduction

This document describes how to configure **OKTA Multi-Factor Authentication (MFA)** in the **Oloid Tenant Admin Portal**. Enabling OKTA MFA adds an additional verification step during login and requires configuring the necessary parameters from the **OKTA Administrator Console**.

## Prerequisites

- You must have **Tenant Admin access** in the Tenant Admin Portal.
- Ensure OKTA Multi Factor Authentication toggle is enabled in the Windows Login Application. To enable, refer [How to Enable OKTA MFA Credential for Windows Login Application in the Tenant Admin Portal | Oloid Help Center](/passwordless/windows/passwordless/windows-login-how-to-enable-okta-multi-factor-authentication-mfa-credential-for-windows-login-in-the-tenant-admin-portal)
- Ensure Token ID is created. To create, refer [How to Create Token ID in OKTA for Windows Login Application | Oloid Help Center](/passwordless/windows/passwordless/how-to-create-token-id-for-windows-login-application-in-okta-admin-console)

## Steps to Configure OKTA MFA

1. Log in to the Tenant Admin Portal.
2. On the homepage of the portal, click **user profile icon**on the bottom left corner of the menu panel. ![](/images/12972617/f13b2a86bc7e.png) The user profile menu is displayed.
3. Click **Tenant** **Settings**. ![](/images/12972617/fe5f5833afe6.png) The **Tenant Settings** page is displayed.
4. Click **Security > 3rd Party Tokens** > **OKTA Configuration for MFA**. ![](/images/13165352/32915ea8c954.png) OKTA Configuration for MFA screen is displayed.
5. Do the following:**Base URL:** Add the **Base URL** in the Base URL field.**Token ID:** Enter the Token ID in the Token ID field.Click **Save**. ![](/images/13165352/72fd48031a10.png) To see the Token ID in **OKTA Administrator Console**, go to **Security**>**API**> **Tokens** tab. ![](/images/13165352/f2ecee2a5b6b.png) The OKTA Configuration for MFA is configured. ![](/images/13165352/91ecd014e102.png)

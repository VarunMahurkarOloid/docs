## Introduction

Enable Windows Default Domain: Allow the use of the default Windows domain for authentication. Users can enroll credentials to the default Windows domain.

## ​Prerequisite

- Email ID must be created for the user account.
- Default domain must be enabled for the application.
- Face + PIN credentials should be enabled for the user account.

## Steps to Enroll Face and PIN as credentials

Users can Enroll credentials:

1. [Before Authentication](#h_70f2fb39a7)
2. [During Authentication](#h_51125c7c7a)

**Note:**Other credentials like **Badge**and **NFC** can also be enrolled using the process mentioned here, refer: [How to enroll credentials using Windows Login app](/passwordless/windows/passwordless/windows-login-how-to-enroll-credentials)

## Steps to Enroll Credentials using Default Domain before authentication

1. Launch the Windows User Application.
2. Click the **Three Arrows icon.**
3. Select **Enroll Credentials.** ![](/images/13615607/5eb6ff6742f8.png) The Verification screen is displayed.
4. Do the following: Enter Domain Name (Auto filled by default)Enter **Username**Enter **Password**Select the Enroll Windows Credentials to your account checkbox. (optional)Click **Continue**. ![](/images/13615607/6d851fb90d9e.png) The Credential Enrollment screen is displayed. ![](/images/13615607/3f41043735bb.png)
5. Select **Face**or **PIN**[For Face](#h_fdb4d9ba44)[For PIN](#h_512bbed465)

## Steps to Enroll Credentials using Default Domain during authentication

1. Launch the Windows User Application.
2. The Camera opens.
3. Position your face in front of the camera and tap the **Capture** button to enroll your face. Missing credentials screen is displayed
4. Click **Manage Credentials**. ![](/images/13615607/77bf409cddc8.png) The Verification screen is displayed.
5. Do the following: Enter Domain Name (Auto filled by default)Enter **Username**Enter **Password**Select the Enroll Windows Credentials to your account checkbox. (optional)Click **Continue**.

## Steps to Enroll Face

1. Click **Face**.
2. The Camera turns on.
3. Position your face in front of the camera and tap the **Capture** button to enroll your face.**Note:** If you do not tap the **Capture** button, the app automatically captures your face after a few seconds. ![](/images/13615607/30847d1fadf5.png)
4. Do one of the following:Tap **Yes- Submit** to submit the image.The face is submitted successfully and is displayed on the details screen.Tap **No- Retake** to take the photo again.The camera turns on to retake the photo. ![](/images/13615607/3e28c211bb7f.png) Enrollment Successful screen is displayed.
5. Click **Done**to finish enrollment.
6. To Enroll other credentials click **Enroll Button / Manage Credentials**.**Note:**The Manage Credentials button may have different UI lables based on the credentials enabled for the user.

## Steps to Enroll PIN using Default Domain during authentication

<Frame>
  <img src="/images/13615607/90612059af52.png" alt="Screenshot" />
</Frame>

The Enter PIN page is displayed.

1. Enter **PIN** and click **Submit**. Invalid PIN message is displayed.**Note:**After maximum PIN attempts have been used. User is redirected to enroll PIN. ![](/images/13615607/730ed3866956.png) Missing Credentials screen is displayed.
2. Click **Enroll Credential**. ![](/images/13615607/97e6ef568335.png) The Verification screen is displayed.
3. Do the following: Enter Domain Name (Auto filled by default)Enter **Username**Enter **Password**Select the Enroll Windows Credentials to your account checkbox. (optional)Click **Continue**. ![](/images/13615607/6d851fb90d9e.png) The Credential Enrollment screen is displayed. ![](/images/13615607/5a59a7195b59.png) **To Enroll PIN**
4. Click **PIN**.The Add/Update PIN screen is displayed.Enter **New PIN**Re-Enter **New PIN**Click **Submit**. ![](/images/13615607/dc2ff1e5e483.png) Enrollment Successful screen is displayed.
5. Click **Done**to finish enrollment. ![](/images/13615607/9a07563f1fd6.png)

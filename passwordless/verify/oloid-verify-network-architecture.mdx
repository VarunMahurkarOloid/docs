**Note:** Ensure that the iPad’s network connection (Wi-Fi or Ethernet) can communicate with the servers listed below. All network requests are outbound.

| **Sn.** | **Domain name** | **Port** | **Description** |
|---|---|---|---|
| 1 | oloid.cloud | 80, 443 | Production Oloid Face VaultPlatform Root Domain |
| 2 | *.oloid.cloud | 80, 443 | Production Flex Tenant SubDomains |
| 3 | oloiddev.com | 80, 443 | Development Oloid Face VaultPlatform Root Domain |
| 4 | *.oloiddev.com | 80, 443 | Development Flex Tenant SubDomains |
| 5 | *.crashlytics.co | 80, 443 | Capturing Crash Logs |
| 6 | *.amazonaws.com | 80, 443 | Accessing AWS Resourcesdirectly ( e.g S3 ) |
| 7 | cv.proxce.co | 80, 443 | Legacy Computer Vision Server |
| 8 | *.googleapis.com | 80, 443 | Firebase Pub Sub ProductionInterface |
| 9 | visionlabsbv.prod.sentinelcloud.com | 80, 443 | On Device FR LicenseManagement Server |

## Introduction

The Hardware Compatibility Check in the Oloid Verify app ensures that the iPad meets the required technical standards for smooth operation. It allows Tenant Admin and Supervisor to quickly verify that key hardware components are working properly before using the device.

## Prerequisite

You must complete the Admin Setup. To Setup. refer [Oloid Verify - Admin Setup.](/administration/admin-portal/oloid-verify-admin-setup)

## Steps to check hardware compatibility

1. Launch the **Oloid Verify App**.**Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App. For more information, refer to [How to pair an Oloid Verify endpoint.](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint) ![](/images/10255794/65448eab37c7.png) The Preview screen is displayed.
2. **Double**-**tap** on the Preview screen with two fingers.The Admin mode pop up box is displayed.
3. Tap **YES-CONTINUE** to log into **Admin Mode**. ![](/images/10255794/26fffe6c9ab4.png) The **Settings** page is displayed.
4. Tap **Start** in the **Hardware Check** section.

## Introduction

Guided Access Mode limits the iPad to one or a few specific apps, preventing users from accessing other features or applications.

The following topics are covered in this document:

- [Set up Guided Access in iPad](#h_a74205a831)
- [Start Guided Access Mode in iPad](#h_00d96227ee)
- [End Guided Access Mode in iPad](#h_cbb510e4cb)

## Steps to set up Guided Access

1. Open your iPad.
2. Go to **Settings > Accessibility > Guided Access.** ![](/images/8650264/42d650a17dec.png)
3. Turn on the **Guided Access** toggle. ![](/images/8650264/f1e7fb1188b3.png)
4. Tap **Passcode Settings**. ![](/images/8650264/e71969198d87.png)
5. Tap **Set Guided Access Passcode.** ![](/images/8650264/0de7cf06eb4d.png)
6. Enter a passcode.
7. Re-enter the passcode to confirm. ![](/images/8650264/5c0566b95929.png) The Guided Access is set up successfully.

## Steps to start Guided Access Mode

1. Launch **Oloid Verify** app. ![](/images/8650264/65448eab37c7.png)
2. Quickly press the **Home/Power** button **three** times.
3. Tap **Start**.![](/images/8650264/8a042ea5cfb0.png)

The Guided Access mode is started successfully.

## Steps to End Guided Access Mode

1. Quickly press the **Home/Power** button **three** times. The enter passcode pop-up box is displayed.
2. Enter your **passcode** when prompted. ![](/images/8650264/15b56408b608.png)
3. Tap **End**. ![](/images/8650264/8241aebce6f3.png) The Guided Access mode is ended successfully. KeywordsGuided Access Mode iPad | Set up Guided Access on iPad | Enable Guided Access Mode iPad | Disable Guided Access Mode iPad

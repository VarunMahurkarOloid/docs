## Introduction

The Add User feature in the Oloid Verify app allows Admins and Supervisors to directly add user from the endpoint.

## Prerequisite

- You must complete the Admin Setup. To setup, refer [Oloid Verify - Admin Setup.](/administration/admin-portal/oloid-verify-admin-setup)
- You must enable Supervisors privileges to allow the supervisor to add user. To enable, refer to [How to enable Add or Delete Users in Tenant Admin Portal for Supervisors](/administration/admin-portal/windows-login-how-to-enable-add-delete-users-in-tenant-admin-portal-for-supervisors)
- The Oloid Verify endpoint must be paired. To pair refer [How to pair an Oloid Verify endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint)

## Steps to Add user

1. Launch the **Oloid Verify** app. ![](/images/10198654/65448eab37c7.png)
2. Log in to Admin mode in Oloid Verify app. To login refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor](/administration/admin-portal/oloid-verify-how-to-log-in-to-admin-mode-as-an-admin-or-supervisor) The **Home**screen is displayed.
3. Tap **+Actions**on the menu at the bottom of the screen. ![](/images/8601073/04d389ce1591.png) The **Actions** screen is displayed.
4. Tap**Add User.** ![](/images/8601073/b6166413e500.png) The **Add User** screen is displayed.
5. Enter **Name**.**Note:**First name and Last name should be separated by a space.
6. Enter **Primary ID**.Only alphabets, numbers, and hyphen are accepted.
7. Enter **Secondary ID**(Optional).Only numerals are accepted.
8. Select connection name from **Connection Name** list.
9. Tap **Add User**.

## Introduction

This document explains how to pair an endpoint using the **Oloid Verify** application. Pairing connects the endpoint to the Oloid Verify application in the Tenant Admin Portal and prepares the endpoint for authentication and transaction activities.

## Prerequisite

- You should be a Tenant Admin or Supervisor.
- You must create and configure Oloid Verify application in the Tenant Admin Portal. To create refer[How to create and configure Application Type - Oloid Verify](/administration/admin-portal/oloid-verify-how-to-create-and-configure-application-in-tenant-admin-portal).
- You must download and install Oloid Verify app from the App store. To download and install refer [How to download and install Oloid Verify App](/passwordless/verify/oloid-verify-how-to-download-and-install-the-app).

## Step to Pair an Endpoint

1. Launch the Oloid Verify app. ![](/images/8601056/65448eab37c7.png) The **LOGIN** page is displayed.
2. Enter **Tenant Name**.
3. Enter email id in the **Email** text field.
4. Enter password in the **Password** text field.
5. Tap **LOGIN**. ![](/images/8616605/e4bc54838f65.png) The **Settings** page is displayed.
6. Do one of the following on the **Settings** page. Add **Template** (optional). For more, refer to [How to create and configure Oloid Verify Endpoint Template](/administration/admin-portal/oloid-verify-how-to-create-and-configure-endpoint-template-in-tenant-admin-portal).Enter **Endpoint Name**.Select Application Name from **Application Name** list.Tap **Pair.** ![](/images/8616605/b538765bd9f6.png) The settings are saved and endpoint is successfully paired and Device Setup successful pop up box is displayed. ![](/images/8601056/1f20c4ba77dc.png) The application prompts you to log out of Admin mode.
7. Do one of the following:Click **Yes** to log out and launch the application (**preview mode**).The app displays preview mode and allows you to do the transactions.Click **No**to stay logged in to the admin mode. ![](/images/8616605/93118f5eef4d.png)

## Introduction

The View User Details feature in the Oloid Verify app allows Admin and Supervisor to quickly access essential information about a user. From this, you can view key details such as the user’s name, primary ID, and the connection assigned to them.

## Prerequisite

- You must have a Tenant Admin or Supervisor account.
- You must add the user. To add user refer[Oloid Verify: Add User](/passwordless/verify/oloid-verify-add-user).
- The Oloid Verify endpoint must be paired. To pair, refer [How to pair an Oloid Verify endpoint](/passwordless/verify/oloid-verify-how-to-pair-an-endpoint)

## Steps to view User details

1. Launch the **Oloid Verify** app. ![](/images/10198654/65448eab37c7.png)
2. Log in to Admin mode in Oloid Verify app. To login, refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](/administration/admin-portal/oloid-verify-how-to-log-in-to-admin-mode-as-an-admin-or-supervisor)The **Users**screen with list of users is displayed.
3. Tap on the preferred **user** to view details. ![](/images/8616846/c7a045920be4.png) The User details are displayed on the**Details** screen. ![](/images/8616846/01cfe2f703e8.png) SEO Keywords|Oloid Verify User Details | View User Details Oloid Verify App | Oloid Verify Users screen|

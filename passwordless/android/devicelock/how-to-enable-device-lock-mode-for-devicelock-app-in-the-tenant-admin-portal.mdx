## Introduction

Device Lock Mode in the Oloid Tenant Admin Portal allows users to authenticate through the Device Lock app. After successful authentication, the device unlocks and displays the device home screen.

## Prerequisite

You must have **Tenant Admin access** to the **Oloid Tenant Admin Portal**.

## Steps to Enable Device Lock Mode

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click the preferred application from the application list. ![](/images/11508439/694bc2601aa2.png) The application details page is displayed.
3. Go to **Configure**tab > click **Configure Passwordless** from the left menu panel. ![](/images/11508439/0d6a1328617e.png)
4. Turn on **Enable Passwordless Config** toggle > select **Device Lock Mode** > click **Save**.**Note**: Turning on this toggle will disable **Clock In / Clock Out** mode. ![](/images/11508439/db17a007fff7.png) The Device Lock mode is successfully enabled. ![](/images/11508439/eef819918052.png)

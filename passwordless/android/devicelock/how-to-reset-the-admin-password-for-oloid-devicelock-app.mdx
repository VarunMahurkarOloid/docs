## Introduction

The Oloid DeviceLock App allows Admin and Supervisors to securely reset their password using the **Forgot Password** option. This feature helps restore access to the app by sending a confirmation code to the registered email address.

## Steps to reset Admin Password

1. Launch DeviceLock app. ![](/images/12106226/d3bb63126deb.png) The Welcome screen is displayed.
2. Click **More option**icon (![](/images/12106226/d1ee5184bf7e.png)) on bottom-right side of the screen. ![](/images/12106226/37eaa1360c13.png) The **Enter Admin Mode** pop-up box is displayed.
3. On the **Enter Admin Mode** pop-up box, tap **Continue**. ![](/images/12106226/036f6527338e.png) The setting page is displayed.
4. Tap **Login as Supervisor**. ![](/images/12106226/e63e18018fab.png) Pair as Supervisor screen is displayed.
5. Tap **Forgot Password**. ![](/images/12106226/e9f761525811.png) Reset Password screen is displayed.
6. Enter Email ID > tap **Reset**. ![](/images/12106226/089fa5317df2.png) Reset Password instructions are sent to the registered email ID successfully. ![](/images/12106226/c5e9b2d01251.jpg)
7. Open your email account and go to the **inbox.**
8. Copy the **confirmation code** > click on the **Reset Password** link. ![](/images/12106226/4e41c657eb9d.png) The**Set New Password**page is displayed.
9. Enter **Work Email ID**.
10. Enter **Confirmation** **Code**in the **Code** field.
11. Enter **New Password**.
12. Click **Login.** ![](/images/12106226/994d113b9c12.png) The Password for Oloid DeviceLock is reset successfully. ![](/images/12106226/4d403c1b325f.png)

## Introduction

The **Passwordless Login** feature in the **Oloid Tenant Admin Portal** allows admin to enable secure, password-free authentication for users. When enabled, the endpoint switches to passwordless mode and redirects users to the configured URL after successful authentication.

## Prerequisite

You must have **Admin access** to the **Tenant Admin Portal**.

## Steps to Enable Passwordless Login

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click the preferred application from the application list. ![](/images/11513914/694bc2601aa2.png) The application detail page is displayed.
3. Go to **Configure**tab > click **Configure Passwordless** from the left menu panel. ![](/images/11513914/12be025beaba.png)
4. Turn on **Enable Passwordless Config** toggle > select **Passwordless Login** > click **Save**.**Note**: The Passwordless SSO URL toggle automatically turns on after you select Passwordless Login. ![](/images/11513914/3136e1b3cd27.png) The Passwordless Login is enabled successfully. ![](/images/11513914/ba8b16ef592c.png)

**Steps to view user details:**

1. Launch **Oloid DeviceLock App** on your device. ![](/images/11495355/d3bb63126deb.png)
2. Log in to the Admin Mode in **Oloid DeviceLock**App. For more details, refer this [How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
3. Go to **Users**tab > click on the preferred User's profile.![](/images/11495355/646e616dd85b.png) The User's details is successfully viewed. ![](/images/11495355/5536d2a0bd27.png)

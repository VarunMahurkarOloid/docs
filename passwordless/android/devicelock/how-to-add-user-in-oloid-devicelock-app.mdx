## Introduction

This feature of Oloid DeviceLock app allows the user in tenant admin mode to add new users using the app.

**Steps to add user:**

1. Launch **Oloid DeviceLock App** on your device. ![](/images/10473240/d3bb63126deb.png)
2. Log in to the Admin Mode in **Oloid DeviceLock**App. For more details, refer this [How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
3. Go to **User**tab > click **Add User** on the right-top side of the screen. ![](/images/9335055/05dd6d2cfbc6.png) The **Add User** screen is displayed.
4. Enter **Name**.**Note:**First name and Last name should be separated by a space.
5. Enter **Primary ID**.**Note:** Only alphabets, numbers, and hyphen are accepted.
6. Enter **Secondary ID**.**Note:** Only numbers are accepted.
7. Click **Select connection**. ![](/images/9335055/18f3a80f75e8.png) The Select Connections pop-up box is displayed.
8. Select the preferred connection.
9. Click **Add**.![](/images/9335055/2035a8eb4409.png) The **Add User** screen is displayed.
10. Click **Add User**.![](/images/9335055/27b7d0196fe4.png) The user is successfully added and listed in the users list. ![](/images/9335055/9ff7f0e6d719.png)

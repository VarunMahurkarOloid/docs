## Introduction

This feature of Oloid DeviceLock app allows the user in tenant admin mode to add face using the app.

## Prerequisite

You must have Admin account to add a user.

## Steps to Add Face

1. Log in to the Admin mode in **DeviceLock App.**To log in refer[How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
2. Go to **Users**tab > select the preferred user. ![](/images/12156735/351c22de56f3.png) The user details screen is displayed.
3. Tap **Submit Consent**. ![](/images/12156735/01d74445216d.png) The user consent screen is displayed.
4. Tap **Accept**. ![](/images/12156735/c913f230de44.png) The Consent is submitted successfully. ![](/images/12156735/53f52bf45494.jpg)
5. Tap **Add Face**. ![](/images/12156735/784c45832560.png)
6. To add a face, position your face in front of the camera and tap the **Capture** button. **Note:** If you do not tap the **Capture** button, the app automatically captures your face after a few seconds. ![](/images/12156735/309765dfdbdc.png) Face is added successfully. ![](/images/12156735/1fb2e18c6891.png) Keywords| Enroll face in DeviceLock app | DeviceLock face authentication setup | How to Add face in DeviceLock app |

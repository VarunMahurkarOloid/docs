## Introduction

Tenant Admin or Supervisor can assign a PIN for users directly in the DeviceLock app through admin mode. Once enrolled, the PIN is linked to the user’s profile and can be used for authentication purpose, providing an additional or alternative login method to access the device.

## Steps to enroll PIN:

1. Log in to the admin mode in **DeviceLock App.**To log in refer[How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
2. Go to **Users**tab > select the preferred user. ![](/images/12157257/351c22de56f3.png)
3. Go to **PIN**tab > tap **Add**PIN. ![](/images/12157257/2f0df6b2e6aa.png) The **create PIN**pop-up box is displayed.
4. Do the following:Enter the **PIN**.Re-enter the **PIN**.Enter recipient email ID to share the **PIN**.Tap **Create**.**Note:**The PIN can be configured as a **4-digit**, **6-digit**, or **open (alpha- numeric) PIN** from the Tenant Admin Portal. ![](/images/12157257/84454a4f7813.png) The PIN is successfully enrolled. ![](/images/12157257/6d051a4ddc13.png)

## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| **Field** | **Value** |
|---|---|
| Product Name | DeviceLock |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| **Service** | **Prod (EU)** | **Description** |
|---|---|---|
| Admin API | api.oloid-eu.com | The Admin API is used for Authentication. |
| Tenant User API | api.myoloid-eu.com | The Tenant User API is used for user authentication credential. |
| Face Authentication | fr.oloid-eu.com | The Face Authentication API used to authenticate users through facial recognition. |

---

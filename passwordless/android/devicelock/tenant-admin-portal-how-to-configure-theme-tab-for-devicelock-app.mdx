## Introduction

The **Theme** tab in the Tenant Admin Portal for **DeviceLock App**allows admin to customize the app’s appearance to match their organization’s branding.

## Prerequisite

You must create DeviceLock Application. To create, refer [How to create and configure Device Lock application](/passwordless/android/devicelock/how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal).

## Steps to configure Theme Tab

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click the **Device Lock Application**to be configured. ![](/images/10009894/37406a18b99b.png) The **Device Lock Application details** page is displayed.
3. Go to **Theme**tab. ![](/images/10009894/6ce9f8823363.png) The theme tab is displayed. ![](/images/10009894/6ce9f8823363.png)
4. Do the following: Edit Customer logo.**Note:** The maximum file dimensions for the logo are **264x72 px**, with a maximum size of **1 MB** in **PNG** format. ![](/images/10009894/a8fab751f871.png) **Background Image:** Do one of the following:Edit Background image. **Note:** The maximum file size is **2 MB** (JPG, PNG, JPEG). This image is used as the widget background.orSelect **Solid Background** option > enter color code. ![](/images/10009894/a29601a2c35f.png) **Foreground Color:**Select **Solid Background** option > enter color code. **Primary Color/Button Default:** Update the primary color code to define the primary button's default background and its hover-state text color.**Secondary Color/Hover State:** Update the secondary color code to define the primary button's hover background and its default text color.**Customize Heading:** Update the heading that appears at the top of the screen.**Heading Text Color:** Update the text color code of the screen heading.**Widget Header/Footer Color:** Update the background color for the Widget's header and footer.**Footer Text Color:** Update the footer text color code in Login App.**Enable Help-text:** Turn on **Enable Help-text** toggle and then enter the help text to display on the **Identity Selection** screen.**Note:** The help text is displayed only on the **Identity Selection** screen and must not exceed **100 characters**. ![](/images/10009894/30a1d43b2463.png)
5. (Optional) In the **Preview** section, select one of the following tabs to preview the theme configuration:**Identity Selection:**Preview the appearance of the identity selection screen displayed before user authentication.**Authentication:** Preview the authentication screen displayed when users authenticate using their configured credentials.**Error:** Preview how error messages and error screens are displayed to users during authentication failures. ![](/images/10009894/5ab0dbf3b5a3.png)
6. Click **Deploy**. ![](/images/10009894/747e56465466.png) The **Confirm Update** pop-up box is displayed.
7. Click **Update**. ![](/images/10009894/f5407af16ed1.png) The DeviceLock theme tab is updated successfully.

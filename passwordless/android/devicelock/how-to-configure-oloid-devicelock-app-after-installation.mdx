## Introduction

This document explains how to perform the initial configuration of the Oloid DeviceLock app after installation. The setup includes granting required permissions to enable core functionality and ensure secure operation of the application.

**Note:** Screenshots in this document were captured on a Samsung Galaxy Tab A11 device.

## Prerequisite

You must install the Oloid DeviceLock app. To install refer [How to install Oloid DeviceLock App](/passwordless/android/devicelock/how-to-install-oloid-devicelock-app).

## Steps to configure Oloid Device Lock Application

1. Tap **Open** to launch the app. ![](/images/12380644/e34b6e434a07.png) The **Data & Usage Consent** screen is displayed.
2. Tap **Agree**. ![](/images/12380644/1bd35ee210bf.png) The grant **Camera** and **Recording** permissions pop-up box is displayed.
3. On the pop-up box, tap one of the following:**While using the app** – The app can use the permission only when it is active.**Only this time** – The app can use the permission once, temporarily.**Don’t allow** – The app will not be allowed to use the permission. ![](/images/12380644/a266f037ec48.png) The Oloid DeviceLock to send you notifications popup box is displayed.
4. Tap **Allow**.![](/images/12380644/f1cd2ca9223d.png) The **Appear on Top**screen is displayed.
5. Turn on **Oloid DeviceLock**toggle to allow the app to appear above other apps > tap **Back**.![](/images/12380644/869550e7ca10.png) The Location access popup-box is displayed.
6. Select one of the following.**While using the app** – The app can use the permission only when it is active.**Only this time** – The app can use the permission once.**Don’t allow** – The app will not be allowed to use the permission. ![](/images/12380644/5bac8ac6fa10.png) The Oloid DeviceLock is installed, and initial configuration is done successfully. ![](/images/12380644/bc85d32bc469.png)

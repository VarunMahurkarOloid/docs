## Introduction

This guide provides step-by-step instructions to install and configure the **Oloid Device Lock** and **Oloid Vault** applications on an Android device using **SOTI MobiControl**. This also captures the basic regression test cases along with expected test results  to be executed to make sure that every time a build a released , each of the use cases continue to function as expected and there are no regression failures.

## Prerequisites

- The device is already enrolled in **SOTI MobiControl**.
- A stable internet connection is available.
- A valid **Microsoft account** is available for the user.

## Installation & Configuration Steps

## 1. Open SOTI MobiControl

- **Action**: Launch the SOTI MobiControl app on the device.
- **Expected Result**: The app opens successfully.

## 2. Access App Catalog

- **Action**: Tap on the **Menu** option → Select **App Catalog**.
- **Expected Result**: The App Catalog screen is displayed.

## 3. Install Required Apps

- **Action**: Navigate to **In-House Apps** → Install **Oloid Device Lock** and **Oloid Vault**.
- **Expected Result**: Both applications are downloaded and installed successfully.

## 4. Launch Device Lock App

- **Action**: Open the Oloid Device Lock app.
- **Expected Result**: The Device Lock app launches and begins the setup process.

## 5. Grant Accessibility Permission

- **Action**:When the Accessibility Permission pop-up appears → Tap **Agree**.You will be redirected to **Accessibility Settings**.Select **Oloid Accessibility Service**.Tap **OK** when prompted.
- **Expected Result**: The Oloid Accessibility Service setup screen is displayed.

## 6. Enable Restricted Settings

- **Action**:Go to the Android **Home Screen**.Long press on the Oloid Device Lock app → Tap **App Info**.Tap the **three-dot menu** (top-right).Select **Allow Restricted Settings**.
- **Expected Result**: Restricted settings are enabled for Oloid Device Lock.

## 7. Activate Oloid Accessibility Service

- **Action**:Return to **Accessibility Settings**.Select **Oloid Accessibility Service** again.Grant **Allow** to enable it.
- **Expected Result**: The Oloid Accessibility Service is successfully enabled.

## 8. Complete Device Lock Setup

- **Action (within Device Lock app)**:Tap **Auto-Pair** → Device pairs successfully.Tap **Continue**.Select **Admin Mode**.Tap **Login as Supervisor**.Select **Login with SSO**.Choose **Continue with Microsoft**.Enter your Microsoft **Email & Password**.Tap **Sign In**.
- **Expected Result**: The device pairs successfully, enters Admin Mode, and displays the **Users tab**. From here, you can enroll users with **Face, NFC, and PIN** authentication. Once enrollment is complete, Device Lock is fully ready for use.

## Oloid Vault Setup

## Basic Setup

For Oloid Vault, the setup is similar to Device Lock:

- Enable **Accessibility Settings** as done for Device Lock.
- Enable the **Autofill Service** under Android settings.
- Ensure the user has a **valid Microsoft account**.

## Authentication Flow

1. Authenticate using **Device Lock** (Face + PIN or NFC + PIN).
2. A **web view** opens. Since it is the first-time login, manually enter your Microsoft account password.
3. A prompt appears asking to **save credentials** → Tap **OK**.
4. After the web view, a **pre-login screen** appears.
5. Using Accessibility, **auto-login** is attempted into SOTI.
6. If auto-login does not occur, tap the **Login button** manually.
7. Once logged in, access is granted to both **Microsoft and non-Microsoft apps**.
8. For all future app logins, **auto-login will occur automatically**.

## Summary

By following the above steps, the **Oloid Device Lock** and **Oloid Vault** applications will be fully installed, configured, and ready for use.

- Administrators can log in using **Microsoft SSO for**enrolling with **Face, NFC, and PIN** credentials
- **Oloid Vault** enables **Autofill**, allowing seamless access and auto-login to Microsoft and non-Microsoft applications.

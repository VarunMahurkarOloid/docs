## Introduction

The **Pair as Supervisor** option in the Oloid DeviceLock App allows Supervisors to set up and manage endpoints securely within their assigned tenant. By pairing as a Supervisor, you can configure the device, assign applications, and optionally apply templates to ensure proper usage and compliance. This process ensures that endpoints are linked to the correct tenant environment and are ready for secure operation.

## Prerequisite:

You must have a Supervisor/Tenant Admin account.

## Steps to pair as Supervisor:

1. Launch **Devicelock App**. ![](/images/10323332/d3bb63126deb.png) The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor**. ![](/images/10323332/f67235d0ef7e.png)
3. Enter **Tenant Name**.
4. Tap **Next**. ![](/images/10323332/3218a9a46e80.png) The **Pair as Supervisor** screen is displayed.
5. Do the following:Enter **Username**or **Email**.Enter **Password**.Tap **Login**. ![](/images/10323332/5835cefcc647.png) The **Settings**screen is displayed.
6. Do the following:Enter **Endpoint**name. ![](/images/10323332/513d7344a26f.png) Tap **Select Application**. ![](/images/10323332/a6b48d33d927.png) The Select Application pop-up box is displayed.Tap the preferred application.Tap **Add**.![](/images/10323332/14be0a88c81b.png) Tap **Select Template**. (optional) ![](/images/10323332/7b77c4ccb0f7.png) The **Select Template**pop-up box is displayed.Tap the preferred template.Tap **Add**. ![](/images/10323332/7cea62ccd68d.png) Tap **Pair**.![](/images/10323332/efd3f2d3a9a4.png) The Endpoint is paired successfully. ![](/images/10323332/24bec909fadc.png)

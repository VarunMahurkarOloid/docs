## Introduction

The **Admin Mode** in the Oloid DeviceLock app allows the Tenant Admin or Supervisor to access advanced settings and manage application configurations securely.

## Prerequisite

You must pair your endpoint with the Oloid DeviceLock app. To pair refer [How to pair a DeviceLock endpoint](/passwordless/android/devicelock/oloid-devicelock-app-ways-to-pair-an-endpoint).

**Note:** After pairing the endpoint using either the _"Auto-Pair"_ or _"Auto-Pair using Config File"_ option, you can tap **Continue with Admin** on the success screen to log in as Admin. If Endpoint is paired you can follow the below steps.

## Steps to log in to admin mode

1. Launch Oloid DeviceLock app. ![](/images/10353022/d3bb63126deb.png) The Welcome screen is displayed.
2. Do one of the following:Tap more option ( ![](/images/10353022/73e66fafa6cf.png) ) on the bottom right side of the screen.orDouble tap on the screen. ![](/images/10353022/661cbc4e80bd.png) The Enter Admin pop-up box is displayed.
3. Tap **Continue**.![](/images/10353022/b16dfa823db7.png) The Setting page is displayed.
4. Tap**Login as Supervisor**.![](/images/10353022/10f3f3c830ac.png) The Pair as Supervisor screen is displayed.
5. Do the following:Enter **Username**or **Email ID** in the text field.Enter **Password**.Tap **Login**. ![](/images/10353022/f6dee9f03213.png) You have logged in to Oloid DeviceLock in Admin mode successfully. ![](/images/10353022/d81f9151f71c.png)

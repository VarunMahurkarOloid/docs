## Introduction

Pairing a DeviceLock endpoint with the app establishes a secure connection, ensuring proper management and readiness for use.

## Prerequisites

- You must install Oloid DeviceLock app. To install refer [How to install Oloid DeviceLock App](/passwordless/android/devicelock/how-to-install-oloid-devicelock-app).

- You must configure Oloid DeviceLock App after installation. To configure refer [How to Configure Oloid DeviceLock App after Installation](/passwordless/android/devicelock/how-to-configure-oloid-devicelock-app-after-installation).

## Ways to pair a DeviceLock Endpoint

You can pair DeviceLock endpoint using any of the following options:

- [How to pair Oloid DeviceLock App using "Pair as Supervisor" option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-pair-as-supervisor-option).
- [How to Pair Oloid DeviceLock App using "Auto-Pair" option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-auto-pair-option).
- [How to Pair Oloid DeviceLock App using the “Auto-Pair using Config File” option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-the-auto-pair-using-config-file-option).

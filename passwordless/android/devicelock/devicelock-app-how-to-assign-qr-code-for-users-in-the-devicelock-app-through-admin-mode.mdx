## Introduction

The **QR Code**feature in the **Oloid DeviceLock App** allows admin to assign QR codes to users for secure, passwordless authentication on Android devices.

## Prerequisite

You must have **Admin Access** in the Device Lock Application.

## Steps to Assign QR Code

1. Login to the Admin mode in **DeviceLock App.**To login refer[How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
2. Go to **Users**tab > select the preferred user. ![](/images/12741303/e97bf2d02ac7.png) The user details screen is displayed.
3. Tap **QR Code**. ![](/images/12741303/0f822302c6ab.png) The QR Code screen is displayed.
4. Tap **Add**. ![](/images/12741303/4e2da4de5beb.png) The **Create QR Code** pop-up box is displayed.
5. Do the following:Select **QR Code Validity**.Enter the Email ID (Optional).Tap **Create**. ![](/images/12741303/a0b3af5329f4.png) The QR Code is added successfully. ![](/images/12741303/4a8a40b68f0f.png) The created QR code is displayed in the QR Code tab. ![](/images/12741303/649edac1bd10.png)

## Introduction

A tenant in Oloid DeviceLock App is a dedicated space with its own users, devices, and configurations. Resetting a tenant clears all existing data and settings, allowing you to start over.

## Prerequisite

You must pair DeviceLock endpoint.  For more details refer: [Oloid DeviceLock - How to pair an endpoint](/passwordless/android/devicelock/oloid-devicelock-app-ways-to-pair-an-endpoint).

## Steps to Reset Tenant

1. Launch **Oloid DeviceLock App** on your device. ![](/images/10473240/d3bb63126deb.png)
2. Log in to the Admin Mode in **Oloid DeviceLock**App. For more details, refer this [Oloid DeviceLock App - How to log in to admin mode](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode)
3. On the bottom right, select More Options ![](/images/10473240/a47d2dbf04f4.png) icon > tap **Reset Tenant**. ![](/images/10473240/e2c63e61469c.png) The confirmation pop-up box is displayed.
4. Tap **Reset**. ![](/images/10473240/46e88ec77ce3.png) The tenant reset successfully. ![](/images/10473240/06a4ba5cfabe.png) Keywords|Reset Tenant in DeviceLock | DeviceLock Configuration Reset |DeviceLock Reconfiguration|

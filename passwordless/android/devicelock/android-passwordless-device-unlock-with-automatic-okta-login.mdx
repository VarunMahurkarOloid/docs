## Introduction

This document provides step by step instructions for configuring passwordless access on Android devices using **Oloid DeviceLock** and **WebKey (Oloid Browser).** The setup enables users to authenticate via **Face or NFC** through the **DeviceLock** app and automatically launch the **WebKey page** in Oloid Browser to seamlessly access the **Okta dashboard** without entering credentials.

## Prerequisites

- You must have **Admin access** to the Tenant Admin Portal.
- You must **create and configure the DeviceLock application** and enable Face and NFC under the authenticator tab.
- You must **create and configure WebKey application.**

## Step 1: Configure Device Lock and Webkey Applications

- [Setup Device Lock Application in platform](#h_82dcd48cb8)
- [Setup Webkey Application in the platform](#h_6df7824f1f)

## Setup Device Lock Application in Tenant Admin Portal

1. Log in to the **Tenant Admin Portal.**
2. On the homepage of the portal, click on the **Device Lock** application to edit. Note: Refer to [create and configure the DeviceLock application.](/passwordless/android/devicelock/how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal) ![](/images/13855587/1c488b358367.png) The application details page is displayed. ![](/images/13855587/f155d7564298.png)
3. Go to **Configure** tab > Click **Settings**. ![](/images/13855587/5b9ee336cae4.png) The Settings page is displayed.
4. Enable **Auto Authentication of Webkey using Local Transaction**toggle**.**
5. Click **Save.** ![](/images/13855587/c36a5deb1437.png)
6. Go to**Configure Passwordless.**The Configure Passwordless screen is displayed.
7. Do the following:**Enable Passwordless Config**toggle.Select **Device Lock Mode.**Click**Save.** ![](/images/13855587/122b22dbbfa9.png) The Device Lock application setup is completed successfully. ![](/images/13855587/d54b92dba6d3.png)

## Setup Webkey Application in the Tenant Admin Portal

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the **Webkey** application to edit. For more, refer to [create and configure WebKey application.](/administration/admin-portal/webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal) ![](/images/13855587/e51ad0786727.png) The **Application Details** page is displayed. ![](/images/13855587/fad884623db8.png)
3. Go to **Configure**> Click**Settings**.The settings page is displayed. ![](/images/13855587/ac05d0fdf55d.png)
4. Do the following:Enable **Auto-Authentication using Local transactions**toggle button will allow user to auto-authenticate into Webkey after device login.Enable **Continue Without Local Transaction** toggle button will allow user to authenticate manually without giving an error if local authentication transaction is not found.Click **Save.** ![](/images/13855587/5f61794c2707.png) The **Webkey**application setup is completed successfully. ![](/images/13855587/ca4a493c5d88.png)

## Step 2: Install, Pair and Setup the Oloid Browser and Device Lock Application on Android Device

## Installation

1. Install Oloid Browser on your android device.**Note:** Contact **Oloid support**to get the**APK files.**
2. Download and install the **DeviceLock** app from the **Google Play Store**. For More, refer to [How to Download DeviceLock App](/passwordless/android/devicelock/how-to-download-devicelock-app)
3. Provide all the required permissions to DeviceLock app. (Go to Settings and allow Restricted Permissions for the DeviceLock app to provide all required permissions.)

## Steps to Pair Device Lock Endpoint

Once the Device Lock application is successfully installed you need to pair your endpoint.  
You can pair DeviceLock endpoint using any of the following options:

- [How to pair Oloid DeviceLock App using "Pair as Supervisor" option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-pair-as-supervisor-option).
- [How to Pair Oloid DeviceLock App using "Auto-Pair" option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-auto-pair-option).
- [How to Pair Oloid DeviceLock App using the “Auto-Pair using Config File” option](/passwordless/android/devicelock/how-to-pair-oloid-devicelock-app-using-the-auto-pair-using-config-file-option).
- (Optional) You can select the Device Lock Endpoint template while pairing the endpoint. For more, refer to [How to Create and Configure DeviceLock Endpoint Template in Tenant Admin Portal](/administration/admin-portal/how-to-create-and-configure-devicelock-endpoint-template-in-tenant-admin-portal) **Note:**After the endpoint is successfully paired, you must enable the **Passwordless Session Token** toggle and the **Include user token in response** toggle for the endpoint in the **Tenant Admin Portal**. For more, refer to [How to Configure Endpoint in the Tenant Admin Portal](/administration/admin-portal/devicelock-app-how-to-configure-endpoint-in-the-tenant-admin-portal)

## Add WebKey Shortcut to Oloid Browser

1. Open **Oloid Browser** on the Android device.
2. Open a new tab and navigate to the **configured WebKey URL**.
3. Tap the **browser menu** (kebab icon). ![](/images/13855587/51d99380019f.png)
4. Select **Add app to Home screen.** ![](/images/13855587/dab031bb3a8a.png) A Confirmation pop-up box is displayed.
5. Tap **Add**. ![](/images/13855587/fa1f28458185.png) The **Oloid WebKey App** shortcut is added to the Android home screen. ![](/images/13855587/a0c9d0354efe.png)

## Step 3: Use Case

## Authenticate using Face

1. Press the **Power button** or tap the screen on your device.The **Welcome** screen is displayed.
2. Tap **Login with Face**. ![](/images/13855587/abcd68534082.png) The camera turns on.
3. Position your face in front of the camera and tap the **Capture** button to complete the authentication process.**Note:** If you do not tap the Capture button, the app automatically captures your face after a few seconds. ![](/images/13855587/064de665c0c6.png) After successful authentication, the user is redirected to the Android home page.
4. Tap **Oloid Webkey App.**

## Authenticate using NFC

1. Press the **Power** button or tap the screen on your device.The **Welcome** screen is displayed.
2. Tap **Login with NFC Tag**.**Note:** Ensure that the Android device must be connected to an external NFC reader/card reader. ![](/images/13855587/f7687fa27857.png) The**Tap NFC Tag at the device**pageis displayed.
3. Scan the NFC Tag. ![](/images/13855587/b1d944d330c2.png) After successful NFC authentication, the user is redirected to the Android home page.
4. Tap **Oloid Webkey App**to launch the browser.

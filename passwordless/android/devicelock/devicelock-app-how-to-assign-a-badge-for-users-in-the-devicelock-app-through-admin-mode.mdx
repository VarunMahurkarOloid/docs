## Introduction

The **Badge Assignment** feature in the **Oloid DeviceLock app** allows admin to assign badge credentials to users for authentication on Android devices. Users can tap their assigned badge on a connected card reader to unlock the device or access Workforce or HRMS applications securely.

## Prerequisite

- You must have Admin Access in the Device Lock Application.
- Ensure the Android device is connected to an external card reader.
- You must have a badge available to assign to a user.

## Steps to Assign Badge

1. Log in to the admin mode in **DeviceLock App.**To login refer[How to log in to admin mode in DeviceLock App](/passwordless/android/devicelock/oloid-devicelock-app-how-to-log-in-to-admin-mode).
2. Go to **Users**tab > select the preferred user. ![](/images/12741589/bd068f618b66.png) The user details screen is displayed.
3. Tap **Badge**. ![](/images/12741589/0d0202d02f36.png) The **Badge** screen is displayed.
4. Tap **Scan Badge**. ![](/images/12741589/35522e434aa2.png) The **Scan Badge** screen is displayed.
5. Do one of the following:Manually enter the Badge number.ORTap the Badge on the card reader to scan it.Tap **create.** ![](/images/12741589/8fa4acbe6cc5.png) Badge is assigned successfully. ![](/images/12741589/0a0a07b93338.png)

**Steps to enable Workday Punch Integration:**

1. Log in to the **Tenant Admin Portal**. For more details refer [How to log in to the Tenant Admin Portal](/administration/admin-portal/how-to-log-in-to-the-tenant-admin-portal).
2. On the homepage of the portal, click the preferred application from the application list. ![](/images/11532508/b2c2ad32750b.png)
3. Go to **Configure**tab > click **Configure Passwordless** from the left menu panel. ![](/images/11532508/89c25bd4ab72.png)
4. Turn on **Enable Passwordless Config** toggle > select **Passwordless Login** ![](/images/11532508/779182348301.png)
5. Turn on **Workday Punch Integration**toggle > click **Save**. ![](/images/11532508/8fd7ef796fa4.png) The Workday punch integration is enabled successfully. ![](/images/11532508/9cc6f913ad8d.png)

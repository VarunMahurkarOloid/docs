Steps to import a Flow

1. Launch your chrome browser.
2. Enter **localhost: port number**in your browser address bar. Then, press Enter on your keyboard.**Note**: Port number should be same as used during installation.Default port number: 80The Workflow Login page is displayed.![](/images/8574815/5d0ee07e4c85.png)
3. Enter username and password in the appropriate fields.
4. Click **Login**.The Oloid Workflow application page is displayed.![](/images/8574815/a4d4932ed68b.png)
5. Click **Import**on the top menu.The **Import Nodes** pop-up box is displayed.
6. Click **Import from file** in the pop-up box.![](/images/8574815/f4ea0280cbb5.png)
7. Select the json file to be imported from your system.![](/images/8574815/cfec6cf926a1.png) The json flow data is displayed in the **Import Nodes** window.
8. Verify the json flow data and Click **Import.** The file import success message is displayed. It shows the number of flows and nodes imported.![](/images/8574815/0bb9080bbadd.png)
9. Click Deploy.The file is successfully deployed and displayed as a tab in the Workflow Application.![](/images/8574815/3b1a66c0c26b.png)

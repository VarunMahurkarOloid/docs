**Oloid Workflow instance runs on the following systems :**

-          Windows 10, 11 (32-bit & 64-bit) (Professional Edition or Higher)

-          Windows Server 2016, 2019, 2022 (Enterprise & Standard Edition) (32-bit & 64-bit)

**Minimum HW requirements are :**

-          2 GB of RAM or above

-          100 GB disk Space (install size + log size)

**Supported Application Scale :**

| **Size** | **Small** | **Medium** | **Large** |
|---|---|---|---|
| Recommended Machine Configuration | CPU - 1 CoreRAM - 2 GB | CPU - 2 CoreRAM - 4 GB | CPU - 4 CoreRAM - 8 GB |
| Max Job Rate | 15/min | 30/min | 60/min |

We need admin access to setup Oloid Workflow instance on the host machine.

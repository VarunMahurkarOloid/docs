## Applications to be installed

1. Node JS v22.18.0 (prerequisite)
2. Oloid Workflow application

## Installation Procedure

## Steps to Install Node JS

1. Double-click on **node-v22.18.0** and click **Next** on the pop-up screen to continue with the installation. ![](/images/8052890/15f84f52a3d4.png)
2. Accept the license agreement and click **Next**. ![](/images/8052890/59aaa0606fdb.png)
3. Click **Next** on **Destination Folder** screen. ![](/images/8052890/833578d9d6f1.png)
4. Click **Next** on **Custom Setup** screen. ![](/images/8052890/a5d608b34b3b.png)
5. Click **Next**. ![](/images/8052890/c0fd7cb287ed.png)
6. Click **Install**. ![](/images/8052890/de884033e02e.png)
7. Click **Finish**.

## Steps to Install Oloid-Workflow

1. Right-click & open **Oloid Workflow Installer** with **Run as Administrator** option.
2. Select **Installation mode** and click **Initiate Installation**.(In Online mode, the installer will fetch necessary install files from internet)(In Offline mode, the installer will fetch necessary install files from build.zip file shared by Oloid executive) ![](/images/8052890/d7ca3cc71e10.png)
3. Click **Continue**. **Note:**The installer will do various checks and show the status here. In case, installer detects any failure, please contact Oloid executive with screenshot. ![](/images/8052890/eb7f42dd0ccd.png)
4. Fill in the required details – Please talk to Oloid executive for this information.Tenant Name – Please talk to Oloid executive for this informationTenant ID – Please talk to Oloid executive for this informationChoose Installer version – Please talk to Oloid executive for this informationInstallation Path – local path where application will be installedPort – default is 80Installation environment – UAT for sandbox, Prod for Production ![](/images/8052890/fc3cb3ff7c94.png) ![](/images/8052890/1d6545fcce8b.png)
5. Check the license agreement and Click **Install**. ![](/images/8052890/06967f9a77c2.png)
6. Wait till the installation is complete. ![](/images/8052890/eb9ac70c2901.png)
7. Installation Progress will be shown here. ![](/images/8052890/e512b99b2c30.png)
8. Installation is complete.
9. Click **Finish and Open Application**. ![](/images/8052890/b8c0b55f49e3.png)

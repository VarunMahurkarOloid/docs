Pre-requisite: Flow should be imported to the application. For instructions on importing flow, see **[How to import a flow?](/workflow/workflow/how-to-import-a-flow)**

Steps to enable/disable flow:

1. Launch your chrome browser.
2. Enter **localhost: port number**in your browser address bar. Then, press Enter on your keyboard.Note: Port number should be same as used during installation.Default port number: 80The **Workflow Login** page is displayed. ![](/images/10264390/5d0ee07e4c85.png)
3. Enter username and password in the appropriate fields.
4. Click **Login**.The Oloid Workflow application page is displayed.![](/images/10264390/de9e179c7428.png)
5. **Double click** on the flow to edit .The edit flow pop-up box is displayed.![](/images/10264390/2ac5ad2e3cad.png) ![](/images/10264390/f7acd0cee8c8.png)
6. Turn on /off **Enable Flow**toggle button to enable or disable the flow.Note: By default the toggle button is enabled.
7. Click **Save Changes**.
8. Next, click **Deploy**.The changes are saved successfully.

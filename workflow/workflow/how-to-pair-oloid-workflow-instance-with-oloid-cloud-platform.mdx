To pair Oloid Workflow instance:

1. Open your web browser and navigate to – [http://localhost](http://localhost).
2. Enter **Tenant Admin** **Username** and **Password**, then Click **Login**. ![](/images/9674352/861cecded9aa.png)
3. Select **Create New Application Instance**, thenClick**Continue**. ![](/images/9674352/32e3cad66f2a.png) The Welcome page is displayed.
4. Do the following:Enter name for workflow application instance in **New Workflow Instance**field.Select appropriate tag in the **Select Tags** fieldClick **Create Application**. ![](/images/9674352/0944a505ef5f.png) You are logged in the application. ![](/images/9674352/5b91d7efea14.png)
